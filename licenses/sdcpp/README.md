# stable-diffusion.cpp in Immuch360

The 360° panoramas of Immuch360 Desktop are generated by stable-diffusion.cpp on Vulkan, through ggml, run as a child
process (`sd-cli`). It is not part of the app: the app downloads it when the user installs the 360° panorama
components, from the prerelease `ai-components-3` of Immuch360, as an archive our CI built from the sources and, for
Windows, signed (`.github/workflows/immuch360-desktop.yml`, jobs `sdcpp-windows` and `sdcpp-linux`;
`.github/workflows/immuch360-desktop-release.yml`, job `sign-windows`).

* stable-diffusion.cpp, MIT: https://github.com/leejet/stable-diffusion.cpp at the commit of
  `.github/desktop/ai/sd_cpp.lock.json`, its licence in `stable-diffusion.cpp-LICENSE.txt`.
* ggml, MIT: https://github.com/leejet/ggml (the submodule of stable-diffusion.cpp) at the commit of the lock, its
  licence in `ggml-LICENSE.txt`.
* The other code built into them, and `immuch360-run`, the launcher of the Linux archive: `THIRD-PARTY.md`.

Every file of this folder goes into the `licenses/` folder of both archives; the job that packs them checks that the
two licences above are those of the sources it built.
