# Copyright notices of the crates without a licence file

Some crates compiled into `brush_app` declare the MIT licence in their `Cargo.toml` but carry no licence file in the
package published on crates.io: cargo about then gives the template of the licence, without its copyright line, and
`THIRD-PARTY.md` says so above that text. Their notices are copied here from the licence file of their repository at
the commit each package was published from (its `.cargo_vcs_info.json`), with the SHA-256 of that file.
`.github/desktop/ai/brush_build.py about` checks each text against its SHA-256, and fails when a crate shown with the
template has no entry here.
