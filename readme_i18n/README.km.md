# Immuch360

**មេឌៀរបស់អ្នក។ គ្រប់អេក្រង់។ គ្រប់ទិដ្ឋភាព។**

Immuch360 គឺជាកម្មវិធីឥតគិតថ្លៃ និងប្រភពបើកចំហ សម្រាប់ស្វែងរក រុករក ចាក់ និងរុករករូបថត និងវីដេអូរបស់អ្នក ទាំងប្រភេទធម្មតា និងប្រភេទប្រព័ន្ធឡើង 360° 3D និងប្រភេទជ្រមុជ ដែលកម្មវិធីផ្សេងបង្ហាញជារាបស្មើ ច្បាប់ចម្លង ឬបត់។ វាអានមេឌៀទាំងនោះនៅទីកន្លែងដែលពួកវាស្ថិតនៅ លើឧបករណ៍ផ្ទាល់ លើ NAS ឬកុំព្យូទ័រ លើម៉ាស៊ីនមេ Plex ឬម៉ាស៊ីនមេ Immich ហើយចាក់ឡើងនៅលើទូរសព្ទ ថេប្លេត ទូរទស្សន៍ កាស Meta Quest និងកុំព្យូទ័រ។ មិនចាំបាច់គណនី មិនចាំបាច់ Cloud មិនចាំបាច់ម៉ាស៊ីនមេ។

- **វាធ្វើអ្វី?** វាបង្ហាញរូបថត និងវីដេអូរបស់អ្នកជាវិចិត្រសាល ហើយចាក់ក្នុងកម្មវិធីមើលដែលសាកសមនឹងឯកសារនីមួយៗ: រាបស្មើ ជាស្វែរដែលអ្នកមើលជុំវិញ ជា 3D ក្នុងកាស។
- **មេឌៀប្រភេទណា?** រូបថត និងវីដេអូរាបស្មើ ផាណូរ៉ាម៉ា រូបថត និងវីដេអូ 360° VR180 3D ជាស្តេរេអូ រូបថតលំហ Apple ស្វែរ 360° របស់ដ្រូន DJI និងឯកសារដើមរបស់កាមេរ៉ា 360° (Insta360 GoPro MAX DJI Osmo 360) ដែលកម្មវិធីតោគ្នា។
- **នៅលើឧបករណ៍អ្វីខ្លះ?** ទូរសព្ទ និងថេប្លេត Android, iPhone និង iPad, Android TV និង Google TV, ទូរទស្សន៍ LG ដែលមាន webOS (កម្មវិធីដាច់ដោយឡែក ជា build សាកល្បង), Meta Quest 2, Pro, 3 និង 3S, Windows (កំណែសាកល្បង) ព្រមទាំង Linux និង macOS ជាការសាកល្បងដំបូង។
- **តើខ្ញុំត្រូវការម៉ាស៊ីនមេ ឬគណនីទេ?** មិនទេ។ Immuch360 ដំណើរការដោយខ្លួនឯងជាមួយមេឌៀនៅលើឧបករណ៍របស់អ្នក។ ម៉ាស៊ីនមេ Immich NAS ម៉ាស៊ីនមេមេឌៀ ឬម៉ាស៊ីនមេ Plex គឺជាជម្រើសដែលអ្នកបន្ថែមនៅពេលអ្នកចង់បាន។
- **តើខ្ញុំចូលគណនីលើទូរទស្សន៍ កាស ឬកុំព្យូទ័រដោយរបៀបណា?** ដោយប្រើទូរសព្ទរបស់អ្នក: ស្កេនកូដ QR ដែលទំព័រចូលរបស់វាបង្ហាញ ឬវាយកូដរបស់វា បញ្ជាក់ ហើយវានឹងបើកលើបណ្ណាល័យ Immich របស់អ្នកក្នុងរយៈពេលប៉ុន្មានវិនាទី ដោយមិនចាំបាច់វាយអ្វីទាំងអស់ជាមួយឧបករណ៍បញ្ជាពីចម្ងាយ។

រូបថត 360° បើកជាស្វែរដែលអ្នកបត់ដោយម្រាមដៃ ឬដោយបង្វិលទូរសព្ទ; វីដេអូ 360° ចាក់ក្នុងកម្មវិធីចាក់ស្វែរជាមួយសំឡេង; ឯកសារ VR180 ត្រូវបានគូរលើស្វែរពាក់កណ្តាល; ឯកសារ 3D ជាស្តេរេអូបង្ហាញភ្នែកមួយនៅលើអេក្រង់រាបស្មើ និងភ្នែកទាំងពីរក្នុងកាស។ ប្រព័ន្ធឡើងផ្នែកនៅតែរក្សារូបកាត់របស់វា ហើយរូបភាពចាប់ផ្តើមនៅទិដ្ឋភាពដែលកាមេរ៉ាបានថត។ ឯកសារដែលម៉ាស៊ីនមេមិនបានសម្គាល់ អាចមើលជា 360° ដោយចុចតែម្តង។

4. សម្រាប់ឯកសារដែលបង្ហាញជារាបស្មើ ទោះបីជាវាជាឯកសារ 360° ក៏ដោយ: ⋮ នៅខាងលើស្តាំ បន្ទាប់មក "មើលជា 360°"។

នៅលើកុំព្យូទ័រ ថតដែលអ្នកជ្រើសដើរតួជាវិចិត្រសាល; នៅលើទូរទស្សន៍ ដែលមិនមានរូបថតផ្ទាល់ខ្លួន ប្រភពបណ្តាញធ្វើដូច្នោះ។

3. ចុច "សាកល្បងការតភ្ជាប់" បន្ទាប់មក រក្សាទុក។ ចុចលើការចែករំលែកដើម្បីរុករកវា: ថតជាមុន បន្ទាប់មករូបថត និងវីដេអូ ជាមួយសញ្ញា 360° លើឯកសារដែលសម្គាល់ថាជា 360°។
4. ជាមួយម៉ាស៊ីនមេ Immich ភ្ជាប់ ជ្រើសឯកសារក្នុងថតមួយ ហើយចុច "ផ្ទុកឡើងទៅ Immich" ដើម្បីផ្ញើវាទៅម៉ាស៊ីនមេរបស់អ្នក។

### រកវិចិត្រសាល Immich របស់អ្នក

1. នៅលើទំព័រស្វាគមន៍ ចុច "ភ្ជាប់ទៅម៉ាស៊ីនមេ Immich" រួចចូលដោយប្រើអាសយដ្ឋានម៉ាស៊ីនមេ អ៊ីមែល និងពាក្យសម្ងាត់របស់អ្នក ដូចនៅក្នុងកម្មវិធី Immich; ថយក្រោយនាំត្រឡប់ទៅទំព័រស្វាគមន៍វិញ។ រហូតដល់ build 23 ទំព័រចូលបើកដោយផ្ទាល់។ បណ្ណាល័យ អាល់ប៊ុម និងការកំណត់បេកអាប់របស់អ្នក គឺជារបស់គណនីរបស់អ្នក។
2. នៅក្នុងការកំណត់ កម្មវិធីមើលឯកសារ វីដេអូ "ប្រភពវីដេអូ" ជ្រើសឯកសារដើមនៅពេលឧបករណ៍នេះអាចឌិកូដវា ជានិច្ចជាឯកសារដើម ឬជានិច្ចជាស្ទ្រីមដែលបានបំលែងកូដ។
3. ដើម្បីបង្ហាញរូបថត 360° ដល់អ្នកដែលមិនមានកម្មវិធីនេះ ចែករំលែកវាជាមួយតំណចែករំលែករបស់ Immich: កម្មវិធីគេហទំព័រ Immich បង្ហាញវាជាស្វែរនៅក្នុងកម្មវិធីរុករករបស់ពួកគេ។

### ចូលគណនីលើទូរទស្សន៍ កាស ឬកុំព្យូទ័រដោយប្រើទូរសព្ទរបស់អ្នក

ការវាយអាសយដ្ឋានម៉ាស៊ីនមេ អ៊ីមែល និងពាក្យសម្ងាត់ជាមួយឧបករណ៍បញ្ជាទូរទស្សន៍ ឬក្នុងកាស ចំណាយពេលច្រើននាទី។ ជាមួយ Immuch360 នៅលើទូរសព្ទរបស់អ្នក ដែលបានចូលម៉ាស៊ីនមេ Immich របស់អ្នករួច ទូរទស្សន៍ Meta Quest ឬកុំព្យូទ័រមួយចូលបានក្នុងរយៈពេលប៉ុន្មានវិនាទី: អេក្រង់ធំបង្ហាញកូដ QR ទូរសព្ទស្កេនវា អ្នកបញ្ជាក់ ហើយអេក្រង់បើកលើបណ្ណាល័យរបស់អ្នក។ ជាមួយកម្មវិធីទូរសព្ទ ពាក្យសម្ងាត់របស់អ្នកនៅតែលើទូរសព្ទ។ កម្មវិធី Immich មិនមានអ្វីដូចនេះទេ។

មិនមានអ្វីទៅកាន់អ្នកអភិវឌ្ឍន៍ឡើយ: គ្មានគណនី គ្មានការវិភាគ គ្មានសេវារាយការណ៍គាំង គ្មានការផ្សាយពាណិជ្ជកម្ម។ កម្មវិធីនិយាយតែជាមួយម៉ាស៊ីនមេដែលអ្នកជ្រើស (ម៉ាស៊ីនមេ Immich ការចែករំលែក ម៉ាស៊ីនមេ Plex កាមេរ៉ារបស់អ្នក) ហើយដោយគ្មានម៉ាស៊ីនមេ គឺគ្មានអ្វីទាល់តែសោះ។ ពាក្យសម្ងាត់ និង token នៅក្នុងការផ្ទុកសុវត្ថិភាពរបស់ឧបករណ៍។ កាមេរ៉ាប្រើតែនៅលើឧបករណ៍ ដោយកម្មវិធីចាក់ Spatial 2.5D និងដើម្បីស្កេនកូដរបស់អេក្រង់ដែលអ្នកឱ្យចូល; រូបភាពរបស់វាមិនដែលត្រូវបានរក្សាទុក ឬផ្ញើទៅទីណាឡើយ។ អេក្រង់ដែលចូលពីទូរសព្ទរបស់អ្នកទទួលបានសម័យផ្ទាល់ខ្លួនរបស់វា ដែលផ្ញើជាទម្រង់អ៊ិនគ្រីបនៅលើបណ្តាញផ្ទះរបស់អ្នក មិនដែលទទួលពាក្យសម្ងាត់របស់អ្នកឡើយ។ គោលការណ៍ពេញលេញមាននៅក្នុង [PRIVACY.md](../PRIVACY.md) និងព័ត៌មានលម្អិតតាមប្រភពនីមួយៗនៅក្នុង [មគ្គុទ្ទេសក៍អ្នកប្រើ](../docs/immuch360/user-guide.md#privacy)។

## គម្រោង

## ផែនការ

អ្វីដែលមិនទាន់ធ្វើ អ្វីដែលទំនងជាងគេមុន។ គ្មានអ្វីនៅទីនេះជាការសន្យាទេ ហើយមតិកែលម្អនៅលើ [issue tracker](https://github.com/freeKC/Immuch360/issues) ជួយសម្រេចថាអ្វីមកមុន។

- **ហាង**: Google Play (build 28 កំពុងពិនិត្យ; បញ្ជីទូរទស្សន៍កំពុងពិនិត្យ), App Store (កំណែ 3.3.1 កំពុងពិនិត្យ បន្ទាប់មកកំណែ 3.3.2 ជាមួយ build 28), Meta Horizon Store (build 28 កំពុងពិនិត្យ)។
- **កុំព្យូទ័រ**: ការសាកល្បងមុខងារនីមួយៗដោយដៃលើ PC Windows រួមទាំងការចូលដោយប្រើទូរសព្ទ; Spatial 2.5D ជាមួយ webcam នៅលើ Windows កំពុងអភិវឌ្ឍសម្រាប់ខែវិច្ឆិកា 2026; បន្ទាប់មកកម្មវិធីបង្ហាញវីដេអូ 360° នៅលើ Linux និង macOS និងការសាកល្បងលើ Mac ពិត និង PC Linux ពិតមួយ; បន្ទាប់មកបច្ចុប្បន្នភាពស្វ័យប្រវត្តិ និងកម្មវិធី macOS ដែលបានចុះហត្ថលេខា។
