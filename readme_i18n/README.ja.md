# Immuch360

**あなたのメディアを。どんな画面でも。あらゆる視点で。**

Immuch360は、あなたの写真や動画を見つけ、閲覧し、再生し、探索するための無料のオープンソースアプリです。ごく普通の写真や動画はもちろん、パノラマ、360°、3D、イマーシブな写真や動画も扱えます。これらは他のアプリでは平らに表示されたり、二重に映ったり、伸びて表示されたりしてしまうものです。Immuch360はそれらをあるがままの場所、つまりデバイス自体、NAS、コンピューター、Plexサーバー、Immichサーバーから読み込み、スマートフォン、タブレット、テレビ、Meta Questヘッドセット、コンピューターで再生します。アカウントもクラウドもサーバーも必要ありません。

- **何ができる?** 写真や動画をギャラリーとして表示し、ファイルごとに最適なビューアーで再生します。フラット表示、見回せる球体表示、3D表示、ヘッドセットでの表示です。
- **対応するメディアは?** フラットな写真や動画、パノラマ、360°写真や360°動画、VR180、立体視3D、Appleの空間写真、DJIドローンの360°球体写真、そして360°カメラ (Insta360、GoPro MAX、DJI Osmo 360) のRAWファイルで、アプリがスティッチ処理します。
- **対応デバイスは?** Androidのスマートフォンとタブレット、iPhoneとiPad、Android TVとGoogle TV、webOS搭載のLGテレビ (別アプリ、最初のテストビルド)、Meta Quest 2、Pro、3、3S、Windows (プレビュー)、そして早期プレビューのLinuxとmacOSです。
- **サーバーやアカウントは必要?** いいえ。Immuch360はデバイス内のメディアだけで単体で動作します。Immichサーバー、NAS、メディアサーバー、Plexサーバーは、必要になったときに追加できる選択肢です。

<p align="center">
  <sub>Immichモバイルアプリの非公式フォークです。ImmichやFUTOとの提携関係はありません。この名前は「I am much 360」と読むことができます。</sub>
</p>

<a id="what-you-can-do"></a>
## できること

以下の各項目では、まず何が得られるかを説明し、それを数ステップで行う方法を示します。すべてのオプション、メッセージ、制限についての完全なガイドは[ユーザーガイド](../docs/immuch360/user-guide.md)にあります。

<a id="watch-your-photos-and-videos"></a>
### 写真や動画を見る

Immuch360は、まず普通の写真や動画のためのギャラリーとプレーヤーです。タイムライン、アルバム、お気に入り、メモリー、検索はImmichサーバーと連携して動作し、デバイス自体の写真や動画、コンピューターのフォルダーはサーバーなしでも表示されます。動画はネイティブプレーヤーで再生され、音声、シーク、バッファリング表示に対応し、360°、Spatial、コンピューター用のプレーヤーでは音声トラックも選べます。テレビではリモコンがすべてを操作し、コンピューターではマウスとキーボードが操作します。

1. 写真タブを開きます。サーバーがある場合はサーバーのタイムライン、ない場合はデバイスのタイムラインです。
2. 写真や動画をタップして開きます。左右にスワイプすると前後に移動し、ピンチまたはダブルタップでズームします。
3. 動画を上にスワイプすると詳細が表示されます。コーデック、サイズ、フレームレート、ビットレート、このデバイスがデコードできるかどうかです。

詳細: [ビューアーと動画プレーヤー](../docs/immuch360/user-guide.md#watch-your-photos-and-videos)、[動画の詳細とデコーダー](../docs/immuch360/user-guide.md#video-details-decoders-and-why-a-video-stutters)。

<a id="turn-a-photo-with-one-key"></a>
### キー1つで写真を回転する

エディターを開かずに、ワンプッシュで写真を90°回転できます。ボタン、キーボードのキー、またはテレビのリモコンのカラーキーを使い、すべてのプラットフォームに対応します。Immichアプリはエディター内で写真を回転しますが、Immuch360はキー1つで回転し、Immichサーバー2.6以降にある自分の写真については同じサーバーのエディターを経由するため、ウェブアプリやほかのデバイスでも回転した状態で表示されます。それ以外の写真は、このデバイス上でのみ回転します。360°、180°、3Dの写真は回転しないため、イマーシブ表示は水平に保たれます。

1. **スマートフォン、タブレット、Meta Questのウィンドウ**: 写真を開き、下段の編集の手前にある回転をタップすると時計回りに回転します。長押しすると逆方向に回転します。キーボードではRとShift+Rです。
2. **Android TVとGoogle TV**: ビューアー内のどこにフォーカスがあっても、リモコンの黄色キーで写真を時計回りに、青色キーで反時計回りに回転します。カラーキーのないリモコンでは下を押すと、回転が選択された状態で写真の下にバーが表示され (写真にテキストボタンがある場合は右に1つ移動)、OKを押すたびに写真が回転します。
3. **LGテレビ (webOS)**: Android TVと同じく黄色と青色のキー、キーボードではRとShift+R、または写真のコントロールにある回転ボタンを使います。
4. **Windows、Linux、macOS**: Rで時計回り、Shift+Rで反時計回りに回転します。または上部バーの全画面ボタンの手前にある回転ボタンを使います。
5. **ネットワーク共有、Plex、カメラの写真**: 上部バーの先頭にある回転ボタン、RとShift+R、または黄色と青色のキーを使います。

回転の保存先: Immich 2.6以降にある自分のアカウントの写真は、サーバーの写真エディターで回転されます。エディターは元のファイルを残したまま回転した画像を作成します (処理中は細いバーが表示され、4回回転するか1回逆に回転すると元に戻ります)。デバイスの写真、共有の写真、パートナーや共有アルバムの写真、および古いサーバー上のすべての写真は、その写真についてこのデバイス上でのみ回転し、ファイルが変更されることはありません。Immichの写真の場合、アプリはそのことを一度だけ知らせます。Android、iOS、コンピューターのアプリでは、デバイス上で保持された回転はビューアーには反映されますが、サムネイル、スライドショー、思い出にはまだ反映されません。動画、鍵付きフォルダー、および360°、180°、3Dの写真には回転がありません。

<a id="explore-panoramas-360-vr180-and-3d"></a>
### パノラマ、360°、VR180、3Dを探索する

360°写真は球体として開き、指でドラッグするか端末を動かして見回せます。360°動画は音声付きの球体プレーヤーで再生されます。VR180ファイルは半球に描画されます。立体視3Dファイルはフラットな画面では片目分だけ、ヘッドセットでは両目分が表示されます。部分的なパノラマはそのクロップを保持し、写真はカメラが記録した向きから始まります。サーバーが360°として認識していないファイルも、ワンタップで360°として表示できます。

<p align="center">
  <img src="../.github/readme/b19-sphere.jpg" width="260" alt="球体ビューアーで表示した湖岸の 360° 写真：左上に閉じるボタン、右上に 360°、3D レイアウト、ジャイロスコープのボタン">
  <img src="../.github/readme/b19-video.png" width="420" alt="横向きに持ったスマートフォンの 360° プレーヤーで再生中の海岸道路の 360° 動画：左上に閉じるボタンとファイル名、右上に 360° と 3D、中央に前へ、巻き戻し、再生、早送り、次へ、下部にタイムバー">
</p>

1. 写真や動画を開きます。360°ファイルのサムネイルには360°バッジが付き、ライブラリタブには期間、ソース、種類、カメラで絞り込める360°リストがあり、そこにまとめて表示されます。
2. 上部バーの360°をタップします。ドラッグで見回し、ピンチでズーム、ジャイロスコープボタンをタップすると端末を動かして見回せます。
3. 3Dボタンは「モノ (3D ではない)」、「3D、上下」、「3D、左右」の順に切り替わります。360°/180°ボタンは全球とVR180の半球を切り替えます。
4. 360°ファイルなのにフラットに表示される場合は、右上の⋮をタップして「360°で表示」を選びます。

スマートフォンやタブレットでは、立体視動画をフラットな画面でも奥行きのある表示にできます。Spatial 2.5Dプレーヤーがフロントカメラで頭の動きを追跡し、両目の間から見た映像を表示します (実験的機能)。iPhoneで撮影されたAppleの空間写真は認識され、Meta Questでは3Dで表示されます。

詳細: [360°写真と360°動画](../docs/immuch360/user-guide.md#360-photos-and-videos-as-a-sphere)、[3DとVR180](../docs/immuch360/user-guide.md#3d-and-vr180-photos-and-videos)、[Spatial 2.5D](../docs/immuch360/user-guide.md#depth-on-a-flat-screen-spatial-25d-experimental)、[Appleの空間写真と空間動画](../docs/immuch360/user-guide.md#apple-spatial-photos-and-videos)、[360°リスト](../docs/immuch360/user-guide.md#find-your-360-shots-the-360-list)。

<a id="use-your-own-files-without-an-account"></a>
### アカウントなしで自分のファイルを使う

Immuch360はアカウントもサーバーも必要ありません。ビルド24からアプリはウェルカムページで開き、そこでは「サーバーなしで使用」が最初に表示されます：これを選ぶとデバイスの写真や動画が、すべてのビューアー、360°リスト、ネットワークソースとともに開きます。どこにも何も送信されません。サーバーは後から設定またはライブラリタブで接続でき、その時点でサーバーの機能が使えるようになります。

<img src="../.github/readme/b19-library-no-server.png" width="260" alt="サーバーなしのライブラリタブ：上部に 360° の項目、次に 360° 写真が 2 枚あるデバイス上の項目、NAS という名前の共有があるネットワーク共有">

1. アプリを開きます。ウェルカムページには「あなたのメディアを。どんな画面でも。あらゆる視点で。」と3つの選択肢が表示され、最初の「サーバーなしで使用」をタップします。ビルド23までは、ログインページが最初に表示され、フォームの下に「サーバーなしで使用」がありました。
2. 写真と動画へのアクセスを許可します。拒否すると、アプリに「アプリはこのデバイスの写真にアクセスできません」と表示され、「アクセスを許可」と「設定を開く」が示されます。
3. 写真タブにはデバイスのタイムラインが表示されます。検索とアルバムはサーバーの機能なのでグレー表示のままです。ライブラリタブの上部に 360°、続いてデバイス上の項目（デバイスのアルバム）とネットワーク共有があります。
4. 右上のメニューには「このデバイスのみ」と表示されます：アプリはこのデバイスの写真と動画を表示し、どこにも何も送信しません。

コンピューターでは、選択したフォルダーがギャラリーの役割を果たします。テレビには写真がないため、ネットワークソースがその役割を果たします。

詳細: [サーバーやアカウントなしで使う](../docs/immuch360/user-guide.md#without-a-server-or-an-account)。

1. ライブラリタブを開き、次にネットワーク共有、続いて+と「ネットワーク共有 (NAS、コンピューター、メディアサーバー)」をタップします。ビルド24からは、ウェルカムページの「ネットワーク共有またはメディアサーバーを追加」から、サーバーなしで直接ネットワーク共有を開けます。
2. 「ネットワーク上で見つかったサーバー」の下に表示されたサーバーをタップするか、種類、サーバー名またはアドレス、共有名またはパス、開始フォルダー、ユーザー名、パスワードを手動で入力します。

### Immichライブラリを見つける

[Immich](https://github.com/immich-app/immich)サーバーがあれば、Immuch360はImmichモバイルアプリそのものになります。ウェブアプリと同じサーバー、同じアカウントを使い、バックアップ、タイムライン、アルバム、検索、人物、メモリー、共有、パートナーが、すべてサーバーと同期します。公式アプリと並べてインストールできます。さらに、360°バッジとリスト、すべてのイマーシブビューアー、動画ごとに元のファイルとサーバーのトランスコード済みストリームを選べる機能、動画の技術的な詳細、共有やデバイスのファイルを手動でサーバーに送信する機能が加わります。

1. ウェルカムページで「Immichサーバーに接続」をタップし、Immichアプリと同様にサーバーのアドレス、メールアドレス、パスワードでログインします。戻るでウェルカムページに戻ります。ビルド23まではログインページが直接開きます。ライブラリ、アルバム、バックアップ設定はあなたのアカウントのものです。
2. 設定、アセットビューアー、動画の「動画のソース」で、このデバイスがデコードできる場合は元のファイル、常に元のファイル、常にトランスコード済みストリームのいずれかを選べます。
3. アプリを持っていない人に360°写真を見せるには、Immichの共有リンクで共有します。Immichウェブアプリがブラウザ上で球体として表示します。

現在のビルド、ビルド27は、2026年10月10日時点のImmichの`main`ブランチ (バージョン3.3.0-rc.0) をベースにしており、Immich 3.2.4サーバーと同じImmichの`main`からビルドしたサーバーの両方でテストされています。問題は、Immichプロジェクトではなく[Issues](https://github.com/freeKC/Immuch360/issues)に報告してください。

詳細: [それ以外はすべてImmichと同じ](../docs/immuch360/user-guide.md#everything-else-is-immich)、[Immichアプリとの比較](../docs/immuch360/compatibility.md#compared-with-the-immich-app)。

### テレビやコンピューターで見る

同じAndroidアプリがAndroid TVとGoogle TVでも動作し、初回起動時からダークテーマで、入力はリモコンのみです。矢印でフォーカスを移動し、OKで開き、戻るで戻ります。ビューアーでは、動画の再生中でも左右キーで前後の写真や動画に移動し、360°の写真や動画では矢印で見回せます。テレビには写真がないため、Immichサーバー、ネットワーク共有、Plexサーバー、カメラを表示します。LGテレビには[専用のアプリ](#immuch360-on-an-lg-tv-webos)があります。Windowsコンピューターでは、Immuch360 Desktopがサーバーなしで選択したフォルダーを読み込み、独自のプレーヤーでフラットおよび360°動画を再生し、同じ共有やサーバーを閲覧でき、自宅ではコンピューターをヘッドセットと共有することもできます。

### LGテレビ (webOS) でImmuch360を使う

Immuch360は、LG webOSテレビ向けのImmichアプリとしても提供されます。webOS 4.0以降 (2018年以降) のLGテレビ向けの別アプリで、リモコンで操作し、Immichサーバーを表示し、360°写真を矢印で回せる球体に表示します。Immich公式のアプリはLGテレビにはインストールできません。このアプリはSeeky91氏の[immich-tv-webos](https://github.com/Seeky91/immich-tv-webos)をベースにしており、タイムライン、アルバム、人物、場所、検索、スライドショー、スマートフォンでのログインはこのプロジェクトによるものです。Seeky91氏に感謝します。バージョン0.1.0はテストビルドです。実機のLGテレビではまだ動かしておらず、Developer Modeでのみインストールでき、[Issues](https://github.com/freeKC/Immuch360/issues)へのどんな報告も役立ちます。

1. Developer Modeにしたテレビにインストールします。[インストール](#lg-tvs-webos)を参照してください。独自のアプリIDを持つため、Seeky91氏のImmich TVと並べてインストールできます。
2. スマートフォンで (QRコードを読み取って)、メールアドレスとパスワードで、またはAPIキーでログインします。
3. 矢印とOKで閲覧します。ビューアーでは、動画の再生中も左右キーで前後の写真や動画に移動します。コントロールは最後のキー操作から5秒後に隠れ、Infoで詳細が開き、チャンネルキーでズームでき、Magic Remoteのポインターとホイールも使えます。
4. 360°写真は矢印で回せる球体に表示されます。「360°で表示」を使うと、サーバーが360°として認識していない2:1の写真も球体で表示できます。VR180の写真は半球に、3D写真は片目で表示されます。黄色と青色のキーでフラットな写真を回転します。

このビルドにないもの: 球体での360°動画 (メッセージを表示してフラットで再生)、ネットワーク共有、PlexとTapoカメラ (予定あり)、アップロード。動画を再生できないときは、回り続けるスピナーの代わりに、その形式とサイズを示すメッセージが表示されます。webOS 25より前では、Immichの前段にあるリバースプロキシがCORSヘッダーを送信する必要があります。アプリはこの問題を検出するとその内容を説明します。

詳細: [webOSアプリ: インストール、リモコンのキー、CORSヘッダー](../webos/README.md)。

<a id="cameras-plex-and-raw-camera-files"></a>
### カメラ、Plex、カメラのRAWファイル

- **Tapoカメラ**: ネットワーク共有と同じ場所にカメラを追加できます。アプリはライブ映像を表示し (Android、Android TV、Quest、Windows)、すべてのプラットフォームでメモリーカードの録画を日付ごとに一覧表示します。クリップはカメラから取得され、通常の動画と同じように再生でき、Immichに送信することもできます。アプリはネットワーク上のカメラとのみ通信し、TP-Linkのサーバーとは一切通信しません。
- **Plex Media Server、plex.tv不要**: アプリは1度だけ貼り付けるトークンを使ってサーバーと直接ペアリングし、ライブラリの元のファイルをそのまま読み込むため、360°は360°のまま、自宅でも、ポート転送を設定していれば外出先でも利用できます。
- **360°カメラのRAWファイル**: Insta360カメラの.inspのRAW写真と.insvの動画 (1レンズまたは2レンズで、1トラック、2トラック、または2ファイル)、GoPro MAXの.360ファイル、DJI Osmo 360の.osvファイルは、再生時にアプリによってスティッチされます。キャリブレーション情報はファイルに書き込まれているため、どこにも何もインストールする必要はありません。Androidでは、スマートフォンのギャラリーにRAWファイルが一覧表示されないため、共有、コンピューター、またはサーバーから再生してください。Immichサーバーが受け付けるのは.inspと.insvのみです。

詳細: [Tapoカメラ](../docs/immuch360/user-guide.md#tapo-cameras-live-view-and-the-recordings-of-the-memory-card)、[Plex Media Server](../docs/immuch360/user-guide.md#plex-media-server-without-plextv)、[360°カメラのRAWファイル](../docs/immuch360/user-guide.md#raw-360-camera-files-without-the-cameras-app)。

<a id="your-dji-drones-photos-and-videos-on-your-immich-server"></a>
### DJIドローンの写真と動画をImmichサーバーへ

DJIドローンの写真と動画をUSB経由でImmichサーバーに直接取り込めます。ドローン、そのコントローラー、またはカードリーダーをAndroidスマートフォンに接続し、新しいファイルを選んで送信します。動画はドローンのフライトデータから地図上に配置され、ドローンの360°球体写真は360°として表示されます。Immichアプリはスマートフォンのギャラリーにすでにあるものしかバックアップせず、ImmichサーバーはまだDJI Neo 2の動画の撮影場所を読み取れません。このページは実験的機能で、Androidのスマートフォンとタブレットのみに対応し、実際のドローンではまだ試していません。

1. 設定、詳細設定で「DJIドローン (実験的)」をオンにします。ライブラリ、ネットワーク共有に「DJIドローン」のタイルが表示されます。
2. ドローン (Neo 2は電源オフのままで構いません)、そのコントローラー、またはカードリーダーを、USB-Cデータケーブルでスマートフォンに接続します。DJIドローンのページで「ドローンまたはカードを選択」をタップし、ピッカーのサイドメニューでそれを選び、DCIMフォルダーを開くかドライブ全体のままにして、「このフォルダを使用」と「許可」をタップします。
3. ページには写真と動画が日付ごとに一覧表示され、.LRF、.SRT、.THM、.m4aの付属ファイルは除外されます。「新しいものをすべて選択」をタップし、続いて「Immichにアップロード」をタップします。以前に送信したファイルには雲のマークが付き、スキップされます。「デバイスに保存」を選ぶと、代わりにファイルがスマートフォンのギャラリーの「Immuch360 import」アルバムにコピーされます。
4. 動画を地図上に配置するには、飛行前にDJI Flyで動画字幕をオンにします (動画モード、設定、カメラ)。するとドローンは各動画の横に.SRTファイルを書き込み、アプリはそこから撮影場所を読み取り、Immichが場所を見つけられなかった場合はアップロード後にサーバーに設定します。

DJIドローン (Mini、Air、Mavicなど、カメラから識別) の360°球体写真は、360°タグがなくてもImmuch360では360°として表示されます。Immichにはそのタグが必要です。アップロードオプション「ドローンの球体写真をImmich向けに360°としてタグ付け」(既定ではオフ) は、写真をそのままにして小さな.xmpファイルを添えて送信するため、Immichでも球体として表示されます。Neo 2には球体モードやパノラマモードがなく、写真も動画もフラットです。スマートフォンがNeo 2のクリップの音声を録音した場合、その音声は別の.m4aファイルにあります。ページはそのクリップに印を付け、Immichは音声なしで受け取ります (音声を残すにはDJI Flyでダウンロードしてください)。DCIMフォルダーのあるカメラのカードであれば、カードリーダーで同じように使えます。DJIには何も送信されません。

<a id="advanced-features"></a>
## 高度な機能

アプリが読み込み、再生できるものを、すべて知りたい方のために詳しく説明します。各項目の詳細は[ユーザーガイド](../docs/immuch360/user-guide.md)と[互換性ページ](../docs/immuch360/compatibility.md)に記載されています。

- **フォーマット**: フラットな写真や動画 (デバイスがデコードできる形式: MP4、MOV、MKVなど)、正距円筒図法の360°写真や動画、部分的なパノラマ (GPanoクロップ)、VR180、上下または左右の立体視3D (ファイルのst3dボックスから読み取る、またはフレームから推測)、Appleの空間写真 (HEICステレオペア) と空間動画 (MV-HEVC、片目)、Insta360の.inspと.insv、GoProの.360、DJIの.osvのRAWファイル、球体上でトーンマッピングされる10bit HLGおよびPQソース。
- **投影とメタデータ**: サーバーや共有に対してはレンジリクエストで、GPanoや球面メタデータをファイルから読み取ります。カメラの初期視点を維持し、DJIドローンの球体写真はカメラから識別し、Immichでも認識されるよう任意で.xmpサイドカーを添えます。「360°で表示」の設定はデバイスに記憶され、VR180はファイルまたはファイル名から認識されます。ドローン動画の撮影場所は.SRTフライトログから読み取ります。常に元のファイルを再生するため、変換されたコピーではなくメタデータがそのまま保持されます。90°の回転はImmichのエディター経由で保存するかデバイス上に保持し、イマーシブなファイルには適用しません。
- **ネイティブ再生**: AndroidとTVはMedia3、iOSはSceneKitとAVFoundation、ヘッドセットはMeta Spatial SDK、Windowsはlibmpvを使用します。デバイスがデコードできる形式に応じて元のファイルかトランスコード済みストリームを選択でき、デバイスの動画デコーダー一覧は設定、高度な設定で確認できます。音声トラックの選択とバッファリング表示にも対応します。
- **デバイス上でスティッチされるRAWファイル**: 写真にはFlutterのフラグメントシェーダーを使用し、単一トラックの動画ではプレーヤー内のGPUエフェクトを使用します。トラックまたはファイルごとに1レンズの動画では、2つのハードウェアデコーダーを同時に使い、GPUコンポジタで合成します (AndroidとQuestではOpenGL ES 3、iOSではMetal、Windowsではデスクトップ版ビルド5以降、2つのlibmpvプレーヤーのフレームをアプリがグラフィックチップ上でペアリングします)。カメラ自体のキャリブレーション (Mei、V6、等距離モデル) と加速度センサーの記録も使用します。デバイスが2つのデコーダーを同時に実行できない場合は、1レンズ、トランスコード済みストリーム、カメラのLRVコピー、またはスティッチされていない動画にフォールバックします。
- **ソース**: デバイスのギャラリー、コンピューターのフォルダー、システムのフォルダーピッカー経由でUSB接続したドローン、そのコントローラー、またはカメラのカード (Android、実験的)、Immichサーバー、SMB 2および3、WebDAV、DLNA/UPnP、サーバー自身の証明書で検証するHTTPS経由のPlex、ローカルネットワーク上のTapoカメラ (HTTPSとRTSP)、Wi-Fi上でWebDAVサーバーとして共有されたスマートフォンやコンピューター。サーバーはBonjour/mDNS、ローカルネットワークスキャン、SSDP、GDM、TP-Linkのディスカバリーで見つけ、アドレスが変わっても追跡します。
- **オンデマンド読み込み**: ローカルブリッジがバイト範囲とセッションごとのトークンでプレーヤーにデータを提供します。大きなブロック単位の先読みと、最大6つのSMB接続の並列処理に対応し、各動画のフレームからサムネイルを生成し、デバイスには何もコピーされません。
- **ハードウェア**: 存在する場合は必ずハードウェアデコーダーを使用し、実測した上限に従います (Quest 3のH.264の上限、ソフトウェアデコーダーでは最大2048x2048の2レンズまで)。Windowsでは、デコードされた各フレームから360°ビューをグラフィックチップで描画し、各コンピューターでフレームサイズを計測し、統合型または専用のグラフィックチップを検出します。
- **プラットフォーム固有の機能**: スマートフォンではジャイロスコープとSpatial 2.5Dプレーヤー、Questではイマーシブビュー、コントローラー、手、Android TVではリモコン用レイアウト、キーボードダイアログ、TVバナーです。コンピューターでは、マウスとキーボード、フルスクリーン、1つのウィンドウに対応し、プログラムで開いた、またはそのウィンドウにドロップしたファイルやフォルダーはフォルダー内のファイルと同じように読み込まれ、Windowsにデコーダーがあればフォルダー内のHEIC、AVIF、TIFF、カメラRAW写真も読み込めるほか、パスワードとトークンにはWindowsのデータ保護が使われます。
- **設計レベルでのプライバシー**: アカウントなし、クラウドなし、解析なし。パスワードとトークンはデバイスのセキュアストレージに保存されます。Spatialプレーヤーのカメラはデバイス上でのみ使用され、共有、Plex、カメラへのアクセスはあなたのネットワーク内に限られます。

<a id="install"></a>
## インストール

### Androidスマートフォンとタブレット

1. [Google Play](https://play.google.com/store/apps/details?id=com.aprogsys.immuch360)、または[Releases](https://github.com/freeKC/Immuch360/releases)ページのAPK。スマートフォン用は`Immuch360-v<version>-arm64-v8a-release.apk`、どの端末でも使える汎用版は`Immuch360-v<version>-release.apk`です。
2. アプリは公式のImmichアプリと並べてインストールされます。GitHubのAPKは自動更新されないため、Releasesページを確認してください。ストアからアプリをインストールした後は、そのストアから更新を受け取ってください。

### iPhoneとiPad

1. App Store版はAppleの審査待ちです。公開されるまでは、Mac上のXcodeでアプリをビルドしてください。[自分でビルドする](../docs/immuch360/build.md)を参照してください。
2. 「サーバーなしで使用」をタップするか、サーバーにログインするには「Immichサーバーに接続」をタップします。どちらもビルド24からウェルカムページにあります。

<a id="android-tv-and-google-tv"></a>
### Android TVとGoogle TV

1. Google Playがテレビでアプリを提供するまでは、[Releases](https://github.com/freeKC/Immuch360/releases)ページの汎用版`Immuch360-v<version>-release.apk`を使用してください。
2. テレビで開発者向けオプションと USB デバッグをオンにします（Google TV の場合：設定、システム、デバイス情報で「Android TV OS ビルド」を 7 回選択し、その後 設定、システム、開発者向けオプション。名前はテレビによって異なります）。
3. 同じネットワーク上のコンピューターから、adb（Android SDK Platform Tools）で `adb connect <address of the TV>` を実行し、テレビに表示される確認を承認してから、`adb install -r Immuch360-v<version>-release.apk` を実行します。
4. アプリはバナー付きでテレビのアプリ一覧に表示されます。次のリリースも同じ方法でインストールします：`-r` によってログインと設定が保持されます。

<a id="lg-tvs-webos"></a>
### LGテレビ (webOS)

1. webOS 4.0以降のLGテレビ、同じネットワーク上のコンピューター、無料のLG開発者アカウントが必要です。テレビでLG Content StoreからDeveloper Modeをインストールしてサインインし、Dev Mode Statusをオンにしてテレビを再起動させます。テレビのIPアドレスと、アプリに表示されるパスフレーズを控えておきます。
2. コンピューターにwebOS CLI (Node.js 18以降) をインストールします: `npm install -g @webos-tools/cli`。続いて`ares-setup-device` (テレビのIPアドレス、ポート9922、ユーザー`prisoner`) と`ares-novacom --device <name> --getkey`でテレビを登録します。後者はパスフレーズを尋ねます。
3. [webOSのプレリリース](https://github.com/freeKC/Immuch360/releases/tag/webos-v0.1.0)から`Immuch360-webOS-0.1.0.ipk`をダウンロードし、`SHA256SUMS.txt`で確認してから、`ares-install --device <name> Immuch360-webOS-0.1.0.ipk`を実行します。webosbrewの[webOS Dev Manager](https://github.com/webosbrew/dev-manager-desktop)を使えば、コマンドラインなしで同じことができます。
4. Developer Modeのセッションは1000時間有効で、Developer ModeアプリのEXTENDボタンで延長できます。期限が切れると、テレビはこの方法でインストールしたアプリを削除します。詳細は[webos/README.md](../webos/README.md#install-on-a-tv-in-developer-mode)にあります。

<a id="meta-quest"></a>
### Meta Quest

1. [Horizon Store](https://www.meta.com/experiences/immuch360/1384208401440714/)から: ストア版で、Metaが各申請を審査するたびに更新されます。
2. または、デベロッパーモードでadbかSideQuestを使って[リリース](https://github.com/freeKC/Immuch360/releases)の`-quest-release.apk`ファイルをサイドロードします: `adb install -r Immuch360-v<version>-quest-release.apk`を実行し、ヘッドセットのライブラリで「不明なソース」を開きます。
3. ストア版とGitHubのAPKは異なる鍵で署名されています。一方から他方に切り替えるには、先にアプリをアンインストールする必要があり、その際ログイン情報、設定、ネットワーク共有の一覧が失われます。

<a id="windows"></a>
### Windows

1. [デスクトップのプレリリース](https://github.com/freeKC/Immuch360/releases/tag/desktop-v3.3.0-rc.0-7)から`Immuch360-Desktop-3.3.0-rc.0-desktop.7-windows-x64-setup.exe`をダウンロードし (`SHA256SUMS.txt`で確認できます)、開きます。ファイルはまだ署名されていないため、Windows SmartScreenが「Windows によって PC が保護されました」と表示することがあります。その場合は「詳細情報」を選び、続いて「実行」を選びます。
2. 「Install for me only」(管理者権限不要) または「Install for all users」を選び、続いてインストーラーの言語を選びます。Windowsの言語がすでに選択されています。
3. スタートメニューからImmuch360 Desktopを起動します。写真や動画は「プログラムから開く」に表示されます (ファイルを右クリックし、プログラムから開く)。既定のプログラムに設定されることはありません。新しいビルドを初めて起動する際は、Windowsがファイルをスキャンするため最大1分ほどかかることがあります。
4. Windows 10または11、64ビット。更新するには、次のビルドのインストーラーを開きます：ログイン、フォルダー、設定はそのまま保持されます。同じリリースのZIPは同じプログラムをフォルダーの形にしたもので、どこにでも解凍して`immuch360.exe`を起動できます。

### Linux

Ubuntu 22.04以降とDebian 12以降では`sudo apt install ./Immuch360-Desktop-3.3.0-rc.0-desktop.7-linux-amd64.deb`を、Fedora 40以降では`sudo dnf install ./Immuch360-Desktop-3.3.0-rc.0-desktop.7-linux-x86_64.rpm`を実行します。どちらも[デスクトップのプレリリース](https://github.com/freeKC/Immuch360/releases/tag/desktop-v3.3.0-rc.0-7)にあります。その後、アプリケーション一覧からImmuch360 Desktopを起動します。プレビューです：コンピューターのフォルダー、写真と360°写真の球体表示、そしてパッケージがインストールするシステムのlibmpvによるフラット動画に対応します (360°、3D、RAWの動画はメッセージを表示してフラットで再生)。SMB共有はUbuntu 22.04とDebian 12以降で使えます。Fedoraでは、カメラの動画にRPM FusionのFFmpegが必要です。GNOME KeyringやKWalletがない場合、パスワードはそのセッションの間だけ保持され、アプリの設定にその旨が表示されます。

### macOS

[デスクトップのプレリリース](https://github.com/freeKC/Immuch360/releases/tag/desktop-v3.3.0-rc.0-7)から`Immuch360-Desktop-3.3.0-rc.0-desktop.7-macos.dmg`を開き、アプリをアプリケーションにドラッグします (Apple SiliconとIntel、macOS 12以降)。まだ署名もノータライズもされていないため、macOS 14以前ではControlキーを押しながらクリックして開くを選び、macOS 15以降ではシステム設定、プライバシーとセキュリティで「このまま開く」を選びます。このプロジェクトに関わる誰もMacを持っていないため、アプリはプロジェクトのCIのMacでしか動かしていません。そこではファイルやフォルダーを開き、独自のlibmpvでフラット動画を再生しますが、ネットワークアクセスは未検証です。報告を歓迎します。

<a id="privacy"></a>
## プライバシー

開発者には何も送信されません。アカウントなし、解析なし、クラッシュ報告サービスなし、広告なしです。アプリが通信するのは、あなたが選んだサーバー (Immichサーバー、共有、Plexサーバー、カメラ) のみで、サーバーを使わない場合はどこにも通信しません。パスワードとトークンはデバイスのセキュアストレージに保存されます。Spatial 2.5Dプレーヤーのカメラはデバイス上でのみ使用され、その映像は保存されることも、どこかに送信されることもありません。完全なポリシーは[PRIVACY.md](../PRIVACY.md)に、ソースごとの詳細は[ユーザーガイド](../docs/immuch360/user-guide.md#privacy)にあります。

<a id="the-project"></a>
## プロジェクトについて

Immuch360は[Immich](https://github.com/immich-app/immich)モバイルアプリの非公式フォークで、[GNU AGPL v3](../LICENSE)の下で公開されており、ImmichチームやFUTOとの提携や承認は一切ありません。このフォークが存在するのは、モバイルでの360°表示が2024年1月からImmichで要望されながらも公式アプリにはまだ実装されていないためです。今それを提供し、実機でのフィードバックを集め、メンテナーが望むものを小さなプルリクエストとしてImmichに還元していきます。公式アプリが行うことはすべて維持されており、ブランチ、ビルドチェーン、CIについては[自分でビルドする](../docs/immuch360/build.md)で説明しています。

360°写真ビューアーは、dmitry-brazhenko氏によるアップストリームのプルリクエスト[immich-app/immich#31169](https://github.com/immich-app/immich/pull/31169)をベースにしており、これ自体はbencefr氏による[#30192](https://github.com/immich-app/immich/pull/30192)のプロトタイプをベースにしています。両氏に感謝します。TVでの検索フィルターのリモコン操作の修正とアルバムの並べ替えは、mlc70氏による[mlc70/Immuch-Android-TV#1](https://github.com/mlc70/Immuch-Android-TV/pull/1)の作業から始まりました。また、アクションレールと画面の高さの80パーセントを使うフィルターシートは、mlc70氏の[mlc70/Immuch-Android-TV#3](https://github.com/mlc70/Immuch-Android-TV/pull/3)によるもので、作者情報はそのまま残しています。mlc70氏に感謝します。LG webOSアプリは、Seeky91氏の[immich-tv-webos](https://github.com/Seeky91/immich-tv-webos)をベースにしており、MITライセンスの下、そのフォルダー内に保持しています。Seeky91氏に感謝します。Tapoカメラの実装は、[pytapo](https://github.com/JurajNyiri/pytapo)、[Home Assistant Tapo Control](https://github.com/JurajNyiri/HomeAssistant-Tapo-Control)、[python-kasa](https://github.com/python-kasa/python-kasa)のドキュメントを元に書かれました。Meta QuestのビューはオープンソースではないMeta Spatial SDKに依存しているため、このフォークにのみ残ります。SMB共有はLGPL 2.1以降でライセンスされたlibsmb2を使用しています。ビルド27とデスクトップビルド7からは、各ビルドにその告知、ライセンス文、ソースアーカイブ`Immuch360-libsmb2-sources.tar.gz`が含まれ、このアーカイブは各リリースにも添付されています。WindowsとmacOSのビルドには、プロジェクトがビルドしたlibmpv ([mpv](https://mpv.io)のライブラリ、[FFmpeg](https://ffmpeg.org)を含む) がLGPLの下でライセンスとソースとともに含まれており、アプリのライセンスページ (プロフィールメニューの一番下にあるライセンス) に一覧表示されます。このページで挙げたプラットフォームの詳細と商標については[ライセンスと商標](../docs/immuch360/platform-support.md#license-and-trademarks)に記載されています。

このページのスマートフォンのキャプチャはAndroidビルドをエミュレーターで撮影したもの、テレビのキャプチャはGoogle TVエミュレーターで撮影したもの、Windowsのキャプチャは実機のWindows 11 PCで撮影したもので、いずれも[Poly Haven](https://polyhaven.com)のCC0パノラマを使用しています。ヘッドセットのキャプチャはQuest 3実機で撮影しました。

<a id="roadmap"></a>
## ロードマップ

まだ実現していないことを、可能性の高い順に並べています。ここにあるものは約束ではありません。[Issue トラッカー](https://github.com/freeKC/Immuch360/issues) でのフィードバックが、何を優先するかを決める助けになります。

- **各ストア**: Google Play (ビルド26は審査中、その後ビルド27。TV版の掲載は審査中)、App Store (バージョン3.3.1が10月14日から審査中)、Meta Horizon Store (ビルド25が審査中)。
- **コンピューター**: まずWindows PCでの各機能の手動テスト、続いてLinuxとmacOSでの360°動画レンダラー、実機のMacと実機のLinux PCでのテスト、その後署名付きビルドと自動更新、そしてウェブカメラを使ったSpatial 2.5Dです。
- **テレビ**: 実機のAndroid TVでのビルド27のテスト、実機のLGテレビでのLG webOSアプリのテスト、続いてその球体での360°動画、ネットワーク共有、Plex、Tapoカメラへの対応、そして大画面に表示したQRコードをスマートフォンで読み取り、テレビやコンピューターをスマートフォンとペアリングする機能です。
- **スマートフォンとタブレット**: iOSの360°動画プレーヤーへのタイムバーの追加、スマートフォンの360°プレーヤーへの前へ・次への追加、フラットプレーヤーでの音声トラック選択、iPhoneとiPadでのTapoライブ映像です。
- **イマーシブメディア**: デュアル魚眼の.dng、GoProとDJIの動画を自身のモーションデータから水平化する機能、デコーダーが対応していればQuestで空間動画を3D表示する機能、ヘッドセット内で空間写真を前へ・次へと切り替える機能です。
- **ソース**: 共有フォルダー内のファイル間をスワイプする機能、WebDAVのダイジェスト認証、コンピューターからPlexトークンを取り込むQRコード、PlexのIPv6対応、H.265のTapo録画、テレビのホーム画面のチャンネルです。
- **ドローン**: 実機のDJI Neo 2でのテスト、続いてスマートフォンが録音した音声をクリップに統合する機能です。ドローンのカメラのライブ映像と操作は後回しにします。
- **アップストリーム**：360° 写真ビューアーから始めて、メンテナーが望む部分について Immich に小さなプルリクエストを送ること。

各機能について実機確認がまだ必要なものを含む完全なリストは、[リリースステータス](../docs/immuch360/release-status.md#roadmap)にあります。
