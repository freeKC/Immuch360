# Immuch360

**ඔබේ මාධ්‍ය. ඕන ම තිරයක්. සෑම දෘෂ්ටි කෝණයක්ම.**

Immuch360 යනු ඔබේ ඡායාරූප සහ වීඩියෝ සොයා, විමසා, ක්‍රීඩනය කර, ගවේෂණය කිරීම සඳහා නොමිලේ හා විවෘත මූලාශ්‍ර යෙදුමකි: සාමාන්‍ය ඒවා, සහ අනෙක් යෙදුම් සමතලව, දෙගුණ කරගෙන හෝ දිගු කරගෙන පෙන්වන පැනෝරමික, 360°, 3D සහ ගැබිනි (immersive) ඒවා. එය ඒවා පවතින තැනින්ම කියවයි, උපකරණය තුළම, NAS එකක හෝ පරිගණකයක, Plex සේවාදායකයක හෝ Immich සේවාදායකයක, ඉන්පසු දුරකථන, ටැබ්ලට්, රූපවාහිනී, Meta Quest හෙඩ්සෙට් සහ පරිගණක මත ඒවා ක්‍රීඩනය කරයි. ගිණුමක් අවශ්‍ය නැත, වලාකුළක් අවශ්‍ය නැත, සේවාදායකයක් අවශ්‍ය නැත.

- **එය කරන්නේ මොකක්ද?** එය ඔබේ ඡායාරූප සහ වීඩියෝ ගැලරියක් ලෙස පෙන්වා, එක් එක් ගොනුවට ගැලපෙන දර්ශකයෙන් ක්‍රීඩනය කරයි: සමතලව, ඔබ වටා බැලිය හැකි ගෝලයක් ලෙස, 3D වලින්, හෙඩ්සෙටයක.
- **කුමන මාධ්‍යද?** සමතල ඡායාරූප සහ වීඩියෝ, පැනෝරමා, 360° ඡායාරූප සහ වීඩියෝ, VR180, ස්ටීරියෝස්කෝපික් 3D, Apple ස්පේෂල් ඡායාරූප, DJI ඩ්‍රෝන වල 360° ගෝල, සහ යෙදුම විසින් එකට සම්බන්ධ කරන 360° කැමරා (Insta360, GoPro MAX, DJI Osmo 360) වල raw ගොනු.
- **කුමන උපාංග මතද?** Android දුරකථන සහ ටැබ්ලට්, iPhone සහ iPad, Android TV සහ Google TV, webOS සහිත LG රූපවාහිනී සහ Tizen සහිත Samsung රූපවාහිනී (වෙනම TV යෙදුමක්, පරීක්ෂණ build ලෙස), Meta Quest 2, Pro, 3 සහ 3S, Windows (පෙරදසුන), සහ Linux සහ macOS ආරම්භක පෙරදසුන් ලෙස.
- **මට සේවාදායකයක් හෝ ගිණුමක් අවශ්‍යද?** නැත. Immuch360 ඔබේ උපකරණයේ මාධ්‍ය සමඟ තනිවම ක්‍රියා කරයි. Immich සේවාදායකයක්, NAS එකක්, මාධ්‍ය සේවාදායකයක් හෝ Plex සේවාදායකයක් ඔබට අවශ්‍ය විට එක් කරන විකල්ප ය.
- **රූපවාහිනියක්, හෙඩ්සෙට් එකක් හෝ පරිගණකයක් පුරනය කරන්නේ කෙසේද?** ඔබේ දුරකථනයෙන්: එහි පුරනය වීමේ පිටුව පෙන්වන QR code එක scan කරන්න, නැතහොත් එහි code එක ටයිප් කරන්න, තහවුරු කරන්න, එවිට තත්පර කිහිපයකින් එය ඔබේ Immich පුස්තකාලය මත විවෘත වේ, දුරස්ථයෙන් කිසිවක් ටයිප් කිරීමට අවශ්‍ය නැතිව.

වර්තමාන build එක, build 29, 2026 ඔක්තෝබර් 10 දිනැති Immich හි `main` මත පදනම් වේ (3.3.0-rc.0 අනුවාදය), build 28 මෙන්ම, එය එම Immich `main` එකෙන්ම සකසන ලද සේවාදායකයක් සමඟ පරීක්ෂා කරන ලදී; build 27 Immich 3.2.4 සේවාදායකයක් සමඟද පරීක්ෂා කරන ලදී. කරුණාකර [Issues](https://github.com/freeKC/Immuch360/issues) හි ගැටළු වාර්තා කරන්න, Immich ව්‍යාපෘතියට නොවේ.

### ඔබේ දුරකථනයෙන් රූපවාහිනියක්, හෙඩ්සෙට් එකක් හෝ පරිගණකයක් පුරනය කරන්න

රූපවාහිනී දුරස්ථයකින් හෝ හෙඩ්සෙට් එකක් තුළ සේවාදායක ලිපිනයක්, email එකක් සහ මුරපදයක් ටයිප් කිරීමට මිනිත්තු ගණනක් ගත වේ. ඔබේ Immich සේවාදායකයට පුරනය වූ Immuch360 ඔබේ දුරකථනයේ ඇති විට, රූපවාහිනියක්, Meta Quest එකක් හෝ පරිගණකයක් තත්පර කිහිපයකින් පුරනය වේ: විශාල තිරය QR code එකක් පෙන්වයි, දුරකථනය එය scan කරයි, ඔබ තහවුරු කරයි, සහ තිරය ඔබේ පුස්තකාලය මත විවෘත වේ. දුරකථන යෙදුම සමඟ, ඔබේ මුරපදය දුරකථනයේම රැඳේ. Immich යෙදුමේ මෙවැනි කිසිවක් නැත.

1. විශාල තිරය මත (Android TV සහ Google TV, Meta Quest කවුළුව, Windows, Linux හෝ macOS), "Immich සේවාදායකයකට සම්බන්ධ වන්න" තෝරන්න: පුරනය වීමේ පිටුව සේවාදායක ෆෝරමය අසලින් "ඔබේ දුරකථනයෙන් පුරනය වන්න", QR code එකක් සහ අක්ෂර 10 ක code එකක් පෙන්වයි.
2. ඔබේ සේවාදායකයට පුරනය වූ දුරකථනයේ: Settings, "රූපවාහිනියක් හෝ පරිගණකයක් සම්බන්ධ කරන්න", ඉන්පසු "code එක scan කරන්න". දුරකථනයකට තිරය scan කළ නොහැකි Meta Quest එකක, "ඒ වෙනුවට code එකක් ඇතුළත් කරන්න" තෝරා හෙඩ්සෙට් එක පෙන්වන code එක ටයිප් කරන්න.
3. දුරකථනය "(තිරය) පුරනය කරන්නද?" ලෙස අසා ඉලක්කම් හයක අංකයක් පෙන්වයි: තිරයද එම අංකයම පෙන්වන බව පරීක්ෂා කර, ඉන්පසු "පුරනය වන්න" තට්ටු කරන්න. තිරය ඔබේ කාලරේඛාව මත විවෘත වේ.

එය ආරක්ෂිතව පවතින ආකාරය: දුරකථනය සහ තිරය එකම නිවසේ ජාලයේ තිබිය යුතු අතර, code එක උපරිම මිනිත්තු දෙකක් පවතින අතර එක් වරක් පමණක් ක්‍රියා කරයි. දුරකථනය එම තිරය සඳහා නව session එකක් ඔබේ සේවාදායකයෙන් ඉල්ලා, එයට තිරයේ නම තබා ("සාලයේ TV එකේ Immuch360"), එය සංකේතනය කර තිරයට යවයි, එබැවින් ඔබේ මුරපදය කිසි විටෙකත් දුරකථනයෙන් පිට නොවේ. "රූපවාහිනියක් හෝ පරිගණකයක් සම්බන්ධ කරන්න" මෙම දුරකථනය පුරනය කළ තිර ලැයිස්තුගත කරයි, එක් එක් එකට "ඉවත් වන්න" සමඟ, සහ Immich ඒවා Account Settings, Authorized Devices හි ලැයිස්තුගත කරයි, එහිදීද ඔබට ඒවා අවලංගු කළ හැකිය. දුරකථනය ඉවත් කළ විට ඒවාද ඉවත් වේ.

දුරකථන පැත්ත දැන් Android මත ක්‍රියා කරන අතර, iPhone සහ iPad මත ඊළඟ iOS නිකුතුවේ සිට ක්‍රියා කරයි. දුරකථනයේ Immuch360 නොමැති නම්, දුරකථනයේ කැමරාවෙන් code එක scan කරන්න: තිරය විසින් සපයන පිටුවක් බ්‍රවුසරයේ විවෘත වේ, ඔබේ email සහ මුරපදය සඳහා, ඒවා සංකේතනය කර එක් වරක් පමණක් භාවිතා කෙරේ. LG රූපවාහිනී දුරකථනයේ බ්‍රවුසරයේ, තමන්ගේම QR code එකකින් පුරනය වේ; build 28 සිට දුරකථන යෙදුමේ scanner එක එය හඳුනාගෙන එම පිටුව විවෘත කරයි.

DJI Fly නොමැතිව සහ කිසිදු ගිණුමක් නොමැතිව, ඔබේ DJI ඩ්‍රෝනය දකින දේ ඔබේ Android දුරකථනයේ බලන්න: DJI RC-N3 දුරස්ථ පාලකයක් එහි කේබලයෙන් දුරකථනයට සම්බන්ධ කරන්න, එවිට Immuch360 ඩ්‍රෝනයේ සජීවී වීඩියෝව, 1080p හි H.265, දුරස්ථ පාලකයේ සහ ඩ්‍රෝනයේ බැටරිය, සංඥාව, gimbal එක සහ පියාසැරි දත්ත සමඟ පෙන්වයි, ඒවා කේබලයෙන් කියවේ. ඩ්‍රෝනයේ සම්පූර්ණ පාලනය දුරස්ථ පාලකය සතුව පවතී. එය RC-N3, DJI Neo 2 සහ Samsung Galaxy S24+ සමඟ බිම මත උත්සාහ කර ඇත; වෙනත් දුරස්ථ පාලක සහ ඩ්‍රෝන උත්සාහ කර නැත. පියාසැරි සහ බැටරි අගයන් තවම DJI Fly සමඟ සසඳා නැත: ඒවා අනුව පියාසර නොකරන්න.

එය සවන් දෙන්නේ පමණි. දුරස්ථ පාලකයට හෝ ඩ්‍රෝනයට කිසි විටෙකත් කිසිදු විධානයක් යවනු නොලැබේ: දුරස්ථ පාලකය විවෘත වී තත්පර 20 කට පසු සිට, පිටුව සෑම තත්පරයකම ලියන එකම byte එක, දුරස්ථ පාලකය දත්ත පිළිගන්නේද යන්න පමණක් පෙන්වන අතර, කිසිදු විධානයක් රැගෙන යන්නේ නැත.

1. Settings, Advanced හි "DJI සම්බන්ධතා විනිශ්චය (පර්යේෂණාත්මක)" පෙරනිමියෙන් සක්‍රියයි (රූපවාහිනියක කිසි විටෙකත් නැත); "DJI සම්බන්ධතාවය" ටයිල් එක පුස්තකාලය, ජාල බෙදාගැනීම් හි ඇත.
2. ඩ්‍රෝනය සහ දුරස්ථ පාලකය සක්‍රිය කර, DJI Fly වසා, ඉන්පසු DJI සම්බන්ධතාවය ටයිල් එක විවෘත කර ආරක්ෂක දැනුම්දීම කියවන්න.
3. "capture එක ආරම්භ කරන්න" තට්ටු කරන්න, ඉන්පසු දුරස්ථ පාලකය එහි කේබලයෙන් සම්බන්ධ කරන්න. එය විවෘත කළ යුත්තේ කුමන යෙදුමදැයි Android ඇසුවොත්, "Always" නොමැතිව Immuch360 තෝරන්න, මන්ද එය DJI Fly වෙතින් දුරස්ථ පාලකය ඉවතට ගනී; එය USB ප්‍රකාරයක් ඉල්ලුවොත්, ආරෝපණය පමණක් තෝරන්න.
4. තත්ත්වය "Accessory එක විවෘතයි", ඉන්පසු "දුරස්ථ පාලකයේ frames පැමිණේ" ලෙස පෙන්වන අතර, තත්පර කිහිපයක් ඇතුළත වීඩියෝව පැමිණේ. රූපය මත ඇති බොත්තම එය සම්පූර්ණ තිරයෙන් පෙන්වන අතර, "පියාසැරිය සහ බැටරිය" කොටස දුරස්ථ පාලකයේ සහ ඩ්‍රෝනයේ අගයන් ලබා දෙයි.
5. "capture එක export කරන්න" `Download/Immuch360/dji-link` වෙත ගොනු තුනක් ලියයි; "capture එකක් ධාවනය කරන්න" දුරස්ථ පාලකය නොමැතිව export එකක් පිටුවේ නැවත ධාවනය කරයි, උපාංගයක් ඩ්‍රෝනයේ වීඩියෝව කොතරම් හොඳින් ඩිකෝඩ් කරනවාද බැලීමට.

ඩ්‍රෝනයේ ඡායාරූප සහ වීඩියෝ දුරස්ථ පාලකය හරහා ළඟා විය නොහැක, මන්ද එය ඩ්‍රෝනයේ ගබඩාව විවෘත නොකරයි: [ඉහත කොටසේ](#your-dji-drones-photos-and-videos-on-your-immich-server) මෙන්, ඒවා USB හරහා ඩ්‍රෝනයෙන්ම හෝ එහි කාඩ්පතෙන් පිටපත් කරන්න. Meta Quest එකකද පිටුව ඇත, නමුත් ඩ්‍රෝනයේ සජීවී වීඩියෝව තවම හෙඩ්සෙට් එකට ළඟා නොවේ. පිටුව පවසන පරිදි, export කළ ගොනු ඔබ ළඟම තබා ගන්න, මන්ද ඒවායේ දුරස්ථ පාලකයේ serial number එක ඇත; පිටුව පෙන්වන තත්ත්වයන් සහ ගණක සමඟ [Issues](https://github.com/freeKC/Immuch360/issues) හි වාර්තාවක් උපකාරී වේ, විශේෂයෙන් වෙනත් DJI දුරස්ථ පාලක සමඟ.

යෙදුම කියවා ක්‍රීඩනය කළ හැකි දේ, සම්පූර්ණ විස්තර අවශ්‍ය පාඨකයා සඳහා. සෑම පෙළක්ම [පරිශීලක මාර්ගෝපදේශය](../docs/immuch360/user-guide.md) සහ [compatibility පිටුව](../docs/immuch360/compatibility.md) හි විස්තර කර ඇත.

- **ආකෘති**: සමතල ඡායාරූප සහ වීඩියෝ (උපකරණය ඩිකෝඩ් කරන දේ: MP4, MOV, MKV සහ තවත්); equirectangular 360° ඡායාරූප සහ වීඩියෝ; අර්ධ පැනෝරමා (GPano ක්‍රොප්); VR180; ස්ටීරියෝස්කෝපික් 3D, ඉහළ සහ පහළ හෝ පැත්තෙන් පැත්තට, ගොනුවෙන් කියවූ (st3d box) හෝ ෆ්‍රේම් එකෙන් අනුමාන කළ; Apple ස්පේෂල් ඡායාරූප (HEIC stereo pairs) සහ ස්පේෂල් වීඩියෝ (MV-HEVC, එක් ඇසක්); Insta360 .insp සහ .insv raw, GoPro .360, DJI .osv; ගෝලය මත tone map කළ 10 bit HLG සහ PQ මූලාශ්‍ර.
- **Projection සහ metadata**: ගොනුවෙන් කියවූ GPano සහ spherical metadata, සේවාදායකයක හෝ බෙදාගැනීමක range requests සමඟ; කැමරාවේ ආරම්භක දෘෂ්ටිය; DJI ඩ්‍රෝන වල ගෝල ඒවායේ කැමරාවෙන් හඳුනා ගනී, Immich ද ඒවා සලකුණු කරන පරිදි විකල්ප .xmp sidecar එකක් සමඟ; "360° ලෙස බලන්න" උපකරණයේ මතක තබා ගනී; VR180 ගොනුවෙන් හෝ එහි නමින් හඳුනා ගනී; ඩ්‍රෝන වීඩියෝවක ස්ථානය එහි .SRT පියාසැරි ලොගයෙන් කියවයි; මූල ගොනුව ක්‍රීඩනය වන බැවින් metadata සම්පූර්ණයෙන් රැකේ, කිසි විටෙකත් පරිවර්තනය කළ පිටපතක් නොවේ; Immich සංස්කාරකය හරහා සුරකින හෝ උපකරණයේ තබාගන්නා 90° කරකැවීමක්, කිසි විටෙකත් ගිල්වන ගොනුවක නොවේ.
- **දේශීය ක්‍රීඩනය**: Android සහ TV මත Media3, iOS මත SceneKit සහ AVFoundation, හෙඩ්සෙටයේ Meta Spatial SDK, Windows මත libmpv; උපකරණය ඩිකෝඩ් කරන දෙයින් මූල ගොනුව හෝ පරිවර්තනය කළ ස්ට්‍රීම් තෝරා ගනී; Settings, Advanced හි උපකරණයේ වීඩියෝ ඩිකෝඩර් ලැයිස්තුවක්; ශ්‍රවණ ට්‍රැක් තේරීම, Android ක්‍රීඩකයේ උපසිරැසි සහ බෆරින් දර්ශකයක්.
- **උපකරණයේම සම්බන්ධ කළ Raw ගොනු**: ඡායාරූප සඳහා Flutter fragment shader එකක්; තනි ට්‍රැක් වීඩියෝ සඳහා ක්‍රීඩකයේ GPU effect එකක්; ට්‍රැක් එකකට හෝ ගොනුවකට ලෙන්ස් එකක් ඇති වීඩියෝ සඳහා එකවර hardware decoder දෙකක් සහ GPU compositor එකක් (Android සහ Quest මත OpenGL ES 3, iOS මත Metal, Windows මත desktop build 5 සිට, යෙදුම ෆ්‍රේම් graphics chip එකෙන් යුගල කරන libmpv ක්‍රීඩක දෙකක්); කැමරාවේම කැලිබ්‍රේෂන් එක (Mei, V6 සහ equidistant මාදිලි) සහ accelerometer වාර්තාව; උපකරණයට decoder දෙකක් ක්‍රියාත්මක කළ නොහැකි විට, ලෙන්ස් එකකට, පරිවර්තනය කළ ස්ට්‍රීම් එකට, කැමරාවේ LRV පිටපතට හෝ සම්බන්ධ නොකළ වීඩියෝවට fallback වේ.
- **මූලාශ්‍ර**: උපකරණයේ ගැලරිය; පරිගණකයක බහාලුම්; පද්ධති ෆෝල්ඩර picker එක හරහා USB මගින් ඩ්‍රෝනයක් හෝ කැමරා කාඩ්පතක් (Android, පර්යේෂණාත්මක); ඩ්‍රෝනයේ සජීවී වීඩියෝව සඳහා එහි කේබලය හරහා DJI RC-N3 දුරස්ථ පාලකයක් (Android, පර්යේෂණාත්මක); Immich සේවාදායකයක්; SMB 2 සහ 3, WebDAV, DLNA/UPnP; සේවාදායකයේම certificate එකට එරෙහිව පරීක්ෂා කළ HTTPS හරහා Plex; දේශීය ජාලය හරහා Tapo කැමරා (HTTPS සහ RTSP); WebDAV සේවාදායකයක් ලෙස Wi-Fi මත බෙදාගත් දුරකථනයක් හෝ පරිගණකයක්; Bonjour/mDNS, දේශීය ජාල scan එකක්, SSDP, GDM සහ TP-Link discovery මගින් හමු වූ, සහ ලිපිනය වෙනස් වන විට අනුගමනය කරන සේවාදායක.
- **ඉල්ලුම මත කියවීම**: දේශීය bridge එකක් byte range සහ session එකකට token එකක් සමඟ ක්‍රීඩකයන්ට සේවය කරයි; විශාල block, කලින් කියවීම සහ එකවර SMB සම්බන්ධතා හයක් දක්වා; සෑම වීඩියෝවකම එක් ෆ්‍රේම් එකකින් සිඟිති රූප; උපකරණයට කිසිවක් පිටපත් නොකරයි.
- **Hardware**: ඒවා ඇති සෑම තැනකම hardware decoder භාවිතා කරයි, ඒවායේ මනින ලද සීමා සමඟ (Quest 3 H.264 සීමාව, software decoder සඳහා වැඩිම 2048x2048 ලෙන්ස් දෙකක්); Windows මත, ඩිකෝඩ් කළ සෑම ෆ්‍රේම් එකකින්ම graphics chip එක 360° දර්ශනය අඳිනු ලබයි, එක් එක් පරිගණකයේ ෆ්‍රේම් ප්‍රමාණය මනිනු ලබයි, integrated හෝ dedicated chip එක හඳුනා ගනී.
- **වේදිකා විශේෂතා**: දුරකථනවල ගයිරෝස්කෝප් එක සහ Spatial 2.5D ක්‍රීඩකය; Quest හි ගැබිනි දර්ශනය, කොන්ට්‍රෝලර් සහ අත්; Android TV හි දුරස්ථය සඳහා පිරිසැලසුම, යතුරුපුවරු dialog එක සහ TV බැනරය; පරිගණකයේ මූසිකය සහ යතුරුපුවරුව, full screen, තනි කවුළුවක්, යෙදුම සමඟ විවෘත කළ හෝ එහි කවුළුව මත දැම ගොනු සහ ෆෝල්ඩර ඔබේ ෆෝල්ඩරවල ගොනු ලෙසම කියවේ, Windows හි ඒවා සඳහා decoder එකක් ඇති විට ෆෝල්ඩරවලින් HEIC, AVIF, TIFF සහ raw කැමරා ඡායාරූප, සහ password සහ token සඳහා Windows data protection එක.
