# Immuch360

Immuch360 d asnas aziraz n Immich s tewlafin d tvidyutin 360° anda tzemreḍ ad tmuqleḍ yal tama, daɣen d ameɣri baṭel i tewlafin d tvidyutin timsawin, 360°, 3D d VR180, ɣef tiliɣriyin d ttablit Android, iPhone d iPad, ticacitin Meta Quest (Quest 3 d 3S, u seg lebni 21 Quest 2 d Quest Pro, ur ttwarmen ara), u seg lebni 20 Android TV d Google TV. Immuch360 Desktop, yiwen usnas-nni ɣef uselkim Windows, yeffeɣ-d d lqem n tirmit, wali [Ɣef uselkim Windows](#on-a-windows-computer-immuch360-desktop-preview).

Yettwaxdem i wid yettṣewwiren s tkamirat 360° (Insta360, GoPro MAX, DJI Osmo 360, Ricoh Theta, Samsung Gear 360) neɣ s uskar n tewlaft tasfirt n tiliɣri, neɣ i wid yesɛan tacacit, u bɣan ad walin tiwlafin-nsen seg uqeddac Immich, seg tiliɣri s yiman-is, seg NAS, seg uqeddac n yimidyaten neɣ seg uqeddac Plex: d yiwen uqeddac, d yiwen umiḍan, war azegrir n uqeddac, neɣ war aqeddac akk. Seg lebni 20 yesskanay-d daɣen tikamiṛatin Tapo, srid d yiseklasen n tkarḍa-nsent n tkatut.

## Tiwlafin d tvidyutin 360° am tsfirt

Tḥerzeḍ tiwlafin-ik ɣef uqeddac [Immich](https://github.com/immich-app/immich), u kra seg-sent d tid n tkamirat 360° neɣ n uskar n tewlaft tasfirt n tiliɣri. Deg usnas aziraz unṣib, tugniwin-a ttbanent am teslent tamsawit, tettwazzel, u tividyutin 360° daɣen ttwaɣrant d timsawin. Asnas web n Immich yezmer ad d-yesken tawlaft 360° am tsfirt, asnas aziraz ala: ttuṭṭlaben-t seg yennayer 2024 deg [udiwenni #6572](https://github.com/immich-app/immich/discussions/6572).

Immuch360 yeldi-tent am tsfirt anda tmuqleḍ yal tama, ɣef tiliɣriyin d ttablit Android d iOS.

Tawlaft tezzi mi ara tt-tzuɣreḍ, tettimɣur s tuqqent n yiḍudan neɣ s usiti snat n tikkal, tkemmel ad tezzi cwiṭ deffir uzuɣer arurad, teldi ɣef tmuɣli tamezwarut i teskles tkamirat (isefka n GPano), u tettawi-d tugna yettwaxedmen ugar mi ara tesmeɣreḍ; tiwlafin tiẓegzawin ur nemmid ara ttwasefraknt daɣen (agzam n GPano). Tavidyut tettwaɣra deg umeɣri n tsfirt unṣib s umeslaw, s uzuɣer d ujiroskop.

Ifuyla 360° yettwasdukklen yakan teddun anda nniḍen akk: isifeḍ seg usnas Insta360 neɣ Studio, GoPro Player, Ricoh Theta, akked tewlafin tisfirin n tiliɣriyin. Ifuyla RAW srid seg tkamirat sdukkulen-ten usnas, wali [Ifuyla RAW n tkamiratin 360°](#raw-360-camera-files-without-the-cameras-app).

- **Tawlaft 360° am tsfirt**: amdal d asawen s azelmaḍ; d asawen s ayeffus taqeffalt 360°/180°, taqeffalt n usefrek 3D d ujiroskop.
- **Tavidyut 360° deg umeɣri 360°**: sit ɣef tugna i tiqeffalin; 360° d 3D d asawen s ayeffus.

### Ldi tawlaft 360° am tsfirt

1. Ldi tawlaft seg tesnakudt, seg ulbom, seg [tebdart 360°](#find-your-360-shots-the-360-list) neɣ seg ukaram yettwabḍan. Tiwlafin 360° sɛant tacreḍt 360° ɣef tugna-nsent tamecṭuḥt.
2. Sit ɣef 360° deg ufeggag n ufella n umeskan. Ameskan n tsfirt yeldi, s umeskan n usali alamma tuli tugna tummidt; asemɣer i tesɛiḍ deg tmuɣli tamsawit yeqqim.
3. Zuɣer akken ad tmuqleḍ yal tama, qqen iḍudan i usemɣer, sit snat n tikkal akken ad tqerbeḍ. Deffir uzuɣer arurad, tamuɣli tkemmel ad tezzi cwiṭ syin ad tḥebbes s ttawil.
4. Akken ad tmuqleḍ yal tama s tuzzya n tiliɣri, sit ɣef taqeffalt n ujiroskop d asawen s ayeffus (tensa s wudem amezwer).
5. Snat n tqeffalin nniḍen d asawen s ayeffus d 360°/180° (tasfirt tummidt neɣ azgen n tsfirt VR180, ur d-tettban ara ɣef tewlafin tiẓegzawin ur nemmid ara) d 3D (asefrek n tewlaft stiriyu), wali [3D d VR180](#3d-and-vr180-photos-and-videos). Tawlaft RAW n Insta360 tesɛa kan ajiroskop.
6. Mdel s ucuddu d asawen s azelmaḍ.

### Ɣer tavidyut 360°

1. Ldi tavidyut u sit ɣef 360° deg ufeggag n ufella. Ɣef tvidyut 360° taqeffalt 360° d tamezwarut; ɣef tiliɣriyin d ttablit, taqeffalt Spatial teḍfer-itt ma yella aɣewwar-nni yermed (wali [Spatial 2.5D](#depth-on-a-flat-screen-spatial-25d-experimental)).
2. Ameɣri 360° unṣib yeldi ɣef ugdil akk, yeqqar s umeslaw: Media3 ɣef Android, SceneKit ɣef iOS.
3. Zuɣer akken ad tmuqleḍ yal tama, neɣ smussu tiliɣri. Ameɣri n Android yettḍafar yal tikkelt tiliɣri; win n iOS yesɛa taqeffalt n ujiroskop, termed s wudem amezwer.
4. Sit ɣef tugna i tiqeffalin: amdal, 360°/180° d 3D d asawen, syin urar, tiqeffalin n unegzum d ufeggag n wakud ɣef Android. Ameɣri n iOS yesɛa kan urar d usteɛfu i tura.
5. Mi ara tesɛu tvidyut sin n yibriden n umeslaw neɣ ugar (tutlayin, awennit), taqeffalt «Abrid n umeslaw» ad ak-teǧǧ ad tefreneḍ yiwen. Mi ara tettali tvidyut neɣ teḥbes, ameɣri yesskan-d «Asali» akked tačurt n tkatut-is n tɣuri.

Ameɣri yeqqar afaylu yettwaḥerzen ɣef tiliɣri, neɣ afaylu n ufaylu yettwabḍan n uẓeṭṭa, ma yella. Ma ulac, yettawi-d asuddem seg uqeddac-ik: tavidyut yettwabeddlen s wudem amezwer, neɣ aṣli ma tessutreḍ-t deg Settings (Iɣewwaṛen), Asset Viewer (Ameskan n yiferdisen), «Aɣbalu n tvidyut» (seg lebni 15; uqbel, taqeffalt «Force original video» (Ḥettem tavidyut taṣlit)), wali [Talɣut n tvidyut d yidekuduren](#video-details-decoders-and-why-a-video-stutters).

## Ifuyla n uẓeṭṭa: NAS, aselkim neɣ aqeddac n yimidyaten

Tividyutin-ik 360° ha-tent ɣef NAS neɣ ɣef uselkim, u tebɣiḍ ad tent-twaliḍ ɣef tiliɣri neɣ deg tcacit war ma tneɣleḍ-tent qbel. Deg tcacit, imdanen nnulfan-d ad nɣlen yal afaylu s tenzeqt; iqeddacen n yimidyaten am Plex d Jellyfin qqaren tividyutin 360° d timsawin, akken i t-id-glemen yisuturen deg tdiwenniyin-nsen; asnas Immich yeqqar kan aqeddac-ik Immich.

Immuch360 yessnirim, yeqqar tiwlafin d tvidyutin n yal aqeddac i yemmeslayen s SMB (Samba, Windows), WebDAV neɣ, seg lebni 19, DLNA/UPnP (aqeddac n yimidyaten: Jellyfin, minidlna, Gerbera, Emby, NAS neɣ tanaka n TV), srid seg ufaylu yettwabḍan. Seg lebni 20 Plex Media Server yesɛa anaw-is, wali [Plex Media Server, war plex.tv](#plex-media-server-without-plextv).

Yettaf-d s yiman-is iqeddacen n uẓeṭṭa-k, yeqqar ifuyla srid deg yimeskanen-nni n usnas (360°, 3D, VR180, Spatial 2.5D, ameskan immersif n Quest), s uqeddac Immich neɣ war-s, ɣef tiliɣriyin d Meta Quest 3. Ulac ayen yettwasidren. Mi ara yili uqeddac yeqqnen, ifuyla i tefreneḍ zemren ad ttwaznen ɣer umiḍan-ik Immich (seg lebni 15).

### Rnu afaylu yettwabḍan

1. Ldi iccer Tamkarḍit, syin Ifuyla n uẓeṭṭa. Tikkelt tamezwarut, asebter yenna-d «Ulac ula d yiwen ufaylu yettwabḍan» s teqffalt «Rnu afaylu yettwabḍan»; + d asawen s ayeffus yexdem ayen-nni yal tikkelt. Seg lebni 20 i sin ttessteqsayen acu ara ternuḍ: «Afaylu n uẓeṭṭa (NAS, aselkim, aqeddac n yimidyaten)», «Plex Media Server» neɣ «Takamiṛat Tapo». Fren amezwaru.
2. Asebter «Rnu afaylu yettwabḍan» yettnadi qbel ɣef yiqeddacen n uẓeṭṭa-k, yessebded-iten ddaw «Yettwaf deg uẓeṭṭa», s wanaw-nsen (SMB, WebDAV, DLNA, Tiliɣri, u seg lebni 20 Plex d Tapo). Anadi yettawi alamma d sḍis n tsinin; «Nadi tikkelt nniḍen» ad t-yales. Yesseqdac Bonjour/mDNS akked usenqed n uẓeṭṭa adigan i d-yettwasentmen s umbadal n tidet SMB neɣ WebDAV, seg lebni 19 anadi SSDP ɣef yiqeddacen n yimidyaten DLNA, u seg lebni 20 GDM, anadi n Plex, d uneggaf n unadi n TP-Link i tkamiṛatin Tapo.
3. Sit ɣef uqeddac: anaw, aqeddac, tawwurt d ubrid ad ttwačaren. Aqeddac Plex neɣ takamiṛat Tapo yeldi deg wadeg-is asebter-is, yettwačaren yakan.
4. Ulac-it deg tebdart? Ččar tiferkit s ufus. Anaw: «SMB (Samba, beṭṭu n Windows)», «WebDAV (Nextcloud, Synology d wiyaḍ)», «Aqeddac n yimidyaten DLNA (Jellyfin, NAS, tanaka n TV)» neɣ, seg lebni 20, «Plex Media Server», i yeldin asebter n [Plex Media Server, war plex.tv](#plex-media-server-without-plextv). Syin Isem, «Isem neɣ tansa n uqeddac» (isem neɣ tansa; tansa tummidt am `smb://nas/photos`, `\\nas\photos` neɣ `https://nas:5006/photos` tettččar urtiyen nniḍen), «Tawwurt (d afrayan)» ma mačči d tin yezgan, «Afaylu yettwabḍan» i SMB neɣ «Abrid n tansa WebDAV» i WebDAV, «Akaram n tazwara (d afrayan)», «Isem n useqdac» d «Awal uffir», akked «Tuqqna taɣellsant (HTTPS)» i WebDAV.
5. SMB: mi ara turiḍ aqeddac d yisem n useqdac, «Fren afaylu yettwabḍan» yesskan-d ifuyla yettwabḍan n uqeddac.
6. DLNA: aqeddac n yimidyaten ur yesɛi ara isem n useqdac neɣ awal uffir. Efk-d aqeddac, tawwurt d «Abrid n uglam» n uglam n yibenk-is (`/rootDesc.xml` i minidlna), neɣ senṭeḍ tansa tummidt, am `http://192.168.1.10:8200/rootDesc.xml`, deg wurti n uqeddac.
7. Sit ɣef «Sekyed tuqqna». Yettarra-d «Yeqqen, N n yiferdisen deg ukaram n tazwara», neɣ yenna-d ayɣer ur yeddi ara. Syin sit ɣef Sekles, d akessar n tferkit.

Isem n useqdac s wawal uffir ilem yettwazen akken yella: Freebox Server yebɣa `freebox` war awal uffir i yiḍebsiyen-is. Akken ad tbeddleḍ neɣ ad tekkseḍ afaylu yettwabḍan ticki, seqdec akeryun ɣer tama-s deg usebter Ifuyla n uẓeṭṭa.

### Snirem u ɣer

1. Sit ɣef ufaylu yettwabḍan. Ikaramen d imezwura, syin tiwlafin d tvidyutin deg uẓeṭṭa s tugniwin timecṭuḥin (daɣen tugna seg yal tavidyut, tettwaḥraz deg tkatut n yibenk). Wid yettwassnen d 360° sɛan tacreḍt 360°, u seg lebni 19 tiwlafin d tvidyutin timennawin n Apple sɛant tacreḍt 3D. Zuɣer ɣer wadda akken ad tesmirreḍ.
2. Sit ɣef tewlaft: teldi ɣef ugdil akk (tuqqent n yiḍudan, asiti snat n tikkal), u taqeffalt-is 360° teldi ameskan n tsfirt.
3. Sit ɣef tvidyut: tettwaɣra deg umeɣri unṣib (urar, asteɛfu, anegzum), s teqffalt 360° i yeldin ameɣri 360° akked tqeffalin-is 3D d 360°/180°, u ɣef tiliɣri taqeffalt Spatial i yifuyla stiriyu.
4. Ɣef Quest, taqeffalt 360° teldi ameskan immersif, u seg lebni 19 «Wali s 3D» yeldi tawlaft tamennawt n Apple s 3D.
5. Umuɣ ⋮ yesɛa «Wali am 360°» i yifuyla war tabzimt 360°, u ɣef tiliɣri «Spatial 2.5D» i tvidyutin ur nelli d stiriyu.

360°, 3D d VR180 ttwassnen-d seg yisefka GPano neɣ yisefka n tsfirt n ufaylu, yettwaɣran s yisuturen n tegrumma (range requests), u VR180 daɣen seg yisem n ufaylu. Seg lebni 16 ifuyla RAW n Insta360 ttwassnen-d daɣen (tawlaft .insp s yisem-is neɣ s yiḥder n useggem n tkamirat, tavidyut .insv s yisem-is d tugna-s) u ttwasdukklen.

Seg lebni 15, mi ara tiliḍ teqqneḍ ɣer uqeddac:

1. Deg ukaram yettwabḍan, ḥettem aṭas ɣef tewlaft neɣ tvidyut, neɣ sit ɣef Fren d asawen s ayeffus.
2. Creḍ ayen tebɣiḍ, neɣ seqdec «Fren akk tugniwin d tvidyutin n ukaram-a».
3. Sit ɣef «Sali ɣer Immich». Ifuyla ttwaznen seg ufaylu yettwabḍan ɣer uqeddac-ik yiwen yiwen, s unnerni ɣef yal tamkarḍit tamecṭuḥt, d ufeggag d akessar i d-yeqqaren «Tuzna n 3 seg 12» s teqffalt Cancel (Sefsex). Eǧǧ asnas yeldi mi ara yettazen.
4. Ɣer tagara asnas yenna-d acḥal i yettwaznen d acḥal i yellan yakan ɣef uqeddac: aqeddac yeḥrez anɣal-is, yekkes isleɣ n yifuyla i yesɛa yakan. Ifuyla yettwaznen uqbel sɛan tacreḍt («Yettwazen ɣer Immich yakan») u ttwaǧǧan tikkelt i d-iteddun.

Tawlaft neɣ tavidyut yeldin seg ufaylu yettwabḍan tesɛa aferdis-nni deg wumuɣ-is. War aqeddac, asebter yenna-d «Qqen ɣer uqeddac Immich akken ad tessaliḍ». Tiwlafin d tvidyutin n yibenk ttwaznent s wudem-nni seg yiccer Tamkarḍit: On this device, albom, fren, «Sali ɣer Immich», ula d tid n yilbumen ur nelli deg ufran n uḥraz; mi ttwaznent, ttwaḥesbent d tid yettwaḥerzen.

### Amek i yettwaɣra war asider

Imeɣriyen ttɣaren ibiten i sran s tqentert daxel n usnas (tansa loopback kan, tajiṭunt n lmendad i yal tiɣimit, tigrummiwin n yibiten), ihi anegzum deg tvidyut yetteddu u ulac ayen yettwanɣalen ɣer yibenk. Imeɣriyen d umeskan n tcacit ur ttawin ara tansa n ufaylu yettwabḍan, ala 127.0.0.1 n tqentert; isuturen ɣer uqeddac d asnas s yiman-is i ten-yettazen.

I tɣuri yelhan, afaylu yettwabḍan yettwaɣra s yiḥedren imeqqranen, afaylu yeqqim yeldi gar tɣuriwin, alamma d 16 MB ttwaɣran send umeɣri, u tavidyut i yettwaɣran tettwaɣra s sḍis n tuqqniwin SMB akk ugar deg yiwen n wakud, mgal tuqqna i yettqeddacen tugniwin timecṭuḥin d tebdarin. Freebox Server yettarra-d s leɛtab i yal taɣuri: yiwet n tuqqna tettak-d 4,5 MB/s, sḍis ttakent-d 19 MB/s, aya yekfa i usifeḍ 5.7K s 132 Mbit/s.

Mi ara yettraǧu umeɣri isefka, imeɣriyen 360° d Spatial sskanayen-d «Asali» akked tačurt n tkatut-nsen n tɣuri; ameɣri amsawi yesskan-d «Asali» war afmiḍi mi ara tettali tvidyut neɣ teḥbes.

### Iqeddacen n yimidyaten DLNA

Seg lebni 19, asnas yettazen anadi SSDP ɣef yiqeddacen n yimidyaten ɣer ugraw multicast n uẓeṭṭa, akked yiwet n tuttra-nni ɣer tewwurt 1900 n yal tansa n uẓeṭṭa adigan /24, syin yeqqar aglam n yibenk n yal aqeddac i d-yerran, yeḥrez wid i d-yessuffuɣen agbur-nsen (ContentDirectory).

Ikaramen d yifuyla ttwabedren s tigawt Browse n uqeddac, asebter s usebter, u ttwasemman s yizwal-nsen: afaylu yettawi asiɣzef n wanaw-is ma yella azwel-is ur t-yesɛi ara, u afaylu wis sin s yiwen n uzwel deg ukaram yuɣal d `name (2)`. Ameslaw yettwakkes. Tugniwin timecṭuḥin d tiwlafin n yilbumen neɣ tugniwin timecṭuḥin i yexdem uqeddac, i d-yessalay usnas s yiman-is, s tugna tamecṭuḥt n usnas ma yella uqeddac ur tent-yesɛi ara. Afaylu yettwaɣra seg uṣli i d-yefka uqeddac, mačči seg unɣal yettwabeddlen ma yefka-d sin-nni, yettwaɣra s yisuturen n tegrumma, ihi anegzum yetteddu.

Yettwasenqed s minidlna d Gerbera; tagrut deg uẓeṭṭa n tidet, Plex, Jellyfin, NAS, Freebox Server, iPhone d Quest d asekyed ɣef yibenk n lebni 19.

<a id="a-share-that-moved"></a>
### Afaylu yettwabḍan i yettwasnkezen

Seg lebni 19, afaylu yettwabḍan DLNA d ufaylu yettwabḍan n tiliɣri (wali [Bḍu tiliɣri-a deg uẓeṭṭa](#share-this-phone-on-the-network)) ḥerzen asulay i d-yebcer uqeddac-nsen. Mi ara yili yiwen ur d-yettarra ara deg tansa-s (tansa tamaynut i d-yefka umsefrak, aqeddac yulsen ad yekker ɣef tewwurt nniḍen), asebter n ukaram-is yesskan-d «Anadi ɣef (isem) deg uẓeṭṭa» u yessenkaz afaylu yettwabḍan ɣer wanda i d-yettarra tura: imir-n i uqeddac DLNA, ur nesɛi awal uffir, u deffir usentem, «Seqdec tansa tamaynut?», i d-yesskanayen snat n tansiwin, i ufaylu yettwabḍan s yisem n useqdac d wawal uffir, acku ad ttwaznen ɣer tansa tamaynut.

Seg lebni 20 aqeddac Plex i d-yettwafen tikkelt nniḍen deg tansa nniḍen n uẓeṭṭa yettwasenkaz daɣen imir-n: aselkin-is yesbegginay d netta s yiman-is uqbel ad yettwazen ujuṭu. Takamiṛat Tapo yettwanadi s tansa-s MAC seg usebter-is, wali [Tikamiṛatin Tapo](#tapo-cameras-live-view-and-the-recordings-of-the-memory-card).

### Tilisa

- **SMB**: SMB 2 d 3 kan, mačči SMB 1.
- **WebDAV**: asesteb Basic kan (Digest ur yettwasefrak ara yakan); aselkin HTTPS yezmlen s yiman-is ilaq ad yettwasbedd ɣef yibenk.
- **Anadi ɣef yiqeddacen**: asenqed n uẓeṭṭa d yinadiyen DLNA, Plex d Tapo ttmuqulen kan aẓeṭṭa adigan /24, u sran tasiregt n uẓeṭṭa adigan ɣef iOS. Ɣef iPhone d iPad, anadi DLNA yettazen kan isuturen unicast, alamma Apple yefka-d i usnas azref multicast (entitlement), u kra n yiqeddacen ur d-ttarran ara fell-asen (minidlna ɣef Linux): rnu-ten s tansa n uglam-nsen.
- **DLNA**: aqeddac i d-yettaken kan anɣal yettwabeddlen n ufaylu ad d-yefk anɣal-nni; akaram yesskan-d 20 000 n yiferdisen akk ugar.
- **Tugniwin timecṭuḥin**: tugniwin timecṭuḥin n tewlafin ttɣaren afaylu akk, u tiwlafin yugaren 30 MB ur sɛint ara tugna tamecṭuḥt.
- **Imeɣriyen**: afran n ubrid n umeslaw ulac-it yakan deg umeɣri amsawi. Ɣef tiliɣri ulac yakan azuɣer seg ufaylu n ukaram ɣer win i d-iteddun (ameskan immersif n Quest yesɛa uzwir d uḍfir i yifuyla 360° n ukaram). Afran 3D neɣ 180° i yettwaxedmen ɣef ufaylu n uẓeṭṭa ur yettwaḥraz ara.
- **Asali**: yetteddu kan mi ara yili usnas yeldi, u afaylu i yesɛa yakan uqeddac yettwazen akk send ad t-id-yini uqeddac d isleɣ.

## Plex Media Server, war plex.tv

Tividyutin-ik llant deg Plex, u Plex yesskanay-d tiwlafin d tvidyutin-ik 360° d timsawin, akken i d-glemen yisuturen deg tdiwenniyt-is (yiwen yeldi seg 2017). Tebɣiḍ daɣen tamkarḍit-nni deg tcacit, ɣef tiliẓri d beṛṛa n uxxam. Asnas Immich yeqqar kan aqeddac-ik Immich, u anaw DLNA n lebni 19 yettaweḍ kan ɣer tama DLNA n Plex deg uxxam.

Seg lebni 20 Immuch360 yettuqqen srid ɣer Plex Media Server-ik, war plex.tv: yettaf-d aqeddac deg uẓeṭṭa, tsenṭḍeḍ ajuṭu yiwet n tikkelt, u asnas yeqqar srid ifuyla iṣliyen n temkarḍiyin-ik, deg yal ameskan n usnas (360°, 3D, VR180, Spatial 2.5D, ameskan immersif n Quest, tilikumand n tiliẓri), deg uxxam u, s usmelleɣ n tewwurt, beṛṛa n uxxam. Ulac ayen yettwaneɣlen, u ifuyla i tefreneḍ zemren ad ttwaznen ɣer Immich.

### Rnu aqeddac Plex

1. Ldi iccer Tamkarḍit, syin Ifuyla n uẓeṭṭa, syin + d «Plex Media Server». Anaw «Plex Media Server» n tferkit n beṭṭu, d uqeddac s tecraḍt Plex ddaw «Yettwaf deg uẓeṭṭa», ldin asebter-nni.
2. Asebter «Rnu aqeddac Plex» yettnadi iqeddacen Plex n uẓeṭṭa-k («Anadi n yiqeddacen Plex deg uẓeṭṭa-k») u yessebded-iten ddaw «Yettwaf deg uẓeṭṭa». Sit ɣef win-ik: takarḍa tesskanay-d isem-is, lqem-is Plex d usulay awezlan.
3. Ulac-it deg tebdart? Aru «Tansa n uqeddac», am `192.168.1.20`, `192.168.1.20:32400` neɣ `https://...plex.direct:32400`, syin sit ɣef «Nadi». Asnas yeqqar aselkin n uqeddac u ur yettazen kra nniḍen.
4. Awi-d ajuṭu, ɣef uselkim: ldi Plex deg yiminig web u qqen, ldi yal tawlaft neɣ tavidyut n temkarḍit-ik, syin «...», «Get Info», «View XML». Iccer amaynut yeldi ɣef tansa i yekfan s `X-Plex-Token=...`. Nɣel tansa-nni akk.
5. Senṭeḍ-tt deg «Ajuṭu n unekcum», neɣ azen-tt ɣer tiliɣri u sit ɣef «Senṭeḍ seg tecfawt»: asnas yettawi seg-s aqeddac d ujuṭu. Aḍris deffir `X-Plex-Token=` iman-is yetteddu daɣen. «Amek ara t-tawiḍ», deg usebter, yenna-d ayen-nni; inedbalen n uqeddac zemren daɣen ad sseqdacen azal `PlexOnlineToken` n ufaylu `Preferences.xml` n uqeddac, ur nettfakka ara. Ɣef tiliẓri, OK yeldi adiwenni n unasiw: aru dinna ajuṭu (s umata d 20 n yisekkilen).
6. Sit ɣef «Sekyed tuqqna». Ad d-yerr «Yeqqen: N n temkarḍiyin», neɣ ad d-yini acu ur neddi ara, am «Aqeddac Plex yugi ajuṭu-a.»
7. «Anekcum seg beṛṛa n uxxam» yesskanay-d syin ayen i d-yenna uqeddac: «Aqeddac yenna-d yezmer ad yettwaweḍ deg (tansa):(tawwurt).», neɣ «Aqeddac ur d-yenni ara tansa-s beṛṛa n uxxam.» Akken ad tesseqdceḍ aqeddac beṛṛa n uxxam, aru tansa-k tazayezt neɣ isem-ik DynDNS deg «Tansa beṛṛa n uxxam (IP neɣ isem)», d tewwurt yettwasmellɣen deg Plex (Iɣewwaren, Anekcum s yimen) deg «Tawwurt beṛṛa n uxxam». Ayen i tettaruḍ yezwar yal tikkelt ɣef wayen i d-yenna uqeddac.
8. «Isem» d isem n uqeddac ma yella ur t-tbeddleḍ ara, u «Akaram n tazwara (d afrayan)» yezmer ad yeldi srid yiwet n temkarḍit. Sit ɣef Save (Sekles). Aqeddac yettban-d d yifuyla yettwabḍan, am `plex://` d tansa-s.

### Snirem timkarḍiyin-ik Plex

1. Sit ɣef uqeddac deg Ifuyla n uẓeṭṭa. Aswir amezwaru yessebded timkarḍiyin i d-yesskanay usnas: tiwlafin, isaragen d tvidyutin nniḍen, tisɣunin n TV. Aẓawan ur d-yettban ara.
2. Ddaw temkarḍit d ikaramen-is akken llan ɣef uḍebsi n uqeddac (askan «s ukaram» n Plex), syin tiwlafin d tvidyutin s yismawen n yifuyla-nsent, s tugniwin timecṭuḥin i d-yexdem Plex. Tamkarḍit n tewlafin ur d-nettarra ara deg uskan s ukaram tesskanay-d deg wadeg-is ilbumen-is.
3. 360° d 3D ttwassnen s tɣuri n yifuyla s yiman-nsen, am deg yal afaylu yettwabḍan: tiwlafin 360° ttawint tabzimt 360°, tiwlafin timennawin n Apple tabzimt 3D.
4. Ldi tawlaft neɣ tavidyut am deg yal afaylu yettwabḍan: 360°, 3D, 360°/180°, Spatial 2.5D ɣef tiliɣri, ameskan immersif deg Quest, tilikumand ɣef tiliẓri. Tavidyut tettwaɣer am ufaylu aṣli, s tegrumma n yibiten s tqentert tadigant n usnas, ihi anegzum yetteddu u isfka-s 360° d 3D ttawḍen ɣer yimeɣriyen akken llan.
5. Fren ifuyla u sit ɣef «Sali ɣer Immich» akken ad ten-tazneḍ ɣer uqeddac-ik, am seg yal afaylu yettwabḍan (wali [Azen ifuyla n ufaylu yettwabḍan ɣer Immich](#send-files-of-a-share-to-immich)).

### Beṛṛa n uxxam

Yal tikkelt ara yeldi aqeddac, asnas yettɛaraḍ qbel tansa n uxxam u, 400 ms deffir, tansa beṛṛa n uxxam. Tin d-yerran tazwara s uqeddac-ik d tin ara yettwasqedcen; mi ara tili d tansa beṛṛa n uxxam, asebter n ukaram yesskanay-d tignit n umaḍal s tecraḍt «Yeqqen s tansa beṛṛa n uxxam».

Ayagi yesra Anekcum s yimen yermed deg Plex (Iɣewwaren, Anekcum s yimen) s tewwurt yettwasmellɣen sɣur tanaka-k: war plex.tv asnas ur yezmir ara ad yesseqdec relay n Plex, ihi aqeddac war asmelleɣ n tewwurt yettaldi kan deg uxxam, u beṛṛa n uxxam asebter ad d-yini «Aqeddac-ik Plex ur yettwaweḍ ara seg beṛṛa n uẓeṭṭa n uxxam. Rmed anekcum s yimen s usmelleɣ n tewwurt deg Plex (Iɣewwaren, Anekcum s yimen), neɣ aru tansa-s tazayezt.»

Tansa i d-yenna uqeddac tettwalmed tikkelt nniḍen yal tuqqna deg uxxam. Mi ara tili ur d-tettarra ara seg beṛṛa (tanaka i yettbeddilen tansa, sin n yimsefrak wa deffir wa), aru tin-ik deg usebter n uqeddac. Mi ara yeḥbes ujuṭu (amedya teffɣeḍ seg tɣimit n yiminig ansi i t-tneɣleḍ), asebter n ukaram ad t-id-yini u ad d-yessumer «Senṭeḍ ajuṭu amaynut», i yeldin asebter n uqeddac ɣef wurti n ujuṭu.

### Asemyaser d Plex d unaw DLNA

- **Ifuyla iṣliyen**: asnas yeqqar ifuyla s yiman-nsen, werǧin anɣal yettwabeddlen sɣur Plex, ihi isfka 360°, 3D d VR180 qqimen akken llan u imeskanen n usnas sseqdacen-ten, ma d isnasen n Plex sskanayen-d ifuyla-a d imsawin.
- **War plex.tv**: asnas yemmeslay kan d uqeddac-ik, yal tikkelt s HTTPS. Aqeddac yettwasenqed s uselkin-is plex.direct, yeqqnen ɣer usulay n uqeddac, uqbel ad yettwazen ujuṭu. Ajuṭu yeqqim deg yibenk, deg uḥraz-is aɣellsan, u yettwazen kan ɣer uqeddac-ik, deg uqerru n usuter.
- **Ma nserwes d tmerna n uqeddac-nni am DLNA**: ikaramen akken llan ɣef uḍebsi, tugniwin timecṭuḥin n Plex, anekcum seg beṛṛa n uxxam d tuqqna taɣellsant.

### Tilisa

- **Iqeddacen yettwasutren kan**: aqeddac ilaq ad yettwasuter deg Plex (yeqqen yiwet n tikkelt ɣer umiḍan Plex), ayen i s-yettaken aselkin-is plex.direct. Ma ulac, asebter ad d-yini «Tansa-a d-terra war aselkin Plex. Ssuter aqeddac deg Plex, neɣ rnu-t am ufaylu SMB, WebDAV neɣ DLNA.»
- **IPv4 kan**: «Tansiwin IPv6 ur ttwasefraknt ara yakan. Aru tansa IPv4 n uqeddac.»
- **Ajuṭu** yettak anekcum ummid ɣer uqeddac-ik Plex. Tukksa n uqeddac deg usnas tettu ajuṭu deg yibenk maca ur t-teffeɣ ara: «Ajuṭu ad yeqqim d ameɣtu deg uqeddac alamma teffɣeḍ seg tɣimit n yiminig ansi i t-tneɣleḍ.» Ajuṭu s wass n taggara yesskanay-d azemz-nni, u asnas ur yezmir ara ad t-yesmaynut.
- **Beṛṛa n uxxam**: s usmelleɣ n tewwurt kan, ulac relay.
- **Timkarḍiyin**: aẓawan ur d-yettban ara, akaram yessebded 20 000 n yiferdisen ma yella aṭas, u aseqdac yettwaḥeddren yezmer ad yaweḍ ɣer «Ajuṭu-a ur yezmir ara ad iɣer timkarḍiyin n uqeddac.»
- **Ifuyla RAW n tkamiratin 360°** (.insv, .insp, .360, .osv) ttbanen-d kan ma yessebded-iten Plex; neɣ rnu akaram-nni n NAS am ufaylu yettwabḍan SMB neɣ WebDAV, wali [Ifuyla RAW n tkamiratin 360°](#raw-360-camera-files-without-the-cameras-app).
- **Tifin n uqeddac**: aqeddac anda yensa uɣewwar «Enable local network discovery (GDM)» ur yettwaf ara, ihi aru tansa-s. Ɣef iPhone d iPad anadi yettazen kan isuturen unicast. Tama DLNA n uqeddac-nni tezmer daɣen ad d-tban deg tebdart, s tecraḍt DLNA: fren izirig s tecraḍt Plex.
- **Ur yettwasenqed ara yakan ɣef yibenk**: tuqqna, ikaramen, tigrumma n yibiten n tvidyut, tugniwin timecṭuḥin, ajuṭu ur nṣeḥḥa ara d tansa beṛṛa n uxxam ttwasenqden seg uselkim ɣef Plex Media Server 1.42.1 n tidet, u timkarḍiyin n tewlafin d tisɣunin n TV ɣef uqeddac yettwasemrasen kan. Taɣuri ɣef tiliɣri, deg Quest, ɣef iPhone d tiliẓri, d usenfel ɣer tansa beṛṛa n uxxam, d asekyed ɣef yibenk n lebni 20.
- Immuch360 ur yeqqin ara ɣer Plex.

## Bḍu tiliɣri-a deg uẓeṭṭa

Tiwlafin d tvidyutin-ik ha-tent ɣef tiliɣri, u tebɣiḍ ad tent-twaliḍ deg tcacit, war aselkim, war NAS, war aqeddac Immich. Seg lebni 19, tiliɣri, Android neɣ iPhone, tettqeddic tiwlafin d tvidyutin-is deg Wi-Fi, u Meta Quest yeqqar-itent. Asnas Immich ur yesɛi ara ayen yecban aya.

### Rmed-it, ɣef tiliɣri

1. Ldi iccer Tamkarḍit, syin Ifuyla n uẓeṭṭa. Tamkarḍit tamecṭuḥt tamezwarut d «Bḍu tiliɣri-a deg uẓeṭṭa» (tenna-d «Yensa», neɣ «Yermed» s tansa).
2. Sit fell-as, syin rmed «Bḍu tiwlafin d tvidyutin deg Wi-Fi». Asnas yessuter tasiregt n tewlafin d tvidyutin ma ulac-itt, u ɣef Android 13 d wayen d-yernan tasiregt n yilɣa.
3. Asebter yesskan-d Tansa (am `http://192.168.1.20:8360`: tawwurt 8360, neɣ tayeḍ tilellit ma tettwaṭṭef), isem s wacu i d-tettwabeccer tiliɣri («Immuch360 on» d yisem n tiliɣri), Isem n useqdac (`phone` d ukkuẓ n wuṭṭunen) d Awal uffir (tam n yisekkilen), yal yiwen s teqffalt n unɣal, syin «N n yibenkan yeqqnen» (ibenkan i t-iseqdacen deg tesdat taneggarut) akked ufaylu aneggaru i yettwaqeddcen.

Isem n useqdac d wawal uffir ttwaxedmen yiwet n tikkelt u ttwaḥerzen, ihi tacacit teḥrez afaylu-ines yettwabḍan yettwaskelsen; «Awal uffir amaynut» ibeddel awal uffir. Tamkarḍit-a tamecṭuḥt ur d-tettban ara deg tcacit.

### Ldi-t, deg tcacit

1. Deg tcacit, ldi Tamkarḍit, Ifuyla n uẓeṭṭa, syin +.
2. Ddaw «Yettwaf deg uẓeṭṭa», sit ɣef tiliɣri: isem n useqdac ad yettwačar.
3. Aru awal uffir yiwet n tikkelt (tallunin d yisekkilen imeqqranen ur ccaḍen ara), syin Sekles.

Seg tama-nni, d afaylu yettwabḍan WebDAV am wiyaḍ: tagrut n 360°, ifuyla RAW, ameskan immersif, anegzum deg tvidyutin. Yal amsaɣ WebDAV n uẓeṭṭa yezmer daɣen ad t-yeɣr. Mi ara tawi tiliɣri tansa nniḍen, tacacit tettnadi fell-as u tessaqsay send ad tesseqdec tansa tamaynut (wali [Afaylu yettwabḍan i yettwasnkezen](#a-share-that-moved)).

### Ayen i yettqeddic, d acḥal n wakud

- **Ikaramen**, i tɣuri kan: `Albums` (yal albom n tiliɣri), `By month` (yal tawlaft d yal tavidyut s wayyur, tamaynut d tamezwarut) d `360` (tiwlafin d tvidyutin 360° i yufa usnas ɣef tiliɣri, ula d ifuyla RAW d wid i twalaḍ am 360°). Ifuyla ḥerzen ismawen-nsen. Ɣef iPhone, tawlaft tudrigt (Live Photo) tettak-d tugna-s tusbiḍt, tawlaft neɣ tavidyut yettwaẓergen tettak-d lqem-is yettwaẓergen, u ayen yettwaḥerzen kan deg iCloud yettwakkes.
- **Android**: beṭṭu yetteddu deg tenfa n uɣawas amezwaru s walɣu (tansa d yisem n useqdac) d teqffalt Seḥbes, u yeǧǧa Wi-Fi d ukalkul ur ṭṭsen ara, ihi ad ikemmel ula s ugdil yensan. Azuɣer n usnas akken ad yemdel ad t-iḥbes.
- **iPhone d iPad**: iOS ur yettak ara akud n ugilal i uqeddac, ihi beṭṭu yetteddu kan mi ara yili usnas sdat, u agdil yeqqim yermed mgal aya. Yesteɛfay mi ara iruḥ usnas ɣer ugilal, u ad d-yuɣal, s yiwet n tansa d yiwen wawal uffir, mi ara d-tuɣaleḍ.
- **Melmi ara yeḥbes**: s tqeffalt n uskar, s Seḥbes, deffir 60 n tesdatin war ula d yiwet n tuttra, u mi ara yemdel usnas. Ur yettbeddu ara s yiman-is: yensa yal tikkelt ara yekker usnas.
- **Taɣellist**: aẓeṭṭa adigan kan. Beṭṭu yesseflid kan ɣef tansiwin Wi-Fi, Ethernet d ataxxam n tuqqna n tiliɣri, werǧin ɣef tansa n yisefka n uziraz neɣ VPN, u yettarra-d kan i yibenkan s tansa tadigant. Yal tuttra tesra isem n useqdac d wawal uffir (HTTP Basic); mraw n wawalen uffiren n tuccḍa seg yiwen n yibenk deg tesdat ad t-sḥebsen i tesdat. Awal uffir yettɛeddi war awgelhen deg Wi-Fi (HTTP amagnu): seqdec beṭṭu deg uẓeṭṭa i tumneḍ, u sens-it mi ara tfakkeḍ.
- **Ataxxam n tuqqna n tiliɣri s yiman-is**: tacacit tezmer ad teqqen ɣur-s; ma ur tufi ara tiliɣri dinna, aru tansa i d-yettbanen ɣef usebter.
- **Ur yettwasenqed ara yakan ɣef yibenk**: aqeddac yettwasenqed s yisekyaden n tyunin d yisekyaden seg yixef ɣer yixef s umsaɣ WebDAV d tqentert n yimidyaten n tcacit s yiman-is, ɣef uselkim. Tiliɣri i yettqeddicen Quest 3 (tagrut, tavidyut n 4 GB yettwaɣran u yettwanegzen, agdil yensa 30 n tesdatin, ataxxam n tuqqna, Seḥbes seg walɣu) akked tama n iPhone, ur nteddu ara yakan ɣef iPhone, d asekyed ɣef yibenk n lebni 19.

## Tikamiṛatin Tapo: tamuɣli tusridt d yiseklasen n tkarḍa n tkatut

Tesɛiḍ tikamiṛatin Tapo deg uxxam, u tebɣiḍ ad twaliḍ takamiṛat n tebḥirt d tvidyutin n yiḍ yezrin ɣer tama n tewlafin-ik war ma teldiḍ asnas Tapo, u ad tḥerzeḍ tavidyut deg Immich. Asnas Immich ur yesɛi acemma i tkamiṛatin, u asnas Tapo d asnas nniḍen, yeqqnen ɣer umiḍan-ik TP-Link, s tvidyutin weḥd-sent, beɛdent ɣef tewlafin-ik.

Seg lebni 20 Immuch360 yettarnu takamiṛat Tapo ɣer tama n yifuyla n uẓeṭṭa. Yesskanay-d takamiṛat srid ɣef tiliɣriyin d ttablit Android, Android TV d Meta Quest, u ɣef yal tiɣerɣert iseklasen n tkarḍa-s n tkatut, ass s wass: tavidyut tettwawi-d seg tkamiṛat, syin tettwaɣer am yal tavidyut u tezmer ad tettwazen ɣer Immich. Asnas yemmeslay d tkamiṛat deg uẓeṭṭa-k kan, werǧin d yiqeddacen n TP-Link, u werǧin ibeddel kra ɣef tkamiṛat.

### Rnu takamiṛat

1. Deg usnas Tapo qbel: snulfu-d amiḍan n tkamiṛat, deg yiɣewwaren n tkamiṛat, Iɣewwaren leqqayen, Amiḍan n tkamiṛat (isem n useqdac d wawal uffir i tkamiṛat-a, i tmuɣli tusridt), u rmed Amṣada d wis kraḍ, ddaw Nekk, syen Tapo Lab.
2. Deg Immuch360, ldi iccer Tamkarḍit, syin Ifuyla n uẓeṭṭa, syin + d «Takamiṛat Tapo».
3. Asebter «Rnu takamiṛat» yettnadi tikamiṛatin («Anadi n tkamiṛatin Tapo deg uẓeṭṭa-k») u yessebded-itent ddaw «Yettwaf deg uẓeṭṭa» s tecraḍt Tapo. Sit ɣef tin-ik akken ad yettwačar «Tansa n tkamiṛat», neɣ aru tansa-s. Takamiṛat s tecraḍt Tapo deg tferkit n beṭṭu teldi asebter-nni.
4. «Isem»: amek ara d-tban tkamiṛat deg tebdart.
5. Ddaw «Iseklasen ɣef tkarḍa n tkatut», «Awal uffir n umiḍan TP-Link»: awal uffir n umiḍan i tesseqdaceḍ deg usnas Tapo. Yettaldi iseklasen; tansa-k imayl ur tettwasra ara.
6. Ddaw «Srid», «Isem n useqdac n umiḍan n tkamiṛat» d «Awal uffir n umiḍan n tkamiṛat»: amiḍan n tkamiṛat n tikli 1.
7. Yiwen seg sin yekfa («Sekcem awal uffir n umiḍan TP-Link, amiḍan n tkamiṛat, neɣ i sin.»): awal uffir TP-Link iman-is yettak iseklasen, amiḍan n tkamiṛat iman-is yettak tamuɣli tusridt.
8. Sit ɣef «Sekyed takamiṛat». Ad d-tesskan «Iseklasen: (tamudemt), firmware (lqem)» s waddad n tkarḍa n tkatut, d «Tamuɣli tusridt: (tavidyut), ameslaw (ameslaw)», neɣ ayen ur neddi ara i yal yiwen.
9. Sit ɣef Save (Sekles). Takamiṛat tettban-d ddaw «Tikamiṛatin», deffir yifuyla yettwabḍan, s tmudemt-is mi ara tettwassen d `tapo://` s tansa-s.

### Wali-tt srid

1. Sit ɣef tkamiṛat. Tamuɣli-s tusridt tella deg ufella n usebter-is: «Tuqqna ɣer tkamiṛat», syin tugna s tebzimt «Srid».
2. Tiqeffalin ɣef tugna: ameslaw, yensa deg tazwara («Rmed ameslaw»; «Ulac ameslaw deg yibenk-a» mi ara yili yibenk ur yezmir ara ad t-yeɣr), SD neɣ HD, d «Agdil ačuran».
3. Tiliɣri tesskanay-d SD deg usebter d HD deg ugdil ačuran; Quest yesskanay-d HD. Tuɣalin teffeɣ qbel seg ugdil ačuran.
4. Ddaw tugna d tamudemt d firmware d tkarḍa n tkatut, am «Takarḍa n tkatut: (yettwasqedcen) yettwasqedcen seg (akk)» neɣ «Ulac takarḍa n tkatut».

Ɣef iPhone d iPad tamuɣli tusridt tenna-d «Tamuɣli tusridt ad d-tas ɣer iPhone d iPad deg lqem ara d-yasen. Iseklasen ttwaɣran dagi yakan.» War amiḍan n tkamiṛat asebter yenna-d «Rnu amiḍan n tkamiṛat akken ad twaliḍ tamuɣli tusridt.»

### Ɣer u ḥrez iseklasen

1. Ddaw «Iseklasen ɣef tkarḍa n tkatut», asebter n tkamiṛat yessebded ussan yesɛan iseklasen, amaynut d amezwaru, s wayyur. War awal uffir n umiḍan TP-Link ad d-yini «Rnu awal uffir n umiḍan TP-Link akken ad twaliḍ iseklasen.»
2. Sit ɣef wass. Tividyutin-is ttbanent-d ddaw isragen n wakud n tkamiṛat s yiman-is, yal yiwet s tazwara-s, teɣzi-s, tugna tamecṭuḥt n tkamiṛat i tedyant, d wanaw-is: Amussu, Amdan, Aɣersiw n uxxam, Takeṛṛust, Imeṭṭawen n llufan, Aɣersiw, Ur yettḥebbis ara neɣ Tadyant.
3. Sit ɣef tvidyut. Asnas yettawi-tt-id seg tkamiṛat («Tavidyut tettwawi-d seg tkamiṛat: N%», s Cancel (Sefsex)), syin yeqqar-itt deg umeɣri n tvidyut, s umeslaw d unegzum. Tavidyut i d-yettwawin tesɛa «Deg yibenk-a» u tettaldi imir-n tikkelt i d-iteddun.
4. Akken ad tḥerzeḍ tavidyut deg Immich, s uqeddac yeqqnen: umuɣ ⋮ n tvidyut, «Sali ɣer Immich».
5. Akken ad tserrḥeḍ i tallunt: asiti aɣezfan ɣef tvidyut i d-yettwawin yessumer «Kkes anɣel deg yibenk-a» (ɣef tiliɣri), u asebter n tkamiṛat yesɛa «Kkes tividyutin i d-yettwawwin seg tkamiṛat-a», s teɣzi-nsent.
6. Taqeffalt n usmiren d asawen s ayeffus, neɣ ajbad n usebter ɣer wadda, ad yessteqsi takamiṛat tikkelt nniḍen.

Mi ara tili tkamiṛat ur d-tettarra ara deg tansa-s, asebter-is yettnadi-tt deg uẓeṭṭa s tansa-s MAC u yessenkaz-itt ɣer wanda i d-tettarra tura, mi ara d-tesskan aselkin-nni. Takamiṛat i d-yesskanayen aselkin nniḍen ur nelli d win i yeẓra usnas tikkelt tamezwarut ad d-tawi asteqsi deg wadeg-is: «Takamiṛat deg (tansa) tesskanay aselkin nniḍen ur nelli d win n yiḍelli. Kemmel kan ma telseḍ-tt-id neɣ tbeddleḍ-tt.»

## Ifuyla RAW n tkamiratin 360°, war asnas n tkamirat

Tikamiratin Insta360 skelsent snat n tewwurin fisheye n tlentilin-nsent, rrif ɣer rrif deg yiwet n tugna, deg sin n yibriden neɣ deg sin n yifuyla (.insp d JPEG, .insv d MP4), u abrid unṣib akken ad d-tekkseḍ tugna 360° seg-sen d asnas Insta360 neɣ Studio. Wid yesɛan X4, X5, X6, GoPro MAX neɣ DJI Osmo 360 ttsaqsayen d acu ara xedmen s yifuyla RAW n tkarḍa-nsen. Asnas web n Immich yettwali yal .insp d tugna equirectangular u yessezzay snat n tewwurin i tsfirt; asnas aziraz yesskanay-iten d imsawin.

Seg lebni 16 Immuch360 yessdukkul ifuyla-a s yiman-is, ɣef tiliɣri, ɣef ttablit neɣ deg tcacit, war ma tesbeddeḍ kra ɣef uqeddac:

- **Tiwlafin Insta360 .insp** (lebni 16): ttwasdukklent ɣef GPU send ameskan n tsfirt, alamma d 8192x4096, s tufrut ɣef CPU s tiddi tamecṭuḥt ugar.
- **Tividyutin Insta360 .insv i yeḥerzen snat n tlentilin deg yiwen ubrid** (lebni 16): ttwasdukklent s usemdu GPU deg umeɣri.
- **Tividyutin Insta360 X4, X4 Air, X5 d X6 .insv, abrid amkuẓ i yal talentilt** (lebni 18): sin n yidekuduren deg yiwet n tikkelt, yiwen i yal talentilt, d umsuddes GPU i ten-yessdukkulen deg tsfirt.
- **Insta360 X3 d tid yezwaren s 5.7K d wayen yugaren: sin n yifuyla, `_00_` d `_10_`** (lebni 18): akken kan, afaylu wis sin yettwaf ɣer tama n umezwaru.
- **GoPro MAX d MAX 2 .360: sin n yibriden, kraḍ n wudmawen n ugeẓum i yal yiwen** (lebni 18): akken kan, s tgejdiyin yemyagaren yettwasdukklen.
- **DJI Osmo 360 .osv: sin n yibriden imkuẓen s 10 bit** (lebni 18): akken kan, s useggem Kannala-Brandt n ufaylu.
- **.dng s snat n tiṭṭawin fisheye** (mazal): tettban-d d tamsawit.

### Wali afaylu RAW

1. Sers ifuyla RAW anda ten-yeqqar usnas: tamidelt n yibenk s yiman-is (yettwanɣel seg tkarḍa n tkamirat), aqeddac-ik Immich (yeqbel .insp d .insv, yugi .360 d .osv), afaylu yettwabḍan SMB neɣ WebDAV, u seg lebni 19 afaylu yettwabḍan n tiliɣri d yiqeddacen DLNA i d-yesskanayen ifuyla-a (ur yettwasenqed ara yakan).
2. Ḥrez sin n yifuyla n tyugit X3 akken: asnas yettnadi afaylu wis sin ɣer tama n umezwaru, ɣef yibenk, ɣef uqeddac neɣ deg ukaram yettwabḍan. Ma ulac wis sin, asnas yenna-d «Asekles-a yebḍa ɣef sin yifuyla, yiwen i yal talentilt, ur d-yettwaf ara (isem) ɣer tama-s», u yessumer ad ttwaḥerzen sin n yifuyla akken neɣ ad tettwasifeḍ tvidyut seg usnas n tkamirat.
3. Ldi afaylu u sit ɣef 360°. Ifuyla RAW sɛan taqeffalt 360°, tiwlafin RAW tacreḍt 360°. Seg lebni 18 ifuyla RAW n Insta360 n uqeddac llan daɣen deg tebdart 360°, ttwafen-d s yisem-nsen.
4. Tawlaft teldi deg umeskan n tsfirt s tcreḍt d akessar: «Afaylu 360° RAW, yettwasdukkel s usnas», d uɣbalu n useggem: «aseggem n tlentilin yettwaɣran seg ufaylu», «aseggem n tlentilin n tkamirat-nni» (yettwaḥerzen seg ufaylu nniḍen n tkamirat-nni, s wuṭṭun-is n umazrar, neɣ s tmudemt-is i ufaylu i d-yebder kan tamudemt-is), neɣ «azalen imezwura n tlentilin, tuqqniwin zemrent ad d-banent» (azalen n X3, mi ara yili ulac ugar).
5. Tavidyut teldi deg umeɣri 360° unṣib u tettwasdukkel mi ara tettwaɣra. Tiqeffalin-is 3D d 360°/180° ffrent, acku tavidyut RAW d yiwet n tsfirt tummidt. Imeɣriyen n tvidyut d tcacit ur sskanayen ula d yiwet n tcreḍt.
6. Deg tcacit, ameskan immersif yettawi tugna tuskirt yettwasdukklen i tewlaft, d usemdu GPU-nni n tiliɣri i tvidyut. Ulac yakan amatar n unnerni mi ara tettwahyya tewlaft RAW.
7. Ma tugna teldi s yiwet n tnila yessewhamen (tawlaft yettwaṭṭfen s tkamirat yeṭṭsen, amedya), zuɣer-itt ɣef tiliɣri, neɣ zzi-tt deg tcacit s ujenṭaḍ ayeffus neɣ s tqeffalt Zzi.

### Mi ara yili yibenk ur yezmir ara ad yeɣr snat n tlentilin

Send ad yeɣr tavidyut s snat n tlentilin, asnas yessaqsay ibenk ma yezmer ad yesseddu sin n yidekuduren s tiddi-nni d urured-nni, u tiliɣri tettɛelim «Tavidyut-a RAW tesra sin yidekuduren n tvidyut (tiddi) deg yiwet n tikkelt: ahat ur tettɣimi ara s leεqel ɣef yibenk-a» ma d ala i d tiririt. Mi ara yili yidekuduren ur zmiren ara ad teddun (snat n tlentilin H.264 n 2880x2880 ɣef Quest 3, amedya), asnas yeqqar yiwet n talentilt u yenna-t-id, azgen n tsfirt yeqqim d aberkan, syin tavidyut yettwabeddlen n uqeddac ma tella. Ma yella usemdu GPU ur yezmir ara ad yeddu ɣef yibenk, tavidyut tettwaɣra war asdukkel, snat n tewwurin ɣef tsfirt, s «Asdukkel 360° ur yeddi ara ɣef yibenk-a».

Seg lebni 19, ɣef Android d Quest:

- **Ulac adekudur n warrum** i ukudik (amserwes, tanaka n TV): ibenk yettawi idekuduren iseɣzanen, i yettḥeddid usenqed ɣer 2048x2048 i yal talentilt mi ara teddun sin deg yiwet n tikkelt.
- **Talentilt ur yezmir ara yibenk ad tt-yeɣr akk** (ulac adekudur i ukudik-is, neɣ ulac win i d-yebdren amaɣnu-ines) tettɛeddi aswir n yiwet n talentilt, ɣer tvidyut yettwabeddlen n uqeddac neɣ, ma ulac, ɣer uṣli war asdukkel deg umeɣri amagnu, s yizen n umeɣri-nni.
- **Talentilt yettwarmen ɣas tettwagi tiddi-s neɣ arured-is** tesskanay-d izen n yiwet n talentilt kan mi ara d-tettwasuneɣ tugna-s tamezwarut.
- **Mi ara ycceḍ udekudur n yiwet n talentilt** u ulac tavidyut yettwabeddlen, tavidyut tettwaɣra war asdukkel deg wadeg ad teḥbes ɣef tuccḍa.
- **Ɣef umserwes Android** tugna n talentilt nniḍen ur d-tettbanay ara (yal tasnalit n talentilt tettwaqqen tura ɣer yiswi n tesnalit tuffiɣt deg yal tugna).

- **Ayen yeqqar usnas**: iḥder n useggem i ternu tkamirat ɣer yal afaylu (tamudemt n tlentilt, ilemmasen, tanila n yal talentilt, tiddi n tɣerda n useggem) d usekles n uɣiwel, i yettwasqedcen akken ad yesgunfu igli. ## Tiwlafin d tvidyutin 3D d VR180

Deg usnas Immich, tawlaft neɣ tavidyut 360° stiriyu tesskanay-d snat n tiṭṭawin deg yiwet n tikkelt, tugna tettwasneɣ snat n tikkal, u afaylu VR180, i yeṭṭfen kan azgen n zdat, yettwazzel ɣef tsfirt akk.

Immuch360 yessen isefraken 3D, s ufella d wadda neɣ rrif ɣer rrif, seg ufaylu (tanaka st3d n tvidyut), neɣ yettxemmim-iten-id seg talɣa n tugna, u yal ameskan yesɛa taqeffalt 3D akken ad ten-tbeddleḍ. Tiliɣri tesskanay-d tiṭ tazelmaḍt; Meta Quest yesskanay i yal tiṭ azgen-is, s 3D n tidet. Ifuyla VR180 ttwasunɣen ɣef wazgen n tsfirt, s deffir d aberkan deg wadeg n tugna yettwazzlen. Ttwassnen-d seg ufaylu (spherical bounds neɣ mesh, agzam n GPano) neɣ seg «vr180» neɣ «180» deg yisem, u yal ameskan yesɛa taqeffalt 360°/180°.

### Beddel asefrek neɣ tiddi n tsfirt

1. Ldi tawlaft neɣ tavidyut am tsfirt (taqeffalt 360°).
2. Taqeffalt 3D tettɛeddi gar «Mono (mačči 3D)», «3D, s ufella d wadda» d «3D, rrif ɣer rrif»; awal-is n tallelt yebder asefrek n tura.
3. Taqeffalt 360°/180° tettɛeddi gar «360°, tasfirt tummidt» d «180°, azgen n tsfirt (VR180)». Ur d-tettban ara ɣef tewlafin tiẓegzawin ur nemmid ara.
4. Deg tcacit, tiqeffalin-a i snat llant ɣef ugalis n talɣut n umeskan immersif.

Afran 360°/180° yettwaḥraz ɣef yibenk i yimidyaten n tmkarḍit, mačči yakan i ufaylu n ufaylu yettwabḍan n uẓeṭṭa. Afran 3D ur yettwaḥraz ara mi ara yemdel umeskan: asefrek i d-yenna ufaylu, neɣ win yettwaxemmen, ad d-yuɣal tikkelt i d-iteddun (ameɣri Spatial 2.5D ddaw-a yeḥrez win-is).

Yettwasenqed ɣef Galaxy S24+ d Quest 3 s tividyutin n tidet 3D 360° n umedya (VRTogether, Vuze, Kandao) d tewlaft 3D; VR180 ɣef umserwes Android d Galaxy S24+ s yimidyaten imsuḍnen. Ansuf ɣer yineqqisen n tkamiratin nniḍen.

## Tiɣmert ɣef ugdil amsawi: Spatial 2.5D (s tirmit)

Tavidyut stiriyu tezmer ad d-tawi tiɣmert ɣef ugdil amsawi. Snat n tiṭṭawin n tvidyut ttakent-d tiɣmert, takamirat n zdat tettḍafar aqerru-ik, u asnas yessenfal tamuɣli gar-asent, ihi agdil yettili am ttaq ɣef tmeẓri: smussu aqerru-ik u tiɣawsiwin iqerben ad mbiwlent ɣef ugilal. Tiliɣriyin d ttablit kan.

### Seqdec-it

1. Senqed ma yermed: Settings, Asset Viewer, Videos (Tividyutin), «Spatial 2.5D (s tirmit)». Yermed s wudem amezwer; asensi-ines yekkes taqeffalt Spatial seg yal adeg.
2. Ldi tavidyut. Mi ara yili uɣewwar yermed, afeggag n ufella yesskanay-d taqeffalt Spatial (tignit 3D yettezzin) ɣef yal tavidyut; deg ukaram n ufaylu yettwabḍan n uẓeṭṭa, d ifuyla stiriyu kan i tt-yesɛan, u wiyaḍ sɛan Spatial 2.5D deg wumuɣ ⋮.
3. Sit fell-as. Tasiregt n tkamirat n zdat tettwasuter tikkelt tamezwarut; takamirat tettwaseqdac kan mi ara tesseḍḍeḍ ɣef tqeffalt.
4. D asawen s ayeffus: Abrid n umeslaw mi ara tesɛu tvidyut sin neɣ ugar, asefrek n tura (sit fell-as i tebdart: Awurman, Mačči d stiriyu, Rrif ɣer rrif, S ufella d wadda, sin-a ineggura daɣen s tiṭṭawin yettwabeddlen), 360°/180° ɣef tvidyut 360°, d «Ales asebded deg tlemmast», i yettawin addad n tura n uqerru-ik d tlemmast.
5. D akessar: urar, tasnakudt, syin «Taḥssast n uqerru» mi ara yettwaḍfar uqerru-ik, d ufeggag n tmuɣli seg L ɣer R, i yessenkaren tamuɣli s ufus; yettban-d mi ara yensa uḍfar n uqerru neɣ mi ara iṛuḥ wudem-ik.
6. Mdel s ucuddu neɣ s tuɣalin n unagraw.

S Settings, Advanced (Talqayt), Troubleshooting (Tifrat n wuguren) yermed, ameɣri yerna tugna d asawen s azelmaḍ (tiktiwin n usunɣ d umgired, aswir n tɣara, tamuɣli, addad n uḍfar), yesskanay-d yal tikkelt afeggag n tmuɣli, u yerna tanaka n ucraḍ «Disparity map» (Takarḍa n umgired) i d-yesskanayen tiɣmert yettwaḥesben deg wadeg n tugna.

### Imasalen, tabaḍnit d tilisa

- **Imasalen**: rrif ɣer rrif d s ufella d wadda, daɣen s tiṭṭawin yettwabeddlen, s tehri tummidt neɣ s wazgen-is, amsawi, 360° d VR180. Asefrek yettwaɣra seg ufaylu, ma ulac yettwaxemmen-d seg talɣa n tugna neɣ seg yisem n ufaylu (sbs, ou, tb d wayen yecban aya; afaylu s wazgen n tehri yettwassen kan s yisem-is), u yezmer ad yettwafren s ufus deg umeɣri. Afran yettwaḥraz i tvidyut n tmkarḍit, mačči i ufaylu n ufaylu yettwabḍan n uẓeṭṭa.
- **Takamirat**: tugniwin ttwaxedment ɣef yibenk kan, werǧin ttwaḥerzent, werǧin ttwaznent ɣer wanda nniḍen. Lebni n Quest ur yesɛi ara akk tasiregt n tkamirat (tacacit ur tesɛi ara takamirat i yezmer usnas ad yesseqdec), u ameɣri Spatial ur yettwasumer ara dinna: taqeffalt-is d uɣewwar-is ffren deg tcacit.
- **Tilisa**: s tirmit, tiliɣriyin d ttablit kan (mačči ɣef Meta Quest), yesra OpenGL ES 3.0 neɣ Metal. Tiɣmert d aḥsab kan. Yetteddu akken iwata s wudem n tehri, s wudem-ik yettwasefsen akken iwata. Yettwasenqed ɣef Galaxy S24+; ansuf ɣer tmuɣliwin n iPhone.
- **Tufrut**: ma yella kra ur yeddi ara (ulac takamirat, ibenk ur yettwasefrak ara, asefrek ur yettwaɣra ara), ad tuɣaleḍ ɣer umeɣri amagnu.

## Tiwlafin d tvidyutin timennawin n Apple

iPhone yettawi tiwlafin d tvidyutin timennawin (spatial), u aqeddac Immich ur d-yeqqar acemma fell-asent: deg usnas Immich d tawlaft neɣ d tavidyut tamsawit. Seg lebni 19 Immuch360 yessen-itent s tɣuri n yifuyla, u yesskanay tawlaft tamennawt s 3D deg tcacit Meta Quest. Wagi mačči d ameɣri Spatial 2.5D d asawen, i yellan i tvidyutin rrif ɣer rrif d s ufella d wadda.

- **Tiwlafin timennawin** d ifuyla HEIC (`.heic`, `.heif`, `.hif`) i yeṭṭfen snat n tugniwin, yiwet i yal tiṭ, yettwasdukklen d tayugit stiriyu. Asnas yeqqar aqerru n ufaylu (ɣef yibenk, aṣli n uqeddac s tuttra n tegrumma, neɣ afaylu n ufaylu yettwabḍan n uẓeṭṭa) u yeḥrez tiririt ɣef tiliɣri, ihi tawlaft tettwaɣra yiwet n tikkelt.
- **Tividyutin timennawin** (MV-HEVC) ttwassnent-d seg ubrid n tvidyut: tissi tis snat, d snat n tiṭṭawin yettwabedren.

### Wali tawlaft tamennawt s 3D deg tcacit

1. Deg tcacit, ldi tawlaft tamennawt deg umeskan, neɣ deg ukaram n ufaylu yettwabḍan n uẓeṭṭa, anda tiwlafin d tvidyutin timennawin sɛant tacreḍt 3D.
2. Sit ɣef «Wali s 3D» deg ufeggag n ufella (asebter n tewlaft n ufaylu yettwabḍan yesɛa-t daɣen).
3. Ameskan immersif yeldi s tewlaft ɣef tɣerda tamsawit 2 m zdat-k, yal tiṭ s tugna-s, s tehri yettwaksen seg wurti n tmuɣli n tkamirat mi ara t-id-yefk ufaylu (48° ma ulac). Aseggem n umgired yettwarun deg ufaylu yettwasnas.
4. Ajenṭaḍ ɣer d asawen neɣ ɣer d akessar yessemɣar neɣ yessemẓi-tt (s tseddarin n 6°, seg 30° ɣer 90°); ajenṭaḍ ayeffus ɣer zelmeḍ neɣ ɣer yeffus ad tt-id-yerr zdat-k.
5. Taqeffalt 3D n ugalis n talɣut tettɛeddi gar 3D d «2D (tiṭ tazelmaḍt)». Tiqeffalin Zzi d 360°/180° ffrent.
6. Sseḍ ɣef B neɣ Y akken ad tuɣaleḍ.

Uzwir d uḍfir ur llin ara yakan seg tewlaft tamennawt («Uzwir d uḍfir ur llin ara yakan i twlafin timennawin»). Ma tacacit ur tezmir ara ad teɣr tiṭ tis snat, tawlaft tettban-d s 2D s «Tiṭ tis snat ur tettwakkes ara i ukud: tettwaskan s 2D». Tamuɣli 3D tesskanay-d afaylu aṣli, war ibeddilen i yettwaxedmen deg Immich.

### Deg wadeg nniḍen akk

- **Tiwlafin**: tiliɣriyin, ttablit d usfaylu n tcacit sskanayen-d tiṭ tazelmaḍt, am zik, u talqayin titiknikanin rnant izirig, «Tawlaft tamennawt n Apple, sin n tmeẓriwin n 3072 x 3072» amedya, s wurti n tmuɣli mi ara t-id-yefk ufaylu. Tiwlafin n uqeddac ur sɛint ara tacreḍt deg tesnakudt: asnas yettissin-itent mi ara teldi yiwet.
- **Tividyutin**: ttwaɣrant s tissi-nsent n tazwara, yiwet n tiṭ, deg yal ameɣri n usnas. Android ur yesɛi ara abrid azayez i tɣuri n tmuɣli tis snat; ibenk yesɛan adekudur-is i MV-HEVC (ɣef kra n yiseklasen Qualcomm) ad yawi tavidyut s yiman-is, ayen ur yettwasenqed ara yakan. Taɣuri tamezwarut n tvidyut am ta deg tɣimit tenna-d «Tavidyut tamennawt: ibenk-a yesselkam yiwet n tiṭ» (tavidyut n ufaylu yettwabḍan n uẓeṭṭa tesɛa tacreḍt 3D deg wadeg-is), u talqayin-is titiknikanin nnant «Tavidyut tamennawt n Apple (MV-HEVC), tettwaskan s 2D», s tiṭ, tazrirt n uzadur d wurti n tmuɣli i yeskelsen ufaylu.
- **Idekuduren**: Settings, Advanced, «Imeɣṛen n tvidyut n yibenk-a» yesɛa aferdis MV-HEVC i d-yebdren adekudur n yibenk i ukudik-a, neɣ yenna-d ulac-it.

### Ur yettwasenqed ara yakan ɣef yibenk

Tagrut tettwasenqed ɣef tewlaft tamennawt n umedya yettwarun s temkarḍit n tugniwin n Apple s yiman-is d yifuyla imsuḍnen, u asuddes 3D s yisekyaden n tyunin. Tamuɣli deg tcacit (snat n tiṭṭawin yettwaɣran, tawlaft tbedd u ur tettwaqleb ara am lemri, tiɣmert deg tnila iṣeḥḥan, talwit-is ɣef 2 m) d tewlafin d tvidyutin n tidet n iPhone d asekyed ɣef yibenk n lebni 19. Ansuf ɣer yineqqisen, s yizirigen n [Iɣmisen](#logs).

## Deg tcacit Meta Quest 3

Imdanen ttaɣen Quest 3 akken ad walin tiwlafin d tvidyutin-nsen 360°, syin ttsaqsayen anda ara srusen ifuyla, amek ara ten-sɛeddin ɣer tcacit war tanzeqt, d wanwa ameɣri ara sqedcen: imeɣriyen n tvidyutin 360° d 3D n tḥanutt s idrimen.

Asnas-nni n Android yetteddu ɣef Quest 3 d 3S, u seg lebni 21 ɣef Quest 2 d Quest Pro (ur ttwarmen ara), am usfaylu, s temkarḍit-ik akk. Taqeffalt-is 360° teldi ameskan immersif anda tawlaft neɣ tavidyut tezzi i tama-k akk, u tmuqleḍ yal tama s tuzzya n uqerru-ik, s 3D n tidet i yifuyla stiriyu (Meta Spatial SDK).

Imidyaten d-ttasen seg uqeddac-ik Immich, seg tcacit s yiman-is, seg NAS, seg uqeddac n yimidyaten, seg tiliɣri neɣ seg uqeddac Plex, ttwaɣran deg wadeg-nsen (aqeddac n yimidyaten d tiliɣri seg lebni 19, aqeddac Plex seg lebni 20, ur ttwasenqden ara yakan deg tcacit), u seg lebni 20 asfaylu yesskanay-d daɣen tikamiṛatin Tapo. D baṭel u d aɣbalu yeldin. Yettwasenqed ɣef Quest 3, u s useqdac s tvidyutin Insta360 X4 8K HEVC.

### Ldi ameskan immersif

1. Sbedd asnas ɣef tcacit: alamma tettwaqbel tebdart n Horizon Store, sbedd APK s ufus, wali [Asebded](#install).
2. Kcem s uqeddac-ik Immich, neɣ sit ɣef «Seqdec war aqeddac» i tewlafin d tvidyutin n tcacit s yiman-is.
3. Ldi tawlaft neɣ tavidyut 360° deg umeskan, seg tesnakudt, seg tebdart 360°, seg ulbom neɣ seg ukaram yettwabḍan.
4. Sseḍ ɣef tqeffalt 360°, neɣ «Wali am 360°» deg wumuɣ ⋮. Deg tcacit ldint srid ameskan immersif, deg wadeg n umeskan n tsfirt n tiliɣriyin.
5. Muqel yal tama s tuzzya n uqerru-ik.
6. Akken ad tuɣaleḍ ɣer usfaylu, sseḍ ɣef B neɣ Y, neɣ ɣef tqeffalt Uɣal n ugalis n talɣut.

|---|---|---|
| Uɣal ɣer usnas | B neɣ Y | Taqeffalt Uɣal |
| Ɣer neɣ steɛfu tavidyut | Tadekkant, mi ara yili ugalis n talɣut yeffer | Taqeffalt Urar neɣ Asteɛfu |
| Sken neɣ ffer agalis n talɣut | A, X, tuṭṭfa neɣ umuɣ | Tamussni n wumuɣ, neɣ aqenṭeḍ mi ara yili ugalis yeffer |
| Zzi tamuɣli (seg lebni 17) | Ajenṭaḍ ayeffus ɣer zelmeḍ neɣ ɣer yeffus, 30° i yal asenned | Taqeffalt Zzi (90°) |

Deg tfelwit-a, tiqeffalin d ufeggag n wakud d wid n ugalis n talɣut. S yimsenqaden teddun daɣen: sken-iten s waẓar u sseḍ ɣef tdekkant.

- **Zzi tamuɣli**: akken ad tmuqleḍ deffir-k war ma tezziḍ aqerru-ik. Ajenṭaḍ ayeffus ikemmel tuzzya mi ara t-teṭṭfeḍ, u tugna n yiwen yizirig tesskanay-d tiɣmert.
- **Tugna n yiwen yizirig**: seg lebni 16, anegzum, tuzzya n tewlaft, neɣ uzwir d uḍfir s ujenṭaḍ sskanayen-d tugna n yiwen yizirig (akud, tiɣmert neɣ isem n umidya) u agalis n talɣut yeqqim yeffer. Uqbel lebni 17 yal ajenṭaḍ yettɛeddi ɣer umidya uzwir neɣ uḍfir.

### Agalis n talɣut, uzwir d uḍfir

Agalis n talɣut n tvidyut yesɛa afeggag n wakud (addad, tanzagt, acḥal i yettwasalayen) gar snat n tqeffalin n unegzum n 10 n tsinin; ddaw-as d Uzwir, Urar neɣ Asteɛfu d Uḍfir, syin Zzi, 3D, 360°/180° d Uɣal. Tawlaft tesɛa izirigen-nni war afeggag n wakud d Urar. Asefrek 3D d ufran 360°/180° llan kan ɣef tqeffalin n ugalis.

Uzwir d uḍfir tteddun gar yimidyaten 360° n wadeg seg wanida d-tusiḍ, war ma teffɣeḍ seg umeskan immersif: tasnakudt, tabdart 360° (akken tettwasizdeg), albom, akaram n ufaylu yettwabḍan n uẓeṭṭa, neɣ imidyaten n tcacit s yiman-is (On this device). Tiwlafin d tvidyutin timsawin ttwaǧǧant. Mi ara tuɣaleḍ ɣer usnas seg tesnakudt, seg ulbom neɣ seg tebdart 360°, ad tḥebbes ɣef umidya i tettmuqqleḍ (asebter n ukaram yettwabḍan yeqqim ɣef ufaylu i teldiḍ), u tavidyut ɣef tledyeḍ ameskan immersif tkemmel seg wanida tḥebes.

Seg lebni 17 ajenṭaḍ ayeffus yessezzay tamuɣli, akken yessezzay ajenṭaḍ ayeffus deg aṭas n yisnasen n tcacit: asenned yezzi s 30°, aṭṭaf yessekmal tuzzya, ihi ayen yellan deffir-k ad d-yas zdat-k war ma tezziḍ aqerru-ik neɣ takersit-ik; uzwir d uḍfir llan ɣef ujenṭaḍ azelmaḍ.

Seg lebni 16, deffir tamuɣli n useqdac ɣef tcacit, anegzum, tuzzya neɣ uzwir/uḍfir s ujenṭaḍ yesskanay-d tugna n yiwen yizirig (akud, tiɣmert neɣ azwel n umidya) i yettfaḍen deffir 1,5 n tsinin deg wadeg ad d-yesbeggen agalis n talɣut; agalis mazal yettas-d s A, X, tuṭṭfa neɣ taqeffalt n wumuɣ. Lebni-nni s yiman-is yeǧǧa askar n ugalis yetteddu mi ara ṭṭsen yimsenqaden, mi ara d-kkren neɣ mi ara eǧǧen amkan i uḍfar n yifassen, u yettaru-d tikli-a deg yiɣmisen, wali [Iɣmisen](#logs).

Tawlaft tamennawt n Apple yettwaldin s «Wali s 3D» ur tettwasers ara ɣef tsfirt: tettɛum zdat-k, wali [Tiwlafin d tvidyutin timennawin n Apple](#apple-spatial-photos-and-videos).

### Ayen i d-tesskanay tcacit

Tiwlafin sskanayent-d tamuɣli tazwarut qbel, syin aṣli, yettwasemẓi ɣer 8192x4096 akk ugar (talast n usnas). Tividyutin ttwaɣrant seg ufaylu yettwaḥerzen ɣef tcacit ma yella, u afaylu n ufaylu yettwabḍan n uẓeṭṭa s tqentert tadigant n usnas; ma ulac, ttasent-d seg uqeddac-ik akken i d-yenna uɣewwar «Aɣbalu n tvidyut» (seg lebni 15; s wudem amezwer aṣli, u tavidyut yettwabeddlen n uqeddac mi ara yili uṣli ur yezmir ara ad yettwaṭṭef s usuddem neɣ yugar idekuduren n tcacit, wali [Talɣut n tvidyut d yidekuduren](#video-details-decoders-and-why-a-video-stutters)). Ifuyla RAW n tkamiratin ldin dagi daɣen seg lebni 16, ttwasdukklen s usnas; tiqeffalin 3D d 360°/180° ffrent i tvidyut RAW, i yellan d yiwet n tsfirt tummidt.

Isefraken 3D, s ufella d wadda d rrif ɣer rrif, 360° d VR180, ttbanen-d s 3D, yal tiṭ s wazgen-is n tugna. Asefrek d-yettas seg ufaylu mi ara t-id-yenna (tividyutin), ma ulac yettwaxemmen-d seg talɣa-s (amkuẓ: s ufella d wadda, 4:1: rrif ɣer rrif); ma yella d awezɣi, seqdec taqeffalt 3D n ugalis n talɣut.

### Ma yella tugna ur tettmuqul ara ɣur-k

Zzi-tt s ujenṭaḍ ayeffus (neɣ s tqeffalt Zzi n ugalis n talɣut) alamma tlemmast-is tella zdat-k. Tiɣmert tettban-d am «Tugna tezzi ɣer N°», ɣef ugalis neɣ ɣef tugna n yiwen yizirig mi ara yili ugalis yeffer: ma ulac aɣilif, aru amḍan-nni deg [ugur](https://github.com/freeKC/Immuch360/issues), s tmudemt n tkamirat-ik, akken ad yuɣal d azal amezwer. Tanila n tazwara ur tettwasentem ara yakan i yal takamirat.

### Tilisa n umeskan immersif

- **Uzwir d uḍfir**: ttmuqulen 400 n yimidyaten akk ugar zdat deg tesnakudt d 50 n yifuyla deg ukaram yettwabḍan, i 12 n tsinin akk ugar; deffir n waya agalis yenna-d ulac amidya 360° uzwir neɣ uḍfir. Akaram yettwabḍan yettwasenqad afaylu s ufaylu, ihi afaylu 360° amezwaru deffir aṭas n yifuyla imsawin yezmer ad yawi kra n tsinin akken ad d-yettwaf. Ur llin ara yakan seg tewlaft tamennawt.
- **Afran 3D**: asefrek yettwafernen s tqeffalt 3D ur yettwaḥraz ara mi ara yemdel umeskan; afran 360°/180° yettwaḥraz, i yimidyaten n tmkarḍit.
- **Anegzum**: tavidyut ur d-yettarra uɣbalu-ines i yisuturen n tegrumma n yibiten ur tettwanegzam ara; agalis yenna-t-id.
- **Tividyutin timsawin**: tavidyut stiriyu tamsawit (mačči 360°) tettwaɣra deg usfaylu s snat n tiṭṭawin yettbanen; tamuɣli immersif 3D d tin n yimidyaten 360° d VR180.
- **Ugar**: ikudiken i teɣɣar tcacit, taḥanutt, tisirag d tiddi n APK llan deg [Meta Quest 3](#meta-quest-3).

## Wali ɣef tiliẓri (Android TV d Google TV)

Tebɣiḍ tiwlafin d tvidyutin 360°, ilbumen-ik d tvidyutin n NAS-ik neɣ n uqeddac-ik Plex ɣef ugdil ameqqran, i twacult ɣef ukursi, s tilikumand n tiliẓri. Asnas aziraz n Immich mačči d asnas n tiliẓri: aseqdac i t-isebdden ɣef tiliẓri yufa-d yetteddu s tɣerdayt, mačči s tilikumand ([adiwenni #1614](https://github.com/immich-app/immich/discussions/1614)), u tarbaɛt n Immich ur tesɛi ara asnas unṣib n tiliẓri deg yiɣawasen-is ([adiwenni #13748](https://github.com/immich-app/immich/discussions/13748)).

Seg lebni 20 asnas-nni n Android yetteddu ɣef Android TV d Google TV, s tilikumand kan am unekcam: yiwen APK i tiliɣriyin d tiliẓriyin, imeskanen 360° d 3D ttezzin s yineccaben, d yifuyla n uẓeṭṭa, Plex d tikamiṛatin Tapo ɣef tiliẓri, s uqeddac Immich neɣ war-s.

<a id="install-it-on-the-tv"></a>
### Sebded-it ɣef tiliẓri

1. Alamma Google Play yessumer asnas ɣef tiliẓriyin, ayen yettraǧun asenqed n Google i usiẓreg n tiliẓri, awi `Immuch360-v<version>-release.apk` amatu seg usebter [Isiẓrigen](https://github.com/freeKC/Immuch360/releases).
2. Ɣef tiliẓri, rmed iɣewwaren n uneflay d tseɣtit USB (ɣef Google TV: Settings, System, About, fren «Android TV OS build» sebɛa n tikkal, syin Settings, System, Developer options; ismawen mgaraden seg tiliẓri ɣer tayeḍ).
3. Seg uselkim deg uẓeṭṭa-nni, s adb (Android SDK Platform Tools): `adb connect <address of the TV>`, qbel asuter ɣef tiliẓri, syin `adb install -r Immuch360-v<version>-release.apk`.
4. Asnas yettban-d gar yisnasen n tiliẓri, s ubanner-is. Sebded asiẓreg i d-iteddun s wudem-nni: `-r` yeḥrez tuqqna d yiɣewwaren.

### Asekker amezwaru

1. Qqen am ɣef tiliɣri: ineccaben ssenkazen akatar seg wurti ɣer wayeḍ, u OK ɣef wurti («Sit ɣef OK akken ad taruḍ») yeldi anasiw n tiliẓri deg udiwenni, i tansa n uqeddac, imayl d wawal uffir.
2. Neɣ fren «Seqdec war aqeddac». Tiliẓri ur tesɛi ara tiwlafin-is, ihi iccer Photos (Tiwlafin) yenna-d «Tiliẓri-a ur tesɛi ara tugniwin neɣ tividyutin-is: ldi afaylu n uẓeṭṭa seg Temkarḍit.» s teqffalt Ifuyla n uẓeṭṭa. ## Af-d tiwlafin-ik 360°: tabdart 360°

Tiwlafin 360° xeltent d tiwlafin nniḍen akk, u imdanen ssutren seg Immich abrid i usizdeg n tsfirin d tewlafin tiẓegzawin ([adiwenni #12824](https://github.com/immich-app/immich/discussions/12824)). Asnas Immich ur yesɛi ara tabdart am ta.

Immuch360 yessers tacreḍt 360° ɣef tugniwin timecṭuḥin n tewlafin 360° (deg ukaram n ufaylu yettwabḍan n uẓeṭṭa, ula ɣef tvidyutin 360°), d uferdis 360° d asawen n yiccer Tamkarḍit. Seg lebni 18 tabdart-a tegber, s uqeddac, tiwlafin d tvidyutin i yecreḍ uqeddac d 360°, ifuyla RAW n Insta360 s yisem-nsen, tiwlafin i yessdukkel tkamirat 360° s yiman-is d tid i tefreneḍ ad tent-twaliḍ am 360°, d wayen yufa unadi deg yibenk; war aqeddac, ayen yufa unadi deg yibenk d tid i tefreneḍ ad tent-twaliḍ am 360°. Yal yiwet tettban-d yiwet n tikkelt, anda yebɣu llan wanɣalen-is, tamaynut d tamezwarut.

### Sizdeg tabdart

1. Ldi iccer Tamkarḍit u sit ɣef 360° (ɣer tama n Favorites (Ismenyifen) s uqeddac, i yiman-is war aqeddac).
2. Sit ɣef Date (Azemz) i tallit: All (Akk), aseggas (ldi-t i «Aseggas akk» d wayyuren-is, yal yiwen s umḍan-is), neɣ Custom (Udmawan) i tegrumma n wussan.

## Talqayin n tvidyut, idekuduren d wayɣer tettḥebbis tvidyut

Imdanen ttsaqsayen anwa akudik, anwa tiddi d wanwa aktum n yibiten i yeqqar Quest 3, d wayɣer asifeḍ 5.7K yettḥebbis deg tcacit ma d ɣef tiliɣri yetteddu. Tiririt d adekudur n warrum: adekudur H.264 n Quest 3 (XR2 Gen 2) yeḥbes ɣer 4096x2304 akka, ihi tavidyut H.264 n 5760x2880 (aswir 6.0, azal n 200 Mbit/s, asifeḍ yezgan n Insta360) tettwaɣra s 17 fps akka deg tcacit, s yiḥricen yettwaxellḍen, ma d afaylu-nni s yiman-is yetteddu akken iwata ɣef tiliɣri.

Tavidyut-nni s HEVC (H.265) tetteddu akken iwata deg tcacit: tavidyut Insta360 X4 8K HEVC (7680x3840, 29.97 fps, 210 Mbit/s, amaɣnu Main aswir 6.1, 8 bit) tetteddu s leɛqel deg umeskan immersif, s tbadut-is taṣlit u war abeddel (yenna-t-id useqdac ɣef Quest 3).

Asnas Immich yesɛa yiwet n tqeffalt «Force original video» u yesskanay-d kan akudik. Immuch360 yesskanay-d d acu i d tavidyut d wayen yeɣɣar yibenk, u yefren afaylu ara yeddun.

<img src="../.github/readme/b19-video-details.png" width="260" alt="Talqayin n tvidyut 360°: Codec H.264 High (avc1.640033), 3840 x 1920, 30 fps; Aktum n yibiten 16 Mbit/s; Tugna 8 bit, SDR, BT.709; Yettwaɣer deg yibenk-a: Ih, Arrum, alamma d 4096 x 2304">

### Ɣer talqayin n tvidyut

1. Ldi tavidyut u zuɣer ɣer d asawen: talqayin ad d-banent ddaw tugna.
2. Codec: akudik s umaɣnu-ines d uzrir-is n yikudiken, tiddi n tugna d urured n tugniwin, amedya «H.264 High (avc1.640033) • 3840 x 1920 • 30 fps», am deg tugna d asawen.
3. Aktum n yibiten (seg lebni 18): aktum n yibiten n ubrid n tvidyut, neɣ win i d-yenna ufaylu; ma ulac yettwacreḍ «afaylu akk, s yimesli» neɣ «yettwaḥseb s teɣzi n ufaylu».
4. Tugna (seg lebni 18): ateɣzi n yibiten, SDR neɣ asiweḍ HDR (HLG, PQ, Dolby Vision) d tallunt n yini.
5. Yettwaɣer deg yibenk-a: ih neɣ ala, arrum neɣ aseɣzan, tiddi tameqqrant i yeqbel udekudur, d «Ulac adekudur i (amaɣnu)» mi ara yesɛu yibenk akudik maca mačči amaɣnu-nni.

Izirig yettban-d kan mi ara yettwaɣer ufaylu, u kan i wayen i d-yenna ufaylu. Tawlaft neɣ tavidyut tamennawt n Apple tettawi izirig i yiman-is, wali [Tiwlafin d tvidyutin timennawin n Apple](#apple-spatial-photos-and-videos).

### Wali ayen yeɣɣar yibenk

Settings, Advanced, «Imeɣṛen n tvidyut n yibenk-a» (seg lebni 15) yesskanay-d ayen yeɣɣar tiliɣri neɣ tacacit: akudik, arrum neɣ aseɣzan, tiddi tameqqrant, arured n tugniwin, u seg lebni 18 imaɣnuten (Main, Main 10, HDR10). Seg lebni 19 yesɛa aferdis MV-HEVC, akudik n tvidyutin timennawin n Apple. Taqeffalt Nɣel tessers tabdart deg tkatut tasenneɣlit i uneqqis n ubug.

### Fren aṣli neɣ tavidyut yettwabeddlen

1. Ldi Settings, Asset Viewer, syin Videos.
2. Ddaw «Aɣbalu n tvidyut» («Anwa afaylu ara yettwaɣren mi ara yesɛu uqeddac anɣal yettwabeddlen»), fren «Aṣli mi ara t-yeɣr yibenk-a», «Yal tikkelt aṣli» neɣ «Yal tikkelt tavidyut yettwabeddlen».

Seg lebni 15 afran yeddu i yal tavidyut n uqeddac: ameɣri amsawi, imeɣriyen 360° d Spatial, d umeskan immersif n Quest. Alamma tferneḍ yiwen, tiliɣri teḥrez ayen i d-yenna tqeffalt taqburt «Force original video» (tensa s wudem amezwer: tavidyut yettwabeddlen, i yellan d aṣli s yiman-is mi ara yili uqeddac ur t-ibeddel ara), u Quest yeqqar aṣli mi ara t-yeɣr tcacit.

Asenqed yeqqar akudik, tiddi d urured n tugniwin seg ufaylu u yesserwas-iten d yidekuduren n warrum (H.264 ɣef Quest 3 yettwaḥbes ɣer 4096x2304 yettwaktalen). Ameɣri ur nezmir ara ad yeɣr aṣli yettɛeddi ɣer tvidyut yettwabeddlen s yizen: «Taɣuri n tvidyut yettwabeddlen: aṣli (codec d tiddi) yugar ayen yeɣra yibenk-a».

Deg tcacit ameskan immersif yessenker aṣli u, deg tugniwin-is timezwura, yettɛeddi ɣer tvidyut yettwabeddlen n uqeddac mi ara yili uṣli yugar idekuduren, yenna-t-id ɣef ugalis n talɣut; mi ara yili ulac tavidyut yettwabeddlen, mi ara tili mazal tameqqrant aṭas, neɣ mi ara d-yekk ufaylu seg tcacit neɣ seg ufaylu yettwabḍan n uẓeṭṭa, agalis n talɣut yenna-t-id i 10 n tsinin, s wayen ilaqen ad yettwabeddel. Lebni 14, win yettwaznen ɣer Horizon Store, yessenqad kan H.264 yugaren 4096x2304, syin yettarem tavidyut n tɣuri n uqeddac s yiwen wudem.

I tvidyutin RAW s snat n tlentilin, asenqed yessuter sin n yidekuduren deg yiwet n tikkelt, u seg lebni 19 yugi sin n yisuddem yugaren 2048x2048 yal yiwen i udekudur aseɣzan, wali [Ifuyla RAW n tkamiratin 360°](#raw-360-camera-files-without-the-cameras-app).

### Efk i tcacit tavidyut i tezmer ad teɣr

Deg Immich, ddu ɣer Administration (Tadbelt), Settings, Video Transcoding Settings (Iɣewwaṛen n ubeddel n tvidyutin), u fren yiwen seg-sen:

- **Yal tavidyut H.264 tettwabeddel ɣer HEVC**: sbedd Video codec (Akudik n tvidyut) ɣef HEVC d Target resolution (Tabadut tiswit) ɣef Original (Aṣli) (720p s wudem amezwer ad tessemẓi tavidyut 360° ɣer 1440x720), u eǧǧ kan HEVC deg Accepted video codecs (Ikudiken n tvidyut yettwaqeblen). Yal tavidyut H.264 n tmkarḍit tettwabeddel, mačči kan tid n 360°, u tacacit tettawi HEVC s tbadut tummidt.
- **Kan ayen yugaren 1440p**: eǧǧ H.264 deg Accepted video codecs, sbedd Transcode policy (Tasertit n ubeddel) ɣef «Videos higher than target resolution or not in an accepted format» (Tividyutin yugaren tabadut tiswit neɣ ur nelli ara deg umasal yettwaqeblen) d Target resolution ɣef 1440p, akken yif s Video codec ɣef HEVC. Ayen yugaren yettwabeddel, u tacacit tettawi 2880x1440. Tividyutin 4K tiyezgan ttwabeddlent daɣen ɣer 1440p.

Iɣewwaṛen-a qqnen ɣer uqeddac akk, i yal aseqdac d yal asnas, u abeddel n temkarḍit tameqqrant yettawi tisaɛtin n CPU d tallunt n uḍebsi nniḍen; iṣliyen ur ttbeddilen ara. Iminigen war tallalt n HEVC (Firefox ɣef tuget n yinagrawen, Chrome war HEVC n warrum) ur ttɣaren ara tavidyut HEVC yettwabeddlen deg usnas web n Immich. Tifrat tafessast i tvidyutin timaynutin d asifeḍ s H.265 seg usnas Insta360 neɣ Studio. Deffir abeddel n yiɣewwaṛen-a, tividyutin yellan ilaq ad ttwabeddlent tikkelt nniḍen: Administration, Job Queues (Tibdarin n twuriwin; Jobs deg yileqman iqburen n Immich), Transcode videos (Beddel tividyutin), All.

Tufrut nniḍen, d tin kan i yifuyla n ufaylu yettwabḍan n uẓeṭṭa neɣ n tcacit (ur sɛin ara tavidyut yettwabeddlen), d abeddel n usifeḍ ɣer HEVC send ad t-tessaliḍ neɣ ad t-tneɣleḍ ɣer ufaylu yettwabḍan:

```bash
ffmpeg -i VID_360.mp4 -c:v libx265 -crf 20 -preset medium -tag:v hvc1 -c:a copy -movflags +faststart VID_360_hevc.mp4
exiftool -overwrite_original -tagsFromFile VID_360.mp4 -XMP-GSpherical:all VID_360_hevc.mp4
exiftool -ProjectionType VID_360_hevc.mp4        # must print: equirectangular
```

`-tag:v hvc1` yecreḍ abrid HEVC akken i t-ttraǧun yibenkan n Apple d yiminigen, `-c:a copy` yeḥrez ameslaw akken yella. ffmpeg yekkes tabzimt 360° n usifeḍ, izirig n exiftool yerra-tt-id; war-s, Immich yesskanay tavidyut d tamsawit.

### Iṣliyen ur nezmir ara ad ttwaṭṭfen s usuddem

Mi ara yili uqeddac ur yettḥulfu ara i yisuturen HTTP Range ɣef uṣli u amatar MP4 (moov) yella deg taggara n ufaylu, afaylu akk ilaq ad yettwasider send tugna tamezwarut, ihi asnas yuɣal ɣer tvidyut n tɣuri n uqeddac. Reverse proxy zdat n Immich i yeḥerzen tiririyin neɣ i yekkesen iqerra Range yezmer ad d-yawi aya.

## Meta Quest 3

Immuch360 yetteddu daɣen ɣef ticacitin Meta Quest s Horizon OS v69 neɣ ugar. Seg lebni 21, lebni n Horizon Store yettwabder i Quest 2, Quest Pro, Quest 3 d 3S, d ukkuẓ-nni i d-yebder yakan `-release.apk` amatu; Quest amezwaru ala, taḥanutt ur t-tqebbel ara tura.

Quest 3 d 3S ttwarmen. Quest 2 d Quest Pro mazal ur ttwarmen ara: imeskuden-nsen n tvidyut ẓẓayit, u tilisa i yesenqad usnas ttwaktalent ɣef Quest 3, ihi tavidyut H.264 tameqqrant tezmer ad tettwagi s yizen neɣ ad tḥebbes ɣef-sen. Ansuf ɣer yineqqisen n snat-a n tcacitin deg [Uguren](https://github.com/freeKC/Immuch360/issues).

Amek ara t-tesqedceḍ yella deg [Deg tcacit Meta Quest 3](#in-the-meta-quest-3-headset); tigezmi-a tettmeslay ɣef usebded-is d wayen yemgaraden deg tcacit.

Lebni n tcacit yettmeslay kan d yiqeddacen s HTTPS, neɣ s HTTP amagnu ɣer yismawen n uẓeṭṭa n wexxam (`.local`, `.lan`, `.home`, `.internal`, `.home.arpa`) d tcacit s yiman-is, akken i t-yessuter Horizon Store. Aqeddac yettwarun d tansa HTTP tamagnut s IP, am `http://192.168.1.10:2283`, yettwagi s lebni-nni: seqdec HTTPS, isem n uẓeṭṭa n wexxam (`nas.local`), neɣ `-release.apk` amatu, i yeḥerzen tasertit yeldin n tiliɣriyin.

Ifuyla yettwabḍan WebDAV, DLNA d tiliɣri ɣef tansa HTTP tamagnut n uẓeṭṭa adigan ur ttwaḥsaben ara: asnas yeqqar-iten s yiman-is u yettak i yimeɣriyen-is kan tansa n tqentert-is tadigant (ilaq ad yettwasentem deg tcacit i DLNA d ufaylu yettwabḍan n tiliɣri, imaynuten deg lebni 19). Seg lebni 20 aqeddac Plex yettwaweḍ s HTTPS, u takamiṛat Tapo s usnas s yiman-is, s tmuɣli-s tusridt s RTSP, ur nelli d HTTP: ur ilaq ara ad ttwaḥesben (ilaq ad yettwasentem deg tcacit).

Alamma yuɣal usebter n tḥanutt d azayez, neɣ akken ad tawiḍ lebni uqbel ad yaweḍ ɣer tḥanutt, sbedd s ufus afaylu `-quest-release.apk` n usiẓreg (yettwabnan i tcacit: 64 bit, SDK iswi 34, kan tisirag i tesseqdac tcacit), neɣ `-release.apk` amatu:

1. Rmed askar n uneflay yiwet n tikkelt. Deg usnas n tiliɣri Meta Horizon, ldi Devices (Ibenkan), fren tacacit, syin Headset settings (Iɣewwaṛen n tcacit), syin Developer mode (Askar n uneflay). Aya yesra amiḍan n uneflay, baṭel ɣef developers.meta.com. Tesriḍ daɣen adb (Android SDK Platform Tools) ɣef uselkim, neɣ SideQuest.
2. Qqen tacacit ɣer uselkim s tenzeqt USB-C. Deg tcacit, qbel «Allow USB debugging» (Sireg aseɣti USB).
3. Sbedd APK:

   ```bash
   adb devices                      # the headset must be listed as "device"
   adb install -r Immuch360-v<version>-quest-release.apk   # for example Immuch360-v3.3.0-rc.0-21-quest-release.apk
   ```

4. Deg tcacit, ldi Tamkarḍit (Library), fren asizdeg «Unknown sources» (Iɣbula irussinen), u sekker Immuch360.
5. APK yettwasbedden s ufus ur yettales ara aleqqem s yiman-is: sbedd asiẓreg i d-iteddun s yiwen wudem (`adb install -r` yeḥrez tuqqna d yiɣewwaṛen). Lqem n Horizon Store d APK n GitHub ttwazeplen s tsura yemgaraden, ihi tacacit tugi yiwen ɣef wayeḍ: akken ad tbeddleḍ, kkes asnas qbel, ayen ara yessenger tuqqna, iɣewwaṛen d tebdart n yifuyla yettwabḍan n uẓeṭṭa.

Asnas akk yetteddu am usfaylu 2D i yettbeddilen tiddi: tuqqna, tasnakudt, ilbumen, anadi, iccer Tamkarḍit (tabdart 360°, On this device, Ifuyla n uẓeṭṭa), iɣewwaṛen, d yimeskanen n tewlafin d tvidyutin, anda ttwaɣrant tiwlafin d tvidyutin timsawin.

Wa d lqem n tirmit: seg desktop build 2, tiwlafin d tvidyutin timsawin teddunt; tividyutin 360°, 3D d VR180 ad d-asent s yilebniyen n desktop i d-iteddun. Seg 9 Tubeṛ 2026, iɣbula n desktop llan deg ufurk agejdan n usenfar, `immuch360`, ihi tiliɣriyin, ticacitin, tiliẓriyin d yiselkimen ffɣen-d seg yiɣbula-nni yiwen. ### Asider d usebded ɣef Windows

Lebni n tura d asiẓreg uzwir n GitHub [Immuch360 Desktop 3.3.0-rc.0, desktop build 2 (Windows preview)](https://github.com/freeKC/Immuch360/releases/tag/desktop-v3.3.0-rc.0-2). Yettwabna seg ufurk agejdan, `immuch360`, deg commit 5b723bd25: iɣbula n lebni 21 n tiliɣri d lqem n uselkim. Yesra Windows 10 neɣ 11, 64 bit.

1. Sider ZIP u sefsi-t anida tebɣiḍ, amedya deg Documents.

Akken ad tesneqdeḍ ZIP, sekker `certutil -hashfile Immuch360-Desktop-3.3.0-rc.0-desktop.2-windows-x64.zip SHA256` deg tdiwent n tiludna, deg ukaram n usider: agmuḍ d win yettwarun deg `SHA256SUMS.txt`. Ulac yakan amsebded neɣ aleqqem awurman: ḍfer asebter [Releases](https://github.com/freeKC/Immuch360/releases), u sefsi lebni i d-iteddun s yiwet n tarrayt-nni.

<a id="build-it-yourself-on-windows"></a>
### Bnu-t s yiman-ik ɣef Windows

Tesriḍ Windows 10 neɣ 11 ɣef x64, Flutter 3.47.2 i Windows, Visual Studio 2022 neɣ Build Tools-is s workload «Desktop development with C++», Developer Mode yermed deg yiɣewwaṛen n Windows (Flutter yesra-t i yizegrar), d Python 3 i uskript n ukemmus.

1. Awi iɣbula u sekker asirew n tengalt. Afurk agejdan, `immuch360`, yebennu daɣen lqem n uselkim: ulac afurk ɣer wacu ara tɛeddiḍ. Asirew n tengalt yesseqdac Java d Node, ihi sekker-it ɣef Linux, macOS neɣ deg WSL; s WSL, eǧǧ aserwes ɣef udebṣi n Windows, i iwala WSL ddaw `/mnt/c` neɣ `/mnt/d`:

   ```bash
   git clone https://github.com/freeKC/Immuch360.git
   cd Immuch360/mobile
   mise install
   mise run install
   mise run codegen
   ```

2. Ɣef Windows, deg ukaram-nni `mobile`, bnu asnas. Lebni amezwaru yessidir-d timkarḍiyin n umeɣri n tvidyut (libmpv d ANGLE) seg GitHub u yesenqad yal aɣbar s SHA-256-ines:

   ```bat
   flutter pub get
   REM try it, with hot reload: a debug build, with a profile of its own (Immuch360 Desktop Debug), so it runs next to the app
   flutter run -d windows -t lib/main_desktop.dart
   REM the app, in build\windows\x64\runner\Release\immuch360.exe
   flutter build windows --release -t lib/main_desktop.dart
   ```

3. Akaram `Release` iteddu ɣef uselkim i t-yebnan. I uselkim nniḍen, ḥrez akaram meṛṛa u rnu runtime n Visual C++ ɣer yidis n `immuch360.exe`. Seg uẓar n userwes, askript n ukemmus yessenɣal-it, yeǧǧa ayen yeqdacen kan i Android, yerna turagin n umeɣri n tvidyut, yesenqad ma yal DLL i d-yessali usnas yella deg ukaram neɣ deg Windows s yiman-is, u yesnulfuy-d ZIP:

   ```bat
   python .github\desktop\windows_bundle.py --release mobile\build\windows\x64\runner\Release --out <folder> --zip <file.zip>
   ```

CI n Immuch360 Desktop (`.github/workflows/immuch360-desktop.yml`) iteddu ɣef ufurk `desktop`, i yeṭṭafaren `immuch360`: isenqaden n tiliɣri (ulac ayen yettbeddilen deg yilebniyen n tiliɣri) d tegrumma n yisekyaden meṛṛa ɣef Linux, isekyaden n desktop ɣef Windows, d ZIP-nni; tiwuriwin-is Linux d macOS (`flutter build linux` d `flutter build macos`, s yiwen `-t lib/main_desktop.dart`-nni) ur teddint ara yakan ɣef yinagrawen-nni.

<a id="build-it-yourself"></a>
## Bnu-t s yiman-ik

Asenselsel n lebni d win n Immich aziraz (Flutter 3.47, yettwasefraken s [mise](https://mise.jdx.dev)):

```bash
git clone https://github.com/freeKC/Immuch360.git
cd Immuch360/mobile
mise install
mise run install
mise run codegen
flutter build apk --release --flavor phone                                   # phones: the universal APK of the GitHub releases (add --split-per-abi for the per ABI files)
flutter build appbundle --release --flavor phone                             # the App Bundle sent to Google Play (also mise run build:android)
flutter build apk --release --flavor quest --target-platform android-arm64 --android-project-arg arm64only=true   # Meta Quest 2, Pro, 3 and 3S: the -quest-release.apk of the releases (also mise run build:quest)
flutter build ios --release                                                  # iPhone and iPad, on a Mac with Xcode and your own signing team
```

Tugniwin n ugdil n tḥuna ttwaṭṭfent ɣef yilmisen debug n usimulatur yettwabnan s `--dart-define=IMMUCH_SCREENSHOTS=true`, i yeffren kan abanner debug.

Snat n tsenfaliyin Android d yiwen usnas. Seg lebni 20 tin n `phone` tettbeddir iman-is daɣen d asnas n tiliẓri (anekcam deg ulanseɣ n tiliẓri d ubanner, ur tesra ara agdil anennal), ayen ur tettarnu ara tin n `quest`.

Tin n `quest` tettnadi SDK 34 u teḥrez kan tisirag i tesseqdac tcacit (tiwlafin, tividyutin, ilɣa): asefrek n yimidyaten, adeg deg ugilal, aḥraz aqbur, ameslaw, adeg n yimidyaten, adeg n yibenk d tkamirat ttwakksent deg `android/app/src/quest/AndroidManifest.xml`, acku Meta Horizon Store yugi snat timezwura u yessuter assaɣ i yal tasiregt nniḍen tamḥulfut; afaylu-nni s yiman-is yebder Quest 2, Quest Pro, Quest 3 d 3S d yibenkan yettwasefraken, u yeḥder HTTP amagnu ɣer tcacit s yiman-is d yismawen n uẓeṭṭa n wexxam. APK d 64 bit kan s sebba n sin n yimuren-nni nniḍen n yizirig-is n tladna (`--target-platform android-arm64 --android-project-arg arm64only=true`). Tin n `phone` d ayen yessuter Google Play.

Akken ad tebnuḍ i iOS ɣef Mac-ik, seqdec Xcode d tarbaɛt-ik n uzmul; s Xcode 26, sekker `xcodebuild -downloadComponent MetalToolchain` yiwet n tikkelt qbel, acku ishaderen Spatial sran-t. War Mac, ilmisen iOS ttedun ɣef Codemagic (Mac yettusneblen) seg ufaylu `codemagic.yaml` n ukufi-a. Ilmisen n usiẓreg Android ttedun ɣef GitHub Actions (`.github/workflows/immuch360-release.yml`).

Immuch360 Desktop, lqem n Windows, yettwabna seg yiɣbula-nni yiwen, afurk `immuch360`, s Flutter i Windows: isurifen llan deg [Bnu-t s yiman-ik ɣef Windows](#build-it-yourself-on-windows).

Ulac ula d yiwet n tbaḍnit deg ukufi-a: tasarut n uzmul Android tettwaḥraz d tibaḍniyin GitHub Actions yettwawgelhen, u ayen n uzmul n Apple yettwaḥraz d imuttiyen yettwawgelhen ɣef Codemagic. Ifuyla n workflow ttbedren-ten kan s yisem. War `android/key.jks` inek, lebni n usiẓreg yettwazmal s tsarut debug u ur yezmir ara ad yettwasbedd ɣef unɣal seg GitHub neɣ seg tḥanutt (kkes-it qbel); lebni debug yettwasbedd ɣer tama-s am Immuch360 debug. Anɣal n Meta Horizon Store d APK `quest` n usiẓreg yettwazemlen s tsarut nniḍen, tin s wacu i yettwajerred usnas n tḥanutt i tikkelt tamezwarut, ihi ur yezmir ara ad yettwasbedd ɣef APK yettwasbedden s ufus, u ula d akessaḍ.

## Iɣmisen

Ɣef Android d Quest, `adb logcat` yesskanay-d ameskan immersif n tcacit ddaw tecreḍt `Immuch360` (seg lebni 19 daɣen snat n tiṭṭawin n tewlaft tamennawt n Apple: amek i tettwaɣra tiṭ tis snat, agzam, anda tettwasers tewlaft), isenqaden n yidekuduren ddaw `VideoDecoders`, asdukkel n tvidyut RAW rrif ɣer rrif ddaw `DualFisheyeEffect`, d tɣuri s snat n tlentilin n lebni 18 ddaw `TwoLensPlayer`, `TwoLensCompositor` d `LensVideoRenderer`:

```bash
adb logcat -c
# reproduce the problem, then
adb logcat -d -v time -s Immuch360 VideoDecoders DualFisheyeEffect TwoLensPlayer TwoLensCompositor LensVideoRenderer
adb logcat -d -v time > quest-full.log      # everything, including crashes and decoder errors (it can contain your server address, check before sharing)
adb logcat -d -v time -s PhoneShareService PhoneShareApi   # on the phone that shares itself (from build 19)
```

Seg lebni 19 amsaɣ DLNA, afaylu yettwabḍan n tiliɣri d tagrut n yimidyaten imennawen n Apple ttarun daɣen deg uɣmis n usnas s yiman-is (Logs (Iɣmisen), deg wumuɣ n tugna n umaɣnu d asawen s ayeffus), ddaw `Ssdp`, `DlnaFileSystem`, `NetworkBrowserPage`, `PhoneShare`, `PhoneShareServer`, `AppleSpatialService`, `HeicStereoProbe` d `NetworkMediaService`. Seg lebni 20 askar n tiliẓri yettaru dinna ddaw `TvMode` d `TvTextEntry`, iqeddacen Plex ddaw `Gdm`, `UdpTransport`, `PlexClient`, `PlexFileSystem` d `PlexServerEditPage`, u tikamiṛatin Tapo ddaw `TapoDiscovery`, `TapoHttps`, `TapoLogin`, `TapoControl`, `TapoMedia`, `TapoFileSystem`, `TapoTest`, `TapoCamera`, `CameraPage`, `CameraEditPage` d `CameraLiveView`; izirigen n Plex werǧin gebren ajuṭu, tansa neɣ azwel, u izirigen n tkamiṛat ur gebren ara awalen uffiren. Izirigen n uɣmis qqimen ɣef yibenk alamma tneɣleḍ-ten s yiman-ik.

Ɣef uselkim (Immuch360 Desktop), asebter Iɣmisen yesɛa daɣen «Sekles iɣmisen deg ufaylu»: aɣmis, neɣ ZIP n uɣmis d yineqqisen n yiɣelluyen ineggura ma llan (isem yettwasumren ad yekfu s «with-crash-reports»). Aneqqis n uɣelluy d minidump amecṭuḥ: inezzaɣ, anida i ḥebsen d wayen kan yettusran i uḍfar n yiɣuniyen-nsen, s yismawen n yifuyla n uhil maca war ikaramen-nsen; mačči d takatut n usnas.

Seg desktop build 2, ameɣri n tvidyut n uselkim yettaru dinna ddaw `DesktopVideo`, `DesktopPlayer`, `DesktopVideoController`, `PlayerPool` d `VideoThumbnailGrabber`, ula d yilɣa n mpv s yiman-is, s yijuṭuyen d wawalen uffiren yettwakksen. Senqed aɣmis uqbel ad t-tebḍuḍ: yezmer ad yegber tansa n uqeddac-ik.
