# Immuch360

**Ayla-k. Yal agdil. Yal tamuɣli.**

Tiwlafin d tividyutin tizeddigin, n 360° d 3D seg yibenk-ik, NAS-ik, aqeddac-ik Immich, tikamirawin-ik d udrun-ik. Ur tesriḍ amiḍan. Immuch360 d asnas ilelli, s uɣbalu yeldin, i yeqqaren tiwlafin-ik d tividyutin-ik anda llant, yerna yesskan yal yiwet deg umeskan i as-iwulmen: d tazeddigt, d takuret i deg tettmuqqleḍ yal tama, s 3D, neɣ yal tama n yiman-ik deg yibenk n uqerru. Yetteddu ɣef tilifunen, tablitin, tiliẓriyin, ibenkan n uqerru Meta Quest d yiselkimen.

**Amaynut: tiwlafin-ik tizeddigin, s 3D.** Fren tawlaft ɣef uselkim-ik, ad tawiḍ tawlaft 3D, asayes 3D ara tkecmeḍ, neɣ tapanuramikt n 360° i d-yessugunen ayen yeqqimen seg umkan i k-d-yezzin. Deg Meta Quest 3 neɣ 3S, yiwen usiti ɣef "Tiɣmert AI" yerna yal tawlaft tazeddigt ad d-tban s tiɣmert. AI teddu ɣef uselkim-ik d yibenk-ik n uqerru, yerna ulac ayen yettwaznen ɣer wanda nniḍen. D armitan, yerna ameskar urɛad t-yermis deg yibenk n uqerru (tirmit tamezwarut ass n 30 Tubeṛ). [Wali amek](#turn-one-photo-into-3d-a-scene-a-panorama).

## I wumi

- **Tiwlafin-ik d tizeddigin** yerna tebɣiḍ-tent s 3D, d asayes ara tqerbeḍ deg yibenk n uqerru, neɣ daxel n tpanuramikt n 360°, war takamirat 3D: [rr yiwet n tewlaft d 3D, d asayes, d tapanuramikt](#turn-one-photo-into-3d-a-scene-a-panorama), d amaynut, yettwaxdem s AI ɣef uselkim-ik.
- **Tessuffuɣeḍ s 360° neɣ s 3D** yerna tebɣiḍ ad tmuqqleḍ yal tama deg tuṭṭfiwin-ik, mačči ad tent-twaliḍ d tizeddigin, snat tikkal neɣ ttwazzelent: [360°, VR180 d 3D](#explore-panoramas-360-vr180-and-3d).
- **Tiwlafin-ik d yisura-k llan ɣef NAS, aselkim, Plex neɣ Immich** yerna tebɣiḍ-ten ɣef tiliẓri war ma tneɣleḍ kra: [ɣef tiliẓri](#watch-on-the-tv-with-the-remote), [NAS, ifuyla n uẓeṭṭa d Plex](#play-the-files-of-a-nas-a-computer-a-media-server-or-plex).
- **Tesɛiḍ Meta Quest** yerna tebɣiḍ ad tkecmeḍ ɣer daxel n tewlafin-ik d tividyutin-ik: [deg yibenk n uqerru](#step-inside-your-photos-and-videos-with-a-meta-quest).
- **Tesseqdaceḍ Immich** yerna tebɣiḍ asnas-is, s yimeskanen imirsifen d yigdilen imeqqranen i tqqneḍ seg tilifun-ik: [tamkarḍit-ik Immich](#keep-your-immich-library-with-more), [s umyeẓri d Immich](#compared-with-immich).
- **Tettɛassaḍ axxam-ik s tkamirawin Tapo** yerna tebɣiḍ-tent ɣer tama n tewlafin-ik, ula ɣef tiliẓri (urɛad ttwasenqdent s tkamirat n tidet): [tikamirawin n wexxam](#watch-your-home-cameras-on-the-big-screen).
- **Tessafgeḍ adrun DJI** yerna tebɣiḍ tugna-ines srid ɣef tilifun-ik war DJI Fly, akked deg Meta Quest neɣ ɣef Android TV i yemdanen yellan yid-k (armitan): [adrun-ik](#see-what-your-drone-sees-on-your-phone).

Ulac amiḍan Immuch360 ara ternuḍ, yerna ulac ayen i d-yettawḍen ɣur-neɣ: asnas yettmeslay kan d yibenkan-ik d yiqeddacen i tferneḍ, yerna yessadar aḥric AI kan mi ara t-tsutreḍ.

### Rr yiwet n tewlaft d 3D, d asayes, d tapanuramikt

Aṭas seg tiwlafin-ik d tizeddigin, yerna ur tezmireḍ ara ad tuɣaleḍ ad tent-teṭṭfeḍ tikkelt nniḍen s 3D. Immuch360 yettak-asent tiɣmert. Ɣef uselkim-ik, yiwet n tewlaft tuɣal d **tawlaft 3D**, d **asayes 3D** ara tqerbeḍ deg yibenk n uqerru, neɣ d **tapanuramikt n 360°** i d-yessugunen ayen yeqqimen seg umkan i k-d-yezzin. Quest 3 neɣ 3S yettxeddim tiɣmert s yiman-is, i yal tawlaft tazeddigt. Kullec yetteddu ɣef uselkim-ik d yibenk-ik n uqerru: ulac cloud, ulac amiḍan, iṣliyen-ik werǧin ttbeddilen. D amaynut deg build 32 d build 13 n Immuch360 Desktop, d armitan yerna yermed s wudem amezwer. Asnas Immich ur yesɛi ara ayen am wa.

**Ɣef uselkim-ik**, s build 13 n Immuch360 Desktop ɣef Windows, Linux neɣ macOS:

1. Fren yiwet neɣ ugar n tewlafin deg tmkarḍit neɣ deg ukaram, sinna "Snulfu-d 3D (AI)".
2. Fren ayen tebɣiḍ: "Tawlaft 3D", "Asayes 3D", "Tamuɣli 360°" neɣ "Lqem 3D n tewlaft 360°" i tewlafin-ik n 360°. Tanaka tettini-d ayen ara yektazel neɣ ara yesnulfu AI ("Qrib 96% seg tmuɣli-a ad yettwasnulfu sɣur AI"), acḥal n wakud ara yeṭṭef ɣef uselkim-a, d anda ara iruḥ ufaylu: "Ɣer yidis n uṣli" neɣ "Akaram i ferneɣ". Anaw ur yezmir ara uselkim-a ad t-yexdem yeqqim ur yettwafran ara, s ssebba-s, am "Mazal ɣef Mac" neɣ "Takarḍa tudlift tesɛa 6.0 GiB n tkatut, timuɣliwin 360° sran 7.5 GiB".
3. Tikkelt tamezwarut, tanaka ad d-tefk iḥricen n wanaw-nni: Sader, yiwet n tikkelt. Teddun ɣef uselkim-a yerna ad xedmen war tuqqna seld aya.
4. Beddel. Imahilen ttṛaǧun ɣef sin n yiberdan, amesbaḍ d tkarḍa tudlift, s yisurifen-nsen d wakud i d-yeqqimen; Sefsex yessḥbas yiwen deg-sen melmi i tebɣiḍ, yerna asnas ad k-id-isteqsi uqbel ad yemdel.
5. Ldi agmuḍ. Tawlaft 3D tettban am "Tiṭ tazelmaḍt", "Rrif ɣer rrif", "Aḥerrek" (tugna yettembiwlen deg uqerru n usebter-a) neɣ "Azeggaɣ d unili" i tlunetin; asayes yesɛa "Taskant s 3D", yettezzi s taɣerdayt neɣ s touchpad, d "Sifeḍ i yisnasen 3D nniḍen (.glb)"; tapanuramikt tettwaldi deg umeskan n 360°.

- **Tiɣmert AI**: ldi yal tawlaft tazeddigt, seg tmkarḍit-ik neɣ seg ufaylu n uẓeṭṭa, sakin sit ɣef "Tiɣmert AI" deg ufeggag n ufella: ibenk n uqerru yettektazal tiɣmert s yiman-is yerna yesskanay-d tawlaft s 3D, "Tiɣmert tettwaktazal s AI". "Ldi tiɣmert AI s 2.5D (s tirmit)", deg Iɣewwaren, Advanced, "AI d 3D", yessembiwil tiɣawsiwin i iqerben zdat n ugilal mi ara tesmussuḍ aqerru-ik. "Wali asayes 3D" ɣef uṣli, neɣ "Snirem asayes 3D" ɣef usayes, yessers asayes deg texxamt-ik: qreb ɣur-s, neɣ mmutti s thumbstick azelmaḍ daxel n temnaḍt yettwabnan tikkelt nniḍen ("Tallunt n tikli: qrib 0.5 m ɣer yal tama" i texxamt deg uqerru n usebter-a); tissiwin ttuɣalent d tizeddigin yerna tafat-nsent tettneqqis ɣer yiri-s, asiti ɣef thumbstick yerra-d tamuɣli akken tella, yerna B neɣ Y yettuɣal ɣer deffir.

**Ɣef tilifunen, tablitin d tiliẓriyin**, ifuyla yexdem uselkim ttwaldin akken llan, yerna ulac ayen yettwasirwen dinna. Tapanuramikt tettwaldi deg umeskan n 360° s tmatart "360° s AI", tafyirt d yizirig ɣef tilifunen d tablitin Android d Android TV; ɣef iPhone, iPad, tiliẓriyin LG d Samsung tettwaldi am tewlaft n 360° tamagnut akka tura. Asayes yettban am tewlaft-is, s tecreḍt tamecṭuḥt 3D SCENE deg teɣmert-is; ɣef Android, talqayt-is ternu "Ldi-tt ɣef Meta Quest akken ad tt-tesnirmeḍ". Tawlaft 3D tesskanay-d snat n wallen-is rrif ɣer rrif.

**Ayen n tidet d wayen mačči n tidet, yettwanna-d yal tikkelt.** D tagi i d lebɣi, mačči d tira tamecṭuḥt. Tiɣmert n tewlaft 3D tettwaktazal seg yiwet n tewlaft, yerna ayen teffer tewlaft yettwaččar, mačči d tidet. Asayes d "Yettwabna-d seg yiwet n tewlaft kan, snirem-it deg tlisa-s". Tapanuramikt teḥraz ipiksilen-ik n tidet anda llan, tesnulfuy-d ayen yeqqimen, qrib 90% seg tkurt i tewlaft tamagnut, yerna tanaka tettini-d acḥal uqbel ad tebduḍ. Asnas yettini-t anda ara tmuqleḍ, s "Tiɣmert tettwaktazal s AI", "Yettwasirew s AI beṛṛa n tlisa n tewlaft" d tmatarin, yerna ifuyla qqaren-t daɣen: deg XMP-nneɣ, yerna i yisayesen d tipanuramikin deg wanaw n uɣbalu umḍin IPTC n tugna yettwaxedmen s AI, akken isnasen nniḍen ad mgarden tapanuramikt yettwasirwen d tewlaft n 360° n tidet. Iṣliyen-ik werǧin ttbeddilen, yerna ulac ayen yettffɣen seg uselkim-ik neɣ seg yibenk-ik n uqerru. Akken i d-tenna tnaka: "Abeddel yemmden ur yeḍmin ara agmuḍ yelhan."

**Ayen yettwasneqden**, alamma d ass n 29 Tubeṛ 2026, s builds n tirmit n tengalt-a: tiwlafin 3D sɣur asnas Linux deg container ɣef PC Linux, ula war tuqqna; isayesen sɣur asnas Windows ɣef uselkim amaḥmul s RTX 4060 Laptop GPU (mraw deg 2 min 39 s) d sɣur amsedday ɣef PC Linux; ɣef uselkim amaḥmul-nni, ukuẓ n tpanuramikin deg 4 min 16 s ar 4 min 44 s yal yiwet, ileqman-nsent 3D deg qrib 30 s, s Sefsex, s usnas yettwaḥebsen s tmara, s wahil nniḍen i yeṭṭfen takarḍa tudlift, yerna asnas ur yeqqin ara ɣer uẓeṭṭa akk deg tirmiyin. ### Qqen TV, ibenk n uqerru neɣ aselkim s tilifun-ik

**Sleḍ. Qqen. Wali.** Tira n tansa n uqeddac, n yimayl d wawal uffir s tlikumand n TV, neɣ deg yibenk n uqerru, tettawi tisdatin. S Immuch360 ɣef tilifun-ik, yeqqnen ɣer uqeddac-ik Immich, TV, Meta Quest neɣ aselkim yeqqen deg kra n tsinin: agdil ameqqran yesskan-d tangalt QR, tilifun yesleḍ-itt, tsentmeḍ, yerna agdil yeldi ɣef tmkarḍit-ik. S usnas n tilifun, awal-ik uffir yeqqim ɣef tilifun. Asnas Immich ur yesɛi ayen yecban aya.

<p align="center">
  <img src="../.github/readme/sign-in-with-your-phone.png" width="720" alt="Tugna, mačči d tuṭṭfa n ugdil: TV tesskan-d tangalt QR ɣef usebter-is n tuqqna, yerna tilifun yettwaṭṭfen zdat-s yesleḍ yiwet n tengalt-nni">
</p>

1. Ɣef ugdil ameqqran (Android TV d Google TV, ṭṭaq n Meta Quest, Windows, Linux neɣ macOS), fren "Qqen ɣer uqeddac Immich": asebter n tuqqna yesskan-d "Qqen s tilifun-ik", tangalt QR d tengalt n 10 n yisekkilen, ɣer tama n tferkit n uqeddac.
2. Ɣef tilifun yeqqnen ɣer uqeddac-ik: Iɣewwaren, "Qqen TV neɣ aselkim", sinna "Sleḍ tangalt". Deg Meta Quest, anda tilifun ur yezmir ara ad yesleḍ agdil-is, fren "Sekcem tangalt deg wadeg-is" yerna aru tangalt i d-yesskan yibenk n uqerru.
3. Tilifun ad k-yesteqsi "Ad yeqqen (agdil)?" yerna ad d-yesken amḍan n sḍis n wuṭṭunen: senqed ma yella agdil yesskan-d yiwen-nni, sinna sit ɣef Qqen. Agdil ad yeldi ɣef wumuɣ-ik azemani.

Amek yeqqim d aɣellsan: tilifun d ugdil ilaq ad ilin ɣef yiwen n uẓeṭṭa n uxxam, yerna tangalt tettdum snat n tesdidin ma yella aṭas, tteddu yiwet n tikkelt kan. Tilifun yessuter seg uqeddac-ik tiɣimit tamaynut i ugdil-nni, s yisem-is ("Immuch360 ɣef TV n usalun"), yerna yazen-itt i ugdil d tawgelhant, ihi awal-ik uffir werǧin ad yeffeɣ seg tilifun. "Qqen TV neɣ aselkim" yesskan-d umuɣ n igdilen i yeqqen tilifun-agi, yal yiwen s Ffeɣ, yerna Immich yesskan-iten-id deg Iɣewwaren n umiḍan, Ibenkan yettusirgen, anda i tzemreḍ daɣen ad ten-tekkseḍ. Tuffɣa n tilifun ad ten-tessuffeɣ ula d nutni.

Tama n tilifun tetteddu tura ɣef Android, yerna ɣef iPhone d iPad seg lexraj i d-iteddun n iOS. War Immuch360 ɣef tilifun, sleḍ tangalt s tkamirat n tilifun: asebter i d-yettak ugdil yeldi deg yiminig, i yimayl-ik d wawal-ik uffir, yettwawgelhen yerna yettwaseqdac yiwet n tikkelt. Tiliẓriyin LG qqnent s tengalt-nsent QR, deg yiminig n tilifun; seg build 28, amsiḍeḍ n usnas n tilifun yessen-itt yerna yeldi asebter-nni. Tiliẓriyin Samsung qqnent s tira i tura.

Ugar: [tuqqna s tilifun-ik](../docs/immuch360/user-guide.md#sign-in-a-tv-a-headset-or-a-computer-with-your-phone), [ayen i ttazznen igdilen d wayen i ḥerrzen](../docs/immuch360/technical-details.md#sign-in-with-your-phone).

### Ssurar ifuyla n NAS, n uselkim, n uqeddac n yimidyaten neɣ n Plex

Tividyutin-ik llant ɣef NAS, aselkim, aqeddac n yimidyaten neɣ Plex. Immuch360 yettaf iqeddacen n uẓeṭṭa-k s yiman-is, yettinig deg-sen yerna yessurar tiwlafin-nsen d tividyutin-nsen deg wadeg-nsen, deg yal ameskan n usnas, war ma yenɣel kra: SMB (Samba, ifuyla n uẓeṭṭa Windows), WebDAV (Nextcloud, Synology d wiyaḍ) d yiqeddacen n yimidyaten DLNA (Jellyfin, Emby, minidlna, NAS, tabewwaṭ n TV). Tilifun yezmer daɣen ad yebḍu agraw-is ɣef Wi-Fi i yibenk n uqerru neɣ i yal amsaɣ WebDAV, akken daɣen aselkim Windows.

<p align="center">
  <img src="../.github/readme/b19-add-share.png" width="260" alt="Asebter Rnu afaylu yettwabḍan: Isem, Isem neɣ tansa n uqeddac, Tawwurt (d afrayan), Afaylu yettwabḍan, Fren afaylu yettwabḍan, Akaram n tazwara (d afrayan), Isem n useqdac, Awal uffir, Sekyed tuqqna, d ugmuḍ Yeqqen, 2 n yiferdisen deg ukaram n tazwara">
  <img src="../.github/readme/b19-share-folder.jpg" width="260" alt="Akaram n ufaylu yettwabḍan n uẓeṭṭa am uẓeṭṭa n tugniwin timecṭuḥin: tiwlafin 360° s tcreḍt 360° akked tvidyut 360° s tcreḍt n urar, taqeffalt Fren d asawen s ayeffus">

1. Ldi iccer Tamkarḍit, sinna Ifuyla n uẓeṭṭa, sinna + akked "Afaylu n uẓeṭṭa (NAS, aselkim, aqeddac n yimidyaten)". Seg build 24, "Rnu afaylu n uẓeṭṭa neɣ aqeddac n yimidyaten" ɣef usebter n ansuf yeldi-d srid Ifuyla n uẓeṭṭa, war aqeddac.
2. Sit ɣef uqeddac ddaw "Yettwaf deg uẓeṭṭa", neɣ ačaṛ isefka s ufus: anaw, isem neɣ tansa n uqeddac, afaylu n uẓeṭṭa neɣ abrid, akaram n ubeddu, isem n useqdac akked wawal uffir.

4. I uqeddac Plex: deg Ifuyla n uẓeṭṭa, + d "A Plex Media Server", sinna sit ɣef uqeddac-ik ddaw "Found on the network", senṭeḍ ajiṭun yiwet n tikkelt ("How to get it" ɣef usebter yeqqar-d anda ara t-tafeḍ), sinna "Test the connection" d Save.

Imeskanen qqaren bytes i ten-ilaqen s allal n tuqqna i gensan deg usnas, s izilal n bytes, akken asikel deg wakud ad ixdem u ulac acemma ara yețwaḥrez ɣef ibenk; tividyut SMB teqqar s ɣer sețța n tuqqniwin ɣer yiwet n tikkelt i wakken ad tedduḍ war ɛeṭṭel. Seg build 29, isura yettwaseklsen s M2TS (Blu-ray, tikamirawin AVCHD, imseklas n TV) ttwaurarent deg usnas Android seg yifuyla n uẓeṭṭa SMB d WebDAV akked yiqeddacen DLNA i ten-yesskanen am transport stream, yerna aqeddac DLNA i d-yemmalen tiddi n 0 dayen ur d-yettak ara tavidyut tilemt.

**Plex Media Server, war plex.tv**: asnas yeqqen srid ɣer uqeddac-ik, s ujiṭun i tsenṭḍeḍ yiwet n tikkelt, yerna yeqqar srid ifuyla iẓuranen n tmkarḍiwin-ik, daymi 360° yeqqim d 360°, deg wexxam yerna, s usiweḍ n tewwurt-ik, beɛid ɣef wexxam. Ɣef tiliẓri LG, Plex yeqqen s tengalt ɣef plex.tv/link.

### Ḥrez tamkarḍit-ik Immich, s wugar

S uqeddac [Immich](https://github.com/immich-app/immich), Immuch360 d asnas n tilifun n Immich, s yiwen uqeddac akked yiwen umiḍan am win n usnas n web: aḥraz, umuɣ azemani, albumat, anadi, imdanen, ismektayen, abeṭṭu, imdukal, kullec yemtawi akked uqeddac-ik. Yețwasebded ɣer tama n usnas arasmi. Nnig-s: tacreṭ d umuɣ n 360°, yal ameskan imirsif, tafrant ger ufaylu agejdan d wafaylu yettwabeddlen n uqeddac i yal tividyut, talqayt tusnakt n tvidyut, akked ifuyla n ufaylu n uẓeṭṭa neɣ n ibenk i d-ttwaznen ɣer uqeddac-ik s ufus.

1. Ɣef usebter n ansuf, sit ɣef "Qqen ɣer uqeddac Immich", sinna qqen s tansa n uqeddac-ik, imayl-ik akked wawal uffir-ik, akken deg usnas Immich; Tuɣalin ad ak-d-terr ɣer usebter n ansuf. Ar build 23 asebter n tuqqna yeldi-d srid. Tamkarḍit, albumat akked yiɣewwaṛen n uḥraz d wid n umiḍan-ik.
2. Deg Iɣewwaṛen, Ameskan n Ayla, Tividyutin, "Aɣbalu n tvidyut" tettxeṣṣes afaylu agejdan ticki ibenk-agi yezmer a t-idikuder, yal tikkelt afaylu agejdan, neɣ yal tikkelt afaylu yettwabeddlen.
3. I wakken a d-tesskeneḍ tawlaft n 360° i yiwen ur-nesɛi ara asnas, beṭṭu-tt s yiwen ussaɣ yebḍan n Immich: asnas n web n Immich yesskan-itt-id d takuret deg iminig-nsen.

Ttxil-k, azen-d uguren deg [Issues](https://github.com/freeKC/Immuch360/issues), mačči i usenfaṛ Immich.

**Anwi tilikumanden d yidrunen**, ass n 26 Tubeṛ 2026: tavidyut srid tusa-d s tlikumand DJI i yeqqnen ɣer tilifun s uselk-is. Tremseḍ tayuga nniḍen? Isell kan. Werǧin ad tettwazen tladna i tlikumand neɣ i udrun: yiwen n ubyte i yettaru usebter yal tasint, seg 20 n tsinin seld mi teldi tlikumand, yeqqar-d kan ma yella tilikumand teqbel isefka, ur yesɛi ara tladna.

Ɣef ugdil srid: aẓru n udrun d wakud n umutur, yerna deg wafug, teɣzi sennig n wadeg n tufgin, arured ubdid, arured d wemmud ddaw udrun. Azal ur d-yettban ara dinna alamma tuṭṭfiwin-nneɣ n wafug sbeggnent-t: teɣzi, aruraden d wemmud ddaw-s ttwasbeggnen ɣef tuṭṭfiwin n sin n yifugen deg uxxam ass n 25 Tubeṛ, ar 1.8 m n teɣzi d 1.5 m/s, urɛad sennig; askan-nsen dinna d amaynut deg build 30 yerna ad yettwarmes i tikkelt tamezwarut yid-s. Teɣzi tettban-d azal n 1.5 s seld tufgin, mi ara yeǧǧ udrun tamurt neɣ afus, yerna teqqim teffer alamma ḥebsen imuturen ma yella tenṭeg s wudem ur yezmir ara yiwen n usafag. Advanced yerna tazmert d tziɣelt n uẓru, tanila (amḍan-is ilem urɛad yettwasenqed ɣer ugafa) d yimuturen, yerna Diagnostics yal amḍan i d-yettak useɣwen, ula d alḥu n uẓru. Ulac isatliten, ideg neɣ amecwaṛ seg wexxam i d-yettbanen. Imḍanen urɛad ttwasemḥezzen d DJI Fly: ur ttafeg ara ɣef leḥsab-nsen.

**Tawinest n yiɛewwiqen**, tremmed s wudem amezwer: mi ara walin yimeɣwaḍen n udrun kra n wayen yqerben, tawinest tafrawant tettban-d deg tlemmast n tugna, s uẓuẓar ɣer uɛewwiq, d tawraɣt tettuɣal d tazeggaɣt mi ara d-yqerreb, amecwaṛ-is ɣer tama-s d useqsi awezlan yettɣawalen; mi ulac ayen yqerben, ulac ayen i d-yettbanen. Tawinest d tnila n uẓuẓar ttwasenqden deg wafug, deg uxxam, ass n 25 Tubeṛ, ɣef build n tirmit anda tanila tella d taɣtest; imi tettban s wudem amezwer, ad tettwarmes i tikkelt tamezwarut s build 30. Deg Advanced, tesbaduḍ imecwaṛen ("Glow from", 3.0 m, d "Strong glow from", 1.0 m), tferneḍ akatar ɣef yiri n tugna deg wadeg n tewinest, neɣ tsenseḍ tawinest, imesli-ines neɣ tirgit-is. Tesskan-d kan ayen i d-ttaznen yimeɣwaḍen n udrun: ulac deg uskar Sport neɣ mi ara yens usewweḥ n yiɛewwiqen, yerna ulac tafat ur yeqqar ara belli abrid d ilelli. D talɣut kan: Immuch360 werǧin yessewjad neɣ yessḥebs adrun.

1. Takarḍa Drone tella deg Tamkarḍit, d "DJI live video" ɣef usebter-is: "DJI live video (experimental)", deg Iɣewwaren, Advanced, tremmed s wudem amezwer.
2. Ssenker adrun d tlikumand, mdel DJI Fly, sinna ldi "DJI live video" yerna ɣer alɣu n tɣellist.
3. Qqen tilikumand ɣer tilifun s uselk-is. Ma yesteqsa Android anwa asnas ara tt-yeldin, fren Immuch360 war "Always", ayen ara yekksen tilikumand i DJI Fly; ma yesteqsa ɣef uskar USB, fren asiɣ kan. Seg tura, tuqqna n tlikumand teldi agdil-agi s yiman-is ("Open this screen when the remote is plugged in", yermed s wudem amezwer deg Advanced).
4. Remote, Drone d Picture sfawent yiwen seld wayeḍ, yerna tugna tettas-d ɣef ugdil ačaran deg kra n tsinin. Kraḍ n tqeffalin (ffeɣ, "Send to a headset or a TV" d Advanced) d wazalen llan deg tsebnin tiberkanin ɣer tama n tugna. Ilɣa, am "Live", ttruḥun seld azal n semmus n tsinin; asiti anda yebɣu yerra-ten-id, yerna ulac ayen ɣef tugna i yettḥerriken adrun. Tuccḍa i k-yessutren ad txedmeḍ kra teqqim.
5. Advanced yesɛa "Save a capture for a bug report", i yettarun tuṭṭfa n useɣwen deg `Download/Immuch360/dji-link`, "Play a saved capture", akken ad tesurareḍ yiwet tikkelt nniḍen war tlikumand, d Diagnostics, s yal amḍan i d-yettak useɣwen.

Tiwlafin d tividyutin n udrun ur zmirent ara ad ttwawḍent s tlikumand, ur nettldi ara asekles n udrun: nɣel-itent srid seg udrun s USB neɣ seg tkarḍa-ines, am [wayen ddaw-a](#bring-a-drones-or-a-camera-cards-photos-and-videos-to-immich). Ḥrez tuṭṭfiwin yettwaskelsen i yiman-ik, akken i d-yeqqar usebter: sɛant tavidyut n udrun d yimḍanen n umazrar n tlikumand d usafag, yerna zemrent ad sɛunt ideg-is; aneqqis deg [Issues](https://github.com/freeKC/Immuch360/issues) s wayen i d-yesskan Diagnostics yettɛawan, ladɣa s tlikumanden-nniḍen n DJI.

<a id="watch-it-in-a-meta-quest-or-on-an-android-tv"></a>
#### Wali-t deg Meta Quest neɣ ɣef Android TV

Tilifun yeqqnen ɣer tlikumand yezmer ad yazen tugna d wazalen n udrun ɣer Immuch360 deg Meta Quest neɣ ɣef Android TV neɣ Google TV deg yiwen uẓeṭṭa adigan, i yemdanen yellan yid-k. Ibenk n uqerru yesskan-iten-id deg usfaylu neɣ, s tmeqqrit, deg tmuɣli n wafug zdat-k, yerna TV ɣef ugdil ačaran, s yiwen wazalen d yiwet n tewinest n yiɛewwiqen am tilifun. Ttwalin kan: ulac ayen yetteg yibenk n uqerru neɣ TV ara yawḍen ɣer tlikumand neɣ ɣer udrun. Ilɣa-nsen, am "Tamuɣli kan", ttruḥun seld kra n tsinin yerna ttuɣalen-d s tqeffalt, s usiti neɣ s tqeffalt n ugdil. Tugna n udrun tewweḍ ɣer Quest 3 yiwet n tikkelt, ass n 24 Tubeṛ, s Wi-Fi n wexxam; asfaylu n yibenk n uqerru d tmuɣli n wafug s wazalen d tewinest n yiɛewwiqen ad ttwarmsen i tikkelt tamezwarut s build 30, yerna Quest 2, Pro d 3S urɛad ttwarmsen. Ma yella tawinest teffer tilemmast n tugna deg yibenk n uqerru, "Akatar ɣef yiran" deg wumuɣ-is yettḥaz tilemmast d tilellit. Ɣef Android TV TCL, tuqqna d tugna ttwarmsent ass n 25 Tubeṛ, s uḥbas d yini azegzaw deg usiweḍ yezrin; ass n 26 Tubeṛ, s build 30, seld abeddel ɣer usuddem urkid, TV tkemmel tesskan-d tugna deg yiwen n wafug anda adrun yettazen 18 Mbit/s, s 7 n yiḥbasen, win yeɣzifen ugar 1.7 s; amek i d-tban tugna ur yettwaru ara. Seg build 31, alɣu n tɣellist ɣef TV yettḥaz asaḍas n tlikumand (yettwasenqed s tirmiyin n widget, urɛad ɣef TV-nni); deg build 30 tamuɣli i yellan seddaw-s tezmer ad tawi asaḍas, ihi alɣu ur yezmir ad yettwaɣer wala ad yettwaqbel, yerna abrid kan n tuffɣa d Tuɣalin, i yeǧǧan asebter. Afug mi ara tettwaliḍ ibenk n uqerru neɣ TV yesra amɛassay ɣer tama-k i yettwalin adrun (taggayt yeldin n EU); war-it, wali adrun.

1. Ɣef tilifun, ɣef ugdil srid, sit ɣef "Send to a headset or a TV" sinna rmed-it.
2. **Meta Quest**: ldi Immuch360, Tamkarḍit, Drone, sinna fren tilifun; aru tangalt i d-yesskan tilifun, yiwet n tikkelt i tilifun-nni. Tugna teldi deg usfaylu; "Open the flight view" yessimɣur-itt, yerna B neɣ Y yerra-d asfaylu.
3. **Android TV d Google TV**: ldi Immuch360, Tamkarḍit, Drone. Ddaw "Let this TV watch", TV tesskan-d tangalt d tengalt-is QR: ɣef tilifun, deg yiwen ugalis-nni, sit ɣef "Add a TV" sinna sleḍ-itt, neɣ aru-tt. Sinna fren tilifun ɣef TV sinna sit ɣef OK: tugna tettas-d ɣef ugdil ačaran; OK yesskan neɣ yeffer imḍanen, yerna Menu yeldi tifranin.
4. Tilifun d ugdil ilaq ad ilin deg yiwen uẓeṭṭa adigan. Beɛid ɣef wexxam, rmed hotspot n tilifun, deg tegrumma n 5 GHz ma tella, sinna qqen ɣur-s seg yibenk n uqerru neɣ seg TV.
5. I uneqqis n wabug, umuɣ n yibenk n uqerru d Options n TV sɛan Diagnostics d "Save a reception record", i yettḥerrizen ayen i d-yewweḍ ɣer ugdil-nni.

**Taɣara n usiweḍ**, tamaynut deg build 30, deg Leqqayen ɣef tilifun: deg wafug adrun yettazen azal n 18 Mbit/s, yerna ass n 25 Tubeṛ abrid n Wi-Fi n wexxam seg tilifun ɣer TV s urawtar yewwi asuddem-nni ačaran kan tis kraḍ n wakud n wafug; deg wakud yeqqimen, tugna n TV tḥebbes, tettruẓ yerna tettawi yini azegzaw. S "S wudem awurman", azal amezwer, agdil anda Wi-Fi ur yezmir ara ad yeḍfer yettawi tugna turkidt i s-d-yettnuɣal tilifun ad tt-yesnegzem, ar 1080p s 30 n tugniwin deg tsint d uktum i yezmer Wi-Fi-ines, yettwaxedmen akken ad teqqim d tazedgant, s drus n telqayt, deg wadeg ad tettruẓ; tettuɣal ɣer tugna n udrun s yiman-is deg usrusu neɣ tufgin i d-iteddun, mi ara yawi Wi-Fi-ines tugna turkidt 30 s war aḥbas; ass n 26 Tubeṛ Wi-Fi n TV-nni ur t-yexdim ara akk, yerna TV teqqim ɣef tugna turkidt, s 15 n tugniwin deg tsint deg 44 seg 59 n tsinin-is. "Asuddem ummid" yettazen yal tikkelt tugna n udrun akken i d-tusa, "Asuddem yerkden" yal tikkelt tin n tilifun. Tugna turkidt teddi i tikkelt tamezwarut ɣef tilifun ass n 26 Tubeṛ, s build 30: Galaxy S24+, i tt-yesnegzamen s HEVC deg hardware s uktum n bit yerkiden. TV ɣef uselk Ethernet, neɣ agdil yeqqnen srid ɣer hotspot n tilifun, yeǧǧa yiwen n uneggez n Wi-Fi deg wadeg n sin.

Ulac-it deg build-agi: adrun ɣef iPhone d iPad (urɛad yebda), asiweḍ ɣer tiliẓriyin LG d Samsung, d usbeggen n wazalen sennig 1.8 m d 1.5 m/s, sinna isatliten d wemcwaṛ seg wexxam, i yettrajun afug beṛṛa.

#### Awi tiwlafin d tividyutin n udrun neɣ n tkarḍa n tkamirat ɣer Immich

Kter tiwlafin d tividyutin n udrun DJI s USB, srid ɣer uqeddac-ik Immich: qqen adrun neɣ ameɣri n tkarḍiwin ɣer tilifun Android, fren ifuyla imaynuten sinna azen-iten, s tividyutin yettwasersen ɣef tkarḍa n tmurt seg yisefka n wafug n udrun, akked tikurin n 360° n udrun yettbanen d 360°. Asnas Immich yeḥraz kan ayen yellan yakan deg ugraw n tilifun, yerna aqeddac Immich urɛad yezmir ad yeqqar adig n tvidyut n DJI Neo 2. Asebter-agi d armitan, ɣef tilifunen d tablitin Android kan, yerna urɛad yettwarmes s udrun n tidet.

<p align="center">
  <img src="../.github/readme/dji-drone-import.png" width="720" alt="Tugna, mačči d tuṭṭfa n ugdil: adrun ɣef ṭṭabla n teẓqa, yeqqnen ɣer tilifun s uselk, yerna tiwlafin-is d tividyutin-is ttruḥunt s uẓuẓar seg udrun ɣer ugraw n tilifun">
</p>

1. Ldi takarḍa Drone deg Tamkarḍit, sinna "Photos and videos from the drone". Aɣewwar-is, "DJI drones (experimental)" deg Iɣewwaren, Advanced, yermed s wudem amezwer; sens-it dinna akken ad teffreḍ asebter-nni.
2. Qqen adrun (Neo 2 yezmer ad yeqqim yensa) neɣ ameɣri n tkarḍiwin ɣer tilifun s ukabel n yisefka USB-C; tilikumand DJI war agdil (RC-N1, RC-N2, RC-N3) ur teḥriz ara tiwlafin. Deg usebter Adrun DJI, sit ɣef "Fren adrun neɣ takarḍa", fren-it deg wumuɣ n tama n umefran, ldi akaram-is DCIM neɣ eǧǧ aḍebsi meṛṛa, sinna "Seqdec akaram-agi" d Sireg.
3. Asebter yesskan-d tiwlafin d tividyutin s wass, war ifuyla n tama .LRF, .SRT, .THM d .m4a. Sit ɣef "Fren akk imaynuten", sinna "Sali ɣer Immich"; ifuyla yettwaznen uqbel sɛan tacreḍt n usigna yerna ttwazeglen. "Eǧǧ-it ɣef ibenk" yesneɣlay ifuyla ɣer ugraw n tilifun deg wadeg n waya, deg walbum "Immuch360 import".
4. Akken ad teqqim tvidyut ɣef tkarḍa n tmurt, rmed iduzwilen n tvidyut (Video Subtitles) deg DJI Fly (askar n tvidyut, Iɣewwaren, Takamirat) uqbel ad tafgeḍ: adrun ad yaru afaylu .SRT ɣer tama n yal tavidyut, asnas ad d-yeqqar seg-s adig sinna ad t-yesbadu ɣef uqeddac-ik seld asali, ma yella Immich ur d-yufi ara adig.

Tikurin n 360° n yidrunen DJI (Mini, Air, Mavic d wiyaḍ, yettwassnen seg tkamirat-nsen) ttbanent d 360° deg Immuch360 ula war tibzimin n 360°. Immich yeḥwaǧ tibzimin-nni: tafrant n usali "Creḍ tikurin n yidrunen d 360° i Immich", tensa s wudem amezwer, tazen tawlaft war abeddel s ufaylu .xmp amecṭuḥ ɣer tama-s, akken Immich ad tt-yesken daɣen d takuret. Neo 2 ur yesɛi ara askar n tkuret neɣ n tpanuramit: tiwlafin d tividyutin-is d tizeddigin. Ticki tilifun yesekles ameslaw n tvidyut n Neo 2, ameslaw-nni yella deg ufaylu .m4a weḥd-s: asebter ad yecreḍ tavidyut-nni, yerna Immich ad tt-yaweḍ war ameslaw (sader-itt s DJI Fly akken ad teḥrezḍ ameslaw). Yal takarḍa n tkamirat s ukaram DCIM txeddem akka kan deg umeɣri n tkarḍiwin. Ulac ayen yettwaznen i DJI.

Ugar: [idrunen DJI s USB](../docs/immuch360/user-guide.md#dji-drones-photos-and-videos-over-usb-experimental), [tasleḍt n useɣwen DJI](../docs/immuch360/user-guide.md#dji-link-diagnostics-experimental).

### Ldi ifuyla raw n tkamirawin n 360°

Tiwlafin raw .insp d tividyutin .insv n tkamirawin Insta360 (yiwet neɣ snat tewlafin n tmuɣli, deg yiwen ubrid, sin n yiberdan neɣ sin n yifuyla), ifuyla .360 n GoPro MAX d yifuyla .osv n DJI Osmo 360 ttwasdukklen sɣur usnas mi ara ttwaurarent, s userked yettwarun deg ufaylu, war ma tesbeddeḍ kra anda yebɣu yili.

1. Sers ifuyla raw anda ten-yeqqar usnas: afaylu n uẓeṭṭa SMB neɣ WebDAV, aqeddac-ik Immich (yeqbel kan .insp d .insv), neɣ ikaramen n uselkim. Agraw n tilifun Android ur d-yesskan ara ifuyla raw, daymi afaylu raw yettwanɣel ɣer tilifun ur d-yettban ara deg ugraw-is ula deg usnas.
2. Ḥrez sin n yifuyla n tuṭṭfa i yesɛan sin n yifuyla akken: asnas yettnadi wayeḍ ɣer tama n umezwaru.
3. Ldi afaylu sinna sit ɣef 360°. Tawlaft tesskan-d "Raw 360° file, stitched by the app" s uɣbalu n userked-is; tavidyut tettwasdukkel mi ara tettwaurar.

Linux d macOS ssurarent tividyutin raw d tizeddigin, yerna ifuyla .dng s snat n tewlafin n tmuɣli n uḥuddu ttbanen d izeddigen i tura.

Ugar: [ifuyla raw n tkamirawin n 360°](../docs/immuch360/user-guide.md#raw-360-camera-files-without-the-cameras-app).

<a id="turn-a-photo-with-one-key"></a>
### Zzi tawlaft s yiwet n tqeffalt

Zzi tawlaft s 90° s yiwen usiti, war ma teldiḍ amaẓrag: taqeffalt, taqeffalt n klavye neɣ taqeffalt s yini n tlikumand n TV, ɣef yal tagrumma. Asnas Immich yettezzi tawlaft deg umaẓrag-is; Immuch360 yexdem-it s yiwet n tqeffalt, yerna i tiwlafin-ik ɣef uqeddac Immich 2.6 neɣ win i d-iteddun, ad iɛeddi s umaẓrag-nni n uqeddac, akken asnas web d yibenkan-ik nniḍen ad ten-sken ttwazzint. Ayen nniḍen n twlafin ttezzint ɣef ibenk-agi kan. Tiwlafin n 360°, 180° d 3D ur ttezzint ara, akken timuɣliwin timirsifin ad qqiment d tusridin.

<p align="center">
  <img src="../.github/readme/rotate-one-key.png" width="720" alt="Tugna, mačči d tuṭṭfa n ugdil: tilifun yesskan-d tawlaft tettezzi s ukuẓ n tezzya s tnila n temrilt, sennig n yizirig n tqeffalin tibeddayin anda taqeffalt n tuzzya tesfaw">
</p>

1. **Tilifunen, tablitin d ṭṭaq n Meta Quest**: ldi tawlaft sinna sit ɣef Zzi deg yizirig n wadda, uqbel Ẓreg, akken ad tezzi ɣer tama n tsegnatin n temrilt; asiti aɣezfan yettezzi-tt ɣer tama nniḍen. S klavye, R d Shift+R.
2. **Android TV d Google TV**: taqeffalt tawraɣt n tlikumand tettezzi tawlaft ɣer tama n tsegnatin n temrilt, taqeffalt tanilit mgal-asent, anda yella uskan deg umeskan. Ɣef tlikumand war tiqeffalen s yini, sit ɣef Adda: afeggag ddaw twlaft ad d-iban s Zzi yettwafernen (yiwen Ayeffus ma yella tawlaft tesɛa taqeffalt n uḍris), yerna yal OK yettezzi tawlaft.
3. **Tiliẓriyin LG (webOS)**: tawraɣt d tanilit am ɣef Android TV, R d Shift+R ɣef unasiw, neɣ taqeffalt n tuzzya n yiferdisen n usefrek n twlaft. Tiliẓriyin Samsung ttezzint daɣen tawlaft s yiwet n tqeffalt.
4. **Windows, Linux d macOS**: R yettezzi ɣer tama n tsegnatin n temrilt, Shift+R mgal-asent, neɣ taqeffalt n tuzzya deg ufeggag n usawen, uqbel agdil ameqqran.
5. **Tiwlafin n ufaylu n uẓeṭṭa, Plex neɣ takamirat**: taqeffalt n tuzzya d tamezwarut deg ufeggag n usawen, R d Shift+R, neɣ tiqeffalen tawraɣt d tanilit.

Anda tettwaḥraz tuzzya: tawlaft n umiḍan-ik ɣef Immich 2.6 neɣ win i d-iteddun tettezzi s umaẓrag n twlafin n uqeddac, i yeḥerzen afaylu agejdan yerna ixeddem tugna yettwazzin (afeggag arqaq yettban mi ara yexdem; ukkuẓ n tuzzyiwin, neɣ yiwet n tuzzya ɣer deffir, ad d-rrent agejdan). Tiwlafin n ibenk, n ufaylu n uẓeṭṭa, n umendad neɣ n walbum yettwabḍan, akked yal tawlaft ɣef uqeddac aqbur ttezzint ɣef ibenk-agi kan, i twlaft-nni, yerna afaylu ur yettbeddil ara; asnas ad t-yini tikkelt kan i twlaft n Immich. Deg yisnasen Android, iOS d uselkim, tuzzya yettwaḥerzen ɣef ibenk tettban deg umeskan, maca mačči yakan deg tugniwin timectuḥin, askan n tugniwin d yimektayen. Tividyutin, akaram yettwasekkṛen d yal tawlaft n 360°, 180° neɣ 3D ur sɛint ara Zzi.

## Tabaḍnit

Ulac ayen yettawḍen ɣer uneflay: ulac amiḍan, ulac tasleḍt n useqdec, ulac ameẕlu n uneqqis n uɣelluy, ulac adellel. Asnas yettmeslay kan d yiqeddacen i tferneḍ (aqeddac-ik Immich, ifuyla-ik n uẓeṭṭa, aqeddac-ik Plex, tikamirawin-ik) yerna, war aqeddac, ulac d wi. Awalen uffiren d yijiṭunen qqimen deg usekles aɣellsan n yibenk; tiliẓriyin LG d Samsung ur sɛint ara aya i usnas, daymi dinna qqimen deg usekles n usnas s yiman-is, ur ttwawgelhen ara. Takamirat tettwaseqdac kan ɣef yibenk, sɣur umeskan Spatial 2.5D d usleḍ n tengalt n ugdil i tqqneḍ; tugniwin-is werǧin ttwaskelsent neɣ ttwaznent anda yebɣu yili. Agdil yeqqnen seg tilifun-ik yettawi tiɣimit-is, yettwaznen yettwawgelhen deg uẓeṭṭa n wexxam-ik, werǧin awal-ik uffir; tiliẓri LG teqqen s usebter deg yiminig n tilifun, i yettazen imayl-ik d wawal-ik uffir ɣer TV war awgelhen deg uẓeṭṭa n wexxam-ik, yerna TV tettḥaz kan tiɣimit. Tuṭṭfiwin d yiɣmisen n tremsit n yisebtar n udrun qqimen ɣef yibenk ala ma tebḍiḍ-ten: sɛan tavidyut n udrun yerna zemren ad sɛun ideg-is, yerna tuṭṭfa imḍanen n umazrar n tlikumand d usafag. Tugna d wazalen n udrun ttruḥun seg tilifun kan ɣer yibenkan n uqerru d tiliẓriyin i tqqneḍ, deg uẓeṭṭa-k adigan, ur ttwawgelhen ara, am tilifun yettwabḍan ɣef Wi-Fi. Ulac ayen yettwaznen i DJI, ula i TP-Link. Tasertit tačarant tella deg [PRIVACY.md](../PRIVACY.md), yerna talqayt i yal aɣbalu deg [udlis n useqdac](../docs/immuch360/user-guide.md#privacy).

**Timahilin AI** xeddment ɣef yibenkan-ik kan. Tawlaft, tiɣmert-is, asayes-is d tpanuramikt-is ttwasiḍnent ɣef uselkim-ik neɣ deg yibenk-ik n uqerru yerna ur ttwaznent ɣer wanda nniḍen. Asnas yeqqen kan i usader n uḥric i tsutreḍ, seg yisufeɣ n usenfaṛ-a ɣef GitHub neɣ, ma ur yeddi ara, seg usebter unṣib n tmudemt ma yella yesɛa-t, yesneqd yal afaylu s SHA-256-ines, sinna yetteddu war tuqqna. ONNX Runtime, i yesseddayen timudmin ɣef uselkim, yettazen telemetry ɣer Microsoft deg builds-is unṣiben; Immuch360 yessens-itt. Ifuyla imaynuten ttruḥun ɣer yidis n yiṣliyen-ik, werǧin ɣef-sen, yerna ttawḍen ɣer uqeddac-ik Immich kan ma tesremdeḍ "Ḥrez daɣen ileqman AI" ("Fren akk" deg walbumat n uḥraz yessermad-it daɣen).
