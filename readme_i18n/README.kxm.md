# Immuch360

**สื่อของเจ้า. จอใดก็ได้. ทุกมุมมอง.**

Immuch360 เป็นแอปฟรีและโอเพนซอร์สสำหรับหา, ดู, เปิด, กับสำรวจภาพถ่ายและวิดีโอของเจ้า: ทั้งแบบธรรมดา กับแบบพาโนรามา, 360°, 3D, และแบบดื่มดำที่แอปอื่นแสดงเป็นแบบแบน, ซ้อนกัน หรือยืดเสีย. มันอ่านมันจากที่มันอยู่, บนอุปกรณ์เอง, บน NAS หรือคอมพิวเตอร์, บนเซิร์ฟเวอร์ Plex หรือเซิร์ฟเวอร์ Immich, แล้วเปิดมันบนโทรศัพท์, แท็บเล็ต, ทีวี, เฮดเซ็ต Meta Quest กับคอมพิวเตอร์. บ่ต้องมีบัญชี, บ่ต้องมีคลาวด์, บ่ต้องมีเซิร์ฟเวอร์.

- **มันเฮ็ดอะไรได้?** มันแสดงภาพถ่ายและวิดีโอของเจ้าเป็นแกลเลอรี แล้วเปิดมันในวิวเวอร์ที่เหมาะกับไฟล์แต่ละอัน: แบบแบน, เป็นทรงกลมที่เจ้ามองไปรอบๆได้, แบบ 3D, ในเฮดเซ็ต.
- **สื่อแบบไหนบ้าง?** ภาพถ่ายและวิดีโอแบบแบน, พาโนรามา, ภาพถ่ายและวิดีโอ 360°, VR180, 3D แบบสเตอริโอ, ภาพ spatial ของ Apple, ภาพทรงกลม 360° ของโดรน DJI, และไฟล์ raw จากกล้อง 360° (Insta360, GoPro MAX, DJI Osmo 360) ที่แอปต่อให้เป็นภาพเดียว.
- **ใช้ได้กับอุปกรณ์ไหนบ้าง?** โทรศัพท์และแท็บเล็ต Android, iPhone กับ iPad, Android TV และ Google TV, ทีวี LG ที่ใช้ webOS (แอปแยกต่างหาก, เป็น build ทดสอบ), Meta Quest 2, Pro, 3 กับ 3S, Windows (พรีวิว), แล้วก็ Linux กับ macOS เป็นพรีวิวช่วงแรก.
- **ต้องมีเซิร์ฟเวอร์หรือบัญชีบ่?** บ่ต้อง. Immuch360 ใช้งานได้เองกับสื่อในอุปกรณ์ของเจ้า. เซิร์ฟเวอร์ Immich, NAS, เซิร์ฟเวอร์สื่อ หรือเซิร์ฟเวอร์ Plex เป็นตัวเลือกที่เจ้าเพิ่มเข้ามาเมื่อเจ้าต้องการ.
- **จะเข้าสู่ระบบบนทีวี, เฮดเซ็ต หรือคอมพิวเตอร์ได้ยังไง?** ใช้โทรศัพท์ของเจ้า: สแกน QR code ที่หน้าเข้าสู่ระบบของมันแสดง, หรือพิมพ์โค้ดของมัน, ยืนยัน, แล้วมันก็เปิดไลบรารี Immich ของเจ้าภายในบ่กี่วินาที, บ่ต้องพิมพ์อะไรด้วยรีโมทเลย.

## เจ้าเฮ็ดอะไรได้บ้าง

การใช้งานแต่ละอย่างข้างล่างนี้บอกว่าเจ้าได้อะไร, แล้วทำยังไงในขั้นตอนไม่กี่ขั้น. คู่มือฉบับเต็ม, ทุกตัวเลือก, ทุกข้อความ, และข้อจำกัด, อยู่ใน [คู่มือผู้ใช้](../docs/immuch360/user-guide.md).

<a id="watch-your-photos-and-videos"></a>
### ดูภาพถ่ายและวิดีโอของเจ้า

Immuch360 เป็นแกลเลอรีและตัวเล่นสำหรับภาพถ่ายและวิดีโอธรรมดาเป็นอันดับแรก. ไทม์ไลน์, อัลบั้ม, รายการโปรด, ความทรงจำ, และการค้นหา ใช้งานได้กับเซิร์ฟเวอร์ Immich; ภาพถ่ายและวิดีโอของอุปกรณ์เอง, และโฟลเดอร์ของคอมพิวเตอร์, แสดงได้โดยบ่ต้องมีเซิร์ฟเวอร์เลย. วิดีโอเล่นในตัวเล่นที่มาพร้อมเครื่อง มีเสียง, เลื่อนไปมาได้, มีตัวบอกว่ากำลังบัฟเฟอร์, และในตัวเล่น 360°, Spatial, กับคอมพิวเตอร์, เลือกแทร็กเสียงได้. บนทีวี รีโมทคุมทุกอย่าง; บนคอมพิวเตอร์ เมาส์กับคีย์บอร์ดคุม.

1. เปิดแท็บ Photos: ไทม์ไลน์ของเซิร์ฟเวอร์เจ้า, หรือของอุปกรณ์ถ้าบ่มีเซิร์ฟเวอร์.
2. แตะภาพถ่ายหรือวิดีโอเพื่อเปิดมัน; ปัดซ้ายขวาเพื่อไปอันต่อไป, หยิกนิ้วหรือแตะสองครั้งเพื่อซูม.
3. ปัดขึ้นบนวิดีโอเพื่อดูรายละเอียดของมัน: codec, ขนาด, เฟรมเรต, บิตเรต, และอุปกรณ์นี้ถอดรหัสมันได้บ่.

เพิ่มเติม: [วิวเวอร์กับตัวเล่นวิดีโอ](../docs/immuch360/user-guide.md#watch-your-photos-and-videos), [รายละเอียดวิดีโอกับตัวถอดรหัส](../docs/immuch360/user-guide.md#video-details-decoders-and-why-a-video-stutters).

<a id="turn-a-photo-with-one-key"></a>
### หมุนภาพถ่ายด้วยปุ่มเดียว

หมุนภาพถ่าย 90° ด้วยการกดเทื่อเดียว, บ่ต้องเปิดตัวแก้ไข: ปุ่มบนจอ, ปุ่มบนคีย์บอร์ด หรือปุ่มสีบนรีโมททีวี, ได้ทุกแพลตฟอร์ม. แอป Immich หมุนภาพถ่ายในตัวแก้ไขของมัน; Immuch360 เฮ็ดด้วยปุ่มเดียว, และสำหรับภาพถ่ายของเจ้าเองบนเซิร์ฟเวอร์ Immich 2.6 ขึ้นไป มันจะผ่านตัวแก้ไขเดียวกันของเซิร์ฟเวอร์, ก็เลยเว็บแอปกับอุปกรณ์อื่นของเจ้าจะแสดงภาพที่หมุนแล้ว. ภาพถ่ายอื่นๆ หมุนแค่บนอุปกรณ์นี้. ภาพถ่าย 360°, 180° และ 3D บ่หมุนเลย, เพื่อให้วิวแบบดื่มดำยังตั้งตรงอยู่.

<p align="center">
  <img src="../.github/readme/rotate-one-key.png" width="720" alt="Immuch360 Rotate 90°">
</p>

1. **โทรศัพท์, แท็บเล็ต และหน้าต่าง Meta Quest**: เปิดภาพถ่ายแล้วแตะ Rotate ในแถวล่าง, ก่อน Edit, เพื่อหมุนตามเข็มนาฬิกา; กดค้างไว้จะหมุนไปอีกทาง. ถ้าใช้คีย์บอร์ด, R กับ Shift+R.
2. **Android TV กับ Google TV**: ปุ่มสีเหลืองของรีโมทหมุนภาพตามเข็มนาฬิกา และปุ่มสีน้ำเงินหมุนทวนเข็มนาฬิกา, บ่ว่าโฟกัสจะอยู่ตรงไหนในวิวเวอร์. บนรีโมทที่บ่มีปุ่มสี, กดลง: แถบใต้ภาพจะขึ้นมาโดยเลือก Rotate ไว้ (กดขวาอีกเทื่อเดียวถ้าภาพมีปุ่มข้อความ), แล้วกด OK แต่ละเทื่อจะหมุนภาพ.
3. **ทีวี LG (webOS)**: ปุ่มเหลืองกับน้ำเงินเหมือนบน Android TV, R กับ Shift+R บนคีย์บอร์ด, หรือปุ่มหมุนในตัวควบคุมของภาพ.
4. **Windows, Linux และ macOS**: R หมุนตามเข็มนาฬิกา, Shift+R หมุนทวนเข็มนาฬิกา, หรือปุ่มหมุนในแถบด้านบน, ก่อนปุ่มเต็มจอ.
5. **ภาพถ่ายจากแชร์ในเครือข่าย, Plex หรือกล้อง**: ปุ่มหมุนอันแรกในแถบด้านบน, R กับ Shift+R, หรือปุ่มเหลืองกับน้ำเงิน.

การหมุนถูกบันทึกไว้ที่ไหน: ภาพถ่ายในบัญชีของเจ้าเองบน Immich 2.6 ขึ้นไปจะหมุนผ่านตัวแก้ไขภาพของเซิร์ฟเวอร์, ซึ่งเก็บไฟล์ต้นฉบับไว้แล้วสร้างภาพที่หมุนแล้วขึ้นมา (มีแถบบางๆ แสดงตอนมันทำงาน; หมุนสี่เทื่อ, หรือหมุนกลับหนึ่งเทื่อ, จะกลับไปเป็นต้นฉบับ). ภาพถ่ายของอุปกรณ์, ของแชร์, ของพาร์ทเนอร์หรืออัลบั้มที่แชร์, และภาพถ่ายทุกภาพบนเซิร์ฟเวอร์รุ่นเก่า จะหมุนแค่บนอุปกรณ์นี้, เฉพาะภาพนั้น, และไฟล์บ่ถูกเปลี่ยนเลย; แอปจะบอกเรื่องนี้หนึ่งเทื่อสำหรับภาพ Immich. ในแอป Android, iOS และคอมพิวเตอร์, การหมุนที่เก็บไว้บนอุปกรณ์จะแสดงในวิวเวอร์, แต่ยังบ่แสดงในภาพย่อ, สไลด์โชว์ และความทรงจำ. วิดีโอ, โฟลเดอร์ที่ล็อกไว้ และภาพถ่าย 360°, 180° หรือ 3D ทุกภาพ บ่มี Rotate.

<a id="explore-panoramas-360-vr180-and-3d"></a>
### สำรวจพาโนรามา, 360°, VR180 กับ 3D

ภาพถ่าย 360° เปิดขึ้นเป็นทรงกลมที่เจ้าหมุนด้วยนิ้วหรือขยับโทรศัพท์; วิดีโอ 360° เล่นในตัวเล่นทรงกลมพร้อมเสียง; ไฟล์ VR180 วาดบนครึ่งทรงกลม; ไฟล์ 3D แบบสเตอริโอแสดงตาเดียวบนจอแบน และสองตาในเฮดเซ็ต. พาโนรามาแบบไม่เต็มจะเก็บส่วนที่ครอปไว้, และภาพจะเริ่มที่มุมที่กล้องบันทึกไว้. ไฟล์ที่เซิร์ฟเวอร์บ่ได้ติดแท็กไว้ ก็ดูเป็น 360° ได้ด้วยการแตะครั้งเดียว.

<p align="center">
  <img src="../.github/readme/b19-sphere.jpg" width="260" alt="รูปภาพ 360° ของริมทะเลสาบในตัวเบิ่งทรงกลม: ปุ่มปิดอยู่ซ้ายบน ปุ่ม 360°, เลย์เอาต์ 3D แล้วก็ไจโรสโคปอยู่ขวาบน">
  <img src="../.github/readme/b19-video.png" width="420" alt="วิดีโอ 360° ของถนนเลียบชายฝั่งกำลังเล่นในเครื่องเล่น 360° ของโทรศัพท์ที่ถือแนวนอน: ปิดแล้วก็ชื่อไฟล์อยู่ซ้ายบน 360° แล้วก็ 3D อยู่ขวาบน ก่อนหน้า ถอยหลัง เล่น ข้ามไปข้างหน้า แล้วก็ถัดไปอยู่ตรงกลาง แถบเวลาอยู่ด้านล่าง">
</p>

1. เปิดภาพถ่ายหรือวิดีโอ. ไฟล์ 360° มีป้าย 360° ติดอยู่บนรูปย่อ, และแท็บ Library มีรายการ 360° ที่รวมมันไว้, กรองได้ตามช่วงเวลา, แหล่งที่มา, ชนิด, และกล้อง.
2. แตะ 360° บนแถบด้านบน. ลากเพื่อมองไปรอบๆ, หยิกนิ้วเพื่อซูม, แตะปุ่มไจโรสโคปเพื่อมองไปรอบๆด้วยการขยับโทรศัพท์.
3. ปุ่ม 3D วนไปเรื่อยๆระหว่าง "โมโน (บ่แม่น 3D)", "3D, บนแล้วก็ล่าง", และ "3D, เคียงข้างกัน"; ปุ่ม 360°/180° สลับไปมาระหว่างทรงกลมเต็มกับครึ่งทรงกลมของ VR180.
4. สำหรับไฟล์ที่แสดงเป็นแบบแบนทั้งที่มันเป็นไฟล์ 360°: ⋮ ที่มุมบนขวา, แล้ว "ดูเป็น 360°".

บนโทรศัพท์และแท็บเล็ต, วิดีโอแบบสเตอริโอยังได้มิติความลึกบนจอแบนได้ด้วย: ตัวเล่น Spatial 2.5D ใช้กล้องหน้าตามหัวของเจ้า แล้วแสดงมุมมองที่อยู่ระหว่างสองตา (ยังทดลองอยู่). ภาพ spatial ของ Apple ที่ถ่ายด้วย iPhone จะถูกจดจำได้ และแสดงเป็น 3D ในเฮดเซ็ต Meta Quest.

<a id="use-your-own-files-without-an-account"></a>
### ใช้ไฟล์ของเจ้าเอง, โดยบ่ต้องมีบัญชี

Immuch360 บ่ต้องมีทั้งบัญชีและเซิร์ฟเวอร์. ตั้งแต่ build 24 แอปจะเปิดที่หน้าต้อนรับ, ที่ "ใช้โดยบ่มีเซิร์ฟเวอร์" อยู่อันดับแรก: มันเปิดแอปไปที่ภาพถ่ายและวิดีโอของอุปกรณ์, พร้อมวิวเวอร์ทุกตัว, รายการ 360° และแหล่งข้อมูลในเครือข่าย. ไม่มีอะไรออกจากอุปกรณ์เลย. เซิร์ฟเวอร์เชื่อมต่อได้ทีหลัง, จาก Settings หรือแท็บ Library, แล้วฟีเจอร์ของเซิร์ฟเวอร์ก็จะปรากฏขึ้น.

<img src="../.github/readme/b19-library-no-server.png" width="260" alt="แท็บคลังภาพแบบบ่มีเซิร์ฟเวอร์: รายการ 360° อยู่ด้านบน ตามด้วย On this device ที่มีรูปภาพ 360° สองรูป แล้วก็แชร์ในเครือข่ายที่มีแชร์ชื่อ NAS">

1. เปิดแอป. หน้าต้อนรับจะสะแดง "สื่อของเจ้า. จอใดก็ได้. ทุกมุมมอง." แล้วก็ตัวเลือกสามอัน: แตะอันแรก, "ใช้โดยบ่มีเซิร์ฟเวอร์". จนถึง build 23, หน้าเข้าสู่ระบบมาก่อน, พร้อม "ใช้โดยบ่มีเซิร์ฟเวอร์" อยู่ใต้ฟอร์ม.
2. อนุญาตให้เข้าถึงรูปภาพแล้วก็วิดีโอของเจ้า ถ้าเจ้าปฏิเสธ แอปจะบอกว่า "แอปเห็นรูปภาพของเครื่องนี้บ่ได้" พร้อม "อนุญาตให้เข้าถึง" แล้วก็ "เปิดการตั้งค่า"
3. แท็บ Photos (รูปภาพ) สะแดงไทม์ไลน์ของเครื่อง Search (ค้นหา) แล้วก็ Albums (อัลบั้ม) ยังเป็นสีเทา เพราะมาจากเซิร์ฟเวอร์ แท็บคลังภาพมี 360° อยู่ด้านบน ตามด้วย On this device (ในเครื่องนี้) ซึ่งเป็นอัลบั้มของเครื่อง แล้วก็แชร์ในเครือข่าย
4. เมนูที่ขวาบนบอกว่า "เครื่องนี้เท่านั้น": แอปสะแดงรูปภาพแล้วก็วิดีโอของเครื่องนี้ บ่มีอะไรถูกส่งไปไหน

บนคอมพิวเตอร์, โฟลเดอร์ที่เจ้าเลือกจะทำหน้าที่เป็นแกลเลอรี; บนทีวี, ที่บ่มีภาพถ่ายของตัวเอง, แหล่งข้อมูลในเครือข่ายจะทำหน้าที่นี้แทน.

เพิ่มเติม: [โดยบ่มีเซิร์ฟเวอร์หรือบัญชี](../docs/immuch360/user-guide.md#without-a-server-or-an-account).

<a id="reach-the-media-of-a-nas-a-computer-or-a-media-server"></a>
### เข้าถึงสื่อจาก NAS, คอมพิวเตอร์ หรือเซิร์ฟเวอร์สื่อ

วิดีโอของเจ้าอยู่บน NAS, คอมพิวเตอร์, หรือเซิร์ฟเวอร์สื่อ. Immuch360 หาเซิร์ฟเวอร์ในเครือข่ายของเจ้าได้เอง, เข้าไปดู, แล้วเปิดภาพถ่ายและวิดีโอของมันตรงที่มันอยู่, ในวิวเวอร์ทุกตัวของแอป, โดยบ่ต้องคัดลอกอะไรเลย: SMB (Samba, แชร์ของ Windows), WebDAV (Nextcloud, Synology และอื่นๆ) และเซิร์ฟเวอร์สื่อ DLNA (Jellyfin, Emby, minidlna, NAS, กล่องทีวี). โทรศัพท์ยังแชร์แกลเลอรีของตัวเองบน Wi-Fi ให้เฮดเซ็ตหรือไคลเอนต์ WebDAV อื่นได้, คอมพิวเตอร์ Windows ก็ทำได้เหมือนกัน.

<p align="center">
  <img src="../.github/readme/b19-add-share.png" width="260" alt="หน้าเพิ่มแชร์: ชื่อ, ชื่อหรือที่อยู่เซิร์ฟเวอร์, พอร์ต (บ่บังคับ), แชร์, เลือกแชร์, โฟลเดอร์เริ่มต้น (บ่บังคับ), ชื่อผู้ใช้, รหัสผ่าน, ทดสอบการเชื่อมต่อ แล้วก็ผลลัพธ์ เชื่อมต่อแล้ว มี 2 รายการในโฟลเดอร์เริ่มต้น">
  <img src="../.github/readme/b19-share-folder.jpg" width="260" alt="โฟลเดอร์ของแชร์ในเครือข่ายเป็นตารางภาพย่อ: รูปภาพ 360° ที่มีป้าย 360° แล้วก็วิดีโอ 360° ที่มีเครื่องหมายเล่น ปุ่มเลือกอยู่ขวาบน">
</p>

1. เปิดแท็บ Library, แล้วก็ Network shares, แล้วก็ + กับ "แชร์บนเครือข่าย (NAS, คอมพิวเตอร์, เซิร์ฟเวอร์สื่อ)". ตั้งแต่ build 24, "เพิ่มแชร์บนเครือข่ายหรือเซิร์ฟเวอร์สื่อ" บนหน้าต้อนรับจะเปิด Network shares ได้ตรงๆ, โดยบ่ต้องมีเซิร์ฟเวอร์.
2. แตะเซิร์ฟเวอร์ที่อยู่ใต้ "พบในเครือข่าย", หรือกรอกฟอร์มด้วยตัวเอง: ชนิด, ชื่อหรือที่อยู่เซิร์ฟเวอร์, แชร์หรือพาธ, โฟลเดอร์เริ่มต้น, ชื่อผู้ใช้และรหัสผ่าน.
3. แตะ "ทดสอบการเชื่อมต่อ", แล้ว Save. แตะแชร์เพื่อดูข้างใน: โฟลเดอร์ก่อน, แล้วภาพถ่ายและวิดีโอ, มีป้าย 360° ติดบนไฟล์ที่จำได้ว่าเป็น 360°.
4. เมื่อเชื่อมต่อเซิร์ฟเวอร์ Immich ไว้แล้ว, เลือกไฟล์ในโฟลเดอร์แล้วแตะ "อัปโหลดไป Immich" เพื่อส่งมันไปเซิร์ฟเวอร์ของเจ้า.

ตัวเล่นอ่านไบต์ที่มันต้องการผ่านบริดจ์ในแอป, ด้วย byte range, ก็เลยเลื่อนไปมาได้ และไม่มีอะไรถูกเก็บไว้ในอุปกรณ์; วิดีโอ SMB อ่านผ่านได้ถึงหกการเชื่อมต่อพร้อมกันเพื่อให้เล่นได้ลื่น.

เพิ่มเติม: [แชร์บนเครือข่าย](../docs/immuch360/user-guide.md#network-shares-a-nas-a-computer-or-a-media-server), [แชร์โทรศัพท์นี้บนเครือข่าย](../docs/immuch360/user-guide.md#share-this-phone-on-the-network), [เซิร์ฟเวอร์สื่อ DLNA](../docs/immuch360/user-guide.md#dlna-media-servers).

<a id="find-your-immich-library"></a>
### หาไลบรารี Immich ของเจ้า

พร้อมเซิร์ฟเวอร์ [Immich](https://github.com/immich-app/immich), Immuch360 ก็เป็นแอป Immich มือถือ, ใช้เซิร์ฟเวอร์เดียวกันและบัญชีเดียวกันกับเว็บแอป: backup, ไทม์ไลน์, อัลบั้ม, ค้นหา, คน, ความทรงจำ, การแชร์, partner, ทุกอย่าง sync กับเซิร์ฟเวอร์ของเจ้า. มันติดตั้งไว้ข้างๆแอปอย่างเป็นทางการ. เพิ่มมาอีก: ป้ายและรายการ 360°, วิวเวอร์แบบดื่มดำทุกตัว, เลือกได้ระหว่างไฟล์ต้นฉบับกับสตรีมที่เซิร์ฟเวอร์แปลงให้แต่ละวิดีโอ, รายละเอียดทางเทคนิคของวิดีโอ, และไฟล์จากแชร์หรือจากอุปกรณ์ที่ส่งไปเซิร์ฟเวอร์ของเจ้าด้วยตัวเอง.

1. บนหน้าต้อนรับ, แตะ "เชื่อมต่อกับเซิร์ฟเวอร์ Immich", แล้วเข้าสู่ระบบด้วยที่อยู่เซิร์ฟเวอร์, อีเมล และรหัสผ่านของเจ้า, เหมือนในแอป Immich; Back จะพาย้อนกลับไปหน้าต้อนรับ. จนถึง build 23 หน้าเข้าสู่ระบบเปิดขึ้นมาตรงๆ. ไลบรารี, อัลบั้ม และการตั้งค่าสำรองของเจ้าเป็นของบัญชีเจ้าเอง.
2. ใน Settings, Asset Viewer, Videos, "แหล่งวิดีโอ" เลือกต้นฉบับเมื่ออุปกรณ์นี้ถอดรหัสมันได้, ต้นฉบับเสมอ, หรือสตรีมที่แปลงแล้วเสมอ.
3. ถ้าจะโชว์ภาพถ่าย 360° ให้คนที่บ่มีแอปดู, แชร์มันด้วยลิงก์แชร์ของ Immich: แอปเว็บ Immich จะแสดงมันเป็นทรงกลมในเบราว์เซอร์ของเขา.

build ปัจจุบัน, build 28, สร้างมาจาก `main` ของ Immich วันที่ 10 ตุลาคม 2026 (เวอร์ชัน 3.3.0-rc.0) และได้ทดสอบกับเซิร์ฟเวอร์ที่สร้างจาก `main` อันเดียวกันของ Immich; build 27 ยังได้ทดสอบกับเซิร์ฟเวอร์ Immich 3.2.4 ด้วย. โปรดแจ้งปัญหาที่ [Issues](https://github.com/freeKC/Immuch360/issues), บ่ใช่ไปที่โปรเจกต์ Immich.

เพิ่มเติม: [ที่เหลือทั้งหมดก็คือ Immich](../docs/immuch360/user-guide.md#everything-else-is-immich), [เทียบกับแอป Immich](../docs/immuch360/compatibility.md#compared-with-the-immich-app).

<a id="sign-in-a-tv-a-headset-or-a-computer-with-your-phone"></a>
### เข้าสู่ระบบทีวี, เฮดเซ็ต หรือคอมพิวเตอร์ด้วยโทรศัพท์ของเจ้า

การพิมพ์ที่อยู่เซิร์ฟเวอร์, อีเมล และรหัสผ่านด้วยรีโมททีวี, หรือในเฮดเซ็ต, ใช้เวลาหลายนาที. ถ้ามี Immuch360 บนโทรศัพท์ของเจ้าที่เข้าสู่ระบบเซิร์ฟเวอร์ Immich ไว้แล้ว, ทีวี, Meta Quest หรือคอมพิวเตอร์จะเข้าสู่ระบบได้ในบ่กี่วินาที: จอใหญ่แสดง QR code, โทรศัพท์สแกนมัน, เจ้ายืนยัน, แล้วจอก็เปิดไลบรารีของเจ้า. ถ้าใช้แอปบนโทรศัพท์, รหัสผ่านของเจ้าจะอยู่แค่ในโทรศัพท์. แอป Immich บ่มีอะไรแบบนี้.

<p align="center">
  <img src="../.github/readme/sign-in-with-your-phone.png" width="720" alt="ทีวีแสดง QR code บนหน้าเข้าสู่ระบบของมัน, และโทรศัพท์ที่ถืออยู่ข้างหน้ากำลังสแกนโค้ดเดียวกัน">
</p>

1. บนจอใหญ่ (Android TV กับ Google TV, หน้าต่าง Meta Quest, Windows, Linux หรือ macOS), เลือก "เชื่อมต่อกับเซิร์ฟเวอร์ Immich": หน้าเข้าสู่ระบบจะแสดง "เข้าสู่ระบบด้วยโทรศัพท์", QR code และโค้ด 10 ตัวอักษร, อยู่ข้างฟอร์มเซิร์ฟเวอร์.
2. บนโทรศัพท์ที่เข้าสู่ระบบเซิร์ฟเวอร์ของเจ้าไว้แล้ว: Settings, "เชื่อมต่อทีวีหรือคอมพิวเตอร์", แล้วก็ "สแกนโค้ด". ใน Meta Quest, ซึ่งโทรศัพท์สแกนจอของมันบ่ได้, ให้เลือก "ใส่โค้ดแทน" แล้วพิมพ์โค้ดที่เฮดเซ็ตแสดง.
3. โทรศัพท์จะถามว่า "เข้าสู่ระบบ (จอ) บ่?" และแสดงตัวเลขหกหลัก: ตรวจเบิ่งว่าจอแสดงเลขเดียวกัน, แล้วแตะ เข้าสู่ระบบ. จอจะเปิดไทม์ไลน์ของเจ้า.

ปลอดภัยยังไง: โทรศัพท์กับจอต้องอยู่ในเครือข่ายบ้านเดียวกัน, และโค้ดใช้ได้นานสุดสองนาทีและใช้ได้เทื่อเดียว. โทรศัพท์ขอ session ใหม่สำหรับจอนั้นจากเซิร์ฟเวอร์ของเจ้า, ตั้งชื่อตามจอ ("Immuch360 บนทีวีห้องนั่งเล่น"), แล้วส่งมันไปให้จอแบบเข้ารหัส, รหัสผ่านของเจ้าจึงบ่เคยออกจากโทรศัพท์. "เชื่อมต่อทีวีหรือคอมพิวเตอร์" แสดงรายการจอที่โทรศัพท์เครื่องนี้เข้าสู่ระบบให้, แต่ละอันมีปุ่มออกจากระบบ, และ Immich ก็แสดงรายการพวกมันใน Account Settings, Authorized devices, ที่เจ้าเพิกถอนพวกมันได้ด้วย. ถ้าออกจากระบบบนโทรศัพท์, จอพวกนั้นก็ออกจากระบบไปด้วย.

ฝั่งโทรศัพท์ตอนนี้ใช้ได้บน Android, และบน iPhone กับ iPad ตั้งแต่รีลีส iOS ถัดไป. ถ้าโทรศัพท์บ่มี Immuch360, ให้สแกนโค้ดด้วยกล้องของโทรศัพท์: หน้าเว็บที่จอให้บริการจะเปิดในเบราว์เซอร์, ให้ใส่อีเมลกับรหัสผ่านของเจ้า, ซึ่งเข้ารหัสไว้และใช้ได้เทื่อเดียว. ทีวี LG เข้าสู่ระบบด้วย QR code ของมันเอง, ในเบราว์เซอร์ของโทรศัพท์; ตั้งแต่ build 28 ตัวสแกนของแอปบนโทรศัพท์รู้จักโค้ดนี้และเปิดหน้านั้นให้.

เพิ่มเติม: [เข้าสู่ระบบด้วยโทรศัพท์](../docs/immuch360/user-guide.md#sign-in-a-tv-a-headset-or-a-computer-with-your-phone), [จอส่งอะไรและเก็บอะไรไว้](../docs/immuch360/technical-details.md#sign-in-with-your-phone).

### ดูบนทีวีและบนคอมพิวเตอร์

แอป Android ตัวเดียวกันทำงานบน Android TV และ Google TV, เป็นธีมมืดตั้งแต่เปิดครั้งแรก, โดยมีรีโมทเป็นตัวควบคุมอย่างเดียว: ลูกศรเลื่อนเฟรม, OK เปิด, Back ย้อนกลับ; ในวิวเวอร์ ซ้ายกับขวาไปภาพถ่ายหรือวิดีโอก่อนหน้าหรือถัดไป, แม้ตอนวิดีโอกำลังเล่นอยู่, และในภาพถ่ายหรือวิดีโอ 360° ลูกศรใช้มองไปรอบๆ. ทีวีบ่มีภาพถ่ายของตัวเอง, ก็เลยแสดงเซิร์ฟเวอร์ Immich ของเจ้า, แชร์ในเครือข่ายของเจ้า, เซิร์ฟเวอร์ Plex ของเจ้า และกล้องของเจ้า; ทีวี LG มี[แอปของตัวเอง](#immuch360-on-an-lg-tv-webos). บนคอมพิวเตอร์ Windows, Immuch360 Desktop อ่านโฟลเดอร์ที่เจ้าเลือกโดยบ่ต้องมีเซิร์ฟเวอร์เลย, เล่นวิดีโอแบบแบนกับ 360° ในตัวเล่นของตัวเอง, เข้าไปดูแชร์และเซิร์ฟเวอร์เดียวกัน, และแชร์คอมพิวเตอร์ให้เฮดเซ็ตที่บ้านได้.

1. บนทีวี: ติดตั้ง APK ด้วย adb (ดู [ติดตั้ง](#android-tv-and-google-tv)); บนหน้าต้อนรับ, เลือก "เพิ่มแชร์บนเครือข่ายหรือเซิร์ฟเวอร์สื่อ" สำหรับแชร์, เซิร์ฟเวอร์ Plex หรือกล้อง, "ใช้โดยบ่มีเซิร์ฟเวอร์", หรือ "เชื่อมต่อกับเซิร์ฟเวอร์ Immich", ซึ่งหน้าของมันจะให้ทีวีเข้าสู่ระบบเมื่อเจ้าสแกน QR code ของมันด้วยโทรศัพท์ (ดู [เข้าสู่ระบบด้วยโทรศัพท์](#sign-in-a-tv-a-headset-or-a-computer-with-your-phone)).
2. บนคอมพิวเตอร์ Windows: ติดตั้งพรีวิว หรือแตกไฟล์ซิปแล้วเริ่ม `immuch360.exe` (ดู [ติดตั้ง](#windows)); ตั้งแต่ desktop build 5, "ใช้โดยบ่มีเซิร์ฟเวอร์" บนหน้าต้อนรับจะเปิดตัวเลือกโฟลเดอร์ของเจ้า, และ "เชื่อมต่อกับเซิร์ฟเวอร์ Immich" จะเปิดหน้าเข้าสู่ระบบ, ที่มี QR code ไว้ให้โทรศัพท์ของเจ้า. ภาพถ่าย, วิดีโอ หรือโฟลเดอร์ที่เปิดด้วยแอป, หรือลากมาวางบนหน้าต่างของมัน, จะเปิดขึ้นทันที, อันที่เป็น 360° ก็เปิดในวิว 360° ของมัน; หลายไฟล์เปิดด้วยกันในหน้าเดียว.
3. ในวิวเวอร์, ปุ่มเล่นกับหยุด, ย้อนกลับ, เดินหน้าเร็ว, ก่อนหน้ากับถัดไปของรีโมทใช้งานได้, และปุ่มคีย์บอร์ดบนคอมพิวเตอร์ก็ใช้ได้ด้วย (Space, J กับ L, F สำหรับเต็มจอ). บนทีวี, กด OK ตอนวิดีโอเล่นอยู่จะแสดงตัวควบคุมโดยเลือกปุ่มเล่นกับหยุดไว้, ตามด้วยปุ่ม -10 s กับ +10 s, และกด OK เทื่อที่สองจะหยุดชั่วคราว; ตัวควบคุมกับวันที่จะซ่อนไป 5 s หลังกดปุ่มสุดท้าย. วิดีโอบนทีวีบ่เล่นวนซ้ำอีกแล้ว, เว้นแต่เจ้าจะเปิด Settings, Asset Viewer, Videos, Looping.
4. บนทีวี, ปุ่ม Menu, ปุ่ม Info หรือกด OK ค้างไว้ จะเปิดรายละเอียดของภาพถ่ายหรือวิดีโอ, อ่านได้อย่างเดียว: วันที่, สถานที่, กล้อง, codec, ขนาด และ bit rate. วิดีโอที่ทีวีถอดรหัสบ่ได้จะบอกเรื่องนี้, พร้อม codec, ขนาด และขีดจำกัดของตัวถอดรหัสของทีวี, แทนที่จะโหลดไปเรื่อยๆ บ่จบ; วิดีโอ 360° ที่เกินขีดของตัวถอดรหัสจะถามก่อนเปิดตัวเล่น 360°, และเหตุผลจะเขียนไว้ในหน้า Logs ของเมนูโปรไฟล์.

เพิ่มเติม: [ดูบนทีวีของเจ้า](../docs/immuch360/user-guide.md#watch-on-your-tv-android-tv-and-google-tv), [บนคอมพิวเตอร์ Windows](../docs/immuch360/user-guide.md#on-a-windows-computer-immuch360-desktop-preview), [รองรับแพลตฟอร์ม](../docs/immuch360/platform-support.md).

<a id="immuch360-on-an-lg-tv-webos"></a>
### Immuch360 บนทีวี LG (webOS)

Immuch360 ยังมาเป็นแอป Immich สำหรับทีวี LG webOS ด้วย: แอปแยกต่างหากสำหรับทีวี LG ที่ใช้ webOS 4.0 ขึ้นไป (ตั้งแต่ปี 2018), ควบคุมด้วยรีโมท, แสดงเซิร์ฟเวอร์ Immich ของเจ้า และวางภาพถ่าย 360° ของเจ้าบนทรงกลมที่เจ้าหมุนด้วยลูกศร. แอปของ Immich เองติดตั้งบนทีวี LG บ่ได้. มันสร้างมาจาก [immich-tv-webos](https://github.com/Seeky91/immich-tv-webos) ของ Seeky91, ซึ่งนำไทม์ไลน์, อัลบั้ม, ผู้คน, สถานที่, การค้นหา, สไลด์โชว์ และการเข้าสู่ระบบด้วยโทรศัพท์มาให้; ขอบคุณ Seeky91. build ทดสอบ 0.2.0 เพิ่มแชร์ในเครือข่าย, Plex และภาพสดจากกล้อง Tapo. เวอร์ชัน 0.1.0 ได้รันบนทีวี LG ของผู้ทดสอบคนหนึ่งแล้ว (webOS 22); 0.2.0 ยังบ่ได้รันบนทีวีจริง. ติดตั้งได้แค่ใน Developer Mode, และทุกรายงานใน [Issues](https://github.com/freeKC/Immuch360/issues) ช่วยได้.

<p align="center">
  <img src="../.github/readme/lg-tv-webos.png" width="720" alt="Immuch360 on an LG TV">
</p>

1. ติดตั้งมันบนทีวีใน Developer Mode, ดู [ติดตั้ง](#lg-tvs-webos). มันมี app id ของตัวเอง, ก็เลยติดตั้งอยู่ข้างๆ Immich TV ของ Seeky91 ได้.
2. เข้าสู่ระบบด้วยโทรศัพท์ของเจ้า (สแกน QR code), ด้วยอีเมลกับรหัสผ่าน, หรือด้วย API key.
3. เลื่อนดูด้วยลูกศรกับ OK. ในวิวเวอร์, ซ้ายกับขวาไปภาพถ่ายหรือวิดีโอก่อนหน้าหรือถัดไป, ตอนวิดีโอเล่นอยู่ก็ได้; ตัวควบคุมซ่อนไป 5 s หลังกดปุ่มสุดท้าย; Info เปิดรายละเอียด; ปุ่มช่องใช้ซูม; ตัวชี้กับล้อของ Magic Remote ใช้ได้.
4. ภาพถ่าย 360° เปิดบนทรงกลมที่เจ้าหมุนด้วยลูกศร; "ดูเป็น 360°" ใช้ได้กับภาพ 2:1 ที่เซิร์ฟเวอร์บ่ได้ระบุไว้; ภาพ VR180 แสดงบนครึ่งทรงกลม และภาพ 3D แสดงด้วยตาเดียว. ปุ่มเหลืองกับน้ำเงินหมุนภาพแบบแบน.
5. ตั้งแต่ 0.2.0, หลังเข้าสู่ระบบแล้ว, "แชร์ในเครือข่าย" ในแถบด้านข้างของแอป: เพิ่มแชร์ SMB, WebDAV หรือ DLNA, เซิร์ฟเวอร์ Plex (เข้าสู่ระบบด้วยโค้ดที่ plex.tv/link) หรือกล้อง Tapo. ภาพถ่ายของพวกมันเปิดในวิวเวอร์เดียวกัน, ภาพถ่าย 360° อยู่บนทรงกลม.

แชร์, Plex และกล้องต้องใช้ webOS 5 (ทีวีปี 2020) ขึ้นไป, ส่วน SMB ต้องใช้ webOS 22 (ทีวีปี 2022) ขึ้นไป. พวกมันมาผ่านเซอร์วิสของแอปเองบนทีวี, ซึ่งอ่านข้อมูลให้แอป, และได้ตรวจกับเซิร์ฟเวอร์จริงบนเครื่อง build ของโปรเจกต์แล้ว, แต่ยังบ่ได้ตรวจบนทีวี. ภาพสดจากกล้องมีแต่วิดีโอ.

ยังบ่มี: วิดีโอบันทึกของกล้อง (บ่ก่อนเดือนธันวาคม 2026) และเสียงของมัน, วิดีโอ 360° บนทรงกลม (เล่นแบบแบน, พร้อมข้อความแจ้ง), การอัปโหลด. เมื่อวิดีโอเล่นบ่ได้, จะมีข้อความบอกรูปแบบกับขนาดของมัน แทนที่จะหมุนรอไปเรื่อยๆ. บน webOS ก่อน 25, reverse proxy ที่อยู่หน้า Immich ต้องส่ง CORS header; แอปจะอธิบายให้เมื่อเจอปัญหานี้.

เพิ่มเติม: [แอป webOS: การติดตั้ง, ปุ่มรีโมท, CORS header](../webos/README.md).

<a id="cameras-plex-and-raw-camera-files"></a>
### กล้อง, Plex, และไฟล์ raw จากกล้อง

- **กล้อง Tapo**: เพิ่มกล้องเข้ามาข้างๆแชร์ในเครือข่าย. แอปแสดงภาพสดให้ดู (Android, Android TV, Quest, Windows และ, แค่วิดีโอ, ทีวี LG ตั้งแต่ webOS 0.2.0; iPhone กับ iPad ตั้งแต่รีลีส iOS ถัดไป) และแสดงรายการวิดีโอที่บันทึกในเมมโมรีการ์ดเรียงวันต่อวันได้บนทุกแพลตฟอร์ม; คลิปหนึ่งจะถูกดึงมาจากกล้อง, เล่นได้เหมือนวิดีโอทั่วไป, และส่งไป Immich ได้. แอปคุยกับกล้องแค่ในเครือข่ายของเจ้าเท่านั้น, บ่คุยกับเซิร์ฟเวอร์ของ TP-Link เลย.
- **Plex Media Server, โดยบ่ต้องใช้ plex.tv**: แอปจับคู่กับเซิร์ฟเวอร์ของเจ้าตรงๆ, ด้วย token ที่เจ้าแปะไว้ครั้งเดียว, แล้วอ่านไฟล์ต้นฉบับของไลบรารีเจ้าแบบสด, ก็เลยทำให้ 360° ยังเป็น 360° อยู่, ทั้งที่บ้านและ, ผ่าน port forwarding ของเจ้า, นอกบ้านก็ได้.
- **ไฟล์ raw จากกล้อง 360°**: ภาพถ่าย .insp และวิดีโอ .insv ของกล้อง Insta360 (เลนส์ตัวเดียวหรือสองตัว, อยู่ในแทร็กเดียว, สองแทร็ก หรือสองไฟล์), ไฟล์ .360 ของ GoPro MAX แล้วก็ไฟล์ .osv ของ DJI Osmo 360 ถูกแอปต่อให้เป็นภาพเดียวตอนกำลังเล่น, พร้อมการแคลิเบรตที่เขียนไว้ในไฟล์, บ่ต้องติดตั้งอะไรที่ไหนเลย. บน Android, เล่นจากแชร์, คอมพิวเตอร์ หรือเซิร์ฟเวอร์ของเจ้า, เพราะแกลเลอรีของโทรศัพท์บ่แสดงไฟล์ raw; เซิร์ฟเวอร์ Immich รับแค่ .insp กับ .insv เท่านั้น.

เพิ่มเติม: [กล้อง Tapo](../docs/immuch360/user-guide.md#tapo-cameras-live-view-and-the-recordings-of-the-memory-card), [Plex Media Server](../docs/immuch360/user-guide.md#plex-media-server-without-plextv), [ไฟล์ raw จากกล้อง 360°](../docs/immuch360/user-guide.md#raw-360-camera-files-without-the-cameras-app).

<a id="your-dji-drones-photos-and-videos-on-your-immich-server"></a>
### ภาพถ่ายและวิดีโอจากโดรน DJI ของเจ้าบนเซิร์ฟเวอร์ Immich ของเจ้า

นำเข้าภาพถ่ายและวิดีโอของโดรน DJI ผ่าน USB, ตรงไปที่เซิร์ฟเวอร์ Immich ของเจ้า: เสียบโดรน, รีโมทคอนโทรลเลอร์ของมัน หรือตัวอ่านการ์ดเข้ากับโทรศัพท์ Android, เลือกไฟล์ใหม่แล้วส่ง, วิดีโอจะถูกวางบนแผนที่จากข้อมูลการบินของโดรน และภาพทรงกลม 360° ของโดรนจะแสดงเป็น 360°. แอป Immich สำรองแค่สิ่งที่อยู่ในแกลเลอรีของโทรศัพท์แล้ว, และเซิร์ฟเวอร์ Immich ยังอ่านสถานที่ของวิดีโอ DJI Neo 2 บ่ได้. หน้านี้ยังทดลองอยู่, ใช้ได้แค่บนโทรศัพท์และแท็บเล็ต Android, และยังบ่ได้ลองกับโดรนจริง.

<p align="center">
  <img src="../.github/readme/dji-drone-import.png" width="720" alt="Immuch360, a DJI drone and Immich">
</p>

1. มีไทล์ "DJI drone" อยู่ใน คลังภาพ, แชร์ในเครือข่าย: "DJI drones (experimental)" (โดรน DJI แบบทดลอง) เปิดอยู่แล้วโดยค่าเริ่มต้นใน Settings, Advanced. ปิดได้ที่นั่นเพื่อซ่อนไทล์.
2. เสียบโดรน (Neo 2 ปิดเครื่องไว้ก็ได้), รีโมทคอนโทรลเลอร์ของมัน หรือตัวอ่านการ์ดเข้ากับโทรศัพท์ด้วยสาย USB-C ที่ส่งข้อมูลได้. ในหน้า DJI drone, แตะ "Choose the drone or the card" (เลือกโดรนหรือการ์ด), เลือกมันในเมนูด้านข้างของตัวเลือกไฟล์, เปิดโฟลเดอร์ DCIM ของมันหรือใช้ทั้งไดรฟ์ก็ได้, แล้วแตะ "Use this folder" (ใช้โฟลเดอร์นี้) กับ Allow (อนุญาต).
3. หน้านี้แสดงภาพถ่ายและวิดีโอเรียงตามวัน, บ่รวมไฟล์ประกอบ .LRF, .SRT, .THM และ .m4a. แตะ "Select all new" (เลือกอันใหม่ทั้งหมด), แล้วก็ "อัปโหลดไป Immich"; ไฟล์ที่ส่งไปแล้วจะมีเครื่องหมายก้อนเมฆและถูกข้ามไป. "Keep on the device" (เก็บไว้ในเครื่อง) จะก๊อปปี้ไฟล์ไปไว้ในแกลเลอรีของโทรศัพท์แทน, ในอัลบั้ม "Immuch360 import".
4. ถ้าอยากให้วิดีโอไปอยู่บนแผนที่, เปิด Video Subtitles ใน DJI Fly (โหมดวิดีโอ, Settings, Camera) ก่อนบิน: โดรนจะเขียนไฟล์ .SRT ไว้ข้างๆ วิดีโอแต่ละอัน, แอปจะอ่านสถานที่จากไฟล์นั้น แล้วตั้งค่าให้บนเซิร์ฟเวอร์ของเจ้าหลังอัปโหลด, ถ้า Immich หาสถานที่บ่เจอ.

ภาพทรงกลม 360° ของโดรน DJI (Mini, Air, Mavic และรุ่นอื่นๆ, รู้จักจากกล้องของมัน) แสดงเป็น 360° ใน Immuch360 แม้บ่มีแท็ก 360°. Immich ต้องการแท็กพวกนั้น: ตัวเลือกการอัปโหลด "Tag drone spheres as 360° for Immich" (ติดแท็กภาพทรงกลมจากโดรนเป็น 360° ให้ Immich), ซึ่งปิดไว้เป็นค่าเริ่มต้น, จะส่งภาพถ่ายไปแบบบ่เปลี่ยนแปลง พร้อมไฟล์ .xmp เล็กๆ อยู่ข้างๆ, เพื่อให้ Immich แสดงมันเป็นทรงกลมด้วย. Neo 2 บ่มีโหมดทรงกลมหรือพาโนรามา: ภาพถ่ายและวิดีโอของมันเป็นแบบแบน. ถ้าโทรศัพท์อัดเสียงของคลิป Neo 2 ไว้, เสียงนั้นจะอยู่ในไฟล์ .m4a แยกต่างหาก: หน้านี้จะทำเครื่องหมายคลิปนั้นไว้, และ Immich จะได้รับคลิปแบบบ่มีเสียง (ดาวน์โหลดด้วย DJI Fly ถ้าอยากเก็บเสียงไว้). การ์ดกล้องอันไหนก็ตามที่มีโฟลเดอร์ DCIM ใช้กับตัวอ่านการ์ดได้แบบเดียวกัน. บ่มีอะไรถูกส่งไปที่ DJI.

<a id="dji-link-diagnostics-experimental"></a>
### การวินิจฉัยลิงก์ DJI (ยังทดลองอยู่)

เป้าหมายระยะยาวคือวิดีโอของโดรน DJI ใน Meta Quest, ผ่านรีโมทคอนโทรลเลอร์ของโดรนเองที่เสียบเข้ากับเฮดเซ็ต. ยังบ่มีใครรู้ว่า Quest อ่านรีโมท DJI ผ่านสายของมันได้หรือบ่. หน้าลิงก์ DJI เป็นก้าวแรก, เป็นเครื่องมือวัดบน Meta Quest และบนโทรศัพท์กับแท็บเล็ต Android: มันแสดงว่าอุปกรณ์อ่านรีโมทได้หรือบ่, มีอะไรเข้ามาบ้าง, และเก็บแคปเจอร์ของมันไว้.

มันแค่ฟังเท่านั้น. บ่มีคำสั่งใดถูกส่งไปที่รีโมทหรือโดรนเลย: ไบต์เดียวที่หน้านี้เขียนทุกวินาที, ตั้งแต่ 20 วินาทีหลังรีโมทเปิด, แค่บอกว่ารีโมทรับข้อมูลหรือบ่, และบ่มีคำสั่งอะไรอยู่ในนั้น.

1. ใน Settings, Advanced, "การวินิจฉัยลิงก์ DJI (ยังทดลองอยู่)" เปิดอยู่แล้วโดยค่าเริ่มต้น (บ่มีบนทีวี); ไทล์ "ลิงก์ DJI" อยู่ใน คลังภาพ, แชร์ในเครือข่าย.
2. เปิดมันแล้วอ่านคำเตือนด้านความปลอดภัย. บล็อกแรกบอกว่าอุปกรณ์นี้อ่านอุปกรณ์เสริม USB ได้หรือบ่; ถ้าบ่ได้, นั่นก็เป็นคำตอบเหมือนกัน.
3. แตะ "เริ่มแคปเจอร์", แล้วเสียบรีโมทด้วยสายของมัน, โดยปิดโดรนไว้. ถ้า Android ถามว่าจะให้แอปไหนเปิดมัน, เลือก Immuch360 โดยบ่เลือก "ทุกครั้ง", ซึ่งจะเอารีโมทไปจาก DJI Fly.
4. เบิ่งสถานะ ("อุปกรณ์เสริมเปิดแล้ว", "ลิงก์รับไบต์ได้", "เฟรมจากรีโมทเข้ามา") และตัวนับ, แล้วกด "ส่งออกแคปเจอร์": ได้สามไฟล์ใน `Download/Immuch360/dji-link`.

มันยังบ่เคยเจอรีโมทจริงเลย. ยินดีรับการทดสอบกับรีโมท DJI, เริ่มจาก RC-N3 กับ Neo 2 ก่อน: โพสต์สถานะและตัวนับที่หน้านี้แสดงใน [Issues](https://github.com/freeKC/Immuch360/issues), และเก็บไฟล์ที่ส่งออกไว้กับตัวเอง, ตามที่หน้านี้บอก, เพราะในไฟล์มีหมายเลขซีเรียลของรีโมท.

"ตาเดียว" หมายถึงไฟล์ 3D แสดงตาซ้ายของมันบนจอแบน. คอลัมน์ LG webOS เป็นแอปแยกต่างหาก, build ทดสอบ 0.2.0: 0.1.0 ได้รันบนทีวี LG ของผู้ทดสอบคนหนึ่งแล้ว, ส่วนแชร์, Plex และกล้องของ 0.2.0 ได้ตรวจกับเซิร์ฟเวอร์จริงบนเครื่อง build ของโปรเจกต์แล้ว, แต่ยังบ่ได้ตรวจบนทีวี. บ่ใช่ทุก ✅ ที่ได้ตรวจสอบบนอุปกรณ์จริงแล้ว: ตรวจอะไรไว้ที่ไหนแล้ว, และอะไรที่ยังต้องยืนยันอีก, อยู่ใน [ฟีเจอร์](../docs/immuch360/features.md), [รองรับแพลตฟอร์ม](../docs/immuch360/platform-support.md) และ [ความเข้ากันได้](../docs/immuch360/compatibility.md).

- **โทรศัพท์และแท็บเล็ต Android**: แอปแบบเต็ม, สัมผัสกับไจโรสโคป, ทุกแหล่งข้อมูล.
- **iPhone กับ iPad**: แอปแบบเต็ม; ตัวเล่นวิดีโอ 360° มีแค่เล่นกับหยุด, ดูภาพสด Tapo และฝั่งโทรศัพท์ของการเข้าสู่ระบบด้วยโทรศัพท์จะมากับรีลีส iOS ถัดไป, และการค้นหา DLNA ส่ง unicast request ไปจนกว่า Apple จะให้สิทธิ์ multicast.
- **Android TV กับ Google TV**: APK ตัวเดียวกัน, คุมด้วยรีโมท, เป็นธีมมืดตั้งแต่เริ่มต้น; เป็นแค่วิวเวอร์: backup, อัปโหลด และตัวแก้ไข ถูกซ่อนไว้ และรายละเอียดอ่านได้อย่างเดียว, แต่ภาพถ่ายยังหมุนได้ด้วยปุ่มเดียว. ตัวกรองการค้นหาทุกอันใช้กับรีโมทได้: สถานที่กับกล้องเปิดตัวเลือกของมันเป็นรายการ, ตัวกรองวันที่แสดงตัวเลือกทั้งหมด, และแผ่นตัวเลือกของ แท็ก, สถานที่, วันที่, ประเภทสื่อ, คะแนนดาว และการแสดงผล วางปุ่มล้างกับใช้ไว้ข้างตัวเลือก, ห่างไปแค่กดขวาเทื่อเดียว, บนพื้นที่เกือบเต็มความสูงของจอ. ตารางภาพถ่ายใช้หน่วยความจำภาพน้อยลง, และการกดลูกศรค้างไว้จะเลื่อนได้บ่เกินประมาณ 10 แถวต่อวินาที. ตั้งแต่ build 28 มันเข้าสู่ระบบจากโทรศัพท์ได้, ด้วย QR code หรือโค้ดสั้นของมัน (ลองระหว่าง emulator สองตัวโดยพิมพ์โค้ด, ยังบ่ได้ลองกับกล้อง). ตรวจสอบบน Google TV emulator; การทดสอบครั้งแรกบน Android TV จริง, วันที่ 21 ตุลาคม, นำไปสู่การเปลี่ยนแปลงด้านทีวีของ build 27, ซึ่งยังบ่ได้ลองบนทีวีจริง.
- **ทีวี LG ที่ใช้ webOS 4.0 ขึ้นไป**: แอปแยกต่างหากสำหรับรีโมทและ Magic Remote, สร้างมาจาก [immich-tv-webos](https://github.com/Seeky91/immich-tv-webos): วิวเวอร์ Immich ที่มีภาพถ่าย 360° บนทรงกลม, หมุนภาพถ่ายด้วยปุ่มเดียว, ธีมมืด และ 89 ภาษาของแอป (ข้อความบ่กี่อันของแอปทีวีเองยังเป็นภาษาอังกฤษอยู่ตอนนี้); ตั้งแต่ 0.2.0 มีแชร์ในเครือข่าย, Plex และภาพสดจากกล้อง Tapo, ผ่านเซอร์วิสของมันเองบนทีวี (webOS 5 ขึ้นไป, SMB ตั้งแต่ webOS 22); วิดีโอ 360° เล่นแบบแบน. เวอร์ชัน 0.1.0 ได้รันบนทีวี LG ของผู้ทดสอบคนหนึ่งแล้ว (webOS 22); 0.2.0 ตรวจด้วยการทดสอบของมันและกับเซิร์ฟเวอร์จริงบนเครื่อง build ของโปรเจกต์, ยังบ่ได้ตรวจบนทีวี.
- **Meta Quest 2, Pro, 3 กับ 3S**: แอปเป็นหน้าต่าง, บวกกับวิวแบบดื่มดำ; HEVC เป็น codec ที่ปลอดภัย, H.264 หยุดอยู่ที่ประมาณ 4096x2304 บน Quest 3; ทดสอบแค่ Quest 3, ส่วน Quest 2, Quest Pro กับ Quest 3S ยังบ่ได้ทดสอบ.
- **Windows 10 กับ 11**: เป็นพรีวิว, มีโฟลเดอร์แทนแกลเลอรี, มีตัวเล่นวิดีโอของตัวเอง (libmpv) สำหรับวิดีโอแบบแบนกับ 360°, ไฟล์ raw ที่ต่อให้เป็นภาพเดียวด้วยชิปกราฟิก, ไฟล์และโฟลเดอร์ที่เปิดด้วยแอปหรือลากมาวางบนหน้าต่าง, แล้วก็ตัวติดตั้งหรือ ZIP, ที่ APROGSYS เซ็นไว้.
- **Linux**: .deb กับ .rpm ที่สร้างโดย CI ของโปรเจกต์, ติดตั้งและตรวจแล้วบน Ubuntu 22.04 กับ 24.04, Debian 12 และ Fedora 40 กับ 44; ภาพถ่าย, ภาพถ่าย 360° และวิดีโอแบบแบนผ่าน libmpv ของระบบ (วิดีโอ 360°, 3D และ raw เล่นแบบแบนพร้อมข้อความแจ้ง), วาดผ่านฮาร์ดแวร์บนเซสชัน X11 ด้วยตั้งแต่ desktop build 7; แชร์ SMB ตั้งแต่ Ubuntu 22.04 กับ Debian 12 ขึ้นไป; ถ้าบ่มี keyring (GNOME Keyring หรือ KWallet) แอปจะบ่ค้าง 25 s ตอนเปิดครั้งแรกอีกแล้ว: มันเก็บรหัสผ่านไว้แค่ในเซสชันนั้น และบอกไว้ในการตั้งค่าของมัน; ยังบ่ได้รันบน Linux PC จริง, มีแค่ใน WSLg และในคอนเทนเนอร์.
- **macOS**: DMG กับ ZIP ที่สร้างโดย CI ของโปรเจกต์, เป็นแบบ universal, ยังบ่ได้เซ็น (Gatekeeper จะถามครั้งเดียว); มันเปิดได้, เปิดไฟล์และโฟลเดอร์ที่ส่งให้มัน รวมทั้งจาก Finder, เก็บข้อมูลลับไว้ใน login keychain และเล่นวิดีโอแบบแบนด้วย libmpv ของตัวเอง, ทั้งหมดนี้ตรวจแค่บน Mac ของ CI โปรเจกต์เท่านั้น; ยังบ่มีอะไรได้รันบน Mac จริงเลย.

## ฟีเจอร์ขั้นสูง

สิ่งที่แอปอ่านและเล่นได้, สำหรับคนที่อยากรู้ทุกรายละเอียด. แต่ละบรรทัดอธิบายไว้ใน [คู่มือผู้ใช้](../docs/immuch360/user-guide.md) และ [หน้า compatibility](../docs/immuch360/compatibility.md).

- **ฟอร์แมต**: ภาพถ่ายและวิดีโอแบบแบน (สิ่งที่อุปกรณ์ถอดรหัสได้: MP4, MOV, MKV และอื่นๆ); ภาพถ่ายและวิดีโอ 360° แบบ equirectangular; พาโนรามาแบบไม่เต็ม (ครอป GPano); VR180; 3D แบบสเตอริโอ, บนแล้วก็ล่าง หรือเคียงข้างกัน, อ่านจากไฟล์ (st3d box) หรือเดาจากเฟรม; ภาพ spatial ของ Apple (HEIC stereo pairs) และวิดีโอ spatial (MV-HEVC, ตาเดียว); raw .insp กับ .insv ของ Insta360, GoPro .360, DJI .osv; แหล่ง 10 bit HLG และ PQ แปลงโทนลงบนทรงกลม.
- **Projection กับ metadata**: metadata GPano กับ spherical อ่านจากไฟล์, ด้วย range request บนเซิร์ฟเวอร์หรือแชร์; มุมมองแรกที่กล้องบันทึกไว้; ภาพทรงกลมของโดรน DJI รู้จักได้จากกล้องของมัน, พร้อมไฟล์ sidecar .xmp ที่เลือกใช้ได้เพื่อให้ Immich ระบุมันด้วย; "ดูเป็น 360°" จดจำไว้ในอุปกรณ์; VR180 จำได้จากไฟล์หรือชื่อไฟล์; สถานที่ของวิดีโอโดรนอ่านจากบันทึกการบิน .SRT ของมัน; metadata ยังอยู่ครบเพราะไฟล์ต้นฉบับคือสิ่งที่เล่นอยู่, บ่ใช่ไฟล์ที่แปลงแล้ว; การหมุนหนึ่งในสี่รอบบันทึกผ่านตัวแก้ไขของ Immich หรือเก็บไว้บนอุปกรณ์, บ่เคยทำกับไฟล์แบบดื่มดำ.
- **การเล่นแบบเนทีฟ**: Media3 บน Android กับทีวี, SceneKit กับ AVFoundation บน iOS, Meta Spatial SDK ในเฮดเซ็ต, libmpv บน Windows; เลือกไฟล์ต้นฉบับหรือสตรีมที่แปลงแล้วตามที่อุปกรณ์ถอดรหัสได้; มีรายการตัวถอดรหัสวิดีโอของอุปกรณ์ใน Settings, Advanced; เลือกแทร็กเสียงได้และมีตัวบอกบัฟเฟอร์.
- **ไฟล์ raw ที่ต่อให้เป็นภาพเดียวบนอุปกรณ์**: Flutter fragment shader สำหรับภาพถ่าย; GPU effect ในตัวเล่นสำหรับวิดีโอแทร็กเดียว; ตัวถอดรหัสฮาร์ดแวร์สองตัวพร้อมกันแล้วก็ GPU compositor สำหรับวิดีโอที่มีเลนส์เดียวต่อแทร็กหรือต่อไฟล์ (OpenGL ES 3 บน Android กับ Quest, Metal บน iOS, แล้วก็บน Windows ตั้งแต่ desktop build 5, ตัวเล่น libmpv สองตัวที่แอปจับคู่เฟรมกันด้วยชิปกราฟิก); การแคลิเบรตของกล้องเอง (โมเดล Mei, V6 และ equidistant) แล้วก็การบันทึกของ accelerometer; ถอยไปใช้เลนส์เดียว, สตรีมที่แปลงแล้ว, สำเนา LRV ของกล้อง หรือวิดีโอที่ยังบ่ได้ต่อ เมื่ออุปกรณ์รันตัวถอดรหัสสองตัวบ่ได้.
- **แหล่งข้อมูล**: แกลเลอรีของอุปกรณ์; โฟลเดอร์ของคอมพิวเตอร์; โดรน, รีโมทคอนโทรลเลอร์ของมัน หรือการ์ดกล้องผ่าน USB, ผ่านตัวเลือกโฟลเดอร์ของระบบ (Android, ยังทดลองอยู่); เซิร์ฟเวอร์ Immich; SMB 2 กับ 3, WebDAV, DLNA/UPnP; Plex ผ่าน HTTPS ที่ตรวจกับ certificate ของเซิร์ฟเวอร์เอง; กล้อง Tapo ผ่านเครือข่ายท้องถิ่น (HTTPS กับ RTSP); โทรศัพท์หรือคอมพิวเตอร์ที่แชร์บน Wi-Fi เป็นเซิร์ฟเวอร์ WebDAV; เซิร์ฟเวอร์ที่หาเจอด้วย Bonjour/mDNS, การสแกนเครือข่ายท้องถิ่น, SSDP, GDM, และการค้นหาของ TP-Link, และยังตามหาเมื่อที่อยู่ของมันเปลี่ยนไป.
- **การอ่านตามต้องการ**: บริดจ์ท้องถิ่นหนึ่งคอยให้ตัวเล่นใช้ byte range กับ token ต่อหนึ่ง session; บล็อกใหญ่ๆ, อ่านล่วงหน้า, และได้ถึงหกการเชื่อมต่อ SMB พร้อมกัน; รูปย่อมาจากเฟรมหนึ่งของวิดีโอแต่ละอัน; ไม่มีอะไรถูกคัดลอกเข้าอุปกรณ์เลย.
- **ฮาร์ดแวร์**: ใช้ตัวถอดรหัสฮาร์ดแวร์ทุกที่ที่มี, พร้อมข้อจำกัดที่วัดไว้ (ขีดจำกัด H.264 ของ Quest 3, เลนส์ 2048x2048 สองตัวเป็นอย่างมากสำหรับตัวถอดรหัสซอฟต์แวร์); บน Windows ชิปกราฟิกวาดวิว 360° จากแต่ละเฟรมที่ถอดรหัสแล้ว, วัดขนาดเฟรมบนคอมพิวเตอร์แต่ละเครื่อง, จำได้ว่าเป็นชิปแบบรวมหรือแบบแยก.
- **เฉพาะแต่ละแพลตฟอร์ม**: ไจโรสโคปกับตัวเล่น Spatial 2.5D บนโทรศัพท์; วิวแบบดื่มดำ, คอนโทรลเลอร์กับมือบน Quest; เลย์เอาต์ของรีโมท, ไดอะล็อกคีย์บอร์ด และแบนเนอร์บน Android TV; บนคอมพิวเตอร์, เมาส์กับคีย์บอร์ด, เต็มจอ, หน้าต่างเดียว, ไฟล์และโฟลเดอร์ที่เปิดด้วยแอปหรือลากมาวางบนหน้าต่างของมัน, อ่านได้เหมือนไฟล์ในโฟลเดอร์ของเจ้า, รวมทั้งภาพถ่าย HEIC, AVIF, TIFF และภาพถ่าย raw จากกล้องของโฟลเดอร์เมื่อ Windows มีตัวถอดรหัสให้มัน, แล้วก็ระบบป้องกันข้อมูลของ Windows สำหรับรหัสผ่านและ token.
- **ความเป็นส่วนตัวตั้งแต่ออกแบบ**: บ่มีบัญชี, บ่มีคลาวด์, บ่มี analytics; รหัสผ่านและ token อยู่ในที่เก็บข้อมูลปลอดภัยของอุปกรณ์; จอที่เข้าสู่ระบบจากโทรศัพท์ได้ session ของมันเอง, ส่งแบบเข้ารหัสในเครือข่ายบ้าน, บ่เคยได้รหัสผ่าน; กล้องของตัวเล่น Spatial และของตัวสแกนโค้ดใช้ในอุปกรณ์เท่านั้น; แชร์, Plex, และกล้อง เข้าถึงได้แค่ในเครือข่ายของเจ้าเท่านั้น.

<a id="install"></a>
## ติดตั้ง

### โทรศัพท์และแท็บเล็ต Android

1. [Google Play](https://play.google.com/store/apps/details?id=com.aprogsys.immuch360), หรือ APK จากหน้า [Releases](https://github.com/freeKC/Immuch360/releases): `Immuch360-v<version>-arm64-v8a-release.apk` สำหรับโทรศัพท์; ตัวสากล `Immuch360-v<version>-release.apk` ใช้ได้ทุกที่.
2. แอปติดตั้งอยู่ข้างๆแอป Immich อย่างเป็นทางการ. APK จาก GitHub บ่อัปเดตตัวเองนะ: คอยดูหน้า Releases เอาไว้; พอเจ้าติดตั้งแอปจากร้านไหนแล้ว, ก็เอาอัปเดตจากร้านนั้นแทน.

### iPhone กับ iPad

1. เวอร์ชัน App Store กำลังรอการตรวจสอบของ Apple อยู่. จนกว่ามันจะเผยแพร่, สร้างแอปด้วย Xcode บน Mac ก่อน, ดู [สร้างขึ้นเอง](../docs/immuch360/build.md).
2. แตะ "ใช้โดยบ่มีเซิร์ฟเวอร์", หรือ "เชื่อมต่อกับเซิร์ฟเวอร์ Immich" เพื่อเข้าสู่ระบบด้วยเซิร์ฟเวอร์ของเจ้า; ทั้งสองอยู่บนหน้าต้อนรับตั้งแต่ build 24.

<a id="android-tv-and-google-tv"></a>
### Android TV กับ Google TV

1. จนกว่า Google Play จะมีแอปนี้บนทีวี, เอาตัวสากล `Immuch360-v<version>-release.apk` จากหน้า [Releases](https://github.com/freeKC/Immuch360/releases) ไปใช้.
2. บนทีวี เปิดตัวเลือกสำหรับนักพัฒนาแล้วก็การแก้จุดบกพร่อง USB (บน Google TV: การตั้งค่า ระบบ เกี่ยวกับ เลือก "Android TV OS build" เจ็ดเทื่อ แล้วก็ การตั้งค่า ระบบ ตัวเลือกสำหรับนักพัฒนา; ชื่อจะต่างกันไปแต่ละทีวี)
3. จากคอมพิวเตอร์ในเครือข่ายเดียวกัน ด้วย adb (Android SDK Platform Tools): `adb connect <address of the TV>` ยอมรับคำถามบนทีวี แล้วก็ `adb install -r Immuch360-v<version>-release.apk`
4. แอปจะสะแดงในบรรดาแอปของทีวี พร้อมแบนเนอร์ของมัน ติดตั้งรีลีสถัดไปแบบเดียวกัน: `-r` จะเก็บการเข้าสู่ระบบแล้วก็การตั้งค่าไว้

<a id="lg-tvs-webos"></a>
### ทีวี LG (webOS)

1. เจ้าต้องมีทีวี LG ที่ใช้ webOS 4.0 ขึ้นไป, คอมพิวเตอร์ในเครือข่ายเดียวกัน และบัญชีนักพัฒนา LG ฟรี. บนทีวี, ติดตั้ง Developer Mode จาก LG Content Store, เข้าสู่ระบบ, เปิด Dev Mode Status แล้วปล่อยให้ทีวีรีสตาร์ท; จดที่อยู่ IP ของมันกับ passphrase ที่แอปแสดงไว้.
2. บนคอมพิวเตอร์, ติดตั้ง webOS CLI (Node.js 18 ขึ้นไป): `npm install -g @webos-tools/cli`, แล้วลงทะเบียนทีวีด้วย `ares-setup-device` (ที่อยู่ IP ของมัน, พอร์ต 9922, ผู้ใช้ `prisoner`) และ `ares-novacom --device <name> --getkey`, ซึ่งจะถาม passphrase.
3. ดาวน์โหลด `Immuch360-webOS-0.2.0.ipk` จาก [พรีรีลีสของ webOS](https://github.com/freeKC/Immuch360/releases/tag/webos-v0.2.0), ตรวจกับ `SHA256SUMS.txt`, แล้วก็ `ares-install --device <name> Immuch360-webOS-0.2.0.ipk`. [webOS Dev Manager](https://github.com/webosbrew/dev-manager-desktop) ของ webosbrew เฮ็ดแบบเดียวกันได้โดยบ่ต้องใช้บรรทัดคำสั่ง.
4. เซสชัน Developer Mode อยู่ได้ 1000 ชั่วโมง และปุ่ม EXTEND ในแอป Developer Mode จะต่ออายุให้; พอหมดอายุ, ทีวีจะลบแอปที่ติดตั้งแบบนี้ออก. รายละเอียดอยู่ใน [webos/README.md](../webos/README.md#install-on-a-tv-in-developer-mode).

<a id="meta-quest"></a>
### Meta Quest

1. จาก [Horizon Store](https://www.meta.com/experiences/immuch360/1384208401440714/): เวอร์ชันร้าน, อัปเดตตามที่ Meta ตรวจสอบแต่ละครั้งที่ส่งไป.
2. หรือ sideload ไฟล์ `-quest-release.apk` ของ [release](https://github.com/freeKC/Immuch360/releases) ในโหมด developer ด้วย adb หรือ SideQuest: `adb install -r Immuch360-v<version>-quest-release.apk`, แล้วเปิด Library ของเฮดเซ็ต, "Unknown sources".
3. เวอร์ชันร้านกับ APK จาก GitHub เซ็นด้วยคีย์คนละตัว: ถ้าจะสลับจากอันหนึ่งไปอีกอัน, ต้องถอนแอปออกก่อน, ซึ่งทำให้เสีย login, การตั้งค่า, และรายการแชร์ในเครือข่ายไปหมด.

<a id="windows"></a>
### Windows

1. ดาวน์โหลด `Immuch360-Desktop-3.3.0-rc.0-desktop.8-windows-x64-setup.exe` จาก [พรีรีลีสของเดสก์ท็อป](https://github.com/freeKC/Immuch360/releases/tag/desktop-v3.3.0-rc.0-8) (พร้อม `SHA256SUMS.txt` ไว้ตรวจสอบมัน) แล้วเปิดมัน. ตัวติดตั้งกับ ZIP เซ็นแล้ว; Windows แสดง APROGSYS เป็นผู้เผยแพร่. ระหว่างที่ผู้เผยแพร่ยังใหม่สำหรับ SmartScreen, มันอาจยังถามอีกเทื่อหนึ่ง: "More info", แล้วก็ "Run anyway".
2. เลือก "Install for me only" (บ่ต้องมีสิทธิ์ผู้ดูแลระบบ) หรือ "Install for all users", แล้วเลือกภาษาของตัวติดตั้ง, ซึ่งเลือกภาษาที่ Windows ใช้อยู่ไว้ให้ก่อนแล้ว.
3. เริ่ม Immuch360 Desktop จากเมนู Start. ภาพถ่ายและวิดีโอจะพบมันอยู่ใน "Open with" (คลิกขวาที่ไฟล์, Open with); มันบ่เคยตั้งตัวเองเป็นแอปเริ่มต้นสำหรับไฟล์พวกนั้นเลย. การเริ่มครั้งแรกของ build ใหม่อาจใช้เวลาถึงหนึ่งนาทีตอนที่ Windows กำลังสแกนไฟล์อยู่.
4. Windows 10 หรือ 11, 64 บิต. ถ้าจะอัปเดต, เปิดตัวติดตั้งของ build ถัดไป: การเข้าสู่ระบบ, โฟลเดอร์ และการตั้งค่าของเจ้ายังอยู่เหมือนเดิม. ZIP ของรีลีสเดียวกันก็คือแอปตัวเดียวกันในรูปโฟลเดอร์, แตกไฟล์ที่ไหนก็ได้แล้วเริ่ม `immuch360.exe` จากในนั้น.

### Linux

บน Ubuntu 22.04 ขึ้นไปและ Debian 12 ขึ้นไป: `sudo apt install ./Immuch360-Desktop-3.3.0-rc.0-desktop.8-linux-amd64.deb`; บน Fedora 40 ขึ้นไป: `sudo dnf install ./Immuch360-Desktop-3.3.0-rc.0-desktop.8-linux-x86_64.rpm`, ทั้งสองอันจาก [พรีรีลีสของเดสก์ท็อป](https://github.com/freeKC/Immuch360/releases/tag/desktop-v3.3.0-rc.0-8). แล้วเริ่ม Immuch360 Desktop จากเมนูแอปของเจ้า. เป็นพรีวิว: โฟลเดอร์ของคอมพิวเตอร์, ภาพถ่ายและภาพถ่าย 360° เป็นทรงกลม, และวิดีโอแบบแบนผ่าน libmpv ของระบบ ซึ่งแพ็กเกจติดตั้งให้ (วิดีโอ 360°, 3D และ raw เล่นแบบแบน, พร้อมข้อความแจ้ง); แชร์ SMB ใช้ได้ตั้งแต่ Ubuntu 22.04 กับ Debian 12 ขึ้นไป. บน Fedora, วิดีโอจากกล้องต้องใช้ FFmpeg ของ RPM Fusion. ถ้าบ่มี GNOME Keyring หรือ KWallet, รหัสผ่านจะเก็บไว้แค่ในเซสชันนั้น, และการตั้งค่าของแอปก็บอกไว้.

### macOS

เปิด `Immuch360-Desktop-3.3.0-rc.0-desktop.8-macos.dmg` จาก [พรีรีลีสของเดสก์ท็อป](https://github.com/freeKC/Immuch360/releases/tag/desktop-v3.3.0-rc.0-8) แล้วลากแอปไปที่ Applications (Apple silicon กับ Intel, macOS 12 ขึ้นไป). มันยังบ่ได้เซ็นหรือ notarized เลย: กด Control ค้างแล้วคลิกมัน แล้วเลือก Open บน macOS 14 กับรุ่นก่อนหน้า, หรือเลือก "Open Anyway" ใน System Settings, Privacy & Security บน macOS 15 ขึ้นไป. บ่มีใครในโปรเจกต์มี Mac เลย: แอปรันแค่บน Mac ของ CI โปรเจกต์เท่านั้น, ที่นั่นมันเปิดไฟล์และโฟลเดอร์ได้ และเล่นวิดีโอแบบแบนด้วย libmpv ของตัวเอง; การเข้าถึงเครือข่ายของมันยังบ่ได้ลองเลย. ยินดีรับรายงานปัญหา.

<a id="privacy"></a>
## ความเป็นส่วนตัว

ไม่มีอะไรส่งไปให้ผู้พัฒนาเลย: บ่มีบัญชี, บ่มี analytics, บ่มี crash reporting service, บ่มีโฆษณา. แอปคุยกับแค่เซิร์ฟเวอร์ที่เจ้าเลือก (เซิร์ฟเวอร์ Immich ของเจ้า, แชร์ของเจ้า, เซิร์ฟเวอร์ Plex ของเจ้า, กล้องของเจ้า) และ, ถ้าบ่มีเซิร์ฟเวอร์, ก็บ่คุยกับใครเลย. รหัสผ่านและ token อยู่ในที่เก็บข้อมูลปลอดภัยของอุปกรณ์. กล้องใช้ในอุปกรณ์เท่านั้น, โดยตัวเล่น Spatial 2.5D และเพื่อสแกนโค้ดของจอที่เจ้าจะเข้าสู่ระบบ; ภาพของมันไม่ถูกเก็บและไม่ถูกส่งไปไหนเลย. จอที่เข้าสู่ระบบจากโทรศัพท์ของเจ้าได้ session ของมันเอง, ส่งแบบเข้ารหัสในเครือข่ายบ้านของเจ้า, บ่เคยได้รหัสผ่านของเจ้า. นโยบายฉบับเต็มอยู่ใน [PRIVACY.md](../PRIVACY.md), และรายละเอียดแต่ละแหล่งอยู่ใน [คู่มือผู้ใช้](../docs/immuch360/user-guide.md#privacy).

<a id="the-project"></a>
## เกี่ยวกับโปรเจกต์

Immuch360 เป็นเวอร์ชันไม่เป็นทางการที่แยกมาจากแอป [Immich](https://github.com/immich-app/immich) มือถือ, อยู่ภายใต้ [GNU AGPL v3](../LICENSE), บ่เกี่ยวข้องกับ, หรือได้รับการรับรองจาก, ทีม Immich หรือ FUTO. โปรเจกต์นี้เกิดขึ้นเพราะการดู 360° บนมือถือถูกขอมาตั้งแต่เดือนมกราคม 2024 ใน Immich แล้วแต่ยังบ่มีในแอปอย่างเป็นทางการ; มันปล่อยให้ใช้ตอนนี้, เก็บความคิดเห็นจากอุปกรณ์จริง, และจะเอากลับไปให้ Immich, เป็น pull request เล็กๆ, ตามที่ maintainer ต้องการ. ทุกอย่างที่แอปอย่างเป็นทางการทำได้ก็ยังเก็บไว้หมด; branch, build chain, และ CI อธิบายไว้ใน [สร้างขึ้นเอง](../docs/immuch360/build.md).

วิวเวอร์ภาพถ่าย 360° อ้างอิงมาจาก pull request ต้นทาง [immich-app/immich#31169](https://github.com/immich-app/immich/pull/31169) ของ dmitry-brazhenko, ซึ่งสร้างมาจาก prototype ของ bencefr ใน [#30192](https://github.com/immich-app/immich/pull/30192) อีกที; ขอบคุณทั้งสองคน. การแก้รีโมทในตัวกรองการค้นหากับการเรียงอัลบั้มบนทีวีเริ่มมาจากงานของ mlc70 ใน [mlc70/Immuch-Android-TV#1](https://github.com/mlc70/Immuch-Android-TV/pull/1), และแถบปุ่มคำสั่งกับแผ่นตัวกรองที่สูง 80 เปอร์เซ็นต์ของจอมาจาก [mlc70/Immuch-Android-TV#3](https://github.com/mlc70/Immuch-Android-TV/pull/3) ของ mlc70, โดยเก็บชื่อผู้เขียนไว้ตามเดิม; ขอบคุณ mlc70. แอป LG webOS สร้างมาจาก [immich-tv-webos](https://github.com/Seeky91/immich-tv-webos) ของ Seeky91, ภายใต้ license MIT, เก็บไว้ในโฟลเดอร์ของมันเอง; ขอบคุณ Seeky91. กล้อง Tapo เขียนขึ้นมาจากสิ่งที่ [pytapo](https://github.com/JurajNyiri/pytapo), [Home Assistant Tapo Control](https://github.com/JurajNyiri/HomeAssistant-Tapo-Control), และ [python-kasa](https://github.com/python-kasa/python-kasa) บอกไว้. วิว Meta Quest พึ่งพา Meta Spatial SDK, ที่บ่เป็น open source, ก็เลยเก็บไว้แค่ในเวอร์ชันนี้. แชร์ SMB ใช้ libsmb2, ภายใต้ LGPL 2.1 ขึ้นไป: ตั้งแต่ build 27 และ desktop build 7, ทุก build มีประกาศของมัน, ข้อความ license ของมัน และไฟล์ source ของมัน, `Immuch360-libsmb2-sources.tar.gz`, ซึ่งแนบไว้กับทุกรีลีสด้วย. build ของ Windows และ macOS มี libmpv (ไลบรารีของ [mpv](https://mpv.io), พร้อม [FFmpeg](https://ffmpeg.org)) ที่โปรเจกต์สร้างขึ้น, ภายใต้ LGPL, พร้อม license และ source ของมัน, ซึ่งมีรายชื่ออยู่ในหน้า license ของแอป (Licenses, ด้านล่างสุดของเมนูโปรไฟล์); รายละเอียดและ trademark ของแพลตฟอร์มที่พูดถึงในหน้านี้อยู่ใน [License และ trademark](../docs/immuch360/platform-support.md#license-and-trademarks).

ภาพโทรศัพท์ในหน้านี้ถ่ายบน Android build ใน emulator, ภาพทีวีถ่ายบน Google TV emulator, และภาพ Windows ถ่ายบนเครื่อง Windows 11 เครื่องหนึ่ง, ทั้งหมดใช้พาโนรามา CC0 จาก [Poly Haven](https://polyhaven.com); ภาพเฮดเซ็ตถ่ายบน Quest 3.

<a id="roadmap"></a>
## แผนงาน

สิ่งที่ยังบ่เสร็จ อันที่น่าจะมาก่อนอยู่ข้างบน บ่มีอะไรในนี้เป็นคำสัญญา แล้วความคิดเห็นใน [ตัวติดตามปัญหา](https://github.com/freeKC/Immuch360/issues) ช่วยตัดสินว่าอะไรจะมาก่อน

- **ร้านค้า**: Google Play (build 28 กำลังตรวจสอบ; รายการทีวีกำลังตรวจสอบ), App Store (เวอร์ชัน 3.3.1 กำลังตรวจสอบ, แล้วก็เวอร์ชัน 3.3.2 กับ build 28), Meta Horizon Store (build 28 กำลังตรวจสอบ).
- **คอมพิวเตอร์**: ทดสอบทุกฟังก์ชันด้วยตัวเองบน Windows PC, รวมทั้งการเข้าสู่ระบบด้วยโทรศัพท์; Spatial 2.5D ด้วยเว็บแคมบน Windows, กำลังพัฒนาสำหรับเดือนพฤศจิกายน 2026; แล้วตัวเรนเดอร์วิดีโอ 360° บน Linux กับ macOS, การทดสอบบน Mac จริงกับ Linux PC จริง; แล้วอัปเดตอัตโนมัติกับแอป macOS ที่เซ็นแล้ว.
- **ทีวี**: ทดสอบ build 27 กับ 28 บน Android TV จริง, รวมทั้งการเข้าสู่ระบบด้วยโทรศัพท์; webOS 0.2.0 บนทีวี LG จริง, พร้อมแชร์, Plex และภาพสดของมัน; แล้ววิดีโอ 360° บนทรงกลม, เสียงของกล้องและวิดีโอบันทึกของมัน (บ่ก่อนเดือนธันวาคม 2026).
- **โทรศัพท์และแท็บเล็ต**: ดูภาพสด Tapo และการเข้าสู่ระบบจอใหญ่บน iPhone กับ iPad มากับรีลีส iOS ถัดไป; แถบเวลาในตัวเล่นวิดีโอ 360° ของ iOS, ย้อนกลับกับถัดไปในตัวเล่น 360° ของโทรศัพท์, เลือกแทร็กเสียงในตัวเล่นแบบแบน.
- **สื่อแบบดื่มดำ**: dual fisheye .dng, ปรับระดับวิดีโอของ GoPro กับ DJI จากข้อมูลการเคลื่อนไหวของตัวมันเอง, วิดีโอ spatial เป็น 3D บน Quest ถ้าตัวถอดรหัสของมันยอม, ย้อนกลับกับถัดไประหว่างภาพ spatial ในเฮดเซ็ต.
- **แหล่งข้อมูล**: ปัดไปมาระหว่างไฟล์ในโฟลเดอร์แชร์, Digest authentication สำหรับ WebDAV, QR code เพื่อเอา Plex token มาจากคอมพิวเตอร์, IPv6 สำหรับ Plex, วิดีโอ Tapo แบบ H.265, ช่องรายการบนหน้าโฮมของทีวี.
- **โดรน**: ทดสอบกับ DJI Neo 2 จริง, แล้วรวมเสียงที่โทรศัพท์อัดไว้เข้าไปในคลิปของมัน; หน้าลิงก์ DJI กับรีโมทคอนโทรลเลอร์จริง, ก้าวแรกสู่วิดีโอของโดรนใน Meta Quest. ยังบ่ได้วางแผนอะไรที่ส่งคำสั่งไปที่โดรนก่อนการทดสอบพวกนั้น.
- **Upstream**: pull request เล็ก ๆ ไปที่ Immich สำหรับส่วนที่ผู้ดูแลต้องการ เริ่มจากตัวเบิ่งรูปภาพ 360°

รายการทั้งหมด, พร้อมการตรวจสอบบนอุปกรณ์ที่ยังรอทำสำหรับแต่ละฟีเจอร์, อยู่ใน [Release status](../docs/immuch360/release-status.md#roadmap).
