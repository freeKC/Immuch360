# Immuch360

Immuch360 вӑл 360° сӑнӳкерчӗксемпе видеосем ӑшӗнче таврана пӑхма май паракан Immich мобильлӗ приложенийӗ, тата тикӗс, 360°, 3D тата VR180 сӑнӳкерчӗксемпе видеосем валли тӳлевсӗр плеер, Android телефонӗсемпе планшечӗсенче, iPhone тата iPad ҫинче, Meta Quest шлемӗсем ҫинче (Quest 3 тата 3S, build 21-ран Quest 2 тата Quest Pro та, тӗрӗслемен), build 20-ран Android TV тата Google TV ҫинче те. Immuch360 Desktop, Windows компьютерӗ ҫинчи ҫав приложенийӗ, тӗрӗслев версийӗ евӗр тухрӗ, пӑхӑр: [Windows компьютерӗ ҫинче](#on-a-windows-computer-immuch360-desktop-preview).

Вӑл 360° камерӑпа (Insta360, GoPro MAX, DJI Osmo 360, Ricoh Theta, Samsung Gear 360) е телефонӑн фотосфера режимӗпе ӳкерекенсем валли, е шлемлӑ ҫынсем валли, хӑйсен ӳкерчӗкӗсене Immich серверӗнчен, телефонран, NAS-ран, медиа серверӗнчен е Plex серверӗнчен пӑхас текенсем валли: ҫав сервер, ҫав аккаунт, серверта плагин кирлӗ мар, е сервер пачах кирлӗ мар. Build 20-ран вӑл Tapo камерисене те кӑтартать: тӳрӗ эфира тата вӗсен асӑм картинчи ҫырса илнисене.

## 360° сӑнӳкерчӗксемпе видеосем сфера евӗр

Эсир хӑвӑрӑн сӑнӳкерчӗксен сыхлӑх копийӗсене [Immich](https://github.com/immich-app/immich) серверӗ ҫине тӑватӑр, вӗсенчен хӑшӗ-пӗри 360° камерӑран е телефонӑн фотосфера режимӗнчен килет. Официаллӑ мобильлӗ приложенире ку ӳкерчӗксем тикӗс, тӑсӑлнӑ хӑю евӗр курӑнаҫҫӗ, 360° видеосем те тикӗс выляҫҫӗ. Immich-ӑн веб-приложенийӗ 360° сӑнӳкерчӗке сфера евӗр кӑтартма пултарать, мобильлӗ приложени пултараймасть: ҫакна 2024 ҫулхи кӑрлачран [#6572 сӳтсе явура](https://github.com/immich-app/immich/discussions/6572) ыйтаҫҫӗ.

Immuch360 вӗсене Android тата iOS телефонӗсемпе планшечӗсенче таврана пӑхма пулакан сфера евӗр уҫать.

Сӑнӳкерчӗк ӑна туртнӑ чухне ҫаврӑнать, икӗ пӳрнепе е икӗ хут пуссан пысӑкланать, хӑвӑрт туртнӑ хыҫҫӑн тата кӑштах ҫаврӑнать, камера ҫырса хунӑ пуҫламӑш курӑнӑмран пуҫланать (GPano метаданнӑйӗсем), пысӑклатнӑ чухне уҫӑмлӑрах текстура илет; пайлӑ панорамӑсене те шута илет (GPano касни). Видео сасӑпа, туртупа тата гироскоппа тӑван сферӑллӑ плеерта выляять.

Ҫыхӑнтарнӑ 360° файлсем пур ҫӗрте те ӗҫлеҫҫӗ: Insta360 приложенийӗнчен е Studio-ран экспорт, GoPro Player, Ricoh Theta тата телефонсен фотосферисем. Камерӑран тӳрех килнӗ чӗрӗ файлсене приложени хӑй ҫыхӑнтарать, пӑхӑр [360° камерӑсен чӗрӗ файлӗсем](#raw-360-camera-files-without-the-cameras-app).

- **360° сӑнӳкерчӗк сфера евӗр**: хупасси сулахайра ҫӳлте; сылтӑмра ҫӳлте 360°/180° кнопки, 3D вырнаҫуни кнопки тата гироскоп.
- **360° видео 360° плеерта**: управлени валли ӳкерчӗк ҫине пусӑр; 360° тата 3D сылтӑмра ҫӳлте.

### 360° сӑнӳкерчӗке сфера евӗр уҫасси

1. Сӑнӳкерчӗке вӑхӑт шкалинчен, альбомран, [360° списокӗнчен](#find-your-360-shots-the-360-list) е тетел папкинчен уҫӑр. 360° сӑнӳкерчӗксен миниатюри ҫинче 360° палли пур.
2. Пӑхавҫӑн ҫӳлти панелӗнче 360° ҫине пусӑр. Сфера пӑхавҫи уҫӑлать, пӗтӗм ӳкерчӗк тиеннӗ вӑхӑтра тиени кӑтартӑвӗ курӑнать; тикӗс курӑнӑмри масштаб упранать.
3. Таврана пӑхма туртӑр, пысӑклатма икӗ пӳрнепе сарӑр, ҫывӑхлатма икӗ хут пусӑр. Хӑвӑрт туртнӑ хыҫҫӑн курӑнӑм тата кӑштах ҫаврӑнать те майӗпенленет.
4. Телефона ҫавӑрса таврана пӑхас тесен, сылтӑмра ҫӳлти гироскоп кнопки ҫине пусӑр (стандартла сӳнтернӗ).
5. Сылтӑмра ҫӳлти ытти икӗ кнопка: 360°/180° (тулли сфера е VR180 ҫур сфера, пайлӑ панорамӑсенче курӑнмасть) тата 3D (стереоскопи сӑнӳкерчӗкӗн вырнаҫӑвӗ), пӑхӑр [3D тата VR180](#3d-and-vr180-photos-and-videos). Чӗрӗ Insta360 сӑнӳкерчӗкӗн гироскоп кӑна пур.
6. Сулахайра ҫӳлти хӗреслӗ кнопкӑпа хупӑр.

### 360° видео пӑхасси

1. Видеона уҫӑр та ҫӳлти панельте 360° ҫине пусӑр. 360° видеора 360° кнопки малта; телефонсемпе планшетсенче ун хыҫҫӑн Spatial кнопки пырать, ку ӗнерленӳ ҫутӑ чухне (пӑхӑр [Spatial 2.5D](#depth-on-a-flat-screen-spatial-25d-experimental)).
2. Тӑван 360° плеер пӗтӗм экран ҫине уҫӑлать те сасӑпа выляять: Android-ра Media3, iOS-ра SceneKit.
3. Таврана пӑхма туртӑр е телефона хускатӑр. Android плеерӗ яланах телефон хыҫҫӑн пырать; iOS плеерӗн гироскоп куҫаркӑчӗ пур, стандартла ҫутӑ.
4. Управлени валли ӳкерчӗк ҫине пусӑр: ҫӳлте хупасси, 360°/180° тата 3D, унтан Android-ра выляс, сикмелли кнопкӑсем тата вӑхӑт йӗрри. iOS плеерӗнче халлӗхе выляс тата пауза кӑна.
5. Видеон икӗ е ытларах сасӑ йӗрӗ пулсан (чӗлхесем, комментари), «Сасӑ йӗрӗ» кнопки пӗрне суйлама май парать. Видео тиеннӗ е чарӑннӑ чухне плеер «Тиени» кӑтартать, выляттармалли буфер миҫе тулнине те.

Плеер телефонра упранакан файла е тетел папкин файлне выляттарать, ҫавнашкал файл пулсан. Унсӑрӑн вӑл сирӗн серверӗнтен поток илет: стандартла транскодланӑ поток, е Settings (Ӗнерленӳсем), Asset Viewer (Пӑхавҫӑ), «Видео ҫӑлкуҫӗ» ӑшӗнче ыйтсан, оригинал (build 15-ран; унччен «Force original video» (Оригинал видеона хистесе выляттар) куҫаркӑчӗ), пӑхӑр [Видео тӗплӗхӗсем тата декодерсем](#video-details-decoders-and-why-a-video-stutters).

### Тикӗс курӑнакан 360° файл: 360° евĕр пăх

Хӑш-пӗр 360° файлсенче проекци палли ҫук, ҫавӑнпа сервер вӗсене 360° тесе палӑртмасть, вӗсем тикӗс курӑнаҫҫӗ.

1. Сӑнӳкерчӗке е видеона уҫӑр та сылтӑмра ҫӳлте ⋮ ҫине пусӑр.
2. Slideshow (Слайд-шоу) тата Download (Тиесе ил) хушшинчи «360° евĕр пăх» ҫине пусӑр. Ҫӳлти панельте 360° кнопки курӑнать.
3. Каялла тавӑрас тесен, ҫав пункт халь «360° евĕр шутлама пăрах» тесе ҫырнӑ.

Суйлава телефон астуса юлать, серверта вӑл нимӗн те улӑштармасть. Тетел папкин файлӗшӗн вӑл ҫак пӑхура кӑна вӑйлӑ.

### Чикӗсем

- **iOS-ри 360° видео плеерӗ**: выляс тата пауза, вӑхӑт йӗрри халлӗхе ҫук.
- **Малтанхи тата малалли**: телефонсенчи 360° плеерсем малтанхи е малалли медиа ҫине халлӗхе куҫмаҫҫӗ; Quest-ри иммерсивлӑ курӑнӑм куҫать.
- **Питӗ пысӑк панорамӑсем**: сӑнӳкерчӗк чи нумаййи 8192x4096 виҫепе курӑнать, ку телефонсен нумай GPU-сем йышӑнакан чи пысӑк текстура, ҫавӑнпа пысӑкрах панорамӑна ҫак виҫене пӗчӗклетеҫҫӗ.
- **Икӗ fisheye .dng**: халлӗхе тикӗс курӑнать.

### Тетел папкине хушасси

1. «Библиотека» вкладкине, унтан «Тетел папкисем» уҫӑр. Пӗрремӗш хут страница «Тетел папкисем халлӗхе ҫук» тет, «Тетел папкине хуш» кнопкипе; сылтӑмра ҫӳлти + кирек хӑҫан та ҫавнах тӑвать. Build 20-ран иккӗшӗ те мӗн хушас килнине ыйтаҫҫӗ: «Тетел папки (NAS, компьютер, медиа сервер)», «Plex Media Server» е «Tapo камери». Пӗрремӗшне суйлӑр.
2. «Тетел папкине хуш» страница малтан сирӗн тетелти серверсене шырать те вӗсене «Тетелте тупӑнчӗ» айӗнче кӑтартать, вӗсен тӗсӗпе (SMB, WebDAV, DLNA, Телефон, build 20-ран Plex тата Tapo). Шырав ултӑ ҫеккунта яхӑн тӑсӑлать; «Тепӗр хут шыра» ӑна ҫӗнӗрен пуҫлать. Вӑл Bonjour/mDNS тата чӑн SMB е WebDAV улшӑнӑвӗпе ҫирӗплетнӗ вырӑнти тетел сканӗпе усӑ курать, build 19-ран DLNA медиа серверӗсене SSDP шыравӗпе те шырать, build 20-ран GDM-па (Plex тупмалли мелпе) тата Tapo камерисем валли TP-Link тупмалли протоколпа та.
3. Сервер ҫине пусӑр: тӗсӗ, сервер, порт тата ҫул хӑйсем тулаҫҫӗ. Plex серверӗ е Tapo камери вара хӑйӗн тултарнӑ страницине уҫать.
4. Списокра ҫук-и? Формӑна алӑпа тултарӑр. Тӗсӗ: «SMB (Samba, Windows папки)», «WebDAV (Nextcloud, Synology тата ыттисем)», «DLNA медиа сервер (Jellyfin, NAS, ТВ-приставка)» е build 20-ран «Plex Media Server», вӑл [Plex Media Server, plex.tv-сӑр](#plex-media-server-without-plextv) страницине уҫать. Унтан «Ячӗ», «Сервер ячӗ е адресӗ» (ят е адрес; `smb://nas/photos`, `\\nas\photos` е `https://nas:5006/photos` пек тулли адрес ытти уйрӑмсене хӑй тултарать), порт яланхи мар пулсан «Порт (кирлӗ мар)», SMB валли «Пӗрлехи папка» е WebDAV валли «WebDAV адресӗн ҫулӗ», «Пуҫламӑш папка (кирлӗ мар)», «Усӑ куракан ячӗ» тата «Пароль», WebDAV валли «Хӳтӗленӗ ҫыхӑну (HTTPS)».
5. SMB: сервер тата усӑ куракан ячӗ ҫырнӑ хыҫҫӑн «Пӗрлехи папкӑна суйлӑр» серверӑн пӗрлехи папкисене кӑтартать.
6. DLNA: медиа серверӑн усӑ куракан ячӗ те, пароль те ҫук. Сервера, порта тата унӑн хатӗр ҫырса кӑтартӑвӗн «Ҫырса кӑтартни ҫулӗ» кӑтартӑр (minidlna валли `/rootDesc.xml`), е сервер уйрӑмне `http://192.168.1.10:8200/rootDesc.xml` пек тулли адреса лартӑр.
7. «Ҫыхӑнӑва тӗрӗсле» ҫине пусӑр. Вӑл «Ҫыхӑннӑ, пуҫламӑш папкӑра N элемент» тесе хуравлать е мӗншӗн ӑнӑҫсӑр пулнине калать. Унтан формӑн аялти пайӗнче «Упра» ҫине пусӑр.

Пушӑ парольлӗ усӑ куракан ячӗ ҫав тӗслӗхпех каять: Freebox Server хӑйӗн дискӗсем валли `freebox` ята парольсӗр ыйтать. Кайран тетел папкине улӑштарас е кӑларса пӑрахас тесен, «Тетел папкисем» страницӑра ун ҫумӗнчи кӑранташ ҫине пусӑр.

### Пӑхасси тата выляттарасси

1. Тетел папки ҫине пусӑр. Малтан папкӑсем, унтан сӑнӳкерчӗксемпе видеосем миниатюрӑсен сетки евӗр (кашни видеон пӗр кадрӗ те, хатӗрте кэшланӑ). 360° тесе палланисен 360° палли пур, build 19-ран Apple тӑвӑмлӑ сӑнӳкерчӗкӗсемпе видеовӗсен 3D палли пур. Ҫӗнетес тесен аялалла туртӑр.
2. Сӑнӳкерчӗк ҫине пусӑр: вӑл пӗтӗм экран ҫине уҫӑлать (икӗ пӳрне, икӗ хут пусни), унӑн 360° кнопки сфера пӑхавҫине уҫать.
3. Видео ҫине пусӑр: вӑл тӑван плеерта вылять (выля, пауза, куҫса ҫӳресси), 360° кнопкипе, ку кнопка 3D тата 360°/180° кнопкиллӗ 360° плеера уҫать, телефонра стереоскопи файлӗсем валли Spatial кнопки те пур.
4. Quest ҫинче 360° кнопки иммерсивлӑ курӑнӑма уҫать, build 19-ран «3D-ра пӑх» Apple тӑвӑмлӑ сӑнӳкерчӗкне 3D-ра уҫать.
5. ⋮ менюра 360° паллисӗр файлсем валли «360° евĕр пăх» пур, телефонра стереоскопи мар видеосем валли «Spatial 2.5D».

360°, 3D тата VR180 файлӑн GPano е сферӑллӑ метаданнӑйӗсенчен паллӑ пулать, вӗсене диапазон ыйтӑвӗсемпе вулаҫҫӗ, VR180 файл ятӗнчен те паллӑ. Build 16-ран чӗрӗ Insta360 файлӗсене те палласа илеҫҫӗ (.insp сӑнӳкерчӗкне ятӗнчен е камерӑн калибровка блокӗнчен, .insv видеона ятӗнчен тата кадрӗнчен) тата ҫыхӑнтараҫҫӗ.

### Тетел папкин файлӗсене Immich-а ярса парасси

Build 15-ран, сервера ҫыхӑннӑ чухне:

1. Тетел папкин папкинче сӑнӳкерчӗк е видео ҫине вӑрахлӑн пусӑр, е сылтӑмра ҫӳлте «Суйла» ҫине пусӑр.
2. Кирлисене паллӑ тӑвӑр, е «Ку папкӑри мӗнпур сӑнӳкерчӗке тата видеона суйла» пунктпа усӑ курӑр.
3. «Immich-а тиесе яр» ҫине пусӑр. Файлсем тетел папкинчен сирӗн сервер ҫине пӗрерӗн каяҫҫӗ, кашни плитка ҫинче мӗн чухлӗ кайни курӑнать, аялта «12 ӑшӗнчен 3 ярса парать» тесе ҫырнӑ йӗрке Cancel (Пӑрахӑҫла) кнопкипе. Ярса панӑ вӑхӑтра приложение уҫӑ тытӑр.
4. Вӗҫӗнче приложени миҫе файл ярса панине тата миҫе файл серверта унччен те пулнине калать: сервер хӑйӗн копине упрать, унра пур файлсене тепӗр хут хӑвармасть. Маларах ярса панӑ файлсен палли пур («Маларах Immich-а ярса панӑ»), тепӗр хут вӗсене сиксе иртеҫҫӗ.

Тетел папкин уҫӑ сӑнӳкерчӗкӗн е видеовӗн менюнче те ҫав пункт пур. Сервер ҫук чухне страница «Тиесе ярас тесен Immich серверӗпе ҫыхӑнӑр» тет. Хатӗрӗн сӑнӳкерчӗкӗсемпе видеовӗсене те «Библиотека» вкладкинчен ҫавӑн пекех яраҫҫӗ: On this device, альбом, суйласси, «Immich-а тиесе яр», сыхлӑх копийӗн суйлавне кӗмен альбомсенчисене те; ярса панӑ хыҫҫӑн вӗсене сыхлӑх копийӗ тунӑ тесе шутлаҫҫӗ.

### Куҫнӑ тетел папки

Build 19-ран DLNA тетел папки тата телефон папки (пӑхӑр [Ку телефона тетелте пайласси](#share-this-phone-on-the-network)) вӗсен серверӗ пӗлтерекен идентификатора упраҫҫӗ. Вӗсенчен пӗри хӑйӗн адресӗнче хуравлама пӑрахсан (роутер ҫӗнӗ адрес панӑ, сервер урӑх портра ҫӗнӗрен хута кайнӑ), унӑн папка страници «(ячӗ) тетелте шыратпӑр» кӑтартать те тетел папкине вӑл халӗ хуравлакан вырӑна куҫарать: парольсӗр DLNA серверӗшӗн тӳрех, усӑ куракан ячӗпе тата парольпе тетел папкишӗн ҫирӗплетнӗ хыҫҫӑн, «Ҫӗнӗ адреспа усӑ курас-и?» ыйтупа, икӗ адреса та кӑтартса, мӗншӗн тесен вӗсене ҫӗнӗ адреса ярса парӗҫ.

Build 20-ран тетелӗн урӑх адресӗнче каллех тупнӑ Plex серверӗ те тӳрех куҫать: токена ярса паличчен унӑн сертификачӗ вӑл ҫав сервер пулнине ҫирӗплетет. Tapo камерине хӑйӗн страницинчен MAC адресӗпе шыраҫҫӗ, пӑхӑр: [Tapo камерисем](#tapo-cameras-live-view-and-the-recordings-of-the-memory-card).

### Чикӗсем

- **SMB**: SMB 2 тата 3 кӑна, SMB 1 ҫук.
- **WebDAV**: Basic аутентификаци кӑна (Digest халлӗхе ӗҫлемест); хӑй алӑ пуснӑ HTTPS сертификатне хатӗр ҫине лартмалла.
- **Серверсене тупасси**: тетел сканӗ тата DLNA, Plex тата Tapo шыравӗсем вырӑнти /24 тетеле кӑна пӑхаҫҫӗ, iOS ҫинче вырӑнти тетел ирӗкӗ кирлӗ. iPhone тата iPad ҫинче DLNA шыравӗ, Apple приложение multicast ирӗкне (entitlement) париччен, unicast ыйтӑвӗсене кӑна ярать, хӑш-пӗр серверсем вӗсене хуравламаҫҫӗ (Linux ҫинчи minidlna): ҫавсене ҫырса кӑтартӑвӗн адресӗпе хушӑр.
- **DLNA**: файлӑн улӑштарнӑ копине кӑна паракан сервер ҫав копие парать; папкӑра чи нумаййи 20 000 элемент.
- **Миниатюрӑсем**: сӑнӳкерчӗк миниатюрисем пӗтӗм файла декодлаҫҫӗ, 30 MB-ран пысӑкрах сӑнӳкерчӗксен миниатюри ҫук.
- **Плеерсем**: тикӗс плеерта сасӑ йӗрне суйлама халлӗхе май ҫук. Телефонра папкӑри пӗр файлтан теприне шӑвӑнтарса куҫма халлӗхе май ҫук (Quest иммерсивлӑ курӑнӑмӗнче папкӑри 360° файлсем валли малтанхипе малалли пур). Тетел файлӗ ҫинче суйланӑ 3D е 180° астуса юлмасть.
- **Тиесе ярасси**: приложени уҫӑ чухне кӑна ӗҫлет, серверта пур файла сервер ӑна дубликат тесе пӗлтериччен пӗтӗмпех ярса параҫҫӗ.

## Plex Media Server, plex.tv-сӑр

Сирӗн видеосем Plex-ра, Plex вара сирӗн 360° сӑнӳкерчӗксемпе видеосене тикӗс кӑтартать, унӑн форумӗнчи ыйтусем ҫырса кӑтартнӑ пек (пӗри 2017 ҫултанпа уҫӑ). Ҫав библиотекӑна шлемра, телевизорта тата килтен тулашра та курас килет. Immich приложенийӗ сирӗн Immich серверне кӑна вулать, build 19-ӑн DLNA тӗсӗ Plex-ӑн DLNA енне килте кӑна ҫитет.

Build 20-ран Immuch360 сирӗн Plex Media Server-па plex.tv-сӑр тӳрех ҫыхӑнать: вӑл сервера тетелте тупать, эсир пӗрре токен лартатӑр, приложени сирӗн библиотекӑсен оригинал файлӗсене тӳрех вулать, приложенин кашни пӑхавҫинче (360°, 3D, VR180, Spatial 2.5D, Quest-ӑн иммерсивлӑ курӑнӑмӗ, телевизор пульчӗ), килте тата, сирӗн порт куҫарӑвӗ урлӑ, килтен тулашра. Нимӗн те копиленмест, эсир суйланӑ файлсене Immich-а ярса пама пулать.

### Plex серверне хушасси

1. «Библиотека» вкладкине, унтан «Тетел папкисем», унтан + тата «Plex Media Server» уҫӑр. Тетел папкин формин «Plex Media Server» тӗсӗ тата «Тетелте тупӑнчӗ» айӗнчи Plex паллиллӗ сервер ҫав страницӑнах уҫаҫҫӗ.
2. «Plex серверне хуш» страница сирӗн тетелти Plex серверӗсене шырать («Сирӗн тетелте Plex серверӗсене шыратпӑр») тата вӗсене «Тетелте тупӑнчӗ» айӗнче кӑтартать. Хӑвӑрӑн сервер ҫине пусӑр: карточка унӑн ятне, Plex версине тата кӗске идентификаторне кӑтартать.
3. Списокра ҫук-и? Унӑн «Сервер адресӗ» ҫырӑр, сӑмахран `192.168.1.20`, `192.168.1.20:32400` е `https://...plex.direct:32400`, унтан «Шыра» ҫине пусӑр. Приложени серверӑн сертификатне вулать, урӑх нимӗн те ямасть.
4. Токена компьютерта илӗр: Plex-а веб-браузерта уҫӑр та кӗрӗр, библиотекӑри кирек хӑш сӑнӳкерчӗке е видеона уҫӑр, унтан «...», «Get Info», «View XML». `X-Plex-Token=...` сӑмахпа вӗҫленекен адреслӑ ҫӗнӗ вкладка уҫӑлать. Ҫав адреса пӗтӗмпех копилӗр.
5. Ӑна «Ҫитмелли токен» ӑшне лартӑр, е телефон ҫине ярӑр та «Буферран лартӑр» ҫине пусӑр: приложени унран сервера тата токена илет. `X-Plex-Token=` хыҫҫӑнхи текст кӑна та ӗҫлет. Страницӑри «Ӑна епле илмелле» ҫавнах калать; сервер администраторӗсем серверӑн `Preferences.xml` файлӗнчи `PlexOnlineToken` пахалӑхӗпе те усӑ курма пултараҫҫӗ, унӑн вӑхӑчӗ иртмест. Телевизорта OK клавиатура диалогне уҫать: токена унта ҫырӑр (унта ытларах чухне 20 паллӑ).
6. «Ҫыхӑнӑва тӗрӗсле» ҫине пусӑр. Вӑл «Ҫыхӑннӑ: N библиотека» тесе хуравлать, е мӗн йӑнӑш пулнине калать, сӑмахран «Plex серверӗ ку токена йышӑнмарӗ.»
7. Унтан «Килтен тулашран ҫитни» сервер мӗн каланине кӑтартать: «Сервер (адрес):(порт) адреспа ҫитме пулать тесе пӗлтерет.» е «Сервер хӑйӗн килтен тулашри адресне пӗлтермерӗ.» Сервера килтен тулашра усӑ курас тесен, хӑвӑрӑн уҫӑ адреса е DynDNS ятне «Килтен тулашри адрес (IP е ят)» ӑшне, Plex-ра куҫарнӑ порта (Ӗнерленӳсем, Аякран ҫитни) «Килтен тулашри порт» ӑшне ҫырӑр. Эсир ҫырни яланах сервер каланинчен малта тӑрать.
8. «Ячӗ» вӑл серверӑн ячӗ, эсир ӑна улӑштармасан, «Пуҫламӑш папка (кирлӗ мар)» пӗр библиотекӑна тӳрех уҫма пултарать. Save (Упра) ҫине пусӑр. Сервер тетел папкисемпе пӗрле `plex://` тата унӑн адресӗ евӗр курӑнать.

### Plex библиотекисене пӑхасси

1. «Тетел папкисем» ӑшӗнче сервер ҫине пусӑр. Пӗрремӗш шайра приложени кӑтартакан библиотекӑсем: сӑнӳкерчӗксем, фильмсем тата ытти видеосем, сериалсем. Музыкӑна кӑтартмаҫҫӗ.
2. Библиотека айӗнче унӑн папкисем, серверӑн дискӗнчи пекех (Plex-ӑн «папкӑсем тӑрӑх» курӑнӑмӗ), унтан сӑнӳкерчӗксемпе видеосем хӑйсен файл ячӗсемпе, Plex тунӑ миниатюрӑсемпе. Папкӑсем тӑрӑх курӑнӑмӗ хуравламан сӑнӳкерчӗк библиотеки вара хӑйӗн альбомӗсене кӑтартать.
3. 360° тата 3D файлсене хӑйсене вуласа палласа илеҫҫӗ, кирек хӑш тетел папкинчи пекех: 360° сӑнӳкерчӗксем 360° палли илеҫҫӗ, Apple тӑвӑмлӑ сӑнӳкерчӗкӗсем 3D палли.
4. Сӑнӳкерчӗке е видеона кирек хӑш тетел папкинчи пекех уҫӑр: 360°, 3D, 360°/180°, телефонра Spatial 2.5D, Quest-ра иммерсивлӑ курӑнӑм, телевизорта пульт. Видеона оригинал файл евӗр вулаҫҫӗ, приложенин вырӑнти кӗперӗ урлӑ байт диапазонӗсемпе, ҫавӑнпа куҫса ҫӳресси ӗҫлет, унӑн 360° тата 3D метаданнӑйӗсем плеерсем патне пӑсӑлмасӑр ҫитеҫҫӗ.
5. Файлсене суйлӑр та «Immich-а тиесе яр» ҫине пусӑр, вӗсене хӑвӑрӑн сервер ҫине кирек хӑш тетел папкинчи пекех ярса памашкӑн (пӑхӑр: [Тетел папкин файлӗсене Immich-а ярса парасси](#send-files-of-a-share-to-immich)).

### Килтен тулашра

Сервера уҫнӑ кашни хутӗнче приложени малтан килти адреса, 400 ms иртсен килтен тулашри адреса тӗрӗслет. Сирӗн серверпа малтан хуравлаканнипе усӑ кураҫҫӗ; вӑл килтен тулашри адрес пулсан, папка страници «Килтен тулашри адреспа ҫыхӑннӑ» ҫырулӑ глобус значокне кӑтартать.

Ҫавӑн валли Plex-ра аякран ҫитессине ҫутмалла (Ӗнерленӳсем, Аякран ҫитни), сирӗн роутер куҫаракан портпа: plex.tv-сӑр приложени Plex-ӑн релейӗпе усӑ кураймасть, ҫавӑнпа порт куҫарӑвӗсӗр сервер килте кӑна уҫӑлать, килтен тулашра страница «Сирӗн Plex серверне килти тетелтен тулашра ҫитме ҫук. Plex-ра порта куҫарнипе аякран ҫитессине ҫутӑр (Ӗнерленӳсем, Аякран ҫитни) е унӑн уҫӑ адресне ҫырӑр.» тет.

Сервер пӗлтерекен адреса килти кашни ҫыхӑнура ҫӗнӗрен вӗренеҫҫӗ. Вӑл тулашран хуравламасан (адресне улӑштаракан роутер, пӗрин хыҫҫӑн тепри тӑракан икӗ роутер), хӑвӑрӑн адреса сервер страницинче ҫырӑр. Токен ӗҫлеме пӑрахсан (сӑмахран, эсир ӑна копиленӗ браузер сеансӗнчен тухрӑр), папка страници ҫавна калать те «Ҫӗнӗ токен лартӑр» сӗнет, вӑл сервер страницине токен уйрӑмӗ ҫинче уҫать.

### Plex-па тата DLNA тӗсӗпе танлаштарни

## Ку телефона тетелте пайласси

Сирӗн сӑнӳкерчӗксемпе видеосем телефонра, эсир вӗсене шлемра пӑхас тетӗр, компьютерсӗр, NAS-сӑр тата Immich серверӗсӗр. Build 19-ран телефон, Android е iPhone, хӑйӗн сӑнӳкерчӗкӗсемпе видеовӗсене Wi-Fi урлӑ парать, Meta Quest вӗсене вылять. Immich приложенийӗнче ҫакӑн пекки ҫук.

### Телефонра ҫутасси

1. «Библиотека» вкладкине, унтан «Тетел папкисем» уҫӑр. Пӗрремӗш плитка «Ку телефона тетелте пайла» (унта «Сӳнтернӗ» е адреспа «Ҫутнӑ» тесе ҫырнӑ).
2. Ун ҫине пусӑр, унтан «Сӑнӳкерчӗксемпе видеосене Wi-Fi урлӑ пайла» ҫутӑр. Ирӗк ҫук пулсан, приложени сӑнӳкерчӗксемпе видеосем валли ирӗк ыйтать, Android 13 тата ҫӗнӗрехсенче пӗлтерӳсем валли те.
3. Страница «Адрес» кӑтартать (`http://192.168.1.20:8360` пек: 8360 порт, е вӑл йышӑннӑ пулсан урӑх ирӗклӗ порт), телефона тетелте пӗлтерекен ят («Immuch360 on» тата телефон ячӗ), «Усӑ куракан ячӗ» (`phone` тата тӑватӑ цифра) тата «Пароль» (сакӑр палӑ), кашнинех копилемелли кнопкипе, унтан «N хатӗр ҫыхӑннӑ» (юлашки минутра усӑ курнӑ хатӗрсем) тата юлашки панӑ файл.

Усӑ куракан ячӗпе пароле пӗрре тӑваҫҫӗ те упраҫҫӗ, ҫавӑнпа шлем хӑй упранӑ тетел папкине хӑварать; «Ҫӗнӗ пароль» пароле улӑштарать. Шлем ҫинче ку плитка курӑнмасть.

### Шлемра уҫасси

1. Шлемра «Библиотека», «Тетел папкисем», унтан + уҫӑр.
2. «Тетелте тупӑнчӗ» айӗнче телефон ҫине пусӑр: усӑ куракан ячӗ хӑй тулать.
3. Пароле пӗрре ҫырӑр (пушӑ вырӑнсем тата пысӑк саспаллисем пӗлтерӗшлӗ мар), унтан «Упра».

Ҫакӑн хыҫҫӑн вӑл ытти пек WebDAV тетел папки: 360° палласа илни, чӗрӗ файлсем, иммерсивлӑ курӑнӑм, видеосенче куҫса ҫӳресси. Тетелти кирек хӑш WebDAV клиенчӗ те ӑна вулама пултарать. Телефон урӑх адрес илсен, шлем ӑна шырать те ҫӗнӗ адреспа усӑ куриччен ыйтать (пӑхӑр [Куҫнӑ тетел папки](#a-share-that-moved)).

Файлсем хӑйсен ячӗсене упраҫҫӗ. iPhone ҫинче live photo хӑйӗн хускалман ӳкерчӗкне парать, тӳрлетнӗ сӑнӳкерчӗк е видео тӳрлетнӗ версине, iCloud-ра кӑна упранаканнине кӑтартмаҫҫӗ.

## 360° камерӑсен чӗрӗ файлӗсем, камера приложенийӗсӗр

Insta360 камерӑсем хӑйсен объективӗсен икӗ fisheye ҫаврашкине ҫырса илеҫҫӗ, пӗр ӳкерчӗкре юнашар, икӗ йӗрпе е икӗ файлпа (.insp вӑл JPEG, .insv вӑл MP4), вӗсенчен 360° ӳкерчӗк тумалли официаллӑ ҫул Insta360 приложенийӗ е Studio. Build 16-ран Immuch360 ҫак файлсене хӑй ҫыхӑнтарать, телефонра, планшетра е шлемра, серверта нимӗн те лартмасӑр:

- **Insta360 X4, X4 Air, X5 тата X6 .insv видеовӗсем, кашни объектив валли пӗр тӑваткал йӗр** (build 18): пӗр вӑхӑтрах икӗ декодер, кашни объектив валли пӗрре, тата вӗсене сфера ҫине ҫыхӑнтаракан GPU компоновщикӗ.

### Чӗрӗ файла пӑхасси

1. Чӗрӗ файлсене приложени вулакан ҫӗре хурӑр: хатӗрӗн хӑйӗн галерейине (камера картинчен копиленӗ), сирӗн Immich серверне (вӑл .insp тата .insv йышӑнать, .360 тата .osv йышӑнмасть), SMB е WebDAV тетел папкине, build 19-ран телефон папкине тата ҫак файлсене кӑтартакан DLNA серверӗсене (халлӗхе тӗрӗслемен).

Тепри ҫук пулсан, приложени «Ку ҫырӑва икӗ файла пайланнӑ, кашни объектившӑн пӗрре, анчах (ячӗ) ун ҫумӗнче тупӑнман» тет те икӗ файла пӗрле тытма е видеона камера приложенийӗнчен экспортлама сӗнет.
3. Файла уҫӑр та 360° ҫине пусӑр. Чӗрӗ файлсен 360° кнопки, чӗрӗ сӑнӳкерчӗксен 360° палли пур. Build 18-ран серверти чӗрӗ Insta360 файлӗсем те 360° списокӗнче, вӗсене ячӗсенчен тупаҫҫӗ.

### Хатӗр икӗ объектива та выляттараймасан

Икӗ объективлӑ видеона выляттариччен приложени хатӗртен ҫав виҫеллӗ тата ҫав хӑвӑртлӑхлӑ икӗ декодера ӗҫлеттерме пултарать-и тесе ыйтать, хурав «ҫук» пулсан телефон «Ку чӗрӗ видеона пӗр вӑхӑтрах икӗ (виҫе) видео декодер кирлӗ: ку хатӗрте вӑл тикӗс выляймасть пулӗ» тесе асӑрхаттарать. ## 3D тата VR180 сӑнӳкерчӗксемпе видеосем

Immich приложенийӗнче стереоскопи 360° сӑнӳкерчӗкӗ е видеовӗ икӗ куҫа та пӗр вӑхӑтрах кӑтартать, ӳкерчӗк икӗ хут курӑнать, малти ҫурине кӑна витекен VR180 файлӗ вара пӗтӗм сфера тавра тӑсӑлать.

Immuch360 3D вырнаҫӑвӗсене, ҫӳлте тата аялта е юнашар, файлтан (видеон st3d блокӗ) палласа илет е кадр формипе шухӑшласа кӑларать, кашни пӑхавҫӑн вӗсене улӑштармалли 3D кнопки пур. Телефон сулахай куҫа кӑтартать; Meta Quest кашни куҫа хӑйӗн ҫурине кӑтартать, чӑн 3D-ра. VR180 файлӗсене ҫур сфера ҫине ӳкереҫҫӗ, тӑсӑлнӑ ӳкерчӗк вырӑнне каялла енӗ хура. Вӗсене файлтан (сферӑллӑ чиксем е mesh, GPano касни) е ятри «vr180» е «180» тӑрӑх палласа илеҫҫӗ, кашни пӑхавҫӑн 360°/180° кнопки пур.

### Вырнаҫӑва е витӗме улӑштарасси

1. Сӑнӳкерчӗке е видеона сфера евӗр уҫӑр (360° кнопки).
2. 3D кнопки «Моно (3D мар)», «3D, ҫӳлте тата аялта» тата «3D, юнашар» хушшинче куҫать; унӑн ӑнлантарӑвӗ хальхи вырнаҫӑва калать.
3. 360°/180° кнопки «360°, тулли сфера» тата «180°, ҫур сфера (VR180)» хушшинче куҫать. Пайлӑ панорамӑсенче вӑл курӑнмасть.
4. Шлемра ҫав икӗ кнопка иммерсивлӑ курӑнӑмӑн информаци панелӗ ҫинче.

360°/180° суйлава хатӗр библиотека медиийӗ валли астуса юлать, тетел папкин файлӗ валли халлӗхе ҫук. 3D суйлава пӑхавҫӑ хупӑнсан астуса юлмасть: файл пӗлтерекен вырнаҫу е шухӑшласа кӑларни тепӗр хут каллех ӗҫлет (аялтарахри Spatial 2.5D плеерӗ хӑйӗннине астуса юлать).

Galaxy S24+ тата Quest 3 ҫинче чӑн 3D 360° тӗслӗх видеосемпе (VRTogether, Vuze, Kandao) тата 3D сӑнӳкерчӗкпе тӗрӗсленӗ; VR180 Android эмуляторӗпе Galaxy S24+ ҫинче синтетика медиапа. Ытти камерӑсенчен килнӗ пӗлтерӳсене хапӑл кӗтетпӗр.

## Тикӗс экранри тарӑнлӑх: Spatial 2.5D (экспериментлӑ)

Стереоскопи видео тикӗс экран ҫинче тарӑнлӑх илме пултарать. Видеон икӗ куҫӗ тарӑнлӑха парать, умри камера сирӗн пуҫ хыҫҫӑн сӑнать, приложени вара хушӑри курӑнӑма синтезлать, ҫавӑнпа экран сцена ҫине уҫӑлакан чӳрече пек пулать: пуҫа хускатӑр, ҫывӑхри япаласем фон тӗлӗшпе куҫаҫҫӗ. Телефонсемпе планшетсем кӑна.

### Усӑ курасси

1. Вӑл ҫутӑ-и, тӗрӗслӗр: Settings, Asset Viewer, Videos (Видеосем), «Spatial 2.5D (экспериментлӑ)». Стандартла вӑл ҫутӑ; сӳнтерсен Spatial кнопки пур ҫӗрте те ҫухалать.
2. Видеона уҫӑр. Ӗнерлев ҫутӑ чухне ҫӳлти панель кашни видео ҫинче Spatial кнопкине (ҫаврӑнакан 3D значок) кӑтартать; тетел папкин папкинче ӑна стереоскопи файлӗсем кӑна илеҫҫӗ, ыттисен ⋮ менюра Spatial 2.5D пур.
3. Ун ҫине пусӑр. Умри камера ирӗкне пӗрремӗш хут ыйтаҫҫӗ; камерӑпа кнопка ҫине пуссан ҫеҫ усӑ кураҫҫӗ.
4. Сылтӑмра ҫӳлте: видеон икӗ е ытларах сасӑ йӗрӗ пулсан «Сасӑ йӗрӗ», хальхи вырнаҫу (список валли ун ҫине пусӑр: «Авто», «Стереоскопи мар», «Юнашар», «Ҫӳлте тата аялта», юлашки иккӗшӗ куҫсене улӑштарнӑ вариантпа та), 360° видеора 360°/180°, тата «Каллех варрине лартас», вӑл пуҫӑн хальхи вырӑнне центр вырӑнне йышӑнать.
5. Аялта: выля, вӑхӑт шкали, унтан пуҫа сӑнанӑ чухне «Пуҫ туйӑмлӑхӗ», тата L-ран R-а пӑхмалли вырӑн шуҫӑмӗ, вӑл пӑхмалли вырӑна алӑпа куҫарать; пуҫа сӑнасси сӳнтернӗ е сирӗн сӑна ҫухатнӑ чухне курӑнать.
6. Хӗреслӗ кнопкӑпа е системӑн «каялла» кнопкипе хупӑр.

Settings, Advanced (Анлӑ ӗнерленӳсем), Troubleshooting (Йӑнӑшсене шырасси) ҫутӑ чухне плеер сулахайра ҫӳлте хушма сий кӑтартать (рендер тата диспаритет хӑвӑртлӑхӗ, пахалӑх шайӗ, пӑхмалли вырӑн, сӑнав тӑрӑмӗ), пӑхмалли вырӑн шуҫӑмне яланах кӑтартать, тата «Disparity map» (Диспаритет карти) паллӑ тумалли ҫӗр хушать, вӑл ӳкерчӗк вырӑнне шутласа кӑларнӑ тарӑнлӑха кӑтартать.

### Форматсем, вӑрттӑнлӑх тата чикӗсем

- **Форматсем**: юнашар тата ҫӳлте тата аялта, куҫсене улӑштарнӑ вариантпа та, тулли е ҫур сарлакӑш, тикӗс, 360° тата VR180. Вырнаҫӑва файлтан вулаҫҫӗ, унсӑрӑн кадр формипе е файл ячӗпе шухӑшласа кӑлараҫҫӗ (sbs, ou, tb тата ҫавӑн пеккисем; ҫур сарлакӑшлӑ файла ячӗпе кӑна палласа илеҫҫӗ), плеерта алӑпа та суйлама пулать. Суйлава библиотекӑри видео валли астуса юлаҫҫӗ, тетел папкин файлӗ валли мар.
- **Камера**: ӳкерчӗксене хатӗр ҫинче кӑна тирпейлеҫҫӗ, нихӑҫан та упрамаҫҫӗ, ниҫта та ямаҫҫӗ. Quest build-ӗнче камера ирӗкӗ пачах ҫук (шлемра приложени усӑ курма пултаракан камера ҫук), Spatial плеерне унта сӗнмеҫҫӗ: унӑн кнопки тата ӗнерлевӗ шлем ҫинче пытарӑннӑ.
- **Чикӗсем**: экспериментлӑ, телефонсемпе планшетсем кӑна (Meta Quest ҫинче мар), OpenGL ES 3.0 е Metal кирлӗ. Тарӑнлӑх вӑл шутласа кӑларни ҫеҫ. Горизонтлӑ тытсан тата сӑн лайӑх ҫутатнӑ чухне чи лайӑх ӗҫлет. Galaxy S24+ ҫинче тӗрӗсленӗ; iPhone ҫинчи отзывсене хапӑл кӗтетпӗр.
- **Запас вариант**: мӗн те пулин ӑнӑҫсӑр пулсан (камера ҫук, хатӗр ку функцие тытса тӑмасть, вырнаҫӑва вулама ҫук), эсир каллех ахаль плеерта.

## Apple-ӑн тӑвӑмлӑ сӑнӳкерчӗкӗсемпе видеовӗсем

iPhone тӑвӑмлӑ сӑнӳкерчӗксемпе видеосем ӳкерет, Immich серверӗ вӗсем ҫинчен нимӗн те каламасть: Immich приложенийӗнче вӗсем тикӗс сӑнӳкерчӗк е видео. Build 19-ран Immuch360 вӗсене файлсене вуласа палласа илет, тӑвӑмлӑ сӑнӳкерчӗке Meta Quest шлемӗ ҫинче 3D-ра кӑтартать. Ку ҫӳлерехри Spatial 2.5D плеер мар, вӑл юнашар тата ҫӳлте тата аялта видеосем валли.

- **Тӑвӑмлӑ сӑнӳкерчӗксем** вӗсем HEIC файлӗсем (`.heic`, `.heif`, `.hif`), вӗсенче икӗ ӳкерчӗк, кашни куҫ валли пӗрре, стерео мӑшӑр евӗр пӗрлештернӗ. Приложени файлӑн пуҫламӑшне вулать (хатӗрте, серверӑн оригиналне диапазон ыйтӑвӗпе, е тетел папкин файлне) тата хуравне телефонра астуса юлать, ҫавӑнпа сӑнӳкерчӗке пӗрре кӑна вулаҫҫӗ.
- **Тӑвӑмлӑ видеосене** (MV-HEVC) видео йӗрӗнчен палласа илеҫҫӗ: иккӗмӗш сий тата икӗ куҫа та пӗлтернӗ.

### Тӑвӑмлӑ сӑнӳкерчӗке шлемра 3D-ра пӑхасси

1. Шлемра тӑвӑмлӑ сӑнӳкерчӗке пӑхавҫӑра уҫӑр, е тетел папкин папкинче, унта тӑвӑмлӑ сӑнӳкерчӗксемпе видеосен 3D палли пур.
2. Ҫӳлти панельте «3D-ра пӑх» ҫине пусӑр (тетел папкин сӑнӳкерчӗк страницинче те пур).
3. Иммерсивлӑ курӑнӑм уҫӑлать, сӑнӳкерчӗк сирӗнтен 2 м малта тикӗс рама ҫинче, кашни куҫ хӑйӗн ӳкерчӗкне илет, сарлакӑшне файл камерӑн курӑм анлӑшне пӗлтерсен ҫавӑнтан илеҫҫӗ (унсӑрӑн 48°). Файлта ҫырнӑ диспаритет тӳрлетӗвне усӑ кураҫҫӗ.
4. Джойстика ҫӳлелле е аялалла туртни ӑна пысӑклатать е пӗчӗклетет (6° утӑмсемпе, 30°-ран 90° таран); сылтӑм джойстика сулахая е сылтӑма туртни ӑна каллех сирӗн умӑра тавӑрать.
5. Информаци панелӗн 3D кнопки 3D тата «2D (сулахай куҫ)» хушшинче куҫать. «Ҫавӑр» тата 360°/180° кнопкисем пытарӑннӑ.
6. Каялла таврӑнма B е Y пусӑр.

Тӑвӑмлӑ сӑнӳкерчӗкрен малтанхи тата малалли халлӗхе ҫук («Тӑвӑмлӑ сӑнӳкерчӗксем валли умӗнхи тата тепри халӗ ҫук»). Шлем иккӗмӗш куҫа декодлаймасан, сӑнӳкерчӗк 2D-ра курӑнать, «Иккӗмӗш куҫа декодлама май килмерӗ: 2D кӑтартать» ҫырупа. 3D курӑнӑм оригинал файла кӑтартать, Immich-ра тунӑ тӳрлетӳсемсӗр.

### Ытти ҫӗрте

- **Сӑнӳкерчӗксем**: телефонсем, планшетсем тата шлем чӳречи сулахай куҫа кӑтартаҫҫӗ, малтанхи пекех, техника тӗплӗхӗсенче ҫӗнӗ йӗрке хушӑнать, сӑмахран «Apple тӑвӑмлӑ сӑнӳкерчӗкӗ, 3072 x 3072 икӗ курӑнӑм», файл пӗлтерсен курӑм анлӑшӗпе. Серверти сӑнӳкерчӗксен вӑхӑт шкалинче палли ҫук: приложени ҫакна сӑнӳкерчӗке уҫсан пӗлет.
- **Видеосем**: вӗсем приложенин кашни плеерӗнче хӑйсен тӗп сийне, пӗр куҫа, выляҫҫӗ. Android-ра иккӗмӗш курӑнӑма декодламалли уҫӑ май ҫук; MV-HEVC валли хӑйӗн декодерӗ пур хатӗр (хӑш-пӗр Qualcomm чипӗсем ҫинче) видеона ҫавӑнта парӗ, ку халлӗхе тӗрӗслемен. Сеансра ҫакнашкал видеона пӗрремӗш хут выляттарсан «Тӑвӑмлӑ видео: ку хатӗр пӗр куҫа вылять» тесе пӗлтереҫҫӗ (тетел папкин видеовӗн вара 3D палли пур), унӑн техника тӗплӗхӗсенче «Apple тӑвӑмлӑ видеоӗ (MV-HEVC), 2D кӑтартать» тесе ҫырнӑ, файл ҫырса хунӑ куҫпа, базӑпа тата курӑм анлӑшӗпе.
- **Декодерсем**: Settings, Advanced, «Ку хатӗрӗн видеодекодерӗсем» ӑшӗнче MV-HEVC пункт пур, вӑл ун валли хатӗр декодерне кӑтартать е ҫук тесе калать.

### Хатӗр ҫинче халлӗхе тӗрӗслемен

Палласа илессине Apple-ӑн хӑйӗн ӳкерчӗк библиотеки ҫырнӑ тӗслӗх тӑвӑмлӑ сӑнӳкерчӗкпе тата синтетика файлӗсемпе тӗрӗсленӗ, 3D композицине модуль тесчӗсемпе. Ку таблицӑри кнопкисем тата вӑхӑт йӗрри информаци панелӗнни. Контроллерсемпе вӗсем те ӗҫлеҫҫӗ: вӗсем ҫине пайӑрпа тӗллӗр те курока пусӑр.

- **Курӑнӑма ҫавӑрасси**: пуҫа ҫавӑрмасӑр каялла пӑхма. Сылтӑм джойстика тытса тӑрсан курӑнӑм ҫаврӑнма пӑрахмасть, пӗр йӗркеллӗ хушма сий кӗтеса кӑтартать.
- **Пӗр йӗркеллӗ хушма сий**: build 16-ран джойстикпа куҫни, сӑнӳкерчӗке ҫавӑрни е малтанхи тата малалли медиа пӗр йӗркеллӗ хушма сий кӑтартать (вӑхӑта, кӗтеса е медиа ятне), информаци панелӗ пытарӑнса юлать. Build 17 умӗн кирек хӑш джойстик те малтанхи е малалли медиана куҫаратчӗ.

### Информаци панелӗ, малтанхи тата малалли

Видеон информаци панелӗнче вӑхӑт йӗрри (вырӑн, тӑршшӗ, миҫе буферланӑ) икӗ 10 ҫеккунтлӑ сикмелли кнопка хушшинче; унӑн айӗнче «Малтанхи», «Выля» е «Пауза» тата «Малалли», унтан «Ҫавӑр», 3D, 360°/180° тата «Каялла». Сӑнӳкерчӗкӗн ҫав йӗркесемех, вӑхӑт йӗррисӗр тата «Выля» кнопкисӗр. 3D вырнаҫӑвӗ тата 360°/180° суйлавӗ панель кнопкисем ҫинче кӑна.

Малтанхи тата малалли эсир килнӗ вырӑнӑн 360° медиийӗ тӑрӑх куҫаҫҫӗ, иммерсивлӑ курӑнӑмран тухмасӑр: вӑхӑт шкали, 360° списокӗ (фильтрланӑ пек), альбом, тетел папкин папки е шлемӑн хӑйӗн медиийӗ (On this device). Тикӗс сӑнӳкерчӗксемпе видеосене сиксе иртеҫҫӗ. Вӑхӑт шкалинчен, альбомран е 360° списокӗнчен приложение таврӑнсан, вӑл эсир пӑхнӑ медиа ҫине лекет (тетел папкин страници эсир уҫнӑ файл ҫинче юлать), иммерсивлӑ курӑнӑма уҫнӑ видео вара чарӑннӑ вырӑнтан малалла вылять.

Build 17-ран сылтӑм джойстик курӑнӑма ҫавӑрать, шлем приложенийӗсен нумайӑшӗнчи пекех: пӗрре туртни 30° ҫавӑрать, тытса тӑрсан ҫаврӑнма пӑрахмасть, ҫавӑнпа сирӗн хыҫри япала пуҫа е пукана ҫавӑрмасӑрах умӑра килет; малтанхипе малалли сулахай джойстик ҫинче.

Build 16-ран, шлемри пӗр усӑ куракан отзывӗ хыҫҫӑн, джойстикпа куҫса ҫӳресси, ҫавӑрасси е малтанхи/малалли пӗр йӗркеллӗ хушма сий кӑтартать (вӑхӑт, кӗтес е медиа ячӗ), вӑл информаци панельне кӑларас вырӑнне 1,5 ҫеккунтран ҫухалать; панель халӗ те A, X, тытмалли кнопка е меню кнопки пуссан тухать. Ҫав build контроллерсем ҫывӑрсан, вӑрансан е алӑсене сӑнас ӗҫе вырӑн парсан та панеле кӑтартассине ӗҫлеттерет, ҫак улшӑнусене журнала ҫырать, пӑхӑр [Журналсем](#logs).

«3D-ра пӑх» уҫнӑ Apple тӑвӑмлӑ сӑнӳкерчӗкне сфера ҫине вырнаҫтармаҫҫӗ: вӑл сирӗн умӑрта ишсе тӑрать, пӑхӑр [Apple-ӑн тӑвӑмлӑ сӑнӳкерчӗкӗсемпе видеовӗсем](#apple-spatial-photos-and-videos).

### Шлем мӗн кӑтартать

Сӑнӳкерчӗксем малтан малтанлӑха пӑхмаллине кӑтартаҫҫӗ, унтан оригинала, чи нумаййи 8192x4096 таран пӗчӗклетнӗскерне (приложенин чикки). Видеосем шлемра упранакан файла выляҫҫӗ, вӑл пур пулсан, тетел папкин файлне приложенин вырӑнти кӗперӗ урлӑ; унсӑрӑн вӗсем сирӗн серверӗнчен «Видео ҫӑлкуҫӗ» ӗнерлевӗ каланӑ пек поток евӗр килеҫҫӗ (build 15-ран; стандартла оригинал, оригинал поток евӗр килеймесен е шлем декодерӗсенчен иртсен серверӑн транскодланӑ версийӗ, пӑхӑр [Видео тӗплӗхӗсем тата декодерсем](#video-details-decoders-and-why-a-video-stutters)). Камерӑн чӗрӗ файлӗсем те кунта build 16-ран уҫӑлаҫҫӗ, вӗсене приложени ҫыхӑнтарать; чӗрӗ видео валли 3D тата 360°/180° кнопкисем пытарӑннӑ, мӗншӗн тесен вӑл пӗр тулли сфера.

3D вырнаҫӑвӗсем, ҫӳлте тата аялта тата юнашар, 360° тата VR180, 3D-ра курӑнаҫҫӗ, кашни куҫ кадрӑн хӑйӗн ҫурине илет. Вырнаҫу файлтан килет, файл ӑна пӗлтерсен (видеосем), унсӑрӑн ӑна формипе шухӑшласа кӑлараҫҫӗ (тӑваткал: ҫӳлте тата аялта, 4:1: юнашар); вӑл тӗрӗс мар пулсан, информаци панелӗн 3D кнопкипе усӑ курӑр.

Ку ӳкерчӗксене приложени французла чухне, build 14 умӗн илнӗ. Панельте халӗ икӗ 10 ҫеккунтлӑ сикмелли кнопка хушшинче вӑхӑт йӗрри, «Малтанхи» тата «Малалли», тата «Ҫавӑр» те пур.

### Ӳкерчӗк сирӗн енне пӑхмасан

Ӑна сылтӑм джойстикпа (е информаци панелӗн «Ҫавӑр» кнопкипе) унӑн варри сирӗн умӑрта пуличчен ҫавӑрӑр. Кӗтес «Ӳкерчӗке N градуса ҫавӑрнӑ» евӗр курӑнать, панель ҫинче е панель пытарӑннӑ чухне пӗр йӗркеллӗ хушма сийре: ҫак хисепе [issue](https://github.com/freeKC/Immuch360/issues) ҫине хӑвӑр камера моделӗпе пӗрле ҫырса хӑварӑр, вӑл стандартлӑ хаклӑх пултӑр. Пуҫламӑш ориентацие кашни камера валли халлӗхе ҫирӗплетмен.

### Иммерсивлӑ курӑнӑмӑн чикӗсем

- **Малтанхи тата малалли**: вӗсем вӑхӑт шкалинче чи нумаййи 400 медиа малалла, тетел папкин папкинче 50 файл пӑхаҫҫӗ, чи нумаййи 12 ҫеккунт; ун хыҫҫӑн панель малтанхи е малалли 360° медиа ҫук тет. Тетел папкин папкине файлӗн-файлӗн тӗрӗслеҫҫӗ, ҫавӑнпа нумай тикӗс файл хыҫҫӑн пӗрремӗш 360° файла тупма темиҫе ҫеккунт кирлӗ пулма пултарать. Тӑвӑмлӑ сӑнӳкерчӗкрен вӗсем халлӗхе ӗҫлемеҫҫӗ.
- **3D суйлавӗ**: 3D кнопкипе суйланӑ вырнаҫӑва пӑхавҫӑ хупӑнсан астуса юлмаҫҫӗ; 360°/180° суйлава библиотека медиийӗ валли астуса юлаҫҫӗ.
- **Куҫса ҫӳресси**: ҫӑлкуҫӗ байт диапазонӗн ыйтӑвӗсене хуравламан видеора куҫса ҫӳреме май ҫук; панель ҫакна калать.
- **Тикӗс видеосем**: тикӗс (360° мар) стереоскопи видео чӳречере икӗ куҫпа та курӑнса вылять; иммерсивлӑ 3D курӑнӑм 360° тата VR180 медиа валли.
- **Ытларах**: шлем декодлакан кодексем, лавкка, ирӗксем тата APK виҫи [Meta Quest 3](#meta-quest-3) пайӗнче.

## Телевизорта пӑхасси (Android TV тата Google TV)

360° сӑнӳкерчӗксемпе видеосене, хӑвӑрӑн альбомсене тата NAS е Plex серверӗнчи видеосене пысӑк экранра, диван ҫинчи ҫемье валли, телевизор пульчӗпе курас килет. Immich мобильлӗ приложенийӗ телевизор приложенийӗ мар: ӑна телевизор ҫине лартнӑ пӗр усӑ куракан вӑл пультпа мар, мышьпа ӗҫленине асӑрханӑ ([#1614 сӳтсе яву](https://github.com/immich-app/immich/discussions/1614)), Immich ушкӑнӗ официаллӑ телевизор приложенине тума шутламасть ([#13748 сӳтсе яву](https://github.com/immich-app/immich/discussions/13748)).

Build 20-ран ҫав Android приложенийӗ Android TV тата Google TV ҫинче ӗҫлет, пульт кӑна кӗртӳ хатӗрӗ: телефонсем тата телевизорсем валли пӗр APK, 360° тата 3D пӑхавҫисене стрелкӑсемпе ҫавӑраҫҫӗ, тетел папкисем, Plex тата Tapo камерисем телевизорта, Immich серверӗпе е унсӑр.

<a id="install-it-on-the-tv"></a>
### Телевизор ҫине лартасси

1. Google Play приложение телевизорсем валли сӗниччен (ку Google телевизор релизне тӗрӗслессине кӗтет), [Releases](https://github.com/freeKC/Immuch360/releases) страницӑран универсаллӑ `Immuch360-v<version>-release.apk` илӗр.
2. Телевизорта аталантаракан параметрӗсене тата USB отладкӑна ҫутӑр (Google TV ҫинче: Ӗнерленӳсем, Система, Хатӗр ҫинчен, «Android TV OS build» ҫичӗ хут суйлӑр, унтан Ӗнерленӳсем, Система, Аталантаракан параметрӗсем; ячӗсем телевизор тӑрӑх улшӑнаҫҫӗ).
3. Ҫав тетелти компьютертан, adb-па (Android SDK Platform Tools): `adb connect <address of the TV>`, телевизорти ыйтӑва йышӑнӑр, унтан `adb install -r Immuch360-v<version>-release.apk`.
4. Приложени телевизор приложенийӗсем хушшинче хӑйӗн баннерӗпе курӑнать. Тепӗр релиза ҫапла майпах лартӑр: `-r` кӗрӗве тата ӗнерленӳсене упрать.

### Пӗрремӗш хут хута ярасси

1. Телефонри пекех кӗрӗр: стрелкӑсем рамкӑна пӗр уйрӑмран тепӗр уйрӑма куҫараҫҫӗ, уйрӑм ҫинчи OK («Ҫырма OK пусӑр») сервер адресӗ, электронлӑ почта тата пароль валли телевизор клавиатурине диалогра уҫать.
2. Е «Серверсӑр усӑ кур» суйлӑр. Телевизорӑн хӑйӗн сӑнӳкерчӗкӗсем ҫук, ҫавӑнпа «Сӑнӳкерчӗксем» вкладки «Ку телевизорта хӑйӗн сӑнӳкерчӗкӗсем е видеосем ҫук: Библиотекӑран тетел папкине уҫӑр.» тет, «Тетел папкисем» кнопкипе. Унта тетел папкине, Plex серверне е камерӑна телефонри пекех хушӑр (пӑхӑр: [Тетел папкисем](#network-shares-a-nas-a-computer-or-a-media-server)).

### Пультпа куҫса ҫӳресси

- Стрелкӑсем рамкӑна куҫараҫҫӗ, OK рамка ҫинчине уҫать, Каялла каялла каять. Вкладкӑран Каялла айккинчи менюна, унтан «Сӑнӳкерчӗксем» патне, унтан приложенирен тухать.
- Канал ҫӳлелле тата аялалла пӗрер страница куҫараҫҫӗ.
- Пӑхавҫӑсенче пультӑн выляс тата пауза, малалла хӑвӑрт ярас, каялла ярас, малалли тата малтанхи кнопкисем ӗҫлеҫҫӗ, информаци кнопки сӑнӳкерчӗкӗн е видеон тӗплӗхӗсене кӑтартать.

### Сӑнӳкерчӗксемпе видеосем пультпа

1. **Сӑнӳкерчӗк**: сулахай тата сылтӑм малтанхи е малалли ҫине куҫараҫҫӗ, OK тытӑма кӑтартать е пытарать, Ҫӳлелле ҫӳлти панеле (360° кнопки ҫавӑнта), Аялалла аялти панеле куҫарать.
2. **Видео**: OK чарать те тытӑма кӑтартать, е вылять. Вылянӑ чухне сулахай тата сылтӑм 10 ҫеккунт каялла е малалла сиксе каҫаҫҫӗ; чарӑннӑ чухне вӗсем малтанхи е тепӗр элемента куҫараҫҫӗ, сӗнӳ каланӑ пек: «Чарӑннӑ: стрелкӑсем малтанхи е тепӗр элемента куҫараҫҫӗ».
3. **360° сӑнӳкерчӗк**, 360° кнопкинчен: стрелкӑсем йӗри-тавра пӑхаҫҫӗ, тытса тӑнӑ чухне хӑвӑртрах, курӑнӑм йӑвашшӑн чарӑнать. OK ҫӳлти панелӗн кнопкисем патне куҫать, «Пысӑклат» ҫине, «Пӗчӗклет», курӑм уйӗ тата 3D юнашар; канал ҫӳлелле тата аялалла та масштаба улӑштараҫҫӗ. Каялла кнопкӑсенчен ӳкерчӗке таврӑнать, унтан хупать. Сӗнӳ ҫапла: «Йӗри-тавра пӑхма стрелкӑсем, тытӑм валли OK, хупма Каялла».
4. **360° видео**, 360° кнопкинчен: тытӑм пытарӑнса тӑнӑ чухне стрелкӑсем йӗри-тавра пӑхаҫҫӗ, OK чарать те ӑна кӑтартать, Каялла ӑна пытарать, унтан хупать. Сӗнӳ ҫапла: «Йӗри-тавра пӑхма стрелкӑсем, чарса тытӑма кӑтартма OK, хупма Каялла».
5. **Memories (Аса илӳсем)**: сулахай тата сылтӑм сӑнӳкерчӗксем тӑрӑх тата тепӗр аса илӳ патне каяҫҫӗ, Ҫӳлелле хупмалли кнопка патне, Аялалла «View in timeline» (Вӑхӑт шкалинче пӑх) патне каять.
6. **Тетел папкисем тата Plex**: тетел папкин сӑнӳкерчӗк тата видео страницисенче ҫав кнопкӑсемех, унта сулахай тата сылтӑм папкӑри малтанхи е малалли файла уҫаҫҫӗ.

### «Пульт валли вырнаҫтару» ӗнерлевӗ

Settings (Ӗнерленӳсем), Preferences (Суйлавсем), «Пульт валли вырнаҫтару»: «Пысӑк фокус рамкисем тата пульт кнопкисем, сенсорлӑ экран кирлӗ тытӑм элеменчӗсемсӗр. Хӑй тӗллӗн режим ӑна Android TV тата Google TV ҫинче ҫутать.» «Хӑй тӗллӗн» яланхи суйлав; «Ҫутнӑ» клавиатурӑпа е геймпадпа тытса пыракан планшет валли килӗшет; «Сӳнтернӗ» ӑна телевизорта сӳнтерет. Ӗнерлев Android ҫинче кӑна пур. Стрелкӑсем тата OK пӑхавҫӑсенче клавиатурӑпа е геймпадпа ӗнерлеве пӑхмасӑр ӗҫлеҫҫӗ.

### Чикӗсем

- **Пӑхавҫӑ**: телевизорта приложени кӑтартать тата вылять. Сыхлӑх копийӗ, тиесе ярасси, тӳрлетесси, хуратасси, пайласси, темиҫе элемента суйласси, Cast, Spatial 2.5D, гироскоп, карттӑ тата Вырӑнсем, «Ку телефона тетелте пайла» пытарӑннӑ.
- **Кӗрӳ**: OAuth веб-страница уҫать, телевизор вара ӑна тӑваймасть: «(провайдер) урлӑ кӗни веб-страница уҫать, ку телевизор вара ӑна тӑваймасть. Вырӑнне электронлӑ почтӑпа тата парольпе кӗрӗр.»
- **Каҫӑсем** браузер уҫас вырӑнне хӑйсен адресне «Урӑх хатӗрте уҫ» айӗнче кӑтартаҫҫӗ, текста системӑн клавиатура диалогӗнче ҫыраҫҫӗ.

Кашниех пӗрре кӑна курӑнать, копийӗсем ӑҫта пулсан та, чи ҫӗннисем малта.

## Видео тӗплӗхӗсем, декодерсем тата видео мӗншӗн чарӑна-чарӑна вылять

Ҫынсем Quest 3 хӑш кодекпа, хӑш виҫепе тата хӑш битрейтпа вылять тесе ыйтаҫҫӗ, 5.7K экспорт мӗншӗн телефонра вылять, шлемра вара чарӑна-чарӑна пырать тесе те. Хуравӗ аппарат декодерӗнче: Quest 3-ӑн (XR2 Gen 2) H.264 декодерӗ 4096x2304 таранах ҫитет, ҫавӑнпа 5760x2880 H.264 видеона (6.0 шай, 200 Mbit/s яхӑн, Insta360-ӑн яланхи экспорчӗ) шлем ҫеккунтра 17 кадр яхӑн декодлать, блок артефакчӗсемпе, ҫав файл телефонра лайӑх вылять пулин те.

Ҫав видео HEVC (H.265) форматпа шлемра лайӑх вылять: Insta360 X4 8K HEVC видеовӗ (7680x3840, 29,97 fps, 210 Mbit/s, Main профиль 6.1 шай, 8 бит) иммерсивлӑ курӑнӑмра тикӗс вылять, хӑйӗн тӑван разрешенийӗпе тата транскодламасӑр (Quest 3 ҫинче пӗр усӑ куракан пӗлтернӗ).

Immich приложенийӗнче пӗр «Force original video» куҫаркӑч кӑна, вӑл кодека ҫеҫ кӑтартать. Immuch360 видео мӗнле иккенне тата хатӗр мӗне декодланине кӑтартать, выляма пултаракан файла суйлать.

<img src="../.github/readme/b19-video-details.png" width="260" alt="360° видеон тӗплӗхӗсем: Кодек H.264 High (avc1.640033), 3840 x 1920, 30 fps; Битрейт 16 Mbit/s; Ӳкерчӗк 8 бит, SDR, BT.709; Ку хатӗрте декодланать: Ҫапла, аппарат, 4096 x 2304 таран">

### Видео тӗплӗхӗсене вуласси

1. Видеона уҫӑр та ҫӳлелле шӑвӑнтарӑр: тӗплӗхсем ӳкерчӗк айӗнче тухаҫҫӗ.
2. «Кодек»: профильпе тата codecs йӗркипе кодек, кадр виҫи тата кадр хӑвӑртлӑхӗ, сӑмахран «H.264 High (avc1.640033) • 3840 x 1920 • 30 fps», ҫӳлти ӳкерчӗкри пек.
3. «Битрейт» (build 18-ран): видео йӗрӗн битрейчӗ е файл пӗлтерекенни; унсӑрӑн ҫумне «пӗтӗм файл, сасӑпа пӗрле» е «файл виҫипе шутласа кӑларнӑ» тесе ҫырнӑ.
4. «Ӳкерчӗк» (build 18-ран): бит тарӑнӑшӗ, SDR е HDR куҫарӑвӗ (HLG, PQ, Dolby Vision) тата тӗс уҫлӑхӗ.
5. «Ку хатӗрте декодланать»: ҫапла е ҫук, аппарат е программа, декодер йышӑнакан чи пысӑк виҫе, тата хатӗрӗн кодек пур, анчах ҫав профиль ҫук чухне «(профиль) валли декодер ҫук».

Йӗрке файла вуланӑ хыҫҫӑн ҫеҫ курӑнать, файл каланине кӑна кӑтартать. Apple тӑвӑмлӑ сӑнӳкерчӗкӗ е видеовӗ хӑйӗн уйрӑм йӗркине илет, пӑхӑр [Apple-ӑн тӑвӑмлӑ сӑнӳкерчӗкӗсемпе видеовӗсем](#apple-spatial-photos-and-videos).

### Хатӗр мӗне декодланине пӑхасси

Settings, Advanced, «Ку хатӗрӗн видеодекодерӗсем» (build 15-ран) телефон е шлем мӗне декодланине кӑтартать: кодек, аппарат е программа, чи пысӑк виҫе, кадр хӑвӑртлӑхӗ, build 18-ран профильсем те (Main, Main 10, HDR10). Build 19-ран унта MV-HEVC пункт пур, Apple тӑвӑмлӑ видеовӗсен кодекӗ. «Копиле» кнопки списока йӑнӑш ҫинчен пӗлтерӳ валли буфера копилет.

### Оригинала е транскодланӑ потока суйласси

1. Settings, Asset Viewer, унтан Videos уҫӑр.
2. «Видео ҫӑлкуҫӗ» («Серверта транскодланӑ копи пулсан хӑш файл выляять») айӗнче «Ку хатӗр декодлама пултарсан оригинал», «Яланах оригинал» е «Яланах транскодланӑ поток» суйлӑр.

Build 15-ран суйлав серверӑн кашни видеовӗшӗн ӗҫлет: тикӗс плеер, 360° тата Spatial плеерӗсем, Quest-ӑн иммерсивлӑ курӑнӑмӗ. Эсир суйличчен телефон кивӗ «Force original video» куҫаркӑчӗ каланине тытса пырать (стандартла сӳнтернӗ: транскодланӑ поток, сервер транскодламан пулсан вӑл оригиналах), Quest шлем декодлама пултарсан оригинала вылять.

Тӗрӗслев кодека, виҫене тата кадр хӑвӑртлӑхне файлтан вулать те вӗсене аппарат декодерӗсемпе танлаштарать (Quest 3 ҫинчи H.264 виҫсе пӑхнӑ 4096x2304 таран чикленӗ). Оригинала декодлайман плеер пӗлтерӳпе транскодланӑ поток ҫине куҫать: «Транскодланӑ поток выляять: оригинал (кодек тата виҫе) ку хатӗр декодлама пултаракантан иртет».

Шлемра иммерсивлӑ курӑнӑм оригинала хута ярать те, оригинал декодерсенчен иртсен, пӗрремӗш кадрсенчех серверӑн транскодланӑ потокӗ ҫине куҫать, ҫакна информаци панелӗнче пӗлтерет; транскодланӑ поток ҫук чухне, вӑл та ытла пысӑк чухне, е файл шлемран е тетел папкинчен килнӗ чухне информаци панелӗ ҫакна 10 ҫеккунт хушши калать, мӗне улӑштармаллине те. Horizon Store-а панӑ build 14 4096x2304-ран пысӑкрах H.264-на кӑна тӗрӗслет, унтан серверӑн выляну потокне ҫавӑн пекех тӗрӗслесе пӑхать.

Икӗ объективлӑ чӗрӗ видеосем валли тӗрӗслев пӗр вӑхӑтрах икӗ декодер ыйтать, build 19-ран кашниех 2048x2048-ран пысӑкрах икӗ потока программӑлла декодера памасть, пӑхӑр [360° камерӑсен чӗрӗ файлӗсем](#raw-360-camera-files-without-the-cameras-app).

### Шлема декодлама пултаракан видео парасси

Immich-ра Administration (Администрировани), Settings, Video Transcoding Settings (Видео транскодлавӗн ӗнерленӗвӗсем) ҫине кӗрӗр те ҫаксенчен пӗрне суйлӑр:

- **Кашни H.264 видеона HEVC-па ҫӗнӗрен кодласси**: Video codec (Видео кодекӗ) HEVC ҫине, Target resolution (Тӗллевлӗ разрешени) Original (Оригинал) ҫине лартӑр (стандартлӑ 720p 360° видеона 1440x720 таран пӗчӗклетӗччӗ), Accepted video codecs (Йышӑнакан видео кодекӗсем) ӑшӗнче HEVC кӑна хӑварӑр. Библиотекӑри кашни H.264 видеона транскодлаҫҫӗ, 360° видеосене кӑна мар, шлем тулли разрешениллӗ HEVC илет.
- **1440p-ран пысӑкраххисене кӑна**: Accepted video codecs ӑшӗнче H.264 хӑварӑр, Transcode policy (Транскодлав йӗрки) «Videos higher than target resolution or not in an accepted format» (Тӗллевлӗ разрешенирен пысӑкрах е йышӑнман форматлӑ видеосем) ҫине, Target resolution 1440p ҫине лартӑр, Video codec HEVC ҫине лартни лайӑхрах. Пысӑкраххисене транскодлаҫҫӗ, шлем 2880x1440 илет. Ахаль 4K видеосене те 1440p таран транскодлаҫҫӗ.

Ку ӗнерленӳсем пӗтӗм серверӗшӗн, кашни усӑ куракан тата кашни приложени валли ӗҫлеҫҫӗ, пысӑк библиотекӑна ҫӗнӗрен кодлама процессорӑн темиҫе сехет ӗҫӗ тата хушма диск вырӑнӗ кирлӗ; оригиналсене улӑштармаҫҫӗ. HEVC тытса тӑман браузерсем (нумай системӑри Firefox, аппарат HEVC-сӑр Chrome) Immich веб-приложенийӗнче HEVC транскодне выляймаҫҫӗ. Ҫӗнӗ видеосем валли чи ҫӑмӑл ҫул вӗсене Insta360 приложенийӗнчен е Studio-ран H.265-па экспортласси. Ку ӗнерленӳсене улӑштарнӑ хыҫҫӑн пур видеосене тепӗр хут транскодламалла: Administration, Job Queues (Ӗҫсен черечӗсем) (Immich-ӑн кивӗрех версийӗсенче Jobs (Ӗҫсем)), Transcode videos (Видеосене транскодла), «Пурте».

Альтернатива, тетел папкин е шлемӑн файлӗсем валли пӗртен-пӗр май (вӗсен транскодланӑ потокӗ ҫук), экспорта тиесе ячченех е тетел папкине копилеччен HEVC-па ҫӗнӗрен кодласси:

```bash
ffmpeg -i VID_360.mp4 -c:v libx265 -crf 20 -preset medium -tag:v hvc1 -c:a copy -movflags +faststart VID_360_hevc.mp4
exiftool -overwrite_original -tagsFromFile VID_360.mp4 -XMP-GSpherical:all VID_360_hevc.mp4
exiftool -ProjectionType VID_360_hevc.mp4        # must print: equirectangular
```

`-tag:v hvc1` HEVC йӗрне Apple хатӗрӗсемпе браузерсем кӗтнӗ пек паллӑ тӑвать, `-c:a copy` сасса мӗнле пур, ҫапла хӑварать. ffmpeg экспортӑн 360° паллине ҫухатать, exiftool йӗрки ӑна каялла копилет; унсӑрӑн Immich видеона тикӗс видео евӗр кӑтартать.

### Поток евӗр выляйман оригиналсем

Сервер оригинал ҫинчи HTTP Range ыйтӑвӗсене шута илмесен тата MP4 индексӗ (moov) файл вӗҫӗнче пулсан, пӗрремӗш кадр умӗн пӗтӗм файла тиесе илмелле пулӗччӗ, ҫавӑнпа приложени серверӑн выляну потокне куҫать. Immich умӗнчи reverse proxy, хуравсене буферлакан е Range заголовокӗсене кӑларса пӑрахакан, ҫакна тума пултарать.

## Форматсем тата ҫӑлкуҫсем, платформӑсем тӑрӑх

Immuch360 вӑл галерея, тата вӑл тӳлевсӗр медиа плеер: официаллӑ приложени выляйманнине вылять, иккӗмӗш списокри ҫӑлкуҫсенчен, файла килӗшекен плеерта.

## Meta Quest 3

Immuch360 Horizon OS v69 е ҫӗнӗрех Meta Quest шлемӗсем ҫинче те ӗҫлет. Build 21-ран Horizon Store build-ӗ Quest 2, Quest Pro, Quest 3 тата 3S валли, универсаллӑ `-release.apk` асӑнакан ҫак тӑватӑ шлем валли; пӗрремӗш Quest валли мар, лавкка ӑна урӑх йышӑнмасть.

Quest 3 тата 3S тӗрӗсленӗ. Quest 2 тата Quest Pro халлӗхе тӗрӗслемен: вӗсен видео декодерӗсем вӑрахрах, приложени тӗрӗслекен чиксене Quest 3 ҫинче виҫнӗ, ҫавӑнпа вӗсем ҫинче пысӑк H.264 видеона пӗлтерӳпе йышӑнмасӑр хӑварма пултараҫҫӗ е вӑл чарӑна-чарӑна выляма пултарать. Ҫак икӗ шлемран пӗлтерӳсене [Issues](https://github.com/freeKC/Immuch360/issues) ҫине хапӑл кӗтетпӗр.

Унпа мӗнле усӑ курмалли [Meta Quest 3 шлемӗнче](#in-the-meta-quest-3-headset) пайӗнче; ку пай ӑна лартасси тата шлем ҫинче мӗн уйрӑлса тӑни ҫинчен.

Шлем build-ӗ серверсемпе HTTPS урлӑ кӑна калаҫать, е ахаль HTTP урлӑ килти тетел ячӗсемпе (`.local`, `.lan`, `.home`, `.internal`, `.home.arpa`) тата шлемӑн хӑйӗнпе, Horizon Store ыйтнӑ пек. IP-лӑ ахаль HTTP адрес евӗр ҫырнӑ сервера, сӑмахран `http://192.168.1.10:2283`, ку build йышӑнмасть: HTTPS, килти тетел ятне (`nas.local`) е телефонсен уҫӑ йӗркине упракан универсаллӑ `-release.apk` усӑ курӑр.

Вырӑнти тетелӗн ахаль HTTP адресӗнчи WebDAV, DLNA тата телефон папкисене ку пырса тивмест: приложени вӗсене хӑй вулать те хӑйӗн плеерӗсене вырӑнти кӗперӗн адресне кӑна парать (DLNA тата телефон папки валли, build 19-ри ҫӗнӗлӗх, шлем ҫинче ҫирӗплетмелле). Build 20-ран Plex серверӗ патне HTTPS урлӑ ҫитеҫҫӗ, Tapo камери патне приложени хӑй ҫитет, унӑн тӳрӗ эфирӗ RTSP урлӑ, вӑл HTTP мар: иккӗшне те ку пырса тивмелле мар (шлем ҫинче ҫирӗплетмелле).

<a id="install"></a>
### Лартасси

Meta Horizon Store ҫинчи страницӑна 2026 ҫулхи юпа уйӑхӗн 7-мӗшӗнче build 14-па ырланӑ, build 21-а унӑн пӗрремӗш ҫӗнелӗвӗ евӗр панӑ. Лавкка страници уҫӑ пуличчен, е лавккара пуличчен build илес тесен, релизӑн `-quest-release.apk` файлне sideload мелӗпе лартӑр (шлем валли тунӑ: 64 бит, target SDK 34, шлем усӑ куракан ирӗксем кӑна), е универсаллӑ `-release.apk`:

1. Аталантаракан режимне пӗрре ҫутӑр. Meta Horizon телефон приложенийӗнче Devices (Хатӗрсем) уҫӑр, шлема суйлӑр, унтан Headset settings (Шлем ӗнерленӗвӗсем), унтан Developer mode (Аталантаракан режимӗ). Ҫакӑн валли аталантаракан аккаунчӗ кирлӗ, вӑл developers.meta.com ҫинче тӳлевсӗр. Компьютер ҫинче adb (Android SDK Platform Tools) е SideQuest те кирлӗ.
2. Шлема компьютерпа USB-C кабельпе ҫыхӑнтарӑр. Шлемра «Allow USB debugging» (USB урлӑ отладкӑна ирӗк пар) йышӑнӑр.
3. APK-на лартӑр:

   ```bash
   adb devices                      # the headset must be listed as "device"
   adb install -r Immuch360-v<version>-quest-release.apk   # for example Immuch360-v3.3.0-rc.0-21-quest-release.apk
   ```

4. Шлемра Библиотекӑна уҫӑр, «Unknown sources» (Паллӑ мар ҫӑлкуҫсем) фильтрне суйлӑр, Immuch360-а хута ярӑр.
5. Sideload мелӗпе лартнӑ APK хӑй тӗллӗн ҫӗнелмест: тепӗр релиза ҫавӑн пекех лартӑр (`adb install -r` кӗрӳ даннӑйӗсене тата ӗнерленӳсене упрать). Horizon Store версийӗ тата GitHub APK-ӗ урӑх-урӑх ҫӑраҫҫисемпе алӑ пуснӑ, ҫавӑнпа шлем пӗрне тепри ҫине лартма памасть: улӑштарас тесен малтан приложение кӑларса пӑрахӑр, вара кӗрӳ, ӗнерленӳсем тата тетел папкисен списокӗ ҫухалаҫҫӗ.

### Чӳречере

Пӗтӗм приложени виҫине улӑштарма пулакан 2D чӳрече евӗр ӗҫлет: кӗрӳ, вӑхӑт шкали, альбомсем, шырав, «Библиотека» вкладки (360° списокӗ, On this device, «Тетел папкисем»), ӗнерленӳсем, сӑнӳкерчӗк тата видео пӑхавҫисем, унта тикӗс сӑнӳкерчӗксемпе видеосем выляҫҫӗ.

Шлем ҫинче 360° кнопки тата ⋮ менюри «360° евĕр пăх» телефонсенчи сфера пӑхавҫи вырӑнне тӳрех иммерсивлӑ курӑнӑма уҫаҫҫӗ, Spatial 2.5D кнопки тата унӑн ӗнерлевӗ курӑнмаҫҫӗ.

Build 19-ран Apple тӑвӑмлӑ сӑнӳкерчӗкӗн «3D-ра пӑх» кнопки пур, «Ку телефона тетелте пайла» плитка курӑнмасть: телефонӑн тетел папкине шлем хӑй вулать. Build 20-ран Plex серверӗсем тата Tapo камерисем те чӳречере уҫӑлаҫҫӗ, камера тӳрӗ эфирӗ HD-ра; «Пульт валли вырнаҫтару» ӗнерлевӗ «Хӑй тӗллӗн» юлать, ҫавӑнпа шлем ҫинче вӑл сӳнтернӗ.

### Шлем ҫинчи чикӗсем

- **Видео кодекӗсем**: HEVC (H.265) шанчӑклӑ суйлав; H.264 4096x2304 таранах ҫитет. Приложени мӗне тӗрӗсленине тата шлема вӑл декодлакан видеона мӗнле памаллине [Видео тӗплӗхӗсем тата декодерсем](#video-details-decoders-and-why-a-video-stutters) пайӗнче ҫырнӑ.

## Windows компьютерӗ ҫинче: Immuch360 Desktop (тӗрӗслев версийӗ)

Сирӗн Immich библиотеки серверте, ытти сӑнӳкерчӗксем компьютер папкисенче, видеосем NAS е Plex серверӗ ҫинче, эсир вара хӑвӑрӑн 360° сӑнӳкерчӗксен ӑшӗнче пысӑк экранра таврана пӑхасшӑн е компьютерӗн сӑнӳкерчӗкӗсене шлемра кӑтартасшӑн. Immuch360 Desktop вӑл Windows компьютерӗ ҫинчи ҫав приложени, телефон приложенийӗсемпе пӗр ҫӑлкуҫ кодӗнчен тунӑскер.

Компьютер ҫинче Immich хӑйӗн веб-приложенине браузерта сӗнет. **Immuch360 Desktop мӗн хушать**: компьютер папкисене серверсӗр те аккаунтсӑр, SMB, WebDAV, DLNA тата Plex тетел папкисене приложенирен пӑхса тухасси, чӗрӗ Insta360 .insp сӑнӳкерчӗкӗсене сфера евӗр уҫасси, компьютера килти Meta Quest шлемӗпе пайласси.

Ку пӗрремӗш build тӗрӗслев версийӗ: сӑнӳкерчӗксем ӗҫлеҫҫӗ, видеосем малалли desktop build-семпе килеҫҫӗ. Телефон, планшет, Quest тата телевизор приложенийӗсем ун пирки улшӑнмаҫҫӗ, Immuch360 ятне упраҫҫӗ.

<a id="download-and-install-on-windows"></a>
### Windows ҫине тиесе илесси тата лартасси

Пӗрремӗш build вӑл GitHub-ӑн [Immuch360 Desktop 3.3.0-rc.0, desktop build 1 (Windows preview)](https://github.com/freeKC/Immuch360/releases/tag/desktop-v3.3.0-rc.0-1) малтанхи релизӗ. Унӑн файлӗ `Immuch360-Desktop-3.3.0-rc.0-desktop.1-windows-x64.zip` (33,5 MB, уҫсан 65 файл), ӑна тӗрӗслеме `SHA256SUMS.txt` пур. Ӑна `desktop` турачӗн 21f285c34 коммитӗнчен тунӑ: телефонӑн build 20-ӗ тата компьютер версийӗ. Ӑна Windows 10 е 11, 64 бит кирлӗ.

1. ZIP-а тиесе илӗр те ӑна кирек ӑҫта уҫӑр, сӑмахран, Документсем ӑшне.
2. Уҫнӑ папкӑран `immuch360.exe` хута ярӑр. Папкӑна пӗтӗмпех хӑварӑр: программӑна ун ҫумӗнчи файлсем кирлӗ.
3. Файлсене халлӗхе алӑ пусман, ҫавӑнпа Windows SmartScreen «Windows protected your PC» (Windows сирӗн компьютера хӳтӗлерӗ) кӑтартма пултарать: «More info» (Тӗплӗнрех) суйлӑр, унтан «Run anyway» (Ҫапах та хута яр). Smart App Control ҫутнӑ пулсан, вӑл алӑ пусман программӑсене чарать.
4. Чӳречене кӗтӗр. Ҫӗнӗ build-ӑн пӗрремӗш хута кайӑвӗ 10 ҫеккунтран пӗр минут таран тӑсӑлать, ытларах Microsoft Defender ҫӗнӗ файлсене тӗрӗсленӗ вӑхӑтра: ҫав хушӑра приложение тепӗр хут ан ярӑр. Малалли хута ярусем пӗр-ик ҫеккунт илеҫҫӗ.
5. Кӗмелли страницӑра хӑвӑрӑн Immich серверне унӑн адресӗпе, электронлӑ почтӑрпа тата парольпе кӗрӗр, е «Серверсӑр усӑ кур» ҫине пусӑр.

ZIP-а тӗрӗслеме, тиесе илнӗ папкӑра команда йӗркинче `certutil -hashfile Immuch360-Desktop-3.3.0-rc.0-desktop.1-windows-x64.zip SHA256` ярӑр: результат `SHA256SUMS.txt` ӑшӗнче ҫырнипе пӗрех. Лартакан программа та, хӑй тӗллӗн ҫӗнелни те халлӗхе ҫук: [Releases](https://github.com/freeKC/Immuch360/releases) страницине сӑнӑр, малалли build-а ҫавӑн пекех уҫӑр.

### Тӗрӗслев версийӗ мӗн тӑвать

- **Сирӗн Immich серверӗ**: вӑхӑт шкали, альбомсем, ҫынсем, асаилӳсем тата шырав, сервер сӑнӳкерчӗкӗсем тулли виҫепе, телефонри пекех.
- **Серверсӑр**: сирӗн сӑнӳкерчӗксемпе видеосен папкисем (Ӳкерчӗксем тата Видеосем сӗнеҫҫӗ) телефон галерейи вырӑнне пулаҫҫӗ. Эсир суйланӑ папкӑсенчен тулашра нимӗн те вуламаҫҫӗ, серверсӑр компьютертан нимӗн те тухмасть.
- **Тиесе ярасси тата резерв копийӗ** ҫав папкӑсенчен сирӗн Immich серверне, приложени уҫӑ чухне.
- **360° сӑнӳкерчӗксем сфера евӗр**, мышьпе тата клавиатурӑпа; Insta360 камерисен чӗрӗ .insp сӑнӳкерчӗкӗсем телефонсенчи пекех уҫӑлаҫҫӗ.
- **Тетел папкисем**: Samba (SMB), WebDAV тата DLNA медиа серверӗсем, plex.tv-сӑр Plex серверӗсем, телефонсенчи пекех пӑхса тухатӑр: вӗсен сӑнӳкерчӗкӗсем уҫӑлаҫҫӗ, видеовӗсем видео плеерне кӗтеҫҫӗ (пӑхӑр [Халлӗхе ҫук](#not-there-yet)). Tapo камерисем валли асӑм картин ҫырса илнисем: списокӗ тата клипа илесси.
- **Ку компьютера тетелте пайласси**: сирӗн папкӑсен альбомӗсем, уйӑхӗсем тата 360° медиийӗ, вулама кӑна, Meta Quest е килти урӑх хатӗр валли, телефон хӑйне пайланӑ пекех.
- **Файлсем**: сервертен тиесе илнисем эсир суйланӑ папкӑна каяҫҫӗ, «Папкӑна упра» суйланӑ сӑнӳкерчӗксемпе видеосен копине упрать, Журналсем страницинче «Журналсене файла упра» пур.

### Компьютер ҫинче усӑ курасси

1. **Хӑвӑр папкӑсене суйлӑр.** Серверсӑр вӑхӑт шкали «Хӑвӑр сӑнӳкерчӗксемпе видеосен папкисене суйлӑр» тесе пуҫланать: «Папка хуш» ҫине пусӑр. Серверпа ҫав карточкӑ Библиотекӑра «Ку компьютер ҫинче» айӗнче тата резерв копийӗ валли альбомсенче курӑнать, папка суйличчен. Унтан вӗсенче «Ку компьютер ҫинчи папкӑсем» йӗрки пулать, Ӗнерленӳсенче те, «Ку компьютер».
2. **Пӗлӗт, USB тата тетел папкисем.** OneDrive (е урӑх пӗлӗт дискӗ) онлайн кӑна упракан файлсене шутлаҫҫӗ, анчах вуламаҫҫӗ, ҫавӑнпа папка хушни пӗтӗм пӗлӗте тиесе илмест: «Тиесе ил те кӗрт» вӗсене эсир хӑҫан кирлӗ пулсан илет. Урӑх саспаллипе таврӑннӑ USB диск хӑйӗн сӑнӳкерчӗкӗсене упрать. Тетел папкисене, асӑм карти е USB диск ҫинчи папкӑсене (Windows ӑна кӑларма пултартӑр тесе) улшӑнусем валли сӑнамаҫҫӗ: унта файлсем хушсан «Ҫӗнет» пусӑр.
3. **360° сӑнӳкерчӗкре таврана пӑхасси**: мышьпе туртӑр, кустӑрмапа, икӗ хут пуснипе е + тата - (кирек хӑш клавиатура йӗркипе, AZERTY те) пысӑклатӑр, ухӑ клавишӗсемпе куҫӑр. F е F11 тулли экран ҫине куҫарать, Escape унтан тухать; Home тата End пӗрремӗш тата юлашки сӑнӳкерчӗк патне каяҫҫӗ; I тӗплӗнрех кӑтартать.
4. **Сӑнӳкерчӗкрен сӑнӳкерчӗке куҫасси**: тикӗс сӑнӳкерчӗкре сулахай тата сылтӑм ухӑсем, е мышь куҫнӑ чухне хӗррисенче курӑнакан палӑсем, малтанхи тата малалли патне каяҫҫӗ. Ӑнлантару хирӗнче ҫырнӑ саспаллисем текстрах юлаҫҫӗ.
5. **Компьютера шлемпа пайласси**: Библиотекӑна, унтан «Тетел папкисем» уҫӑр; пӗрремӗш плитка «Ку компьютера тетелте пайла», [Ку телефона тетелте пайласси](#share-this-phone-on-the-network) пайӑн компьютер енӗ. «Сӑнӳкерчӗксемпе видеосене тетелте пайла» ҫутӑр, унтан ҫав пайра каланӑ пек компьютера шлемра хушӑр. Пайлани приложени хупӑнсан е усӑ курмасӑр пӗр сехет иртсен чарӑнать.
6. **Тетеле ирӗк парӑр**: Windows Immuch360 Desktop тетелпе усӑ курма пултарать-и тесе ыйтма пултарать. Ӑна уйрӑм тетелсенче ирӗк парӑр, унсӑрӑн шлем компьютера тупаймасть. Windows пӗтӗм халӑх тетелӗ тесе палӑртнӑ тетелте (кафе, хӑна ҫурчӗ), е унӑн тӗсне палласа илеймен тетелте, эсир «Ку сеанс валли пайла» суйламасан пайлани хута каймасть, компьютер хӑйне пайлакан тетелте кӑна пӗлтерет.
7. **Ӗнерленӳсем, «Ку компьютер»**: папкӑсем, тиесе илнисен папки, тетел папкисене шырама тата компьютера пайлама усӑ куракан тетел адаптерӗ (вӗсем темиҫе пулсан, сӑмахран Wi-Fi тата Ethernet), шанчӑклӑ сертификатсем: хӑвӑр сервер сертификачӗсен центрӗ, PEM файл евӗр, Windows хӑй шанман HTTPS адрес валли. Клиент сертификачӗсене Ӗнерленӳсем, Advanced (Анлӑ) ӑшӗнче импортлаҫҫӗ, телефонсенчи пекех.

### Телефон приложенийӗсемпе танлаштарсан

- **Резерв копийӗ приложени уҫӑ чухне ӗҫлет** (е пӗчӗклетнӗ чухне), чӳрече хупӑ чухне фонра мар. Тиесе ярусем пынӑ чухне е компьютера пайланӑ чухне чӳречене хупсан малтан ыйтать.
- **Галерея вырӑнне папкӑсем**: приложени эсир суйланӑ папкӑсене вулать, хӑйӗн индексне, миниатюрисене тата кэшне компьютер ҫинче упрать.
- **Пӗр чӳрече**: приложение иккӗмӗш хут уҫсан иккӗмӗш копи хута каймасть, пӗрремӗш чӳрече каялла тухать.
- **Сирӗн папкӑсенчен нимӗн те хуратӑнмасть**: «Хатӗртен хурат» пытарнӑ, «Хурат» сервер копине кӑна хуратать, приложени файлсене Windows ҫӳп-ҫап коробкине яма пултариччен.
- **Мышь тата клавиатура** пӳрнепе пусни тата гироскоп вырӑнне.

<a id="not-there-yet"></a>
### Халлӗхе ҫук

- **Видеосем**: халлӗхе вӗсем вырӑнне палӑ курӑнать, миниатюрисем вырӑнне фильм значокӗ. Выляттарасси малалла килет: малтан тикӗс видеосем, унтан 360°, 3D тата VR180 видеосем тата чӗрӗ 360° видеосем.
- **Spatial 2.5D**, каярах веб-камерӑпа; **Tapo тӳрӗ эфирӗ**; **карттӑ** тата Вырӑнсем курӑнӑмӗ; **OAuth урлӑ кӗресси** (ун вырӑнне электронлӑ почтӑпа тата парольпе кӗрӗр); **Google Cast**; **пӗлтерӳсем**.
- **Лартакан программа, алӑ пуснӑ build тата хӑй тӗллӗн ҫӗнелни**: ку build `immuch360.exe` пур папка.
- **Linux тата macOS**: вӗсен проекчӗсем ҫӑлкуҫ кодӗнче, анчах вӗсене ҫав системӑсем ҫинче халлӗхе туман та, тӗрӗслемен те; вӗсем Windows хыҫҫӑн килеҫҫӗ.
- **Куҫарусем**: компьютер версийӗн ҫӗнӗ текстӗсем халлӗхе акӑлчанла.

### Паллӑ йывӑрлӑхсем

- **Шлем пайланӑ компьютертан файл вуланӑ чухне** (вӑл выляттаракан видео, вӑл тиесе илекен сӑнӳкерчӗк), Windows ҫав файла ятне улӑштараймасть, куҫараймасть, хуратаймасть, вӑл Immuch360 Desktop-ра уҫӑ тесе калать: малтан выляттарассине чарӑр. Резерв копийӗсем сирӗн файлсене ҫапла тытмаҫҫӗ: тиесе янӑ чухне файлӑн ятне улӑштарма, ӑна куҫарма е хуратма пулать.
- **Тӳрлетмелли вырӑнсем**: ҫӳлти функцисем Windows ҫинче хӑйсен автоматлӑ тестӗсене тухаҫҫӗ (475 desktop тестӗ), Windows 11 компьютерӗ ҫинче приложени хута каять, Immich серверӗ ҫинчи упранӑ сеанса уҫать, синхронлать тата тирпейлӗн хупӑнать. Чӑн компьютер ҫинче кашни функцие алӑпа тӗрӗслесси халӗ те пырать.

Темӗн йӑнӑш пулсан, тархасшӑн, Журналсем страницинчен упранӑ журналпа [issue](https://github.com/freeKC/Immuch360/issues) уҫӑр, пӑхӑр: [Журналсем](#logs). Журнала пайлас умӗн тӗрӗслӗр: унта сирӗн сервер адресӗ пулма пултарать.

<a id="build-it-yourself-on-windows"></a>
### Windows ҫинче хӑвӑр тӑвасси

Сире x64 ҫинчи Windows 10 е 11, Windows валли Flutter 3.47.2, «Desktop development with C++» ӗҫ тиевӗллӗ Visual Studio 2022 е унӑн Build Tools, Windows ӗнерленӗвӗсенче ҫутнӑ Developer Mode (Аталантаракан режимӗ) (Flutter-а вӑл плагинсем валли кирлӗ) тата пакетлакан скрипт валли Python 3 кирлӗ.

1. `desktop` турачӗ илӗр те код генерацине ярӑр. Вӑл Java тата Node усӑ курать, ҫавӑнпа ӑна Linux, macOS е WSL ӑшӗнче ярӑр; WSL пулсан, клона Windows дискӗ ҫинче тытӑр, WSL ӑна `/mnt/c` е `/mnt/d` айӗнче курать:

   ```bash
   git clone https://github.com/freeKC/Immuch360.git
   cd Immuch360
   git switch desktop
   cd mobile
   mise install
   mise run install
   mise run codegen
   ```

2. Windows ҫинче, ҫав `mobile` папкӑрах, приложение тӑвӑр:

   ```bat
   flutter pub get
   REM try it, with hot reload: a debug build, with a profile of its own (Immuch360 Desktop Debug), so it runs next to the app
   flutter run -d windows -t lib/main_desktop.dart
   REM the app, in build\windows\x64\runner\Release\immuch360.exe
   flutter build windows --release -t lib/main_desktop.dart
   ```

3. `Release` папки ӑна тунӑ компьютер ҫинче ӗҫлет. Урӑх компьютер валли пӗтӗм папкӑна упрӑр, `immuch360.exe` ҫумне Visual C++ runtime хушӑр. Клон тымарӗнчен пакетлакан скрипт ӑна копилет, Android валли кӑна кирлӗ япаласене кӑларса хӑварать, приложени тиекен кашни DLL папкӑра е Windows хӑйӗнче пуррине тӗрӗслет, ZIP тӑвать:

   ```bat
   python .github\desktop\windows_bundle.py --release mobile\build\windows\x64\runner\Release --out <folder> --zip <file.zip>
   ```

`desktop` турачӗн CI-ӗ (`.github/workflows/immuch360-desktop.yml`) телефон тӗрӗслевӗсене тата пӗтӗм тест пухмачне Linux ҫинче ярать, desktop тестӗсене Windows ҫинче, ҫав ZIP-ах тӑвать; унӑн Linux тата macOS ӗҫӗсем (`flutter build linux` тата `flutter build macos`, ҫав `-t lib/main_desktop.dart` пекех) ҫав системӑсем ҫинче халлӗхе ӗҫлемен.

<a id="build-it-yourself"></a>
## Хӑвӑр хатӗрлесси

Хатӗрлев йӗрки Immich мобильлӗ приложенийӗнни пекех (Flutter 3.47, [mise](https://mise.jdx.dev) урлӑ йӗркеленӗ):

```bash
git clone https://github.com/freeKC/Immuch360.git
cd Immuch360/mobile
mise install
mise run install
mise run codegen
flutter build apk --release --flavor phone                                   # phones: the universal APK of the GitHub releases (add --split-per-abi for the per ABI files)
flutter build appbundle --release --flavor phone                             # the App Bundle sent to Google Play (also mise run build:android)
flutter build apk --release --flavor quest --target-platform android-arm64 --android-project-arg arm64only=true   # Meta Quest 2, Pro, 3 and 3S: the -quest-release.apk of the releases (also mise run build:quest)
flutter build ios --release                                                  # iPhone and iPad, on a Mac with Xcode and your own signing team
```

Лавкка скриншочӗсене `--dart-define=IMMUCH_SCREENSHOTS=true` параметрпа тунӑ симулятор debug build-ӗсем ҫинче илеҫҫӗ, ку debug баннерне кӑна пытарать.

Android-ӑн икӗ flavour-ӗ пӗр приложени. Build 20-ран `phone` flavour хӑйне телевизор приложенийӗ тесе те пӗлтерет (телевизор лаунчерӗн пункчӗ тата баннер, сенсорлӑ экран кирлӗ мар), `quest` flavour вара ҫакна кӗртмест.

`quest` flavour SDK 34-а тӗллет тата шлем усӑ куракан ирӗксене кӑна хӑварать (сӑнӳкерчӗксем, видеосем, пӗлтерӳсем): медиа управленийӗ, фонри вырӑн, кивӗ управ, сасӑ, медиа вырӑнӗ, хатӗр вырӑнӗ тата камера ирӗкӗсене `android/app/src/quest/AndroidManifest.xml` ӑшӗнче кӑларса пӑрахнӑ, мӗншӗн тесен Meta Horizon Store пӗрремӗш иккӗшне йышӑнмасть, ытти кашни сисӗмлӗ ирӗк валли сӑлтав ыйтать; ҫав файлах Quest 2, Quest Pro, Quest 3 тата 3S-а тытса тӑракан хатӗрсем тесе палӑртать, ахаль HTTP-на шлемӑн хӑйӗнпе тата килти тетел ячӗсемпе кӑна чиклет. APK 64 битлӑ кӑна, унӑн команда йӗркин икӗ хушма аргументне пула (`--target-platform android-arm64 --android-project-arg arm64only=true`). `phone` flavour вӑл Google Play ыйтаканни.

iOS валли хӑвӑрӑн Mac ҫинче хатӗрлеме Xcode тата хӑвӑрӑн алӑ пусу ушкӑнӗпе (signing team) усӑ курӑр; Xcode 26-па малтан пӗрре `xcodebuild -downloadComponent MetalToolchain` ӗҫлеттерӗр, мӗншӗн тесен Spatial шейдерӗсене вӑл кирлӗ. Mac ҫук пулсан, iOS build-ӗсем Codemagic ҫинче (хостинглӑ Mac) ҫак репозиторин `codemagic.yaml` файлӗпе ӗҫлеҫҫӗ. Android релиз build-ӗсем GitHub Actions ҫинче ӗҫлеҫҫӗ (`.github/workflows/immuch360-release.yml`).

Immuch360 Desktop, Windows версийӗ, `desktop` турачӗнчен Windows валли Flutter-па тӑваҫҫӗ: утӑмсем [Windows ҫинче хӑвӑр тӑвасси](#build-it-yourself-on-windows) пайра.

Ку репозиторире пӗр вӑрттӑнлӑх та ҫук: Android алӑ пусу ҫӑраҫҫине шифрланӑ GitHub Actions secrets евӗр упраҫҫӗ, Apple алӑ пусу материалне Codemagic ҫинче шифрланӑ улшӑнакансем евӗр. Workflow файлӗсем вӗсене ячӗпе кӑна асӑнаҫҫӗ. Хӑвӑрӑн `android/key.jks` ҫук пулсан, релиз build-не debug ҫӑраҫҫипе алӑ пусаҫҫӗ, вӑл GitHub-ран е лавккаран лартнӑ копи ҫине лартӑнаймасть (малтан ӑна кӑларса пӑрахӑр); debug build ун ҫумне Immuch360 debug ятпа лартӑнать. Meta Horizon Store копийӗ вӑл релизӑн `quest` APK-ӗ, урӑх ҫӑраҫҫипе алӑ пуснӑскер, лавкка приложенийӗ малтан ҫав ҫӑраҫҫипе регистрациленнӗ, ҫавӑнпа вӑл та sideload мелӗпе лартнӑ APK ҫине лартӑнаймасть, урӑхла та ҫаплах.

### Турачӑсем

- **`main`**: `immuch360` никӗсӗ пулакан коммитри Immich `main` (хальхи build-сем валли 2026 ҫулхи авӑн уйӑхӗн 29-мӗшӗ), нихӑҫан та улӑштарман; форка Immich-ӑн ҫӗнӗрех версийӗ ҫине rebase тусан вӑл малалла куҫать.
- **`immuch360`**: ку форкӑн Immich ҫийӗнчи улшӑнӑвӗсем. Кашни релиз хӑш Immich версийӗ ҫинче никӗсленнине калать.
- **`desktop`**: Immuch360 Desktop, компьютер версийӗ, `immuch360` ҫийӗнче. Телефон релизӗсене ун ӑшне пӗрлештереҫҫӗ, desktop малтанхи релизӗсене унран тӑваҫҫӗ (desktop build 1 21f285c34 коммитран, телефонӑн build 20-ӗ тата компьютер версийӗ). `mobile/android` тата `mobile/ios` айӗнче унта нимӗн те улшӑнмасть.

<a id="logs"></a>
## Журналсем

Android тата Quest ҫинче `adb logcat` шлемӑн иммерсивлӑ курӑнӑмне `Immuch360` тег айӗнче кӑтартать (build 19-ран Apple тӑвӑмлӑ сӑнӳкерчӗкӗн икӗ куҫне те: иккӗмӗш куҫа мӗнле декодланӑ, касни, сӑнӳкерчӗк ӑҫта вырнаҫнӑ), декодер тӗрӗслевӗсене `VideoDecoders` айӗнче, юнашар чӗрӗ видеона ҫыхӑнтарассине `DualFisheyeEffect` айӗнче, build 18-ӑн икӗ объективлӑ выляттарӑвне `TwoLensPlayer`, `TwoLensCompositor` тата `LensVideoRenderer` айӗнче:

```bash
adb logcat -c
# reproduce the problem, then
adb logcat -d -v time -s Immuch360 VideoDecoders DualFisheyeEffect TwoLensPlayer TwoLensCompositor LensVideoRenderer
adb logcat -d -v time > quest-full.log      # everything, including crashes and decoder errors (it can contain your server address, check before sharing)
adb logcat -d -v time -s PhoneShareService PhoneShareApi   # on the phone that shares itself (from build 19)
```

Build 19-ран DLNA клиенчӗ, телефон папки тата Apple тӑвӑмлӑ медиине палласа илни приложенин хӑйӗн журналне те ҫыраҫҫӗ (Logs (Журналсем), сылтӑмра ҫӳлти профиль ӳкерчӗкӗн менюнче), `Ssdp`, `DlnaFileSystem`, `NetworkBrowserPage`, `PhoneShare`, `PhoneShareServer`, `AppleSpatialService`, `HeicStereoProbe` тата `NetworkMediaService` айӗнче. Build 20-ран телевизор режимӗ унта `TvMode` тата `TvTextEntry` айӗнче ҫырать, Plex серверӗсем `Gdm`, `UdpTransport`, `PlexClient`, `PlexFileSystem` тата `PlexServerEditPage` айӗнче, Tapo камерисем `TapoDiscovery`, `TapoHttps`, `TapoLogin`, `TapoControl`, `TapoMedia`, `TapoFileSystem`, `TapoTest`, `TapoCamera`, `CameraPage`, `CameraEditPage` тата `CameraLiveView` айӗнче; Plex йӗркисенче токен, адрес е ят нихӑҫан та ҫук, камера йӗркисенче парольсем ҫук. Журнал йӗркисем хатӗрте юлаҫҫӗ, эсир вӗсене хӑвӑр копилемесен.

Компьютер ҫинче (Immuch360 Desktop) Журналсем страницинче «Журналсене файла упра» те пур: журнал, е юлашки ӳкӗмсем пулсан журналпа вӗсен пӗлтерӗвӗсем пур ZIP (ун чухне унӑн сӗнекен ячӗ «with-crash-reports» тесе пӗтет). Ӳкӗм пӗлтерӗвӗ вӑл пӗчӗк minidump: потоксем, вӗсем ӑҫта чарӑннӑ тата вӗсен чӗнӗвӗсене йӗрлеме мӗн кирли кӑна, программа файлӗсен ячӗсемпе, анчах вӗсен папкисемсӗр; приложени асӑмӗ мар. Журнала пайлас умӗн тӗрӗслӗр: унта сирӗн сервер адресӗ пулма пултарать.

<a id="privacy"></a>
## Вӑрттӑнлӑх

- **Аталантаракан патне нимӗн те каймасть**: приложени эсир суйланӑ Immich серверӗпе калаҫать (картта уҫсан, ҫав сервер усӑ куракан карттӑ плиткисен службипе те), унра реклама та, аналитика та, аталантаракан тытса тӑракан ӳкӗм (crash) пӗлтерӗвӗсен службы та ҫук, Immuch360 аталантаракан патне нимӗн те ямасть.
- **Серверсӑр** нимӗнле сервер патне те ҫыхӑнмаҫҫӗ: приложени тетелпе эсир уҫакан тетел папкисем, Plex серверӗсем тата камерӑсем валли, тата эсир ҫутсан телефон папки валли кӑна усӑ курать.
- **Тетел папкисем**: тетел папкисен списокне хатӗрте упраҫҫӗ, нихӑҫан та сервер ҫине ямаҫҫӗ; парольсем хатӗрӗн keychain е keystore ӑшне каяҫҫӗ.
- **Plex** (build 20-ран): токен хатӗрӗн хӑрушсӑр управӗнче юлать, HTTPS урлӑ ыйту заголовокӗнче хӑвӑрӑн сервер патне кӑна каять; приложени plex.tv патне нихӑҫан та ҫыхӑнмасть.
- **Tapo камерисем** (build 20-ран): TP-Link аккаунчӗн пароле тата камера аккаунчӗн пароле хатӗрӗн хӑрушсӑр управӗнче юлаҫҫӗ; приложени камерӑпа вырӑнти тетелте кӑна калаҫать, TP-Link серверӗсемпе нихӑҫан та мар; илнӗ клипсем приложени кэшӗнче юлаҫҫӗ, камерӑпа пӗрле хуратӑнаҫҫӗ.
- **Телевизор**: хатӗр телевизор пулнине хатӗр ҫинчех вулаҫҫӗ; нимӗн те ямаҫҫӗ.
- **Телефон папки**: вырӑнти тетел кӑна, усӑ куракан ячӗпе тата парольпе, ахаль HTTP урлӑ (пӑхӑр [Ку телефона тетелте пайласси](#share-this-phone-on-the-network)).
- **Камера**: Spatial 2.5D плеерӗ кӑна усӑ курать, хатӗр ҫинче; ӳкерчӗксене нихӑҫан та упрамаҫҫӗ, ниҫта та ямаҫҫӗ.
- **Компьютер ҫинче** (Immuch360 Desktop, Windows тӗрӗслев версийӗ): приложени эсир суйланӑ папкӑсене кӑна вулать, хӑйӗн индексне, миниатюрисене тата кэшне компьютер ҫинче упрать, парольсемпе токенсене Windows даннӑйӗсен хӳтӗлевӗпе упрать, сирӗн Windows аккаунчӗ валли кӑна. Компьютер папки телефон папкин йӗркисене пӑхӑнать, Windows пӗтӗм халӑх тетелӗ тесе палӑртнӑ тетелте, е унӑн тӗсне палласа илеймен тетелте, эсир хӑвӑр каламасан хута каймасть.

## Аталану плана

Мӗн халлӗхе тумасӑр юлнӑ, чи пулма пултараканни малта. Кунта нимӗн те сӑмах пани мар, [issue tracker](https://github.com/freeKC/Immuch360/issues) ҫинчи отзывсем малтан мӗн тумаллине татса пама пулӑшаҫҫӗ.

- **Immuch360 Desktop, малтан Windows**: пӗрремӗш тӗрӗслев версийӗ тухрӗ (пӑхӑр [Windows компьютерӗ ҫинче](#on-a-windows-computer-immuch360-desktop-preview)). Малалла, видео выляттарасси (малтан тикӗс видеосем, унтан 360°, 3D, VR180 тата чӗрӗ файлсем), ноутбукӑн икӗ видеокарти ҫинче виҫнӗскер; унтан кашни функцие Windows компьютерӗ ҫинче тӗрӗслесси тата унӑн тӳрлетӗвӗсем; унтан веб-камерӑпа Spatial 2.5D; унтан Linux тата macOS, пакетсем, алӑ пусни тата ҫӗнелӳсем.
- **Google Play**: build 18 ӗҫлет; build 20 2026 ҫулхи юпа уйӑхӗн 7-мӗшӗнченпе Google тӗрӗслевӗнче, build 19 вырӑнне. Build 21 телефонсемпе планшетсенче нимӗн те улӑштармасть.
- **App Store**: 3.3.0 версийӗ Apple тӗрӗсленине кӗтет; унра build 11 функцийӗсем, ҫавӑнпа Immich-а тиесе ярасси тата видео декодерне тӗрӗслесси (build 15) тата чӗрӗ Insta360 файлӗсем (build 16) App Store-ӑн тепӗр ҫӗнелӗвӗпе килеҫҫӗ. Ӗҫлеме тытӑнсан каҫӑ кунта хушӑнать.
- **Meta Horizon Store**: Meta страницӑна 2026 ҫулхи юпа уйӑхӗн 7-мӗшӗнче build 14-па ырланӑ. Build 21-а унӑн пӗрремӗш ҫӗнелӗвӗ евӗр панӑ: вӑл build 14-ран пуҫласа мӗн пуррине пурне те илсе килет (тетел папкинчен Immich-а тиесси, шлем декодерлама пултарнине кура суйланӑ видео ҫӑлкуҫӗ, Insta360, GoPro тата DJI чӗрӗ файлӗсем, DLNA, телефона тетелте уҫасси, Apple тӑвӑмлӑ сӑнӳкерчӗкӗсем, Plex Media Server библиотекисем, Tapo камерисем), лавкка ӑна Quest 2, Quest Pro, Quest 3 тата 3S валли кӑтартать. Страница уҫӑ пулсан лавкка каҫи кунта хушӑнать; sideload мелӗпе лартнӑ копие малтан кӑларса пӑрахмалла (пӑхӑр [Лартасси](#install)).
- **Лавккасенчи страницӑсем**: Google Play страницине 2026 ҫулхи юпа уйӑхӗнче ҫӗнӗ скриншотсемпе ҫӗнӗрен ҫырнӑ, телевизор релизӗпе вӑл телевизор скриншочӗсене тата телевизор баннерне илӗ. App Store текстӗ халӗ те пӗрремӗш build-сене ҫырса кӑтартать (360° сӑнӳкерчӗксемпе видеосем, чӗрӗ файлсем тикӗс курӑнаҫҫӗ); вӑл 3D, VR180 тата Spatial пӑхавҫисене, серверсӑр режима, тетел папкисене, медиа плеера тата чӗрӗ Insta360 файлӗсене кӑтартӗ. Build 20-ӑн Tapo камерисене уҫӑ кодлӑ [pytapo](https://github.com/JurajNyiri/pytapo), [Home Assistant Tapo Control](https://github.com/JurajNyiri/HomeAssistant-Tapo-Control) тата [python-kasa](https://github.com/python-kasa/python-kasa) проекчӗсем ҫак камерӑсем ҫинчен ҫырса кӑтартнине тӗпе хурса ҫырнӑ.

Мӗншӗн форк: мобильлӗ хатӗрте 360° пӑхассине 2024 ҫулхи кӑрлачран ыйтаҫҫӗ, официаллӑ приложенире вӑл халӗ те ҫук; сӑнӳкерчӗк пӑхавҫине upstream-ра [#31169](https://github.com/immich-app/immich/pull/31169) ӑшӗнче тӗрӗслеҫҫӗ. Ку форк ӑна халех парать, чӑн хатӗрсенчен отзывсем пухать, тытса тӑракансем мӗн кирлӗ тесе шутланине пӗчӗк pull request-семпе Immich-а сӗнӗ. Meta Quest курӑнӑмӗ Meta Spatial SDK-па усӑ курать, вӑл уҫӑ кодлӑ мар, ҫавӑнпа ку форкра юлать.

Ку страницӑри телефон ӳкерчӗкӗсене эмуляторти Android build-ӗнче, акӑлчан интерфейсӗпе тата [Poly Haven](https://polyhaven.com) сайтӗнчи CC0 панорамӑсемпе илнӗ.
