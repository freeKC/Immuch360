# Immuch360

**Хӑвӑн ӳкерчӗксем. Кашни экранра. Кашни кӗтесрен.**

Хатӗрӳнтен, NAS-унтан, Immich серверунтан, камерусенчен тата дронунтан тӳрем, 360° тата 3D ӳкерчӗксемпе видеосем. Аккаунт кирлӗ мар. Immuch360 тӳлевсӗр тата уҫӑ кодлӑ программа, вӑл санӑн ӳкерчӗкӳсемпе видеоусене вӗсем ӑҫта выртаҫҫӗ, ҫавӑнтах вулать тата кашнине хӑйне килӗшекен курӑмра кӑтартать: тӳрем, эсӗ тавра пӑхакан сфера пек, 3D евӗр е гарнитурӑра сан тавра пӗтӗмпех. Вӑл телефонсем, планшетсем, телевизорсем, Meta Quest гарнитурисем тата компьютерсем ҫинче ӗҫлет.

**Ҫӗнӗ: хӑвӑн тӳрем ӳкерчӗксем, 3D-ра.** Компьютерта ӳкерчӗк суйла та 3D ӳкерчӗк, ӑшне кӗме пултаракан 3D сцена е сан тавра вырӑнӑн юлнӑ пайне шухӑшласа кӑларакан 360° панорама ил. Meta Quest 3 е 3S ӑшӗнче "ИИ рельефӗ" тӳмене пӗрре пус, кирек мӗнле тӳрем ӳкерчӗк те рельеф илет. ИИ хӑвӑн компьютерунта тата гарнитурунта ӗҫлет, нимӗн те ниҫта та каймасть. Сӑнав мелӗнче, автор ӑна гарнитурӑра халлӗхе тӗрӗслемен (пӗрремӗш тест юпа уйӑхӗн 30-мӗшӗнче). [Мӗнле тумаллине пӑх](#turn-one-photo-into-3d-a-scene-a-panorama).

## Кам валли

- **Санӑн ӳкерчӗксем тӳрем** тата эсӗ вӗсене 3D-ра, гарнитурӑра ӑшне тайӑлмалли сцена пек е 360° панорама ӑшӗнче, 3D камерасӑр курасшӑн: [пӗр ӳкерчӗкрен 3D, сцена, панорама ту](#turn-one-photo-into-3d-a-scene-a-panorama), ҫӗнӗ, ӑна ИИ хӑвӑн компьютерунта тӑвать.
- **Эсӗ 360° е 3D ӳкеретӗн** тата ӳкерчӗкӳсенче тавра пӑхасшӑн, вӗсене тӳрем, йӗкӗреленнӗ е тӑсӑлнӑ курасшӑн мар: [360°, VR180 тата 3D](#explore-panoramas-360-vr180-and-3d).
- **Ӳкерчӗкӳсемпе фильмусем NAS, компьютер, Plex е Immich ҫинче выртаҫҫӗ** тата эсӗ вӗсене нимӗн те копилемесӗр телевизорта курасшӑн: [телевизорта](#watch-on-the-tv-with-the-remote), [NAS, пайсем тата Plex](#play-the-files-of-a-nas-a-computer-a-media-server-or-plex).
- **Санӑн Meta Quest пур** тата эсӗ хӑвӑн ӳкерчӗкӳсемпе видеоусен ӑшне кӗресшӗн: [гарнитурӑра](#step-inside-your-photos-and-videos-with-a-meta-quest).
- **Эсӗ Immich тытатӑн** тата унӑн программине, ҫумне путаракан курӑмсене тата телефонран кӗртекен пысӑк экрансене илесшӗн: [хӑвӑн Immich библиотеки](#keep-your-immich-library-with-more), [Immich-пе танлаштарни](#compared-with-immich).
- **Эсӗ килӳне Tapo камерисемпе сӑнатӑн** тата вӗсене ӳкерчӗкӳсем ҫумӗнче, телевизорта та курасшӑн (чӑн камерӑпа халлӗхе тӗрӗсленмен): [килти камерӑсем](#watch-your-home-cameras-on-the-big-screen).
- **Эсӗ DJI дронне вӗҫтеретӗн** тата унӑн чӗрӗлле сӑнне DJI Fly-сӑр телефонра, сан ҫумри ҫынсем валли Meta Quest-ра е Android TV ҫинче курасшӑн (сӑнав мелӗнче): [хӑвӑн дронӗ](#see-what-your-drone-sees-on-your-phone).

Immuch360 аккаунчӗ туса хумалла мар, пирӗн пата нимӗн те килмест: программа хӑвӑн хатӗрӳсемпе тата эсӗ суйланӑ серверсемпе кӑна калаҫать, ИИ компонентне эсӗ ыйтсан кӑна тиесе илет.

## Хатӗрӳ ҫине вырнаҫтар

Программӑна хатӗрӳн магазинӗнчен ил, вӑл унта кӑларнӑ пулсан, е хальлӗхе [Releases](https://github.com/freeKC/Immuch360/releases) страницӑран ил.

### Android телефонсемпе планшетсем

1. [Google Play](https://play.google.com/store/apps/details?id=com.aprogsys.immuch360), е [Releases](https://github.com/freeKC/Immuch360/releases) страницăн APK-йĕ: телефон валлин `Immuch360-v<version>-arm64-v8a-release.apk`; пур çĕрте те ĕçлекен `Immuch360-v<version>-release.apk` универсаллă файл.
2. Программа официаллă Immich программи çумне вырнаҫать. GitHub-ри APK хăй тĕллĕн çĕнелмест: Releases страницăна сăна тăр; магазинран программа вырнаҫтарнă пулсан, çĕнелÿсене çав магазинранах ил.

### iPhone тата iPad

1. App Store верси Apple тĕрĕслевĕнче. Ăна кăларичченех, Mac çинче Xcode-па программана хăвăн алăпа пух, кур [Хăвăн алăпа пухса ту](../docs/immuch360/build.md).
2. "Серверсӑр усӑ кур" çине пус, е "Immich сервера ҫыхӑн" хăвăн серверпе кĕме; икĕшĕ те пуçламăш страницăра 24-мĕш сборкаран пуçласа.

<a id="android-tv-and-google-tv"></a>
### Android TV тата Google TV

1. Google Play телевизорсем валлин программа сунтарма пуçламасăрах, [Releases](https://github.com/freeKC/Immuch360/releases) страницăн универсаллă `Immuch360-v<version>-release.apk` файлне ил.
2. Телевизорта аталантаракан параметрӗсене тата USB отладкӑна ҫутӑр (Google TV ҫинче: Ӗнерленӳсем, Система, Хатӗр ҫинчен, «Android TV OS build» ҫичӗ хут суйлӑр, унтан Ӗнерленӳсем, Система, Аталантаракан параметрӗсем; ячӗсем телевизор тӑрӑх улшӑнаҫҫӗ).
3. Ҫав тетелти компьютертан, adb-па (Android SDK Platform Tools): `adb connect <address of the TV>`, телевизорти ыйтӑва йышӑнӑр, унтан `adb install -r Immuch360-v<version>-release.apk`.
4. Приложени телевизор приложенийӗсем хушшинче хӑйӗн баннерӗпе курӑнать. Тепӗр релиза ҫапла майпах лартӑр: `-r` кӗрӗве тата ӗнерленӳсене упрать.

### Пӗр ӳкерчӗкрен 3D, сцена, панорама ту

Санӑн ӳкерчӗксен нумайӑшӗ тӳрем, вӗсене каялла кайса 3D-ра ҫӗнӗрен ӳкерме май ҫук. Immuch360 вӗсене тарӑнлӑх парать. Компьютерунта пӗр ӳкерчӗк **3D ӳкерчӗк**, гарнитурӑра ӑшне тайӑлмалли **3D сцена** е сан тавра вырӑнӑн юлнӑ пайне шухӑшласа кӑларакан **360° панорама** пулса тӑрать. Quest 3 е 3S рельефа хӑй тӑвать, кирек мӗнле тӳрем ӳкерчӗк валли. Пурте хӑвӑн компьютерунта тата гарнитурунта ӗҫлет: пӗлӗт ҫук, аккаунт ҫук, санӑн оригиналусене нихҫан та улӑштармаҫҫӗ. 32-мӗш сборкӑра тата 13-мӗш desktop сборкӑра ҫӗнни, сӑнав мелӗнче тата йӑлапа ҫутӑ. Immich программинче ҫакӑн пек нимӗн те ҫук.

**Компьютерта**, Windows, Linux е macOS ҫинчи 13-мӗш desktop сборкӑпа:

1. Библиотекӑра е папкӑра пӗр е темиҫе ӳкерчӗк суйла, унтан "3D ту (ИИ)".
2. Мӗн кирлине суйла: "3D сӑнӳкерчӗк", "3D сцена", "360° панорама" е хӑвӑн 360° ӳкерчӗкӳсем валли "360° сӑнӳкерчӗкӗн 3D версийӗ". Чӳрече ИИ мӗне шутласа е шухӑшласа кӑларассине калать ("Ку панорамӑн 96% яхӑн пайне ИИ шухӑшласа кӑларӗ"), ку компьютерта мӗн чухлӗ вӑхӑт кайнине тата файл ӑҫта каясси: "Оригинал ҫумӗнче" е "Эпӗ суйланӑ папка". Ку компьютер тума пултарайман тӗс сӑрӑ юлать, сӑлтавӗпе, сӑмахран "Mac ҫинче халлӗхе ҫук" е "Видеокартӑн асӑмӗ 6.0 GiB, 360° панорамӑсем валли 7.5 GiB кирлӗ".
3. Пӗрремӗш хут чӳрече ҫав тӗсӗн компоненчӗсене сӗнет: Тиесе ил, пӗрре. Вӗсем ку компьютерта ӗҫлеҫҫӗ, кайран интернетсӑр та ӗҫлеҫҫӗ.
4. Улӑштар. Ӗҫсем икӗ йӗрпе черете тӑраҫҫӗ, процессор тата видеокарта, вӗсен утӑмӗсемпе тата юлнӑ вӑхӑтпа; Cancel кирек хӑҫан та пӗр ӗҫе чарать, программӑран тухас умӗн вӑл малтан ыйтать.
5. Результата уҫ. 3D ӳкерчӗк "Сулахай куҫ", "Юнашар", "Силлентерни" (ку страницӑн ҫиелти анимацийӗ) е куҫлӑх валли "Хӗрлӗпе сенкер" пек курӑнать; сценӑн "3D-ра малтанлӑха пӑх" пур, ӑна мышьпа е touchpad-па ҫавӑраҫҫӗ, тата "Урӑх 3D приложенисем валли экспортла (.glb)"; панорама 360° курӑмра уҫӑлать.

**Мӗн чӑн, мӗн чӑн мар, яланах калаҫҫӗ.** Ку тӗп шухӑш, вӗтӗ шрифт мар. 3D ӳкерчӗкӗн рельефне пӗр ӳкерчӗкрен шутласа кӑлараҫҫӗ, ӳкерчӗк пытарнине тултараҫҫӗ, вӑл чӑн мар. Сцена вӑл "Пӗр сӑнӳкерчӗкрен ҫӗнӗрен тунӑ, ӑна унӑн чикки ӑшӗнче ҫеҫ курса ҫаврӑнӑр". Панорама санӑн чӑн пикселусене хӑйсен вырӑнӗнче хӑварать, юлнине шухӑшласа кӑларать, ахаль ӳкерчӗк валли сферӑн 90% яхӑн, чӳрече пуҫличчен мӗн чухлине калать. Программа ҫакна эсӗ пӑхнӑ ҫӗрте калать, "ИИ шутласа кӑларнӑ рельеф", "Сӑнӳкерчӗк хӗррисенчен тулашри пайне ИИ туса кӑларнӑ" тата паллӑсемпе, файлсем те калаҫҫӗ: пирӗн XMP-ра, сценӑсемпе панорамӑсенче вара ИИ тунӑ ӳкерчӗкӗн IPTC цифрӑлла ҫӑлкуҫ тӗсӗнче, ытти программӑсем тунӑ панорамӑна чӑн 360° ӳкерчӗкрен уйӑрма пултарччӑр. Санӑн оригиналусене нихҫан та улӑштармаҫҫӗ, санӑн компьютерунтан е гарнитурунтан нимӗн те тухмасть. Чӳрече калашле: "Вӗҫленнӗ улӑштару лайӑх результата шантармасть."

**Мӗн тӗрӗсленӗ**, 2026 ҫулхи юпа уйӑхӗн 29-мӗшӗ тӗлне, ку кодӑн тест сборкисемпе: 3D ӳкерчӗксене Linux компьютерӗ ҫинчи контейнерта Linux программипе, интернетсӑр та; сценӑсене RTX 4060 Laptop GPU ноутбукӗ ҫинче Windows программипе (вуннӑ 2 min 39 s хушшинче) тата Linux компьютерӗ ҫинче движокпа; ҫав ноутбук ҫинче тӑватӑ панорама, кашнинех 4 min 16 s-ран 4 min 44 s-а ҫити, вӗсен 3D версийӗсем 30 s яхӑн, Cancel-па, вӗлернӗ программӑпа, видеокартӑна йышӑнакан урӑх программӑпа, тестсем вӑхӑтӗнче программӑн нимӗнле тетел ҫыхӑнӑвӗсӗр. Видео вӑхӑтӗнче OK элеменчӗсене яр тата чар суйланӑ пек кӑтартать, иккӗмӗш OK чарса лартать; унтан -10 s тата +10 s кнопкисем, фильмра пулсан аудио тата субтитр кнопкисем пыраҫҫӗ. 29-мӗш сборкӑран пуҫласа яр тӳминчен аялалла пуссан вӑхӑт йӗрне ҫитетӗн: сулахай тата сылтӑм пӗрре пуснӑ май 10 s куҫараҫҫӗ, тытса тӑрсан хӑвӑртрах, OK вылять е чарать. Элеменчӗсемпе дата юлашки тӳмерен 5 s иртсен пытанаҫҫӗ, унтан сулахай тата сылтӑм малтанхи е тепӗр файла куҫараҫҫӗ; пайра ҫав файл хӑйӗн страницинче уҫӑлать, ӑна тытса пыракан элеменчӗсемпе. Телевизорта видеосем урӑх ҫаврӑнса вылямаҫҫӗ, эсӗ Ӗнерленӳсем, Asset Viewer, Videos, Looping ҫутӑтмасан.
3. Menu тӳми, Info тӳми е тытса тӑнӑ OK ӳкерчӗкӗн е видеон тӗплӗ даннӑйӗсене уҫать, вулама кӑна: дата, вырӑн, камера, кодек, виҫе тата битрейт. Телевизор декодлаймасть пулсан, видео ҫакна хӑй пӗлтерет, хӑйӗн кодекӗпе, виҫипе тата телевизор декодерӗсен чикӗпе, вӗҫӗмсӗр тиенмест; декодерсем вӑйӗнчен пысӑкрах 360° видео 360° плеера уҫиччен ыйтать, сӑлтавне профиль менюн Logs страницинче ҫырса хураҫҫӗ.

28-мӗш сборка юпа уйӑхӗн 23-мӗшӗнче чӑн Android TV ҫинче ӗҫленӗ; 29-мӗш сборкӑн видео тӳрлетӗвӗсем ҫав тӗрӗслеврен тухнӑ, вӗсене Google TV эмуляторӗнче тӗрӗсленӗ, ҫав телевизор ҫинче халлӗхе мар.

#### LG телевизорӗ ҫинче (webOS)

Immich-ӑн хӑйӗн программисем LG телевизорӗ ҫине вырнаҫмаҫҫӗ. Immuch360-ӑн webOS 5.0 тата ҫӗнӗрех LG телевизорӗсем (2020 ҫулхи телевизорсенчен пуҫласа) валли хӑйӗн телевизор программи пур, ӑна пультпа тата Magic Remote-па тытса пыраҫҫӗ: вӑл хӑвӑн Immich серверна, тетел папкусене, Plex серверна тата Tapo камерусене кӑтартать, 360° ӳкерчӗкӳсене йӗпписемпе ҫавӑракан сфера ҫине вырнаҫтарать. Вӑл Seeky91 тунӑ [immich-tv-webos](https://github.com/Seeky91/immich-tv-webos) никӗсӗ ҫинче тунӑ, вӑл вӑхӑт шкалине, альбомсене, ҫынсене, вырӑнсене, шырава, слайд-шоу тата телефонпа кӗрӗве илсе килнӗ; Seeky91-не тав. 1.0.0 версине юпа уйӑхӗн 24-мӗшӗнче LG Content Store-а янӑ, вӑл LG Cloud Test Lab-ӗнчи webOS 25 телевизорӗсем ҫинче ӗҫленӗ; LG ӑна ырламасӑр вӑл Developer Mode урлӑ вырнаҫать, [Issues](https://github.com/freeKC/Immuch360/issues) страницӑри кашни отчет пулӑшать.

1. Ӑна Developer Mode ҫинчи телевизор ҫине вырнаҫтар, [Вырнаҫтарни](#lg-tvs-webos) пӑх. Унӑн хӑйӗн app id пур, ҫавӑнпа вӑл Seeky91-ӑн Immich TV программипе юнашар вырнаҫать.
2. Телефонпа (QR кода сканла), электрон почтӑпа тата паропа е API ҫӑрипе кӗр.
3. Йӗпписемпе тата OK-па пӑхса тух. Курӑмра сулахай тата сылтӑм малтанхи е тепӗр ӳкерчӗке е видеона куҫараҫҫӗ, видео вылянӑ вӑхӑтра та; элеменчӗсем юлашки тӳмерен 5 s иртсен пытанаҫҫӗ; Info тӗплӗ даннӑйсене уҫать; канал тӳмисем зум тӑваҫҫӗ; Magic Remote указателӗпе кустӑрми ӗҫлеҫҫӗ. 1.0.1 версирен пуҫласа, GitHub ҫинче, Ҫӳлелле ӳкерчӗке тӳрех пысӑклатать, унтан йӗпписем ӑна куҫараҫҫӗ, Каялла пӗчӗклетет, ӳкерчӗк килсе ҫитмен чухне Тиенет палли курӑнать.
4. 360° ӳкерчӗк сфера ҫинче уҫӑлать: йӗппине кашни пуссан вӑл пӗр утӑм ҫаврӑнать, тытса тӑнӑ тӳме ӑна ҫавӑрма чарӑнмасть. "360° евӗр пӑх" сервер палӑртман 2:1 ӳкерчӗке те витет; VR180 ӳкерчӗк ҫур сфера ҫинче, 3D ӳкерчӗк пӗр куҫпа курӑнать. Сарӑ тата кӑвак тӳмесем тӳрем ӳкерчӗке ҫавӑраҫҫӗ.
5. Кӗнӗ хыҫҫӑн, программӑн айккинчи панелӗнчи "Network shares": SMB, WebDAV е DLNA пайне, Plex сервера (plex.tv/link ҫинчи кодпа кӗнӗ) е Tapo камерине хуш. Вӗсен ӳкерчӗкӗсем ҫав курӑмрах уҫӑлаҫҫӗ, 360° ӳкерчӗксем сфера ҫинче.

1.0.0 версине LG Content Store валли тунӑ: Каялла «Сӑнӳкерчӗксем» ҫинчен е пуҫламӑш страницӑран программӑран кашни webOS верси кӗтнӗ пек тухать, малтан уҫӑ попап чӳречене хупать; 15 s хушшинче хуравламан сервер мӗншӗн пулнине калакан пӗлтерӳпе тата «Тепӗр хут» кнопкипе вӗҫленет; вӑрттӑнлӑх политики программӑра уҫӑлать, [унӑн LG телевизорӗсен пайне](../PRIVACY.md#lg-tvs-webos) телефонра вулама QR кодпа; телевизор LG ӳкерчӗк программисенчен ыйтнӑ пек хӑйӗн Gallery ӳкерчӗк режимне усӑ курать; иккӗмӗш пакет вара LG 1280x720 программасем паракан Full HD телевизорсем валли килӗшет.

Чиккисем: SMB валли webOS 22 (2022 ҫулхи телевизорсем) е ҫӗнӗрех кирлӗ. Пайсем, Plex тата камерасем программӑн телевизор ҫинчи хӑйӗн служби урлӑ килеҫҫӗ, вӑл вӗсене программа валли вулать, вӗсене проектӑн сборка серверӗ ҫинче чӑн серверсемпе тата симуляциленӗ камерӑпа тӗрӗсленӗ, телевизор ҫинче халлӗхе мар. Камерӑн чӗрӗлле курӑмӗ видео кӑна. Халлӗхе ҫук: камерасен ҫырнисем (2026 ҫулхи раштав уйӑхӗччен мар) тата вӗсен сасси, сфера ҫинчи 360° видеосем (вӗсем тӳрем выляҫҫӗ, пӗлтерӳпе), тиесе яру. 25-мӗшчен webOS ҫинче Immich умӗнчи reverse proxy CORS заголовокӗсене ярса тӑмалла; программа ҫак йывӑрлӑха тӗл пулсан вӗсене ӑнлантарать. webOS 26 халлӗхе тӗрӗсленмен.

### Телевизора, гарнитурӑна е компьютера телефонпа кӗрт

**Сканла. Кӗр. Пӑх.** Сервер адресне, электрон почтӑна тата парольне телевизор пульчӗпе е гарнитурӑра ҫырма минутсем кирлӗ. Телефонри Immuch360 хӑвӑн Immich серверне кӗнӗ пулсан, телевизор, Meta Quest е компьютер пӗрер ҫеккунтрах кӗрет: пысӑк экран QR код кӑтартать, телефон ӑна сканлать, эсӗ ҫирӗплететӗн, вара экран хӑвӑн библиотекине уҫать. Телефон программипе усӑ курсан, санӑн пароль телефонрах юлать. Immich программинче ҫакӑн пек нимӗн те ҫук.

</p>

1. Пысӑк экранра (Android TV тата Google TV, Meta Quest чӳречи, Windows, Linux е macOS) "Immich сервера ҫыхӑн" суйла: кӗрӳ страници сервер формипе юнашар "Sign in with your phone", QR код тата 10 паллӑллӑ код кӑтартать.
2. Хӑвӑн сервера кӗнӗ телефонра: Ӗнерленӳсем, "Connect a TV or computer", унтан "Scan the code". Meta Quest-ра унӑн экранне телефон сканлаймасть, ҫавӑнпа "Enter a code instead" суйла тата гарнитура кӑтартакан кода ҫыр.
3. Телефон "Sign (the screen) in?" тесе ыйтать тата улттӑ цифрӑллӑ хисеп кӑтартать: экран ҫав хисепех кӑтартнине тӗрӗсле, унтан Sign in ҫине пус. Экран хӑвӑн хроникине уҫать.

Хӑрушсӑрлӑхӗ: телефонпа экран пӗр килти тетелре пулмалла, код икӗ минутран ытла тӑмасть тата пӗрре кӑна ӗҫлет. Телефон хӑвӑн серверӗнчен ҫав экран валли ҫӗнӗ сеанс ыйтать, ӑна экран ячӗпе калать ("Immuch360 on Living room TV"), тата ӑна шифрласа экрана ярать, ҫавӑнпа санӑн пароль телефонран нихӑҫан та тухмасть. "Connect a TV or computer" ҫак телефон кӗртнӗ экрансен списокне кӑтартать, кашнинче Sign out пур, Immich вӗсене Шута ҫырни ӗнерленӳ, Authorized devices ӑшӗнче кӑтартать, унта вӗсене пӑрахӑҫлама та пулать. Телефонран тухсан вӗсем те тухаҫҫӗ.

Телефон енӗ халь Android ҫинче ӗҫлет, iPhone тата iPad ҫинче вара iOS-ӑн тепӗр версийӗнчен пуҫласа ӗҫлӗ. Телефонра Immuch360 ҫук пулсан, кода телефон камерипе сканла: браузерта экран паракан страница уҫӑлать, электрон почтӑпа пароль валли, вӗсене шифрлаҫҫӗ тата пӗрре кӑна усӑ кураҫҫӗ. LG телевизорӗсем хӑйсен QR кодӗпе, телефон браузерӗнче кӗреҫҫӗ; 28-мӗш сборкӑран пуҫласа телефон программин сканерӗ ӑна палласа илет тата ҫав страницӑна уҫать. Samsung телевизорӗсене халлӗхе ҫырса кӗртеҫҫӗ.

Тата: [телефонпа кӗрӳ](../docs/immuch360/user-guide.md#sign-in-a-tv-a-headset-or-a-computer-with-your-phone), [экрансем мӗн яраҫҫӗ тата мӗн упраҫҫӗ](../docs/immuch360/technical-details.md#sign-in-with-your-phone).

### NAS, компьютер, медиа сервер е Plex файлӗсене выля

Хӑвӑн видеосем NAS, компьютер, медиа сервер е Plex ҫинче тӑраҫҫӗ. Immuch360 хӑй тӗллӗн тетелӳнти серверсене тупать, вӗсене пӑхса тухать тата вӗсен ӳкерчӗкӗсемпе видеосене хӑйсен вырӑнӗнчех, программӑн кашни курӑмӗнче, нимӗн те копилемесӗр кӑтартать: SMB (Samba, Windows пайӗсем), WebDAV (Nextcloud, Synology тата ыттисем) тата DLNA медиа серверӗсем (Jellyfin, Emby, minidlna, NAS, TV приставки). Телефон хӑй галерейине Wi-Fi тӑрӑх гарнитура е кирек мӗнле WebDAV клиент валли пайлама пултарать, Windows компьютерӗ те ҫапла тума пултарать.

1. «Библиотека» вкладкине уç, унтан «Тетел папкисем», унтан + тата "Тетел папки (NAS, компьютер, медиа сервер)". 24-мĕш сборкаран пуçласа, "Тетел папкине е медиа сервера хуш" пуçламăш страницăра Тетел папкисене тÿрех уçать, серверсĕр.
2. "Тетелте тупӑнчӗ" айĕнчи серверĕ çине пус, е формăна хăвăн алăпах тултар: тĕс, сервер ячĕ е адресĕ, пай е çул, пуçламăш папка, усă куракан ячĕ тата пароль.

Плеерсем кирлӗ байтсене программа ӑшӗнчи мост урлӑ, байт диапазонӗсемпе вулаҫҫӗ, ҫавӑнпа малалла-каялла куҫма пулать тата хатӗр ҫинче нимӗн те упранмасть; SMB видеона лӑпкӑ кӑтартмашкӑн ултӑ ҫыхӑнӑва ҫити пӗр вӑхӑтрах усӑ курса вулаҫҫӗ. 29-мӗш сборкӑран пуҫласа M2TS форматпа ҫырса илнӗ фильмсем (Blu-ray, AVCHD видеокамерисем, телевизор рекордерӗсем) Android программинче SMB тата WebDAV пайӗсенчен тата вӗсене transport stream пек кӑтартакан DLNA серверӗсенчен выляҫҫӗ, 0 калӑпӑш кӑтартакан DLNA сервер вара урӑх пушӑ видео памасть.

LG телевизорӗ ҫинче Plex-а plex.tv/link ҫинчи кодпа кӗртеҫҫӗ.

Тата: [тетел папкисем](../docs/immuch360/user-guide.md#network-shares-a-nas-a-computer-or-a-media-server), [ку телефона тетелре пайла](../docs/immuch360/user-guide.md#share-this-phone-on-the-network), [DLNA медиа серверӗсем](../docs/immuch360/user-guide.md#dlna-media-servers), [Plex Media Server](../docs/immuch360/user-guide.md#plex-media-server-without-plextv).

### Хӑвӑн Immich библиотекине упра, тата ытларах

[Immich](https://github.com/immich-app/immich) серверпе Immuch360 вăл Immich мобильлĕ программи, веб-программăн çав серверĕпех тата çав аккаунтĕпех: резерв копи, хроника, альбомсем, шырав, çынсем, аса илÿсем, пайлашу, партнерсем, пурте хăвăн серверпе синхронлаштарнă. Вăл официаллă программа çумне вырнаҫать. Унчченкинчен ытла: 360° паллăпа список, кашни путаракан курăм, кашни видео валлин тĕп файлпа серверĕн транскодланă потокĕ хушшинчи суйлав, видео техникăлла тĕплĕхĕ, тата пайран е хатĕртен алăпа серверне янă файлсем.

1. Пуçламăш страницăра, "Immich сервера ҫыхӑн" çине пус, унтан хăвăн сервер адресĕпе, электрон почтăпа тата парольпе кĕр, Immich программинчи пекех; Каялла пуçламăш страницăна тавăрать. 23-мĕш сборка таранччен кĕрÿ страници тÿрех уçăлнă. Хăвăн библиотека, альбомсем тата резерв копи настройкисем хăвăн аккаунтăнни пулса тăраççĕ.
2. Настройкасенче, Файл курăмĕнче, Видеосенче, "Видео ҫăлкуҫĕ" ку хатĕр декодлама пултарнă чухне тĕп файла, яланах тĕп файла, е яланах транскодланă потока суйлать.
3. Программа çук çынна 360° ÿкерчĕк кăтартмашкăн, ăна Immich пайланă ссылкăпа пайла: Immich веб-программи ăна унăн браузерĕнче сфера пек кăтартать.

Advanced батарейӑн напряженине тата температурине, ҫул-йӗре (унӑн нулӗ ҫурҫӗрпе тӗрӗсленмен) тата моторсене хушать, Diagnostics вара ҫыхӑну паракан кашни цифрӑна, батарея токне те. Спутниксем, вырӑн тата киле ҫити инҫеш кӑтартӑнмаҫҫӗ. Цифрисене DJI Fly-па халлӗхе танлаштарман: вӗсем тӑрӑх ан вӗҫтер.

**Чӑрмав унки**, стандартпа ҫутӑ: дронӑн сенсорӗсем ҫывӑхра темӗн курсан, ӳкерчӗкӗн варринче тавра ҫутӑ витӗр куракан ункӑ тухать, чӑрмав еннелле дуга, вӑл ҫывхарнӑ май янтарь тӗсӗнчен хӗрлӗ тӗсе куҫать, ҫумӗнче унӑн инҫешӗ тата хӑвӑртланса пыракан кӗске шаккав сасси; ҫывӑхра нимӗн те ҫук пулсан, нимӗн те тухмасть. Ункӑпа дуга енне юпа уйӑхӗн 25-мӗшӗнче пӳлӗмри вӗҫевре, ен суйлав пулнӑ тест версийӗ ҫинче тӗрӗсленӗ; стандартпа кӑтартнине 30-мӗш сборкӑпа пӗрремӗш хут тӗрӗслеҫҫӗ. Advanced ӑшӗнче инҫешсене лартатӑн ("Glow from", 3,0 m, тата "Strong glow from", 1,0 m), ункӑ вырӑнне ӳкерчӗк хӗррисенчи рамкӑна суйлатӑн, е ункӑна, унӑн сассине е чӗтревне сӳнтеретӗн. Вӑл дронӑн сенсорӗсем пӗлтернине кӑна кӑтартать: Sport режимӗнче е чӑрмавсенчен пӑрӑнасси сӳннӗ чухне нимӗн те ҫук, ҫутӑ ҫукки вара ҫул уҫӑ тенине пӗлтермест. Пӗлтерӳ кӑна: Immuch360 дрона нихӑҫан та тытса пымасть те, чармасть те.

1. Drone карточки Библиотекӑра, "DJI live video" унӑн страницинче: Ӗнерленӳсем, Advanced ӑшӗнчи "DJI live video (experimental)" стандартпа ҫутӑ.
2. Дронпа пульта ҫут, DJI Fly-а хуп, унтан "DJI live video" уҫ тата хӑрушсӑрлӑх асӑрхаттарӑвне вула.
3. Пульта телефона хӑйӗн кабелӗпе ҫых. Android ӑна хӑш программа уҫмаллине ыйтсан, Immuch360-а "Яланах"-сӑр суйла, унсӑрӑн пульт DJI Fly-ран кайӗ; USB режимӗ ҫинчен ыйтсан, зарядка кӑна суйла. Ун хыҫҫӑн пульта ҫыхсанах ку экран хӑех уҫӑлать ("Open this screen when the remote is plugged in", Advanced ӑшӗнче стандартпа ҫутӑ).
4. Remote, Drone тата Picture черетпе ҫутӑлаҫҫӗ, сӑн темиҫе ҫеккунтрах тулли экранпа тухать. Виҫӗ кнопка (тухмалли, "Send to a headset or a TV" тата Advanced) тата кӑтартусем сӑн ҫумӗнчи хура йӗрсенче вырнаҫнӑ. "Live" евӗр паллӑсем пилӗк ҫеккунт яхӑн иртсен ҫухалаҫҫӗ; кирек ӑҫта пуссан та вӗсем каялла тухаҫҫӗ, сӑн ҫинчи нимӗн те дрона витӗм кӳмест. Санран мӗн те пулин тума ыйтакан йӑнӑш юлать.
5. Advanced ӑшӗнче "Save a capture for a bug report" пур, вӑл ҫыхӑну ҫырӑвне `Download/Immuch360/dji-link` ӑшне ҫырать, "Play a saved capture" пульсӑр ҫырӑва тепӗр хут вылятма, тата Diagnostics, ҫыхӑну паракан кашни цифрӑпа.

Дронӑн ӳкерчӗкӗсемпе видеосене пульт урлӑ илме май ҫук, вӑл дронӑн хранилищине уҫмасть: вӗсене дронран хӑйӗнчен USB урлӑ е унӑн картинчен копиле, [аяларах](#bring-a-drones-or-a-camera-cards-photos-and-videos-to-immich) ҫырнӑ пек. Упраннӑ ҫырусене, страница каланӑ пек, хӑвӑнта упра: вӗсенче дронӑн видеовӗ, пультӑн тата вӗҫев хатӗрӗн серийлӗ номерӗсем пур, унӑн вырӑнӗ те пулма пултарать; Diagnostics кӑтартнипе [Issues](https://github.com/freeKC/Immuch360/issues) страницӑри отчет пулӑшать, уйрӑмах ытти DJI пульчӗсемпе.

#### Ӑна Meta Quest-ра е Android TV ҫинче пӑх

Пульта ҫыхнӑ телефон дронӑн сӑнне тата кӑтартӑвӗсене ҫав вырӑнти тетелти Meta Quest-ри е Android TV, Google TV ҫинчи Immuch360 патне яма пултарать, сан ҫумри ҫынсем валли. Гарнитура вӗсене чӳречере е, пысӑкрах, сан умӗнчи вӗҫев курӑмӗнче кӑтартать, телевизор вара тулли экранпа, телефонри пекех кӑтартусемпе тата чӑрмав ункипе. Вӗсем пӑхаҫҫӗ кӑна: гарнитура е телевизор мӗн тунин нимӗнӗ те пульта е дрона ҫитмест. Вӗсен "Пӑхмалли ҫеҫ" евӗр паллисем темиҫе ҫеккунтран ҫухалаҫҫӗ тата тӳмепе, пуснипе е кнопкӑпа каялла тухаҫҫӗ. Дронӑн сӑнӗ юпа уйӑхӗн 24-мӗшӗнче килти Wi-Fi урлӑ Quest 3 патне пӗрре ҫитнӗ; гарнитура чӳречине тата кӑтартусемпе чӑрмав ункиллӗ вӗҫев курӑмне 30-мӗш сборкӑпа пӗрремӗш хут тӗрӗслеҫҫӗ, Quest 2, Pro тата 3S тӗрӗсленмен. Гарнитурӑра ункӑ сӑнӑн варрине хупласан, унӑн менюнчи "Хӗррисенче рамка" варрине уҫӑ хӑварать. TCL Android TV ҫинче ҫыхӑнтарӑва тата сӑна юпа уйӑхӗн 25-мӗшӗнче тӗрӗсленӗ, малтанхи куҫару чухне сӑн чарӑнкаласа пынӑ тата симӗсрех тӗс илнӗ; юпа уйӑхӗн 26-мӗшӗнче, 30-мӗш сборкӑпа, тикӗс поток ҫине куҫнӑ хыҫҫӑн, дрон 18 Mbit/s янӑ вӗҫев тӑршшӗпех телевизор сӑна кӑтартса пынӑ, 7 хут чарӑнса, чи вӑрӑмми 1,7 s; сӑн мӗнле курӑннине ҫырса хурман. 31-мӗш сборкӑран пуҫласа телевизор ҫинчи хӑрушсӑрлӑх асӑрхаттарӑвӗ пульт фокусне тытса тӑрать (виджет тесчӗсемпе тӗрӗсленӗ, ҫав телевизор ҫинче халлӗхе мар); 30-мӗш сборкӑра унӑн айӗнчи курӑм фокуса илме пултарнӑ, ҫавӑнпа асӑрхаттарӑва вулама та, йышӑнма та май пулман, тухмалли пӗртен-пӗр ҫул Каялла пулнӑ, вӑл страницӑран тухать. Гарнитурӑна е телевизора пӑхса вӗҫтерме сан ҫумӗнче дрона куҫран ямасӑр сӑнакан ҫын кирлӗ (ЕС уҫӑ категорийӗ); унсӑрӑн дрона пӑх.

1. Телефонта, чӗрӗлле экранра "Send to a headset or a TV" ҫине пус тата ӑна ҫут.
2. **Meta Quest**: Immuch360, «Библиотека», Drone уҫ тата телефона суйла; телефон кӑтартакан кода ҫыр, ҫав телефон валли пӗрре. Сӑн чӳречере уҫӑлать; "Open the flight view" ӑна пысӑклатать, B е Y чӳречене каялла тавӑрать.
3. **Android TV тата Google TV**: Immuch360, «Библиотека», Drone уҫ. "Let this TV watch" айӗнче телевизор кодпа унӑн QR кодне кӑтартать: телефонта, ҫав панельтех "Add a TV" ҫине пус тата ӑна сканла е ҫыр. Унтан телевизорта телефона суйла тата OK пус: сӑн тулли экранпа тухать; OK цифрисене кӑтартать е пытарать, Menu вариантсене уҫать.
4. Телефонпа экран пӗр вырӑнти тетелте пулмалла. Килтен тухсан телефонӑн хотспотне ҫут, пулсан 5 GHz диапазонӗнче, тата гарнитурӑна е телевизора ӑна ҫых.
5. Йӑнӑш отчечӗ валли гарнитура менюнче тата телевизорӑн Options ӑшӗнче Diagnostics тата "Save a reception record" пур, вӑл ҫав экран мӗн йышӑннине упрать.

**Куҫару пахалӑхӗ** ("Ярас пахалӑх"), 30-мӗш сборкӑн ҫӗнӗлӗхӗ, телефонри "Анлӑ" ӑшӗнче: вӗҫевре дрон 18 Mbit/s яхӑн ярать, юпа уйӑхӗн 25-мӗшӗнче вара телефонран маршрутизатор урлӑ телевизор патне каякан килти Wi-Fi ҫулӗ ҫав тулли потока вӗҫев вӑхӑтӗн виҫҫӗмӗш пайӗнче кӑна илсе ҫитернӗ; юлнӑ вӑхӑтра телевизор сӑнӗ чарӑнкаласа пынӑ, саланнӑ тата симӗсрех тӗс илнӗ. "Хӑй тӗллӗн" (стандартпа) чухне Wi-Fi-ӗ ҫитӗнеймен экран тикӗс сӑн илет, ӑна телефон ун валли ҫӗнӗрен кодлать, 30 кадр/ҫеккунтпа 1080p таран тата унӑн Wi-Fi-ӗ илсе ҫитерекен хӑвӑртлӑхпа, саланас вырӑнне таса юлма тунӑ, сахалтарах тӗплӗхпе; унӑн Wi-Fi-ӗ тикӗс сӑна 30 s чарӑнмасӑр илсе ҫитерсен, тепӗр ларнӑ е вӗҫсе хӑпарнӑ чухне вӑл дронӑн хӑйӗн сӑнне таврӑнать; юпа уйӑхӗн 26-мӗшӗнче ҫав телевизорӑн Wi-Fi-ӗ ҫакна пӗрре те туман, телевизор тикӗс сӑнра юлнӑ, хӑйӗн 59 ҫеккунчӗн 44-ӗнче ҫеккунтра 15 кадрпа. "Тулли поток" дронӑн сӑнне ялан килнӗ пекех ярать, "Тикӗс поток" ялан телефонӑннине. Тикӗс сӑн телефон ҫинче пӗрремӗш хут юпа уйӑхӗн 26-мӗшӗнче ӗҫленӗ, 30-мӗш сборкӑпа: Galaxy S24+ ҫинче, вӑл ӑна аппаратлӑ HEVC-па улшӑнман битрейтпа кодлать. Ethernet кабельлӗ телевизор е телефонӑн хӑйӗн хотспотне ҫыхӑннӑ экран икӗ Wi-Fi сикӗ вырӑнне пӗрре хӑварать.

Ку сборкӑра ҫук: iPhone тата iPad ҫинчи дрон (пуҫланман), LG тата Samsung телевизорӗсем патне куҫару, 1,8 m тата 1,5 m/s ытларах кӑтартусене ҫирӗплетни, унтан спутниксем тата киле ҫити инҫеш, вӗсем уҫӑ сывлӑшри вӗҫеве кӗтеҫҫӗ.

DJI дронӑн ӳкерчӗкӗсемпе видеосене USB урлӑ тӳрех хӑвӑн Immich серверне импортла: дрона е карта вулавҫине Android телефона ҫых, ҫӗнӗ файлсене суйла тата яр, видеосене дронӑн вӗҫев даннӑйӗсем тӑрӑх карттӑ ҫине лартаҫҫӗ, дронӑн 360° сферисене 360° пек кӑтартаҫҫӗ. Immich программи телефон галерейинче пур япалана кӑна резерв копилет, Immich сервер DJI Neo 2 видеон вырӑнне халлӗхе вулаймасть. Ку страница сӑнав мелӗнче, Android телефонсемпе планшетсем ҫинче кӑна, тата чӑн дронпа халлӗхе тӗрӗслесе пӑхман.

### 360° камерасен чӑн файлӗсене уҫ

Insta360 камерисен чӑн .insp ӳкерчӗкӗсемпе .insv видеосене (пӗр е икӗ линза, пӗр е икӗ дорожкӑра е икӗ файлра), GoPro MAX .360 файлӗсене тата DJI Osmo 360 .osv файлӗсене программа вылятнӑ вӑхӑтра пӗрлештерет, калибровка файл ӑшӗнче ҫырнӑ, нимӗн те вырнаҫтармалла мар.

3. Файла уҫ тата 360° ҫине пус. Ӳкерчӗк хӑйӗн калибровкин ҫӑлкуҫӗпе "Чӑн 360° файл, программа пӗрлештернӗ" кӑтартать; видеона вылятнӑ май пӗрлештереҫҫӗ.

Linux тата macOS чӑн видеосене тӳрем выляҫҫӗ, икӗ «пулӑ куҫӗ» объективлӑ .dng файлсем халлӗхе тӳрем курӑнаҫҫӗ.

### Ӳкерчӗке пӗр тӳмепе ҫавӑр

Ӳкерчӗке редактор уҫмасӑрах пӗр пуснипе 90° ҫавӑр: кнопкӑпа, клавиатура тӳмипе е телевизор пульчӗн тӗслӗ тӳмипе, кашни платформӑра. Immich программи ӳкерчӗке хӑйӗн редакторӗнче ҫавӑрать; Immuch360 ӑна пӗр тӳмепе тӑвать, тата Immich 2.6 е ҫӗнӗрех сервер ҫинчи хӑвӑн ӳкерчӗксем валли ҫав сервер редакторӗ урлӑ ӗҫлет, ҫавӑнпа веб-программа тата санӑн ытти хатӗрӳсем вӗсене ҫавӑрнӑ пек кӑтартаҫҫӗ. Ытти кирек мӗнле ӳкерчӗке те ҫак хатӗр ҫинче кӑна ҫавӑраҫҫӗ. 360°, 180° тата 3D ӳкерчӗксем нихҫан та ҫаврӑнмаҫҫӗ, путаракан курӑмсем тикӗс юлччӑр тесе.

1. **Телефонсем, планшетсем тата Meta Quest чӳречи**: ӳкерчӗке уҫ тата ӑна сехет йӗппи майӗпе ҫавӑрма аялти ретре Edit умӗнчи Rotate ҫине пус; вӑрӑм пусни ӑна тепӗр енне ҫавӑрать. Клавиатурӑпа R тата Shift+R.
2. **Android TV тата Google TV**: пультӑн сарӑ тӳми ӳкерчӗке сехет йӗппи майӗпе, кӑвак тӳми сехет йӗппине хирӗҫ ҫавӑрать, курӑмра фокус ӑҫта пулсан та. 3. **LG телевизорӗсем (webOS)**: Android TV ҫинчи пекех сарӑ тата кӑвак тӳмесем, клавиатура ҫинче R тата Shift+R, е ӳкерчӗк элеменчӗсен ҫавӑру кнопки. Samsung телевизорӗсем те ӳкерчӗке пӗр тӳмепе ҫавӑраҫҫӗ.
4. **Windows, Linux тата macOS**: R сехет йӗппи майӗпе ҫавӑрать, Shift+R сехет йӗппине хирӗҫ, е ҫиелти йӗрти ҫавӑру кнопки, тулли экран кнопки умӗнче.
5. **Тетел пайӗнчи, Plex е камера ӳкерчӗкӗсем**: ҫиелти йӗрти пӗрремӗш ҫавӑру кнопки, R тата Shift+R, е сарӑ тата кӑвак тӳмесем.

Ҫавӑрни ӑҫта упранать: Immich 2.6 е ҫӗнӗрех ҫинчи хӑвӑн аккаунту ӳкерчӗкне сервер ӳкерчӗк редакторӗ урлӑ ҫавӑраҫҫӗ, вӑл тӗп файла упрать тата ҫавӑрнӑ ӳкерчӗк тӑвать (ӗҫленӗ вӑхӑтра ҫинҫе йӗр курӑнать; тӑватӑ ҫавӑру е пӗр каялла ҫавӑру тӗп ӳкерчӗке тавӑрать). Хатӗрӗн, пайӑн, партнерӑн е пайланӑ альбомӑн ӳкерчӗкӗсене, тата кивӗрех сервер ҫинчи кирек мӗнле ӳкерчӗке те ҫак хатӗр ҫинче кӑна, ҫав ӳкерчӗк валли ҫавӑраҫҫӗ, файл нихҫан та улшӑнмасть; Immich ӳкерчӗкӗ валли программа ҫакӑн ҫинчен пӗрре пӗлтерет. Видеосен, хупӑ папкӑн тата кашни 360°, 180° е 3D ӳкерчӗкӗн Rotate ҫук.

## Вӑрттӑнлӑх

Developer-а нимӗн те каймасть: аккаунт ҫук, аналитика ҫук, ӳкнӗ ҫинчен пӗлтерекен служба ҫук, реклама ҫук. Программа хӑв суйлакан серверсемпе кӑна калаҫать (хӑвӑн Immich серверӗпе, пайусемпе, Plex серверӗпе, камерусемпе), тата серверсӗр пулсан нимӗнпе те калаҫмасть. Парольсемпе токенсем хатӗрӗн хӑрушсӑр хранилищинче юлаҫҫӗ; LG тата Samsung телевизорӗсенче программа валли ун пек хранилище ҫук, ҫавӑнпа унта вӗсем программӑн хӑйӗн хранилищинче шифрламасӑр юлаҫҫӗ. Камера хатӗр ҫинче кӑна усӑ курать, Spatial 2.5D плеерӗ валли тата эсӗ кӗртекен экранӑн кодне сканлама; унӑн ӳкерчӗкӗсем нихӑҫан та упранмаҫҫӗ тата нихӑҫан та ниҫта та ярӑнмаҫҫӗ. Телефонран кӗртнӗ экран хӑйӗн сеансне илет, ӑна хӑвӑн килти тетелӳнте шифрласа яраҫҫӗ, санӑн парольне нихӑҫан та мар; LG телевизорне телефон браузерӗнчи страница кӗртет, вӑл санӑн электрон почтупа парольне телевизора хӑвӑн килти тетелӳнте шифрламасӑр ярать, телевизор сеанса кӑна упрать. Дрон страницисен ҫырӑвӗсемпе йышӑну ҫырӑвӗсем эсӗ вӗсене пайламасан хатӗр ҫинче юлаҫҫӗ: вӗсенче дронӑн видеовӗ пур, унӑн вырӑнӗ те пулма пултарать, ҫыхӑну ҫырӑвӗнче вара пультӑн тата вӗҫев хатӗрӗн серийлӗ номерӗсем те. Дронӑн сӑнӗпе кӑтартӑвӗсем телефонран эсӗ ҫыхӑнтарнӑ гарнитурӑсемпе телевизорсем патне кӑна каяҫҫӗ, вырӑнти тетелӳнте, шифрламасӑр, Wi-Fi ҫинче пайланӑ телефонри пекех. DJI патне те, TP-Link патне те нимӗн те каймасть. Тулли политика [PRIVACY.md](../PRIVACY.md) файлра, тата кашни ҫӑлкуҫ тӑрӑх тӗплӗхсем [усӑ куракан справкинче](../docs/immuch360/user-guide.md#privacy).

**ИИ функцийӗсем** санӑн хатӗрӳсенче кӑна ӗҫлеҫҫӗ. Ӳкерчӗке, унӑн рельефне, сценине тата панорамине санӑн компьютерунта е гарнитурунта шутласа кӑлараҫҫӗ, ниҫта та ямаҫҫӗ. Программа эсӗ ыйтнӑ компонента тиесе илме кӑна ҫыхӑнать, ку проектӑн GitHub ҫинчи кӑларӑмӗсенчен е, унта ҫук пулсан, моделӗн официаллӑ страницинчен, вӑл пур пулсан, кашни файла хӑйӗн SHA-256 тӑрӑх тӗрӗслет, унтан интернетсӑр ӗҫлет. Моделсене компьютерта ӗҫлеттерекен ONNX Runtime хӑйӗн официаллӑ сборкисенче Microsoft-а телеметри ярать; Immuch360 ӑна сӳнтерет. Ҫӗнӗ файлсем санӑн оригиналусем ҫумне каяҫҫӗ, нихҫан та вӗсен ҫине мар, санӑн Immich серверне эсӗ "ИИ версийӗсен сыхлӑх копине те ту" ҫутсан кӑна ҫитеҫҫӗ (сыхлӑх копийӗн альбомӗсенчи "Select all" ӑна та ҫутать).

Windows тата macOS сборкисем проект тунӑ libmpv-не (LGPL айӗнчи [mpv](https://mpv.io) библиотеки, [FFmpeg](https://ffmpeg.org)-па пӗрле) хӑйӗн лицензийӗсемпе тата ҫӑлкуҫӗсемпе йӑтса ҫӳреҫҫӗ, вӗсене программӑн лицензи страницинче кӑтартнӑ (Licenses, профиль менюн аялти пайӗнче); ҫак страницӑра асӑннӑ платформасен тӗплӗхсемпе сӑмах палӑкӗсем [Лицензи тата сӑмах палӑкӗсем](../docs/immuch360/platform-support.md#license-and-trademarks) страницӑра.
