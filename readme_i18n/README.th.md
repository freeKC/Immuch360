# Immuch360

**มีเดียของคุณ ทุกหน้าจอ ทุกมุมมอง**

Immuch360 เป็นแอปฟรีและโอเพนซอร์สสำหรับค้นหา ไล่ดู เล่น และสำรวจรูปภาพและวิดีโอของคุณ ทั้งแบบธรรมดา และแบบพาโนรามา 360° 3D และแบบดื่มด่ำที่แอปอื่นมักแสดงเป็นภาพแบน ภาพซ้อน หรือภาพยืดเพี้ยน แอปอ่านไฟล์เหล่านั้นตรงจากที่มันอยู่ ไม่ว่าในอุปกรณ์เอง ใน NAS หรือคอมพิวเตอร์ ในเซิร์ฟเวอร์ Plex หรือเซิร์ฟเวอร์ Immich แล้วเล่นไฟล์เหล่านั้นบนโทรศัพท์ แท็บเล็ต ทีวี เฮดเซ็ต Meta Quest และคอมพิวเตอร์ ไม่ต้องมีบัญชี ไม่ต้องใช้คลาวด์ ไม่ต้องมีเซิร์ฟเวอร์เลย

- **มันทำอะไรได้บ้าง** แสดงรูปภาพและวิดีโอของคุณเป็นคลังภาพ และเล่นไฟล์แต่ละไฟล์ในตัวดูที่เหมาะกับมัน ไม่ว่าจะเป็นภาพแบน เป็นทรงกลมที่คุณมองไปรอบ ๆ ได้ เป็น 3D หรือในเฮดเซ็ต
- **สื่อแบบไหน** รูปภาพและวิดีโอแบบแบน พาโนรามา รูปภาพและวิดีโอ 360° VR180 3D แบบสเตอริโอสโคปิก รูปภาพ spatial ของ Apple และไฟล์ดิบจากกล้อง 360° (Insta360, GoPro MAX, DJI Osmo 360) ที่แอปเย็บต่อให้
- **บนอุปกรณ์ไหน** โทรศัพท์และแท็บเล็ต Android, iPhone และ iPad, Android TV และ Google TV, Meta Quest 2, Pro, 3 และ 3S, Windows (รุ่นพรีวิว) ส่วน macOS และ Linux กำลังอยู่ระหว่างการพัฒนา
- **ต้องมีเซิร์ฟเวอร์หรือบัญชีไหม** ไม่ต้อง Immuch360 ทำงานได้เองด้วยมีเดียในอุปกรณ์ของคุณ เซิร์ฟเวอร์ Immich, NAS, เซิร์ฟเวอร์สื่อ หรือเซิร์ฟเวอร์ Plex เป็นตัวเลือกที่คุณเพิ่มได้เมื่อต้องการ

## สิ่งที่คุณทำได้

การใช้งานแต่ละอย่างด้านล่างนี้จะบอกว่าคุณจะได้อะไร แล้วบอกวิธีทำแบบย่อเป็นขั้นตอน คู่มือฉบับเต็ม พร้อมตัวเลือก ข้อความ และข้อจำกัดทั้งหมด อยู่ใน [คู่มือผู้ใช้](../docs/immuch360/user-guide.md)

<a id="watch-your-photos-and-videos"></a>
### ดูรูปภาพและวิดีโอของคุณ

ก่อนอื่นเลย Immuch360 เป็นคลังภาพและเครื่องเล่นสำหรับรูปภาพและวิดีโอธรรมดา ไทม์ไลน์ อัลบั้ม รายการที่ชอบ ความทรงจำ และการค้นหา ทำงานกับเซิร์ฟเวอร์ Immich ส่วนรูปภาพและวิดีโอของอุปกรณ์เอง และโฟลเดอร์ในคอมพิวเตอร์ แสดงได้โดยไม่ต้องมีเซิร์ฟเวอร์เลย วิดีโอเล่นในเครื่องเล่นแบบเนทิฟที่มีเสียง เลื่อนหาตำแหน่งได้ มีตัวบอกสถานะบัฟเฟอร์ และในเครื่องเล่น 360°, Spatial และบนคอมพิวเตอร์ยังเลือกแทร็กเสียงได้ด้วย บนทีวีรีโมตควบคุมทุกอย่าง บนคอมพิวเตอร์ใช้เมาส์และคีย์บอร์ด

1. เปิดแท็บ รูปภาพ: ไทม์ไลน์ของเซิร์ฟเวอร์ หรือของอุปกรณ์เมื่อไม่มีเซิร์ฟเวอร์
2. แตะรูปภาพหรือวิดีโอเพื่อเปิด ปัดซ้ายขวาเพื่อไปรูปถัดไป หยิกนิ้วหรือแตะสองครั้งเพื่อซูม
3. ปัดขึ้นบนวิดีโอเพื่อดูรายละเอียด: codec ขนาดไฟล์ เฟรมเรต บิตเรต และอุปกรณ์นี้ถอดรหัสได้หรือไม่

เพิ่มเติม: [ตัวดูและเครื่องเล่นวิดีโอ](../docs/immuch360/user-guide.md#watch-your-photos-and-videos), [รายละเอียดวิดีโอและตัวถอดรหัส](../docs/immuch360/user-guide.md#video-details-decoders-and-why-a-video-stutters)

<a id="explore-panoramas-360-vr180-and-3d"></a>
### สำรวจพาโนรามา 360° VR180 และ 3D

รูปภาพ 360° จะเปิดเป็นทรงกลมที่คุณหมุนด้วยนิ้วหรือขยับโทรศัพท์ วิดีโอ 360° เล่นในเครื่องเล่นทรงกลมพร้อมเสียง ไฟล์ VR180 วาดบนครึ่งทรงกลม ไฟล์ 3D แบบสเตอริโอสโคปิกแสดงภาพข้างเดียวบนหน้าจอแบนและทั้งสองข้างในเฮดเซ็ต พาโนรามาแบบไม่เต็มมุมจะคงการครอปของมันไว้ และภาพจะเริ่มที่มุมที่กล้องบันทึกไว้ ไฟล์ที่เซิร์ฟเวอร์ไม่ได้ติดแท็กไว้ก็สามารถดูแบบ 360° ได้ด้วยการแตะครั้งเดียว

<p align="center">
  <img src="../.github/readme/b19-sphere.jpg" width="260" alt="รูปภาพ 360° ของริมทะเลสาบในตัวดูทรงกลม: ปุ่มปิดที่มุมบนซ้าย ปุ่ม 360° เลย์เอาต์ 3D และไจโรสโคปที่มุมบนขวา">
  <img src="../.github/readme/b19-video.png" width="420" alt="วิดีโอ 360° ของถนนเลียบชายฝั่งที่กำลังเล่นในเครื่องเล่น 360° บนโทรศัพท์แนวนอน: ปุ่มปิดและชื่อไฟล์ที่มุมบนซ้าย 360° และ 3D ที่มุมบนขวา ก่อนหน้า ย้อนกลับ เล่น ข้ามไปข้างหน้า และถัดไปตรงกลาง แถบเวลาด้านล่าง">
</p>

1. เปิดรูปภาพหรือวิดีโอ ไฟล์ 360° จะมีป้าย 360° อยู่บนภาพขนาดย่อ และแท็บ คลังภาพ มีรายการ 360° ที่รวบรวมไฟล์เหล่านี้ไว้ พร้อมตัวกรองตามช่วงเวลา แหล่งที่มา ประเภท และกล้อง
2. แตะ 360° ที่แถบด้านบน ลากเพื่อมองไปรอบ ๆ หยิกนิ้วเพื่อซูม แตะปุ่มไจโรสโคปเพื่อมองไปรอบ ๆ ด้วยการหมุนโทรศัพท์
3. ปุ่ม 3D จะสลับไปเรื่อย ๆ ระหว่าง "โมโน (ไม่ใช่ 3D)", "3D, บนและล่าง" และ "3D, เคียงข้างกัน" ปุ่ม 360°/180° สลับระหว่างทรงกลมเต็มกับครึ่งทรงกลมของ VR180
4. สำหรับไฟล์ที่แสดงเป็นภาพแบนทั้งที่เป็นไฟล์ 360°: แตะ ⋮ ที่มุมบนขวา แล้วเลือก "ดูแบบ 360°"

บนโทรศัพท์และแท็บเล็ต วิดีโอแบบสเตอริโอสโคปิกยังสามารถมีมิติความลึกบนหน้าจอแบนได้ด้วย: เครื่องเล่น Spatial 2.5D ใช้กล้องหน้าตามการเคลื่อนไหวของศีรษะคุณ และแสดงมุมมองที่อยู่ระหว่างสองตา (ยังเป็นฟีเจอร์ทดลอง) รูปภาพ spatial ของ Apple ที่ถ่ายด้วย iPhone จะถูกจดจำและแสดงเป็น 3D ใน Meta Quest

<a id="use-your-own-files-without-an-account"></a>
### ใช้ไฟล์ของคุณเอง โดยไม่ต้องมีบัญชี

Immuch360 ไม่ต้องมีทั้งบัญชีและเซิร์ฟเวอร์ ที่หน้าเข้าสู่ระบบ "ใช้งานโดยไม่มีเซิร์ฟเวอร์" จะเปิดแอปไปที่รูปภาพและวิดีโอของอุปกรณ์ พร้อมตัวดูทุกแบบ รายการ 360° และแหล่งข้อมูลบนเครือข่าย ไม่มีอะไรออกจากอุปกรณ์เลย เซิร์ฟเวอร์สามารถเชื่อมต่อได้ทีหลังจากหน้า ตั้งค่า แล้วฟีเจอร์ของเซิร์ฟเวอร์จะปรากฏขึ้นมา

<img src="../.github/readme/b19-library-no-server.png" width="260" alt="แท็บ คลังภาพ แบบไม่มีเซิร์ฟเวอร์: รายการ 360° อยู่ด้านบน ตามด้วย บนอุปกรณ์นี้ ที่มีรูปภาพ 360° สองรูป และ แชร์บนเครือข่าย ที่มีแชร์ชื่อ NAS">

1. เปิดแอป ที่หน้าเข้าสู่ระบบ ใต้ที่อยู่เซิร์ฟเวอร์และ ตั้งค่า ให้แตะ "ใช้งานโดยไม่มีเซิร์ฟเวอร์"
2. อนุญาตให้เข้าถึงรูปภาพและวิดีโอของคุณ หากคุณปฏิเสธ แอปจะแสดง "แอปไม่สามารถเห็นรูปภาพในอุปกรณ์นี้" พร้อม "อนุญาตการเข้าถึง" และ "เปิดการตั้งค่า"
3. แท็บ รูปภาพ แสดงไทม์ไลน์ของอุปกรณ์ ค้นหา และ อัลบั้ม ยังเป็นสีเทาเพราะมาจากเซิร์ฟเวอร์ แท็บ คลังภาพ มี 360° อยู่ด้านบน ตามด้วย บนอุปกรณ์นี้ (อัลบั้มของอุปกรณ์) และ แชร์บนเครือข่าย
4. เมนูที่มุมบนขวาแสดง "เฉพาะอุปกรณ์นี้": แอปแสดงรูปภาพและวิดีโอของอุปกรณ์นี้ ไม่มีการส่งข้อมูลไปที่ใด

บนคอมพิวเตอร์ โฟลเดอร์ที่คุณเลือกจะทำหน้าที่เป็นคลังภาพ ส่วนบนทีวีซึ่งไม่มีรูปภาพของตัวเอง แหล่งข้อมูลบนเครือข่ายจะทำหน้าที่นั้นแทน

เพิ่มเติม: [ไม่มีเซิร์ฟเวอร์หรือบัญชี](../docs/immuch360/user-guide.md#without-a-server-or-an-account)

<a id="reach-the-media-of-a-nas-a-computer-or-a-media-server"></a>
### เข้าถึงมีเดียจาก NAS คอมพิวเตอร์ หรือเซิร์ฟเวอร์สื่อ

วิดีโอของคุณอาจอยู่ใน NAS คอมพิวเตอร์ หรือเซิร์ฟเวอร์สื่อ Immuch360 จะค้นหาเซิร์ฟเวอร์ในเครือข่ายของคุณเอง ไล่ดูไฟล์ และเล่นรูปภาพและวิดีโอตรงจากที่อยู่ ในตัวดูทุกแบบของแอป โดยไม่ต้องคัดลอกอะไรเลย: SMB (Samba, แชร์ของ Windows), WebDAV (Nextcloud, Synology และอื่น ๆ) และเซิร์ฟเวอร์สื่อ DLNA (Jellyfin, Emby, minidlna, NAS, กล่องทีวี) โทรศัพท์ก็สามารถแชร์คลังภาพของตัวเองบน Wi-Fi ให้เฮดเซ็ตหรือไคลเอนต์ WebDAV ใด ๆ ได้เหมือนกัน และคอมพิวเตอร์ Windows ก็ทำได้เช่นกัน

<p align="center">
  <img src="../.github/readme/b19-add-share.png" width="260" alt="หน้า เพิ่มแชร์: ชื่อ, ชื่อหรือที่อยู่เซิร์ฟเวอร์, พอร์ต (ไม่บังคับ), แชร์, เลือกแชร์, โฟลเดอร์เริ่มต้น (ไม่บังคับ), ชื่อผู้ใช้, รหัสผ่าน, ทดสอบการเชื่อมต่อ และผลลัพธ์ เชื่อมต่อแล้ว มี 2 รายการในโฟลเดอร์เริ่มต้น">
  <img src="../.github/readme/b19-share-folder.jpg" width="260" alt="โฟลเดอร์ของแชร์บนเครือข่ายแสดงเป็นตารางภาพขนาดย่อ: รูปภาพ 360° ที่มีป้าย 360° และวิดีโอ 360° ที่มีสัญลักษณ์เล่น ปุ่ม เลือก ที่มุมบนขวา">
</p>

1. เปิดแท็บ คลังภาพ แล้วไปที่ แชร์บนเครือข่าย จากนั้นแตะ + และ "แชร์บนเครือข่าย (NAS, คอมพิวเตอร์, เซิร์ฟเวอร์สื่อ)"
2. แตะเซิร์ฟเวอร์ใต้หัวข้อ "พบในเครือข่าย" หรือกรอกแบบฟอร์มด้วยตัวเอง: ประเภท ชื่อหรือที่อยู่เซิร์ฟเวอร์ แชร์หรือพาธ โฟลเดอร์เริ่มต้น ชื่อผู้ใช้ และรหัสผ่าน
3. แตะ "ทดสอบการเชื่อมต่อ" แล้วบันทึก แตะแชร์เพื่อไล่ดู: จะเห็นโฟลเดอร์ก่อน ตามด้วยรูปภาพและวิดีโอ โดยไฟล์ที่ระบบรู้จักว่าเป็น 360° จะมีป้าย 360° ติดอยู่
4. เมื่อเชื่อมต่อเซิร์ฟเวอร์ Immich ไว้แล้ว ให้เลือกไฟล์ในโฟลเดอร์แล้วแตะ "อัปโหลดไปยัง Immich" เพื่อส่งไฟล์เหล่านั้นไปยังเซิร์ฟเวอร์ของคุณ

เครื่องเล่นจะอ่านข้อมูลที่ต้องการผ่านตัวเชื่อมภายในแอป โดยใช้ byte range ทำให้เลื่อนหาตำแหน่งได้และไม่มีอะไรถูกเก็บไว้ในอุปกรณ์ วิดีโอจาก SMB จะถูกอ่านผ่านการเชื่อมต่อพร้อมกันได้สูงสุดหกการเชื่อมต่อเพื่อให้เล่นได้ลื่นไหล

เพิ่มเติม: [แชร์บนเครือข่าย](../docs/immuch360/user-guide.md#network-shares-a-nas-a-computer-or-a-media-server), [แชร์โทรศัพท์นี้บนเครือข่าย](../docs/immuch360/user-guide.md#share-this-phone-on-the-network), [เซิร์ฟเวอร์สื่อ DLNA](../docs/immuch360/user-guide.md#dlna-media-servers)

<a id="find-your-immich-library"></a>
### ค้นหาคลังภาพ Immich ของคุณ

เมื่อใช้ร่วมกับเซิร์ฟเวอร์ [Immich](https://github.com/immich-app/immich) Immuch360 ก็คือแอปมือถือของ Immich โดยใช้เซิร์ฟเวอร์และบัญชีเดียวกันกับแอปเว็บ: การสำรองข้อมูล ไทม์ไลน์ อัลบั้ม การค้นหา ผู้คน ความทรงจำ การแชร์ และคนร่วมอัลบั้ม ทุกอย่างซิงก์กับเซิร์ฟเวอร์ของคุณ แอปนี้ติดตั้งคู่ไปกับแอปทางการได้ และยังมีเพิ่มเติม: ป้ายและรายการ 360° ตัวดูแบบดื่มด่ำทุกแบบ ตัวเลือกระหว่างไฟล์ต้นฉบับกับสตรีมที่เซิร์ฟเวอร์ถอดรหัสใหม่สำหรับแต่ละวิดีโอ รายละเอียดเชิงเทคนิคของวิดีโอ และไฟล์จากแชร์หรืออุปกรณ์ที่ส่งไปยังเซิร์ฟเวอร์ของคุณด้วยตัวเอง

1. เข้าสู่ระบบด้วยที่อยู่เซิร์ฟเวอร์ อีเมล และรหัสผ่านของคุณ เหมือนกับในแอป Immich คลังภาพ อัลบั้ม และการตั้งค่าการสำรองข้อมูลจะเป็นของบัญชีคุณ
2. ใน ตั้งค่า > ตัวแสดงไฟล์ > วิดีโอ หัวข้อ "แหล่งวิดีโอ" จะเลือกไฟล์ต้นฉบับเมื่ออุปกรณ์นี้ถอดรหัสได้ เลือกต้นฉบับเสมอ หรือเลือกสตรีมที่ถอดรหัสใหม่เสมอ
3. หากต้องการให้คนที่ไม่มีแอปนี้ดูรูปภาพ 360° ให้แชร์ด้วยลิงก์แชร์ของ Immich: แอปเว็บของ Immich จะแสดงเป็นทรงกลมในเบราว์เซอร์ของเขา

build ปัจจุบัน คือ build 23 สร้างจาก Immich `main` วันที่ 10 ตุลาคม 2026 (เวอร์ชัน 3.3.0-rc.0) และผ่านการทดสอบกับเซิร์ฟเวอร์ Immich 3.2.4 และเซิร์ฟเวอร์ที่สร้างจาก Immich `main` รุ่นเดียวกัน หากพบปัญหาโปรดรายงานที่ [Issues](https://github.com/freeKC/Immuch360/issues) ไม่ใช่กับโปรเจกต์ Immich

### กล้อง, Plex และไฟล์ดิบจากกล้อง

- **กล้อง Tapo**: เพิ่มกล้องเข้ามาข้าง ๆ แชร์บนเครือข่ายได้ แอปแสดงภาพสดได้ (Android, Android TV, Quest และ Windows) และแสดงรายการบันทึกในเมมโมรีการ์ดแยกตามวันบนทุกแพลตฟอร์ม คลิปจะถูกดึงมาจากกล้อง เล่นได้เหมือนวิดีโอทั่วไป และส่งไปยัง Immich ได้ แอปจะคุยกับกล้องผ่านเครือข่ายของคุณเท่านั้น ไม่เคยติดต่อกับเซิร์ฟเวอร์ของ TP-Link เลย
- **Plex Media Server โดยไม่ต้องใช้ plex.tv**: แอปจับคู่กับเซิร์ฟเวอร์ของคุณโดยตรง ด้วยโทเค็นที่คุณวางแค่ครั้งเดียว และอ่านไฟล์ต้นฉบับจากคลังภาพของคุณแบบสด ทำให้ 360° ยังเป็น 360° อยู่เสมอ ทั้งที่บ้านและผ่าน port forwarding เมื่ออยู่นอกบ้าน
- **ไฟล์ดิบจากกล้อง 360°**: ไฟล์ดิบ .insp และวิดีโอ .insv จากกล้อง Insta360 (เลนส์เดียวหรือสองเลนส์ ในแทร็กเดียว สองแทร็ก หรือสองไฟล์), ไฟล์ .360 ของ GoPro MAX และไฟล์ .osv ของ DJI Osmo 360 จะถูกเย็บต่อโดยแอปขณะเล่น โดยใช้ค่าการปรับเทียบที่เขียนไว้ในไฟล์ ไม่ต้องติดตั้งอะไรเพิ่มเลย

เพิ่มเติม: [กล้อง Tapo](../docs/immuch360/user-guide.md#tapo-cameras-live-view-and-the-recordings-of-the-memory-card), [Plex Media Server](../docs/immuch360/user-guide.md#plex-media-server-without-plextv), [ไฟล์ดิบจากกล้อง 360°](../docs/immuch360/user-guide.md#raw-360-camera-files-without-the-cameras-app)

<a id="advanced-features"></a>
## ฟีเจอร์ขั้นสูง

สิ่งที่แอปสามารถอ่านและเล่นได้ สำหรับผู้ที่ต้องการรู้รายละเอียดทั้งหมด แต่ละรายการมีคำอธิบายเพิ่มเติมใน [คู่มือผู้ใช้](../docs/immuch360/user-guide.md) และ [หน้าความเข้ากันได้](../docs/immuch360/compatibility.md)

- **รูปแบบไฟล์**: รูปภาพและวิดีโอแบบแบน (ตามที่อุปกรณ์ถอดรหัสได้: MP4, MOV, MKV และอื่น ๆ); รูปภาพและวิดีโอ 360° แบบ equirectangular; พาโนรามาแบบไม่เต็มมุม (ครอปแบบ GPano); VR180; 3D แบบสเตอริโอสโคปิก ทั้งบนล่างหรือเคียงข้างกัน อ่านจากไฟล์ (st3d box) หรือเดาจากเฟรม; รูปภาพ spatial ของ Apple (คู่ภาพสเตอริโอ HEIC) และวิดีโอ spatial (MV-HEVC, ตาเดียว); ไฟล์ดิบ Insta360 .insp และ .insv, GoPro .360, DJI .osv; สื่อ 10 บิต HLG และ PQ ที่ถูกแปลงโทนสีลงบนทรงกลม
- **การแสดงภาพและเมทาดาทา**: เมทาดาทา GPano และแบบทรงกลมอ่านจากไฟล์ ด้วย range request บนเซิร์ฟเวอร์หรือแชร์; มุมมองเริ่มต้นของกล้อง; "ดูแบบ 360°" จะถูกจดจำไว้ในอุปกรณ์; VR180 จะถูกจดจำจากไฟล์หรือชื่อไฟล์; เมทาดาทายังคงสมบูรณ์เพราะเล่นจากไฟล์ต้นฉบับ ไม่ใช่ไฟล์ที่ถูกแปลง
- **การเล่นแบบเนทิฟ**: Media3 บน Android และทีวี, SceneKit และ AVFoundation บน iOS, Meta Spatial SDK ในเฮดเซ็ต, libmpv บน Windows; เลือกไฟล์ต้นฉบับหรือสตรีมที่ถอดรหัสใหม่ตามความสามารถของอุปกรณ์; มีรายการตัวถอดรหัสวิดีโอของอุปกรณ์ใน ตั้งค่า > ขั้นสูง; เลือกแทร็กเสียงได้ และมีตัวบอกสถานะบัฟเฟอร์
- **ไฟล์ดิบที่เย็บต่อในอุปกรณ์**: ใช้ Flutter fragment shader สำหรับรูปภาพ; เอฟเฟกต์ GPU ในเครื่องเล่นสำหรับวิดีโอแบบแทร็กเดียว; ใช้ตัวถอดรหัสฮาร์ดแวร์สองตัวพร้อมกันและ GPU compositor สำหรับวิดีโอที่มีเลนส์เดียวต่อแทร็กหรือต่อไฟล์ (OpenGL ES 3 บน Android และ Quest, Metal บน iOS, libmpv filter graph บน Windows); ใช้ค่าการปรับเทียบของกล้องเอง (โมเดล Mei, V6 และ equidistant) และข้อมูลจากแอคเซเลอโรมิเตอร์; มีทางเลือกสำรองไปที่เลนส์เดียว สตรีมที่ถอดรหัสใหม่ ไฟล์ LRV สำรองของกล้อง หรือวิดีโอที่ไม่ได้เย็บต่อ เมื่ออุปกรณ์รันตัวถอดรหัสสองตัวไม่ได้
- **แหล่งข้อมูล**: คลังภาพของอุปกรณ์; โฟลเดอร์ในคอมพิวเตอร์; เซิร์ฟเวอร์ Immich; SMB 2 และ 3, WebDAV, DLNA/UPnP; Plex ผ่าน HTTPS ที่ตรวจสอบกับใบรับรองของเซิร์ฟเวอร์เอง; กล้อง Tapo ผ่านเครือข่ายภายใน (HTTPS และ RTSP); โทรศัพท์หรือคอมพิวเตอร์ที่แชร์บน Wi-Fi เป็นเซิร์ฟเวอร์ WebDAV; เซิร์ฟเวอร์ที่พบผ่าน Bonjour/mDNS, การสแกนเครือข่ายภายใน, SSDP, GDM และการค้นหาของ TP-Link และถูกติดตามเมื่อที่อยู่เปลี่ยน
- **การอ่านตามต้องการ**: ตัวเชื่อมภายในให้บริการเครื่องเล่นด้วย byte range และโทเค็นต่อเซสชัน; อ่านเป็นบล็อกใหญ่ล่วงหน้า และเชื่อมต่อ SMB พร้อมกันได้สูงสุดหกการเชื่อมต่อ; ภาพขนาดย่อสร้างจากเฟรมหนึ่งของแต่ละวิดีโอ; ไม่มีอะไรถูกคัดลอกไปยังอุปกรณ์
- **ฮาร์ดแวร์**: ใช้ตัวถอดรหัสฮาร์ดแวร์ทุกที่ที่มี พร้อมขีดจำกัดที่วัดไว้ (ขีดจำกัด H.264 ของ Quest 3, เลนส์ 2048x2048 สองตัวสูงสุดสำหรับตัวถอดรหัสแบบซอฟต์แวร์); บน Windows มุมมอง 360° ถูกวาดโดยชิปกราฟิกจากแต่ละเฟรมที่ถอดรหัสแล้ว ขนาดเฟรมถูกวัดในแต่ละคอมพิวเตอร์ และตรวจพบว่าเป็นชิปแบบฝังตัวหรือชิปแยก
- **เฉพาะแพลตฟอร์ม**: ไจโรสโคปและเครื่องเล่น Spatial 2.5D บนโทรศัพท์; มุมมองแบบดื่มด่ำ คอนโทรลเลอร์ และมือ บน Quest; เลย์เอาต์รีโมต กล่องโต้ตอบคีย์บอร์ด และแบนเนอร์ทีวี บน Android TV; บนคอมพิวเตอร์ ใช้เมาส์และคีย์บอร์ด เต็มหน้าจอ หน้าต่างเดียว เปิดไฟล์ด้วยโปรแกรมหรือลากมาวาง รองรับไฟล์ HEIC, AVIF, TIFF และไฟล์ camera raw ในโฟลเดอร์เมื่อ Windows มีตัวถอดรหัสให้ และมีการป้องกันข้อมูลของ Windows สำหรับรหัสผ่านและโทเค็น
- **ความเป็นส่วนตัวตั้งแต่การออกแบบ**: ไม่มีบัญชี ไม่มีคลาวด์ ไม่มีการวิเคราะห์ข้อมูล; รหัสผ่านและโทเค็นเก็บไว้ในที่จัดเก็บที่ปลอดภัยของอุปกรณ์; กล้องของเครื่องเล่น Spatial ใช้ในอุปกรณ์เท่านั้น; แชร์ Plex และกล้องเข้าถึงผ่านเครือข่ายของคุณเท่านั้น

<a id="install"></a>
## การติดตั้ง

### โทรศัพท์และแท็บเล็ต Android

1. [Google Play](https://play.google.com/store/apps/details?id=com.aprogsys.immuch360) หรือดาวน์โหลด APK จากหน้า [Releases](https://github.com/freeKC/Immuch360/releases): `Immuch360-v<version>-arm64-v8a-release.apk` สำหรับโทรศัพท์; ส่วน `Immuch360-v<version>-release.apk` แบบ universal ใช้ได้กับทุกเครื่อง
2. แอปนี้จะติดตั้งคู่ไปกับแอปทางการของ Immich APK จาก GitHub จะไม่อัปเดตให้เอง: ให้ติดตามหน้า Releases เอง เมื่อคุณติดตั้งแอปจากสโตร์ใดแล้ว ให้รับอัปเดตจากสโตร์นั้นต่อไป

### iPhone และ iPad

1. เวอร์ชัน App Store กำลังรอการตรวจสอบของ Apple ระหว่างที่ยังไม่เผยแพร่ ให้สร้างแอปด้วย Xcode บน Mac ดู [สร้างเอง](../docs/immuch360/build.md)
2. เข้าสู่ระบบด้วยเซิร์ฟเวอร์ Immich ของคุณ หรือแตะ "ใช้งานโดยไม่มีเซิร์ฟเวอร์"

<a id="android-tv-and-google-tv"></a>
### Android TV และ Google TV

1. ระหว่างที่ Google Play ยังไม่เปิดให้โหลดแอปบนทีวี ให้ดาวน์โหลด `Immuch360-v<version>-release.apk` แบบ universal จากหน้า [Releases](https://github.com/freeKC/Immuch360/releases)
2. บนทีวี ให้เปิดตัวเลือกสำหรับนักพัฒนาและการแก้ไขข้อบกพร่องผ่าน USB (บน Google TV: การตั้งค่า, ระบบ, เกี่ยวกับ, เลือก "Android TV OS build" เจ็ดครั้ง แล้ว การตั้งค่า, ระบบ, ตัวเลือกสำหรับนักพัฒนา ชื่อเมนูอาจต่างกันในแต่ละทีวี)
3. จากคอมพิวเตอร์ในเครือข่ายเดียวกัน ด้วย adb (Android SDK Platform Tools): `adb connect <address of the TV>` ยอมรับข้อความถามบนทีวี แล้ว `adb install -r Immuch360-v<version>-release.apk`
4. แอปจะแสดงในรายการแอปของทีวีพร้อมแบนเนอร์ ติดตั้งรีลีสถัดไปด้วยวิธีเดียวกัน: `-r` จะเก็บการเข้าสู่ระบบและการตั้งค่าไว้

<a id="meta-quest"></a>
### Meta Quest

1. จาก [Horizon Store](https://www.meta.com/experiences/immuch360/1384208401440714/): เป็นเวอร์ชันของสโตร์ ซึ่งจะอัปเดตเมื่อ Meta ตรวจสอบแต่ละการส่งผ่านแล้ว
2. หรือ sideload ไฟล์ `-quest-release.apk` จาก [release](https://github.com/freeKC/Immuch360/releases) ในโหมดนักพัฒนาด้วย adb หรือ SideQuest: `adb install -r Immuch360-v<version>-quest-release.apk` จากนั้นเปิด คลังภาพ ของเฮดเซ็ตที่ "Unknown sources"
3. เวอร์ชันสโตร์และ APK จาก GitHub ถูกเซ็นด้วยคีย์คนละชุด: ถ้าต้องการสลับจากตัวหนึ่งไปอีกตัว ต้องถอนการติดตั้งแอปก่อน ซึ่งจะทำให้สูญเสียการเข้าสู่ระบบ การตั้งค่า และรายการแชร์บนเครือข่าย

<a id="windows"></a>
### Windows

1. ดาวน์โหลด `Immuch360-Desktop-3.3.0-rc.0-desktop.4-windows-x64.zip` จาก [desktop pre-release](https://github.com/freeKC/Immuch360/releases/tag/desktop-v3.3.0-rc.0-4) (ขนาดประมาณ 58 MB มี `SHA256SUMS.txt` ให้ตรวจสอบได้) แล้วแตกไฟล์ไว้ที่ไหนก็ได้ เช่นในโฟลเดอร์ Documents
2. เริ่ม `immuch360.exe` จากโฟลเดอร์ที่แตกไฟล์ไว้ และเก็บโฟลเดอร์นั้นให้ครบ: โปรแกรมต้องใช้ไฟล์ที่อยู่ข้าง ๆ มัน ซึ่งรวมถึง `libmpv-2.dll` ซึ่งเป็นตัวเล่นวิดีโอ
3. ไฟล์ยังไม่ได้เซ็นลายเซ็นดิจิทัล: Windows SmartScreen อาจแสดง "Windows protected your PC" ให้เลือก "More info" แล้วเลือก "Run anyway" การเริ่มครั้งแรกของ build ใหม่อาจใช้เวลานานถึงหนึ่งนาทีขณะที่ Windows สแกนไฟล์
4. รองรับ Windows 10 หรือ 11 แบบ 64 บิต ยังไม่มีตัวติดตั้งหรือการอัปเดตอัตโนมัติ: แตกไฟล์ build ถัดไปด้วยวิธีเดียวกัน

### macOS และ Linux

โปรเจกต์เหล่านี้อยู่ในซอร์สโค้ดและถูกสร้างโดย CI ของโปรเจกต์ทุกครั้งที่มีการเปลี่ยนแปลง แต่แอปยังไม่ได้เริ่มพัฒนาบนระบบเหล่านี้และยังไม่มีไลบรารีสำหรับเครื่องเล่นวิดีโอ จึงยังไม่มีให้ดาวน์โหลด ขั้นตอนการสร้างเองอยู่ใน [สร้างเอง](../docs/immuch360/build.md)

<a id="privacy"></a>
## ความเป็นส่วนตัว

ไม่มีข้อมูลอะไรส่งไปถึงนักพัฒนาเลย: ไม่มีบัญชี ไม่มีการวิเคราะห์ข้อมูล ไม่มีบริการรายงาน crash ไม่มีโฆษณา แอปจะคุยกับเซิร์ฟเวอร์ที่คุณเลือกเท่านั้น (เซิร์ฟเวอร์ Immich ของคุณ แชร์ของคุณ เซิร์ฟเวอร์ Plex ของคุณ กล้องของคุณ) และเมื่อไม่มีเซิร์ฟเวอร์ ก็จะไม่คุยกับใครเลย รหัสผ่านและโทเค็นจะอยู่ในที่จัดเก็บที่ปลอดภัยของอุปกรณ์ กล้องของเครื่องเล่น Spatial 2.5D ใช้ในอุปกรณ์เท่านั้น ภาพจากกล้องนี้จะไม่ถูกเก็บไว้และไม่ถูกส่งไปที่ไหนเลย นโยบายฉบับเต็มอยู่ใน [PRIVACY.md](../PRIVACY.md) และรายละเอียดแยกตามแหล่งข้อมูลอยู่ใน [คู่มือผู้ใช้](../docs/immuch360/user-guide.md#privacy)

<a id="the-project"></a>
## เกี่ยวกับโปรเจกต์

Immuch360 เป็นฟอร์กไม่เป็นทางการของแอปมือถือ [Immich](https://github.com/immich-app/immich) อยู่ภายใต้สัญญาอนุญาต [GNU AGPL v3](../LICENSE) ไม่มีความเกี่ยวข้องและไม่ได้รับการรับรองจากทีม Immich หรือ FUTO ฟอร์กนี้เกิดขึ้นเพราะการดูภาพ 360° บนมือถือถูกขอมาตั้งแต่เดือนมกราคม 2024 ใน Immich แต่ยังไม่มีในแอปทางการ จึงปล่อยออกมาให้ใช้งานตอนนี้ก่อน เก็บความเห็นจากผู้ใช้อุปกรณ์จริง และจะเสนอกลับไปให้ Immich เป็น pull request เล็ก ๆ ตามที่ผู้ดูแลต้องการ ทุกอย่างที่แอปทางการทำได้ยังคงอยู่ครบ; branch, build chain และ CI อธิบายไว้ใน [สร้างเอง](../docs/immuch360/build.md)

ตัวดูรูปภาพ 360° สร้างขึ้นจาก pull request ต้นน้ำ [immich-app/immich#31169](https://github.com/immich-app/immich/pull/31169) โดย dmitry-brazhenko ซึ่งสร้างต่อจากต้นแบบของ bencefr ใน [#30192](https://github.com/immich-app/immich/pull/30192) ขอบคุณทั้งสองคนมา ณ ที่นี้ กล้อง Tapo ถูกเขียนขึ้นจากเอกสารของ [pytapo](https://github.com/JurajNyiri/pytapo), [Home Assistant Tapo Control](https://github.com/JurajNyiri/HomeAssistant-Tapo-Control) และ [python-kasa](https://github.com/python-kasa/python-kasa) มุมมองของ Meta Quest ใช้ Meta Spatial SDK ซึ่งไม่ใช่โอเพนซอร์ส จึงยังคงอยู่เฉพาะในฟอร์กนี้ ไฟล์ ZIP ของ Windows มี libmpv (ไลบรารีของ [mpv](https://mpv.io) ร่วมกับ [FFmpeg](https://ffmpeg.org)) ที่สร้างโดยโปรเจกต์นี้ภายใต้สัญญาอนุญาต LGPL พร้อมสัญญาอนุญาตและซอร์สโค้ดของมัน รายละเอียดและเครื่องหมายการค้าของแพลตฟอร์มที่กล่าวถึงในหน้านี้อยู่ใน [สัญญาอนุญาตและเครื่องหมายการค้า](../docs/immuch360/platform-support.md#license-and-trademarks)

ภาพถ่ายหน้าจอโทรศัพท์ในหน้านี้ถ่ายจาก build ของ Android บน emulator ส่วนภาพของทีวีถ่ายจาก Google TV emulator และภาพของ Windows ถ่ายจากพีซี Windows 11 ทั้งหมดใช้ภาพพาโนรามา CC0 จาก [Poly Haven](https://polyhaven.com) ส่วนภาพของเฮดเซ็ตถ่ายจาก Quest 3

<a id="roadmap"></a>
## แผนงาน

สิ่งที่ยังไม่ได้ทำ เรียงจากที่น่าจะมาก่อน ไม่มีอะไรในนี้เป็นคำสัญญา และความคิดเห็นใน [ตัวติดตามปัญหา](https://github.com/freeKC/Immuch360/issues) ช่วยตัดสินว่าอะไรจะมาก่อน

- **สโตร์**: Google Play (build 23 กำลังตรวจสอบ, รายการบนทีวีกำลังตรวจสอบ), App Store (เวอร์ชัน 3.3.0 กำลังตรวจสอบ), Meta Horizon Store (build 21 กำลังตรวจสอบ)
- **คอมพิวเตอร์**: ทดสอบแต่ละฟังก์ชันด้วยมือบนพีซี Windows ก่อน; จากนั้น Spatial 2.5D ด้วยเว็บแคม; จากนั้นเริ่มพัฒนาและปล่อย macOS และ Linux พร้อมเครื่องเล่นวิดีโอของมัน; แล้วจึงทำตัวติดตั้ง build ที่เซ็นลายเซ็น และการอัปเดตอัตโนมัติ
- **โทรศัพท์และแท็บเล็ต**: แถบเวลาในเครื่องเล่นวิดีโอ 360° บน iOS, ปุ่มก่อนหน้าและถัดไปในเครื่องเล่น 360° บนโทรศัพท์, การเลือกแทร็กเสียงในเครื่องเล่นแบบแบน, การดูภาพสดของ Tapo บน iPhone และ iPad
- **มีเดียแบบดื่มด่ำ**: .dng แบบ dual fisheye, การปรับระดับแนวนอนของวิดีโอ GoPro และ DJI จากข้อมูลการเคลื่อนไหวของมันเอง, วิดีโอ spatial แบบ 3D บน Quest ถ้าตัวถอดรหัสรองรับ, ปุ่มก่อนหน้าและถัดไประหว่างรูปภาพ spatial ในเฮดเซ็ต
- **แหล่งข้อมูล**: ปัดสลับไฟล์ในโฟลเดอร์แชร์, การยืนยันตัวตนแบบ Digest สำหรับ WebDAV, คิวอาร์โค้ดสำหรับนำโทเค็น Plex มาจากคอมพิวเตอร์, IPv6 สำหรับ Plex, การบันทึกแบบ H.265 ของ Tapo, ช่องรายการบนหน้าจอหลักของทีวี
- **ต้นน้ำ (upstream)**: pull request ขนาดเล็กไปยัง Immich สำหรับส่วนที่ผู้ดูแลต้องการ โดยเริ่มจากตัวดูรูปภาพ 360°

รายการทั้งหมด พร้อมการตรวจสอบอุปกรณ์ที่ยังรอดำเนินการในแต่ละฟีเจอร์ อยู่ใน [สถานะการเปิดตัว](../docs/immuch360/release-status.md#roadmap)
